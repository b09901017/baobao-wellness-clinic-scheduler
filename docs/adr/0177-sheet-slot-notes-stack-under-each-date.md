# ADR-0177：試算表的記一句也疊在那一個日期那一欄的矩陣底下、塗淡色

日期：2026-11-06
狀態：已接受
延伸：[ADR-0175](./0175-sheet-layout-frozen-counts-and-cell-notes.md)（記一句收進那一格的附註 —— 附註照留，這裡多一個一眼看得到的地方）、
[ADR-0161](./0161-sheet-remembers-fingerprints.md)（`LAYOUT_VERSION` 5 → 6，部署後每一頁重畫一次）

## 背景

ADR-0175 把記一句從矩陣裡自己那一列搬進那一格的附註（右上角小黑三角），矩陣好掃了，但記一句要滑過、點過才看得到。
她 11/6 拿她的舊表給主控看（勾勾那幾列底下，日期那一欄寫著一句一句、各自往下疊、有幾格塗了底色），原話在 `.scratch/sheet-push-gaps/issues/15`：
「有些附註我希望可以一目瞭然的看到」「in sis 那種做了什麼的就不用」「附註的那一個可以用舒服的顏色填滿，你就隨機填顏色就好」。

## 決定

1. **矩陣底下，每一個日期那一欄各自往下疊**：二返註記在最上面（位置、小字、字色照舊，不塗底），那一天的每一句記一句接在底下 ——
   有額度的段照矩陣上面那幾列的先後，再來沒有額度的段（體驗、送的、n返；`log[].items[].note`）照時間。
2. **附註（小黑三角）與來訪紀錄那一行都照留**：疊的這一份是刻意多一份。所以「一句只印一次」改成「它自己那一個地方一次＋日期底下一次」。
3. **器材不疊**：照舊在那一格的字裡（「✓ IN」）。
4. **記一句那一格塗淡色**，五種照畫的順序輪流（一欄一欄、由上往下；`.gs` 的 `NOTE_FILLS`），避開狀態色（綠、黃、淡藍、灰、紅）；置中、文字格式（一句「10/15」不會被認成日期）。
5. **只動 `.gs`**：資料一個字都沒變、不升 `SYNC_FORMAT`。`LAYOUT_VERSION` 5 → 6。

## 為什麼

- **她要的是一眼看得到**：附註要一格一格去點，十幾位、每位幾十天，等於沒有。矩陣底下本來就是她舊表寫字的地方（二返註記一直在那裡），疊在那一天那一欄底下，往上看就是那一天做了什麼。
- **輪流不隨機**：她說隨機就好；輪流的話上下挨著的不同色，同一份資料每次畫出來都一樣 —— 隨機會讓每一次推送都像「這一頁變了」（指紋、ADR-0161）。
- **避開狀態色**：疊在日期那一欄底下，綠或黃會被看成那一天做完了／排了。

## 沒有選的

- **拿掉附註、只留疊的那一份**：她說「除了有他之外」—— 附註在矩陣那一格上，看狀態的時候順手就看得到是哪一段記的。
- **照 app 裡短備註的顏色塗**：記一句在 app 裡沒有顏色。
- **跟二返註記混在同一列、同一個日期蓋掉**（以前 `.gs` 二返註記一個日期只畫得下一格）：疊起來一句都不會蓋掉。
