# 方案範本不做版本，改用複製

方案每季會推出新的或修改舊的，而使用者的硬性要求是「改範本絕對不能動到已經買的人」。我們**不替範本加 version 欄位**，改為：範本可就地修改、可複製一份改名成為新範本、可停用。

不需要版本的原因是額度在展開的當下就整份複製到客戶身上了（SPEC 第 6.4 節的脫鉤要求），範本之後怎麼改都碰不到它——這個保證來自架構，不是來自使用者記得別改錯。使用者口中「5 月的範本」與「8 月的範本」是兩個各自有名字的範本，不是同一個範本的兩個版本。

## Consequences

建立客戶的流程是：選一個範本展開額度（或完全不選）→ 再手動加減（例如多給 20 次復能、一次健檢）→ 也可以純加購單項。展開後的額度與範本再無關聯，因此客戶詳情頁顯示的方案名稱是展開當下的文字快照，不是指向範本的連結。

代價是無法回頭查詢某個範本在過去某個時間點長什麼樣。這被接受，因為要回答的問題永遠是「這位客戶買到了什麼」，而那個答案就在他自己的額度上。
