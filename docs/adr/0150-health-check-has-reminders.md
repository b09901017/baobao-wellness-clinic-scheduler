# ADR-0150：資料健檢多一種「提醒」—— 知道就好、沒有要做的事

日期：2026-10-18
狀態：已接受
延伸：[ADR-0136](./0136-data-health-says-whether-and-what.md)（這一頁只回答有沒有事、要做什麼）。舊的一個字都不改。

## 背景

ADR-0136 把這一頁分成「有事的」與「沒事的」兩種。可是有兩項**有東西、但沒有要她做的事**：

- 「資料過期」（`staleAvailability`）：還有次數、沒問過這一輪方便的時間的客戶。那是壓表排序的參考，不是錯；
  她現在不一定問時間（同一輪她要把待辦的「問這輪的時間」藏起來）。
- 「匯進來的額度還叫舊表的名字」（`importedLabel`）：匯入時刻意留著原字的那幾筆，她 9/16 說「讓我之後逐筆改」，本來就沒有修正鈕。

兩項的每一筆都是 `attention`，於是跟「額度超用」「衝突殘留」一樣算進「有 N 項要你看」、畫成一張大卡、每一位攤開一句說明。
她 10/17 把真資料放上 staging，那一頁最上面是「有 2 項要你看」，底下 31 位客戶。她 10/18：

> 這兩個問題是不用解決的對吧，像是沒有收集可用性這點，我覺得沒關係，只要提醒就好，但是不要展開這麼多人然後每個人底下又有說明，胎多資訊了，
> 然後舊表名稱也是，他是我一開始就同意的，不算是問題，所以應該也只是要提醒就好，不要占版面
> 然後我希望改名，資料過期，直接說是"還沒問這輪方便的時間"不要說麼可用性甚麼的，看不懂

## 決定

**第三種：提醒。** `CHECKS` 上選填的 `notice: true` 標記「知道就好、沒有要做的事」，現在只給那兩項。

1. 畫在「要處理」之後、「沒問題的」之前，一段「提醒」：**一項一行**（名字＋幾位／幾筆），**預設收著**，點開才是名字清單 —— 名字底下**不印說明**。
2. **不算「要你看」**：結論只數不是提醒的那幾項；只剩提醒時寫「沒有要處理的」＋「N 項提醒」。
3. 「資料過期」改名「**還沒問這輪方便的時間**」，那一項的字一律不寫「可用性」；每一筆的說明不再叫她去待辦的「問這輪的時間」（那一列之後預設藏起來）。
4. 檢查本身、finding 的 `severity`、`fix`、`CHECKS` 的 id 與順序與總數一個都沒動 —— `notice` 只管畫在哪、算不算數。

## 沒有選的

- **把那兩項的 `severity` 改成第三種**：`severity` 講的是一筆資料有多嚴重，提醒講的是整項要不要她動手；同一項裡不會一筆是提醒、一筆不是。
  改 `severity` 會連 `totalsOf()` 的數字與既有測試一起動，而畫面上沒有人讀那個數字。
- **整項拿掉**：她說「只要提醒就好」—— 要看得到、不要佔版面。
- **壓表卡片上那一句「還沒問這輪的時間」一起改名**：她指名的是這一頁，那一句不在這一輪。
