# ADR-0106：被刪掉的任務，勾過的才算做過

日期：2026-09-23
狀態：已接受
收窄：2026-09-16 那一條「比對時把軟刪除的也算進去」（`.scratch/prelaunch-fixes-2026-09-16/issues/09`，沒有 ADR）

## 背景

9/16 為了「清掉的待辦不要再長回來」，比對改成連軟刪除的一起看，而且**全部**當成
「這件事有人做過了」。但軟刪除有三種來源，只有一種是做過了：

| 誰刪的 | `done` | 做過了嗎 |
|---|---|---|
| 她在待辦按「清掉」／垃圾桶（只有已完成那一格有） | `true` | 是 |
| 「復原」（新增的那幾張被 softDelete） | `false` | 不是 |
| 系統收掉（課程換掉了、來訪取消了） | `false` | 不是 |

於是按過一次「復原」之後再確認，Examine 與耀聖一張都不長；再取消，「取消 Abovee」
也不長，而確認框照樣說會長（2026-09-23 實跑，`.scratch/prelaunch-audit-2026-09-23/issues/01`）。

## 決定

**軟刪除的任務，勾過的才算做過；沒勾過的當成不存在。**

- 判準只有一支：`domain/taskRules.js` 的 `seenTasks()`。來訪那一條（`syncTasksForVisit()`）、
  取消那一條（`cancelTasksFor()`）、健檢鏈那一條（`followups.js` 的 `syncFollowupTasks()`）都走它
- 軟刪除的只拿來比對，一個字都不改（9/16 那一條規矩不變）
- 取消的確認框讀比對用的那一份（`listByVisitForSync()`），跟真的寫入同一份（ADR-0070）

## 後果

- 9/16 那一條的行為不退：清掉（已勾）之後再存，照樣不長
- 復原、系統收掉之後，該長的照長
