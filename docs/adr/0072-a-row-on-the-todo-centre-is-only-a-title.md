# 待辦中心的一列只有標題，說明搬到她真的要操作的那一頁

2026-09-04 她的原話：

> 我希望不要有多餘的說明文字，像是總攬的那 7 個步驟中的每個子項目都有說明，
> 其實不用，**就留標題**，像是問這輪時間，客戶填好的時間等等就好，
> 不需要多餘的說明，**會讓畫面很亂**。

## 十三句同時在畫面上等於零句

總覽上每一列都帶著一句：「壓好了、還沒問過本人」「預約作業 → 查核 → 已報到」
「報告拿到了，寄一份給要看報告的那位醫師」……加上七個段落標題，一頁二十行字。

那一頁回答的是「**接下來做什麼**」，而那十三句回答的是「這十三種各自是什麼
意思」—— 那是第一次用的人的問題，不是第三百次用的人的問題。她掃這一頁的時候，
每一行字都是一次停頓。

## 一句都不會真的消失，這是敢做的唯一理由

每一句在**點進去那一頁的第一行**都還在（`GROUPS[].lead` 與 `renderGroup()` 的
`meta.lead`）：

```
confirm: '壓好了、還沒問過本人。問完回來按打勾。'
close:   '客人來了、療程單簽了就打勾。次數是這時候才扣的。'
cancel:  '來訪取消後，要回去把已經做掉的登記收回來。'
已取消的種類: '這個類別已經取消了 —— 底下是舊資料，不會再長出新的。'
```

Examine 與耀聖那兩句（`KIND_NOTES`）另外還住在 `docs/操作手冊.md`
與 `CONTEXT.md` 的兩條詞條裡。

換句話說，這一支做的不是刪字，是**把操作說明搬到她真的要操作的那一頁**：
「Examine：預約作業 → 查核 → 已報到」在她按下去之後才有用。

## 推翻 ADR-0033 的一半

ADR-0033 的原話是「一個數字後面配一句話，比兩個互相矛盾的數字好懂」，
講的是「問這輪的時間」那一列的「其中 N 位已經發出連結」。

**要解釋的那件事沒有變**（那個數字確實不減掉已經發出連結的人），變的是
解釋它的地方。2026-09-02 之後點進去那一頁分成三區 —— 還沒發連結／已經發出／
這個月已經問到了 —— 而「已經發出」那一區每一列還帶著 `等待回覆`／
`已填寫時段`／`已確認排定` 三顆徽章之一。**那一區是那句話的完整版**，
而且它就在那個數字後面一次點擊處。同一件事在 `docs/常見問題.md` 也有一條。

一句話有三個家的時候，總覽上那一個是最沒用的：它出現在她**還沒問這個問題**
的時候。

## `groupRow()` 沒有 `note` 這個參數

**參數整個拿掉，不是傳空字串。** 留著參數就是留著一條路，而這一頁就是這樣
長出十三句的 —— 每一次都只是「多一句而已」。

已經取消的種類（打電話、Abovee 的舊資料）那一列例外，但它拿到的是 `tag`，
一顆寫著「舊資料」的小丸子。**一顆丸子放不進「預約作業 → 查核 → 已報到」，
那個限制本身就是護欄。** 丸子講的是「這一列跟別列不同」，一整行講的是
「讓我解釋給你聽」，她要的是前者。

## Consequences

- **`.grouprow` 的 52px 是照兩行字調的**，剩一行之後要收成 48px ——
  拿掉東西不重新調間距的話，畫面不會變乾淨，只會變空。48 是手指的下限 44px
  加一點餘裕給兩位數的數字。段的 `margin` 反而要放大一級：段落線只有 3px 寬，
  那口氣是「這七段是七件事」剩下的唯一線索。
- **首頁少讀一次 `formInvites`。** 那一次讀取只為了算「其中 N 位已經發出連結」，
  而那句話沒有了。點進去那一頁本來就要讀邀請。
- 「壓表登記」那一列的月份也跟著拿掉了；點進去那一頁的標題還是寫著
  「9月壓表登記」。
- `KIND_NOTES` **不要刪** —— 它現在是點進去那一頁的 `meta.lead` 的來源。
