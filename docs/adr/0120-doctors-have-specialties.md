# ADR-0120：醫師有科別，課程指定哪一科 —— 排前面，不是限制

日期：2026-10-05
狀態：已接受
延伸：[ADR-0026](./0026-doctors-are-assignable-staff.md)（醫師是可以指派的人）、
[ADR-0058](./0058-outpatient-always-picks-a-doctor.md)（門診一律選得到醫師）。舊的一個字都不改。

## 背景

`config/staff` 只有兩種角色（物理治療師、醫師），醫師沒有科別。課程上「選不選得到醫師」只看
`picksDoctor()`：A 類一律選得到、其餘看 `requiresDoctor`（ADR-0058）。醫師那一排列出**全部醫師**，照主檔順序。

Abovee 上的醫師有八位，分四科。她 2026-10-05：

> 四、醫師要分科：功能／二返、泌尿科、心臟科、復健科。物理治療師是另一種人（操作復能機器的）。

> 每個課程都要可以自己選：…哪一科的醫師…

> 羊膜：加購（有次數，像營養針）；選復健科醫師（只有一位）；要簽療程單

八位全部排成一排，她每一次都要從裡面找出那一科的那一兩位。

## 決定

**醫師多一格 `specialties`（字串陣列），課程多一格 `doctorPick`。**

- `specialties`：設定 → 治療師與醫師 → 編輯，角色是醫師時多一排丸子。可以勾不只一科。
  物理治療師沒有這一格（帶著科別存不下去）。
- `doctorPick`：`'none'`（不用醫師）／`'any'`（哪一科都可以）／某一科的字。
  課程表單上「來訪時要選醫師」那個開關換成這一排。

判斷只寫在 `domain/masterData.js`：

| 問什麼 | 哪一支 |
|---|---|
| 這門課要不要醫師、哪一科 | `doctorRuleOf(course)` |
| 選不選得到醫師 | `picksDoctor(course)` ＝ `doctorRuleOf(course) !== 'none'`（呼叫端一個都沒改） |
| 醫師那一排怎麼排 | `doctorChoicesFor(course, staff)` → `{ first, others, preselect }` |

三個入口（壓表、來訪編輯器、拍 Abovee）都走 `doctorChoicesFor()`。

## 科別不是一份新的主檔

名單＝預設的四科＋醫師身上已經有的字（`specialtyNames()`）。她在某一位醫師身上打一個新的字，
那個字就出現在其他醫師與課程的那一排上。

不開集合的理由跟課程的分類（`group`）一樣：它是一個標籤，身上沒有別的欄位；
而客戶身上的警示已經示範過「存字串不存 id」站得住（ADR-0002）—— 改名的人自己回去重選。

## 排序，不是限制

指定了一科之後，**那一科的醫師排前面、其餘收在「其他醫師」後面，照樣點得到**。
跟常用診間（`preferredRoomIds`，ADR-0079）同一個作法，理由也一樣：

- 代診是真的會發生的事。硬擋等於那一天記不進系統（ADR-0002：app 記錄決定，不做決定）
- 她還沒替醫師填科別之前，每一門課都要照樣選得到人 —— 所以**那一科一位都沒有時退回全部列出來**

沒選醫師照舊是 warning 不是 error（ADR-0026）。這一支不動那一條。

## 那一科剛好一位時先選好他

羊膜只有一位復健科醫師。只有一個正確答案的時候讓她多點一下沒有換到任何資訊
（同「只有一次健檢就自動選好」、「買的那一款品項先選好」）。

- **兩位以上一個都不預選**：預選第一位等於替她答了一個她還沒回答的問題
- **「哪一科都可以」不預選**，就算主檔裡只有一位醫師 —— 那一格沒有說出任何偏好，行為跟以前一樣
- **只在新的一段、還沒選醫師時套**。既有的一段一個字都不動：她存過「還沒定」的那一段，
  打開改個時間不可以被填上一位醫師

## 為什麼沒有遷移

**沒有 `doctorPick` 的課程照 ADR-0058**：A 類或開了 `requiresDoctor` → `'any'`，其餘 `'none'`。
讀的時候退回，既有資料一筆都不搬。舊課程在設定頁打開時那一排照 `doctorRuleOf()` 畫好。

`requiresDoctor` 留在資料上，存檔時跟著寫（`doctorPick !== 'none'`）—— 讀的那一側只認 `doctorRuleOf()`。

## 種子

二返 → 功能／二返；復健科醫師門診 → 復健科；心臟科評估 → 心臟科。
種子醫師（三個姓）**不填科別**：她還沒說誰是哪一科，由她自己在設定填。
在那之前這三門課的醫師那一排跟以前長得一模一樣（那一科沒有人 → 全部列出來）。

## 後果

- 她替醫師填了科別之後，門診的醫師那一排從八位縮成一兩位，其餘收在「其他醫師」後面
- A 類的課也關得掉醫師那一排了（`doctorPick: 'none'`）—— 以前關不掉（ADR-0058 那一句
  「這一格開不開都一樣」跟著拿掉）
- 拍 Abovee 認人（`staffFrom()`）不看科別 —— 那是照片上的字對到哪一位，跟課程要哪一科無關
