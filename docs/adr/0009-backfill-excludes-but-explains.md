# 時段反查可以把人排除，但要說得出理由

ADR-0002 說 app 只記錄不判斷，那為什麼時段反查敢把人從名單上拿掉？因為這裡拿掉的不是**儲存**，是**一份建議名單的排序範圍** —— 而且四種排除的依據都不是推測：沒有剩餘次數（她自己的資料）、醫療禁忌把池裡的器材全鎖死（硬性阻擋）、那個時間他已經有另一筆來訪（同一個人不可能同時在兩個地方）、以及**他自己說那天不行**（本輪可用性的原文）。所以這一頁的規矩是：**排除的人與理由一律列出來**，收在「沒列進來的」底下。

## Consequences

「還沒問這輪的時間」的人**不會**被排除，只標成「不知道他那天行不行」照樣排進名單 —— 沒問過不等於不能來，用沒有的資料去排除人才是真的在判斷。

代價是名單不會短。這被接受：她要的是「誰可以補」的完整答案，而不是一個乾淨但可能漏人的清單。看不到「XXX 為什麼不在上面」的名單，她問過一次之後就不會再用了。
