# ADR-0179：複製到別天、連在一起的隨手記是每一天一筆，共用一個 `linkId`

日期：2026-11-06
狀態：已接受
延伸：[ADR-0044](./0044-a-dated-note-goes-on-the-calendar.md)（日曆上的待辦就是隨手記本人 —— 照 `date` 查，這一支一行都不用改）、
[ADR-0060](./0060-a-row-answers-two-gestures.md)（長按的每一顆都要另有一條不靠長按的路）、
[ADR-0158](./0158-incomplete-read-does-not-save.md)（讀不完整就不存 —— 隨手記不在那一條裡）

## 背景

她 11/6（`.scratch/notes-widget/spec.md`）：

> 我想要連起來誒，不然就是可以複製的時候決定，但預設是連起來的，然後複製這個功能也可以放入長按裡面? 長按就可以選複製

同一件事要在好幾天各提醒一次，其中一天做完了其他天也一起勾掉（backlog 第 14 條）。隨手記一直是一筆就是一件事：一格 `done`、一格 `date`。

長按選單每一種情境本來就剛好五顆（`openActions()` 上限六顆含「先不要」），多「複製到別天」放不下。她：
「可以但我希望收成『改日期』比較直觀對吧 ? 改成今天 改成某天 改成拿掉日期」。

## 決定

1. **每一天一筆真的文件**，同一組共用一格選填的 **`linkId`**（字串）。日曆、逾期／今天／明天照舊照 `date` 查，每一天各一筆。
2. **`linkId` 用最初那一筆的 id**；複製一筆已經連著的沿用它的 `linkId`。兩個例外用新的 id：
   它拆開過（id 還是舊那一組的 `linkId`，用它會連回去）、它已經勾掉了（新的那幾筆是還沒勾的，拉進來就是一組勾得不一樣 —— 新的那幾筆自己一組）。
3. **連在一起＝同一個 `linkId`、還活著（沒軟刪除）的兩筆以上**。刪掉、還原、復原都**不清** `linkId`：只剩一筆時自然不算連在一起，還原回來自然連回去。判斷只有 `domain/notes.js` 的 `linkedPeers()`。
4. 哪幾種一起變（spec 那張表）：

   | 對其中一筆做了什麼 | 同一組其他那幾筆 |
   |---|---|
   | 勾掉、拿回來 | 一起（過去的、還沒到的、不在畫面上的都算） |
   | 改字、改掛給誰 | 一起 |
   | 改日期 | 只這一筆 |
   | 刪掉 | 只這一筆 |
   | 拆開這一天 | 這一筆的 `linkId` 清成 null，以後各勾各的 |

   **照真的變了什麼，不是照帶了哪些鍵**（`linkedChanges()`）：日曆編輯器每次存都帶字、日期、掛給誰，只改日期那一下另外那幾天一筆都不寫。
   **勾不勾例外**：那是她明說的那個值 —— 這一筆其實已經勾了（手上那一份舊了）、或一組勾得不一樣時，按下去同一組每一筆都變成她按的那個樣子。
5. **寫的那一刻照 `linkId` 重讀同一組**（只用等號查、不加排序，不用新索引）。一組一起變的同一個 commit。
6. **營養品的提醒不給複製、不能連進一組**（`validateNote()` 與 Rules 都擋 `linkId`＋`entitlementId`）。
7. **怎麼列**：清單類（首頁那張卡、隨手記那一頁、客戶詳情、小工具）一組一列（`groupLinked()`）；**日曆、逾期／今天／明天每一天各一列**。
   - 那一列代表的那一天＝今天或之後最早的；全部過了＝最後一天；沒有日期的成員不當代表
   - 旁邊「共 N 天」數**不同的日子**（沒日期的不算一天、同一天兩筆算一天）；只剩一天但兩筆以上寫「共 N 筆」；一筆的不畫（`linkedBadge()`）
   - 一組勾得不一樣分成勾了的與還沒勾的兩列，一筆都不藏
   - 數字（首頁「隨手記 N」、隨手記那一頁兩個數字、客戶詳情「N 未處理」、「清掉這 N 筆」）一組算 1
   - **清單上一列＝一組時**：勾／拿回來、改字、掛給誰、垃圾桶、清掉這 N 筆 → 整組；改日期、拆開 → 代表的那一天。日曆與三格上一格就是一天，照上面那張表
8. **長按選單重排**：勾掉（拿回來）／改日期／掛給誰／改文字／複製到別天。日期那幾顆收成「改日期」一張卡（改成今天／改成某天／拿掉日期，`dateChoices()`）；
   「拆開這一天」收在「複製到別天」那張卡的最上面。已勾掉那幾筆的「刪掉」放不下了 —— 刪掉還有隨手記那一頁的垃圾桶、「清掉這 N 筆」、日曆編輯器的「刪掉」。
9. **離線**：重讀只拿得到快取裡剛好有的那幾筆 —— 隨手記照寫（ADR-0158 只管會算次數的寫入）。一組勾得不一樣的由資料健檢最後一項「連在一起的隨手記勾得不一樣」列出來（只是提醒、不修）。
10. 稽核：`linkId` 有中文名（「連在一起」），兩句專門講它：「待辦「x」・連到別天」「待辦「x」・11/8(日) 拆開」。勾一組在「今天做了什麼」上連續一樣的收成 ×N，不另寫一句。

## 為什麼

- **每一天一筆 vs. 一筆帶好幾個日期**：日曆、三格、客戶詳情、備份、試算表、Android 小工具都照「一筆一個 `date`」寫好了。一筆帶一串日期的話每一處都要學會展開，而且「改日期只改這一天」「刪掉只刪這一筆」「這一天勾了」都要變成陣列裡的一格 —— 每多一個讀的地方就多一個會漏的地方。每一天一筆，只有「一起變」那幾種要多做一件事（同一組一起寫），而那件事只在 `data/notes.js` 一處。
- **不清 `linkId`**：「連在一起」由「活著的有幾筆」推出來，刪掉與還原就不用記得回頭改別筆；清了的話還原那一筆時要知道它以前跟誰一組，而那個資訊已經沒了。
- **最初那一筆的 id 當 `linkId`**：重按、重試算出來的是同一個，加上「同一組那一天已經有一筆就不再建」，按兩次不會多一份。
- **重讀**：畫面手上那一份都只是一部分（日曆只讀一個月、首頁只讀還沒勾的、客戶詳情一位、小工具的快取）。拿它去算「另外那幾天」，不在畫面上的那幾天就勾不到（lessons 二）。
- **代表今天或之後最早的那一天**：清單是「接下來要做什麼」，下一次要做的那一天最有用；全部過了寫最後一天（過期的顏色），看得出它拖到現在。

## 沒有選的

- **一筆帶好幾個日期**：見上面。
- **另開一個「組」的集合**：多一份要同步的資料，刪掉、還原、備份、Rules 都要多管一份；`linkId` 一格就夠。
- **清單上連在一起的每一天各一列**：她問「應該只會有一列吧?」—— 三列看起來像三件事，勾一列另外兩列跟著劃掉會嚇到人。
- **離線時擋下來不寫**：隨手記要三秒記完，擋下來的代價比偶爾一組勾得不一樣（資料健檢列得出來、再按一次就對齊）大。

## 後果

- Android 小工具（ADR 待寫）照抄這一份：欄位名 `linkId`、連在一起的判斷、一起變的那張表、寫之前照 `linkId` 重讀、一組一個 commit。改這一支要兩邊一起改。
- `normalize()` 每一筆新的都寫 `linkId: null`（跟 `entitlementId` 一樣）；`normalizePatch()` 只在有帶到時碰它。
- 還沒做的（05）：「複製到別天」那張小月曆、「改日期」那張卡、「共 N 天」那一顆、選單最上面列出是哪幾天、日曆的待辦卡多兩顆不靠長按的路。
