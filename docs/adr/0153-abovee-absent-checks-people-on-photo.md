# ADR-0153：「app 有、這次照片上沒有」對誰，看照片上有幾位

日期：2026-10-18
狀態：已接受
延伸：[ADR-0129](./0129-abovee-photo-checks-what-is-missing.md)（拍 Abovee 也講「app 有、這次照片上沒有」）的「對象」那一段。
[ADR-0128](./0128-a-matching-chart-number-forgives-one-character.md)（差一個字）、[ADR-0103](./0103-chart-number-helps-identify.md)（認人）。舊的一個字都不改。

## 背景

ADR-0129 的對象是「照片上每一列都認出來、而且是同一位 → 那一位；否則範圍裡每一位」。
只要有一列沒認出是誰（AI 抄錯一個字、病歷號對不上、同名兩位），就退回對大家。她 10/18 在 staging 拍了一位客戶的整個月，
起訖讀到 10/2–10/31，那一塊列了 104 段：

> 有時候我會只拍某個人的整個月，所以照片當然不會有當月其他人的 但這不是錯誤
> 能不能如果這張照片中只有一個人的話 … 就看這段時間 這個人有沒有app有但abovee 沒有的就好不用看大家
> 但如果一張照片中有很多人很明顯是拍大家的那就可以顯示大家的
> 我在這邊通常都是我壓好一個人後 我想記到app中就拍照，大部分時候是一張只會有一個人

她 10/18 回：照片上剛好兩位不同的人 →「只對那兩位」。

## 決定

**照片上有幾位，看照片上的字，不看認不認得出來**（`aboveeImport.js` 的 `photoPeople()`）：
先照病歷號分組；沒有病歷號的那一列，名字跟某一組一樣或差一個字（`oneCharOff()`）→ 併進那一組；都不像 → 自己一組。
拿不準的當成不同的兩位。名字與病歷號都空的那一列不算人。

**對誰**（`photoWho()`）：

- 1～2 位 → 只對那幾位，「那幾位」是那幾列**認出來的人**（她「換一位」之後照她換的）
- 其中一位一列都沒認出來 → 那一位先不對，那一塊講一句「照片上的 ○○ 還沒認出是誰，先沒對」（照片上的原字），**不退回對大家**
- 3 位以上 → 當成拍大家的，照舊對範圍裡每一位

**「對誰」與「範圍放不放寬」是兩件事**。範圍（`photoBounds()`，ADR-0129）一個字都不變：放寬到整個月照舊要「每一列都認出來、同一位、而且每一列都在這裡」。
`flagMoved()`（Abovee 改了時間）讀同一份範圍 —— 拿寬的那個判準來放寬的話，很多人的列表最後一頁只剩一兩位時會被放寬到月底，改期也跟著變。

**月底對帳**（`.claude/skills/month-end-reconciliation/`）明說對每一位（`absentFromPhoto(…, { everyone: true })`）：它拿的是一整個月，
照片上幾位跟它要不要對每一位無關。

## 後果

- **已知的限制**：一天的列表剛好只有一兩位時，第三位只在 app 上有、Abovee 上沒有的那一段不會被抓到。這是「兩位只對兩位」的代價 ——
  照 ADR-0129 的取捨，少對幾段好過喊錯一大堆（月底對帳會對每一位）
- 抄錯兩個字以上、又沒有病歷號的那一列會被當成另一位：那一位先沒對、講一句；她選了人之後重算
- 照片上兩位、其中一位還沒認出來時，那一位那一天同一個時間的段照舊先不列（ADR-0129：那一列可能就是他）
