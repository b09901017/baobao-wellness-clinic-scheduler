# ADR-0135：講來訪的數字數的是段，不是筆

日期：2026-10-07
狀態：已接受
延伸：[ADR-0087](./0087-the-screen-says-slot-or-day-never-record.md)（畫面上只有兩個單位：這一段、這一天）、
[ADR-0061](./0061-a-cancelled-visit-is-drawn-but-dimmed.md)（取消的畫出來、暗掉、不算數）。舊的一個字都不改。

## 背景

ADR-0087 拿掉了「筆」，但盯著它的測試只認一份固定的舊句子，之後新寫的漏網了。而且有幾處不只是用詞，**數的東西就不一樣**：
月曆上方寫「24 筆來訪」數的是來訪文件；週檢視每天右上角的「10 筆」是來訪文件＋行事備註＋待辦，底下列的卻是一段一列（含取消的灰列）；
客戶詳情「看全部 N 筆」底下一列是一天。2026-10-07 逐條驗證時找到的。

她的回答：

> 筆 :  照你的建議，全部統一改為「段」，讓顯示的數字與下方看到的列數一致

> 週檢視每天右上角那個數字：底下灰掉劃線的取消段算不算？不算

## 決定

**判準是她那一句：數字跟底下看到的列數一致。** 一列是一段就寫段、是一天就寫天。

- 月曆上方：「N 段來訪」，數**還算數的段**（`liveSlots()`），一天裡取消的那一段不算。
- 週檢視每天右上角：底下**沒被劃掉的列數**（還算數的段＋行事備註＋待辦），三種混在一起所以寫「項」。勾掉的待辦照算 —— 那一列還在。
- 壓表：「已記 N 段」「加這一段」。客戶詳情：「看全部 N 天」（底下一列是一天）。
- 「今天做了什麼」頂端那一排**拿掉單位**（「壓了 13・簽了 10」）：每一個數字是「底下那一段有幾列」，而②壓表底下一列是一則新增來訪 ——
  併進同一天的段不印（ADR-0071）。寫「段」數字就不等於底下的列數；不替每一種挑量詞，也就沒有對不上的那一個。

ADR-0061 不動：取消的照樣畫出來、暗掉，只是不算。

**例外**（不是來訪）：行事備註、額度、隨手記、營養品、待辦中心的任務 —— 它們一則就是一筆。資料健檢與稽核本來就在講資料。

`tests/day-slot-words.test.js` 多一條掃「數字後面接著『筆』」的，例外寫成名單、每一條附理由。

## 沒有選的

- **「今天做了什麼」也改數段**：一次存兩段算 2。但數字就不等於底下的列數，撞到這一份自己的判準與 `SPEC.md`「數的是留下來的」。
