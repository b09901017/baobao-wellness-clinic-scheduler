# ADR-0123：拍 Abovee 的確認層跟壓表一樣選得了

日期：2026-10-05
狀態：已接受
延伸：[ADR-0104](./0104-many-slots-from-one-photo.md)（確認層就是第一道、存檔前只問一次）、
[ADR-0103](./0103-chart-number-helps-identify.md)（對不上不自動挑人）、
[ADR-0121](./0121-a-course-can-be-uncounted.md)（「這一段可以做什麼」那一排）。舊的一個字都不改。
（09 合併扣課、10 時間不同、11 改成 Abovee 的，做的時候接在這一份後面。）

## 背景

拍 Abovee 的確認層（ADR-0104）是照「Abovee 上寫什麼、app 就記什麼」做的：照片認得的那一列，
額度預選好、她勾一下；認不得的那一格就沒得選。

她 2026-10-05：

> **一、拍 Abovee 要能代替壓表。** 我只想拍一張照，再補充或修正需要的，就記好了。
> - 現在辨識錯了就錯了：不能改是誰、不能選課程。認不出課程時只叫我去壓表手動記。
> - 治療師常常沒認出來（Abovee 寫全名）。我要可以像壓表那樣直接選。

查到的形狀：

- **認得的人換不掉**：「是誰」那一排只有認不得、而且有候選時才畫；`app 裡沒有` 的一排都沒有
- **課程認不出來就整列做不下去**：額度那一排是拿照片上的課程去篩的，認不出課程就是空的，只剩一句「到壓表手動記」
- **二返排在健檢旁邊**（她 2026-09-24：一指就約錯）：那一排只照有沒有剩排，沒走 `followupsLast()`
- n返、不算次數的課、約的時候選的時長：這一層都沒有
- 照片上寫的營養點滴品項會被額度上買的那一款蓋掉

## 決定

**確認層的每一列跟壓表那一張卡選得了一樣的東西，而且是同一份名單、同一支組時段。**

1. **每一列都能「換一位」**（還沒記好的，種類不限）：打名字找（`domain/customers.js` 的 `searchCustomers()`，
   比法同認人），換了整列重算（`resolveItem()`）。**她自己選的人不自動勾**；app 裡真的沒有就講一句
   「先去新增客戶」—— 這一層不建客戶
2. **「要做什麼」那一排＝壓表那一排**（`slotOptionsFor()`，ADR-0121）：額度（二返排最後）、＋n返、不算次數的課。
   **用完的額度也列**（`includeUsedUp`）：Abovee 上已經約了，那一段是既成事實，選了照舊有「會超過次數」的提醒
3. 照片認得的那一顆**先按好**，她按一顆跟翻譯按好的走**同一支** `pickOption()`：
   器材對得上的池、品項（**照片上寫的那一款優先**，挑額度時品項對得上的那一筆優先）、時長一樣的那一筆；
   `三返` → ＋n返、返數三返；不算次數的課 → 那一顆（身上還有那門課的額度就照舊扣）
4. 接著那幾排照壓表的順序：器材 → 品項 → 接哪一次健檢（二返只有一次按得下去才先選；**n返 不替她選**）→
   第幾返 → 排多久（ADR-0122，照照片上的數字）→ 診間／治療師 → 醫師（照片上認得的人先選、不套 `preselect`）
5. 組時段照舊只有 `slotFromPicks()` 一條路 —— 這一層存下去的那一段跟同樣選法在壓表存的一模一樣
6. 存檔前那一道多講兩句（同壓表那一道）：n返「加約的、不扣次數」、不算次數的課「數字一個都不會變」

## 為什麼不另做一張

壓表那張卡已經有這幾排了。讓拍 Abovee 打開壓表那張卡去改，等於一次記十幾段要來回十幾次；
在確認層裡再畫一份不同的選法，則是同一位客戶在兩個入口看到兩種排法（CLAUDE.md「先看誰」那一列同一個理由）。
所以名單（`slotOptionsFor()`）與組法（`slotFromPicks()`）都共用，只有畫法是這一層自己的。

## 沒有改的

- **認人的規則**（ADR-0103）：對不上照舊不自動挑人 —— 換一位是她挑的
- **「對不上」那幾列這一層不改**（ADR-0056、0116）：它們也能換一位（認錯人才對不上的那種），
  換了之後照新的人重算，可能變成新的
- **記住寫法**（`aliasWrites()`）只在服務資源那一格認不出來、她選了人時寫；換課程不寫任何寫法

## 後果

- 「到壓表那張卡上手動記這一段」那一句拿掉了
- 拍 Abovee 一次記得進 n返、不算次數的課、二返60
- `slotFromPicks()` 卡在後面那幾道時照樣交回課程（`course`、`assigns`）：這一層還沒選齊時，
  要靠它畫接下來那幾排。壓表與來訪編輯器只讀 `slot` 與 `errors`，不受影響
- 日曆新增的「要幫誰排？」與批次取消那一頁的找人還各寫各的（`String(name).includes(q)`）
