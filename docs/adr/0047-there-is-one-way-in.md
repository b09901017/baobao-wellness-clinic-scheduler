# 舊資料只有一條路進得來

2026-08-23

## 決定

**拿掉「把舊試算表的文字直接貼進 app」那條路**（`#/settings/import`）。
舊資料只剩一條路：貼 `.claude/skills/calendar-sheet-merge` 產生的合併檔（`#/settings/merge`）。

舊表的解析器（`domain/legacyImport.js` 的 `parseSheet()`、`planForSheet()`）**留著**，
只是消費者換人：以前是那一頁，現在是 skill 那側的 `merge.mjs`。

## 為什麼

兩條路吃的是**同一張舊表**，共用**同一個寫入端**（`importPlan()`），
差別只在合併檔多了一次跟行事曆的對帳：

| | 貼試算表 | 貼合併檔 |
|---|---|---|
| 來訪的日期 | 有 | 有 |
| 時間、診間、治療師、器材 | **沒有** | 對得上的那幾筆有 |
| 行事曆記了但試算表忘記勾的 | **看不見** | 逐筆列出來 |
| 兩邊講的不是同一件事 | **看不見** | 逐筆列出來 |
| 行事備註、休假、待辦 | **沒有** | 分好類讓她挑 |

所以那條路能做到的事，是這條路的**子集**。留著它不是多一個選擇，是多一個
「匯進去比較少東西」的入口，而兩條路長得很像 —— 她不會記得哪一條比較完整。

`.scratch/first-real-import/issues/07` 本來要修的是「貼試算表那條路一律建成已完成」。
那條路不在了，那個 bug 也就不在了：狀態現在只由 `domain/mergeImport.js` 的
`statusFor()` 在匯入當下依日期判（ADR-0029），而**產檔那側算不準「未來」** ——
一份 8/19 產的檔案她可能 8/21 才貼。

## 一起搬過來的東西

拿掉一條路不可以順手拿掉一個安全網。那一頁上有一件事是這條路沒有的：

**文字裡提到醫療禁忌的提示。** 舊表沒有「永久限制」這個欄位，那幾句話寫在
購買名稱（`0604 顧客會-手有金屬，只能INDIBA`）或空白處。匯進來之後
`customer.flags` 是空的，而擋器材是拿 flags 去比對的 —— **沒有那個標記，
超磁場與高能量雷射不會被擋下來**，而那是整個系統唯一會造成實際傷害的一條。

所以 `contraindicationHints()` 從 `domain/legacyImport.js` 搬到
`domain/contraindications.js`（本來就該在那裡），兩條路共用；合併檔那一頁
現在會把這幾位排在**所有東西前面**的一張紅卡上。

它仍然**只提示，不自動填 flags**：「手有金屬」是禁忌，「金屬已取出」不是，
而兩句話都含有「金屬」。那是她的判斷（ADR-0002）。

## 代價

- `sheets/export-legacy.gs`（把 21 張分頁串成一份文字給她貼）跟著刪掉。
  那支本來就寫著「一次性的，跑完可以整份刪掉」。
- `domain/legacyImport.js` 的 `summarize()` / `attentionPoints()` / `reportText()` /
  `parseWorkbook()` 一起刪掉 —— 那份報告只有那一頁在讀，而 skill 那側有自己的
  `reportText()`。少了那一份，`docs/legacy/samples/dry-run-report.txt` 只是留作參考。

  **但 `planForSheet()` 的 `problems` 不是報告，是資料。** 第一版連它一起丟了：
  拿真檔跑有 28 筆（`勾了 3 次但總次數只有 1，匯進去之後資料健檢會列成額度超用`、
  `勾了 N 次，但營養品不排班，沒有匯入成來訪`、`這些日期沒有寫年份`），
  而那些以前是那一頁在顯示的。現在由 skill 的報告接手，印在 ⓪b 那一段。
  這是第二個「拿掉一條路不可以順手拿掉一個安全網」—— 兩個都是雙軸審查抓到的。
- 她如果哪天真的只想貼一張分頁進來：那要重寫一個入口。但在那之前，
  行事曆的對帳是她最在意的那一件事（「記在行事曆上了卻忘記記在試算表中，這個很嚴重」），
  而那件事只有合併檔那條路做得到。

## 沒有被推翻的

**ADR-0012 還是成立的**：匯入還是「貼上」，不是接 Google Sheets API。
拿掉的是其中一種貼上的東西，不是那個決定。
