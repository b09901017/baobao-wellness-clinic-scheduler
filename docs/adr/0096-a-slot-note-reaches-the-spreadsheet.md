# ADR-0096：那一段的記一句會上試算表

日期：2026-09-16
狀態：已接受
延伸：ADR-0084（那一句話屬於時段）、ADR-0018（試算表是唯讀報表）

## 背景

上線前健檢 §4.7：她的工作筆記寫著「家人用本人的課時，要在 Examine 建家人
病歷、預約系統填家人病歷號＋關聯扣課」。app 裡那一段只記在本人身上，
待辦的 Examine 也掛本人 —— **沒有地方寫「實際來的是誰」**。

報告問她要不要加一欄。她 2026-09-16 的答案：

> 這個如果寫在當天那一個時段的記一句可以嗎？⋯⋯希望是可以⋯⋯記在當天那一列的
> 下面，或是你覺得記在試算表的哪比較好都可以

並且接受了兩個代價（明確問過）：試算表要重貼 `.gs` 並重新部署，
以及**以後每一句記一句都會上試算表**，不只家屬那一種。

## 決定

**不另開欄位。** 「實際來的是誰」寫在那一段的 `slot.note` 裡（ADR-0084 的
那一句話），而整包推給 Apps Script 的內容多一份 `slotNotes`。

形狀**照 `equipmentNotes` 抄**（`{rowIndex, label, cells}`）：那一份 2026-09-06
就是為了「像二返那些註記一樣，在當天的那一列下面」做的，這是同一個模子的
第二次用。`.gs` 那側兩種共用同一支 `noteRowAt()` 與 `noteLine()`。

`SYNC_FORMAT` 4 → **5**，`sheets/readonly-report.gs` 的 `SUPPORTED_FORMAT` 同步。

## 為什麼

**不另開欄位**：ADR-0084 剛把「一句話」收攏到時段身上、四個入口共用一支，
再長一個平行欄位等於把那件事拆回兩半。而且「實際來的是誰」跟「她說想換一台」
在她的用法裡是同一種東西 —— **這一段發生的特殊狀況**。

**不塞進 `followupNotes`**：`.gs` 把那一份全部畫在同一列，同一個 `dateIndex`
後面的會蓋掉前面的，而一位客戶同一天做了健檢又做了四選一是會發生的。
格式 4 當初分出來就是為了這個。

**取消掉的那一段不印**：那一場沒發生，而那一格印出來的東西會讓她以為發生過。

**讀那一句走 `slotNoteOf()`**，不是直接讀 `slot.note` —— 舊資料退回整筆那一句
的規則在那一支裡面（ADR-0084）。

## 後果

- **她要回 Google 試算表把 `.gs` 重新貼一次並重新部署。** 不貼的話 app 照樣推、
  `.gs` 整包拒收，而畫面上看起來跟推好了一模一樣（`CLAUDE.md` 對 `SYNC_FORMAT`
  的警告）。`tests/sheet-script.test.js` 盯著兩邊的數字一樣
- **記一句從此是給外面看的。** 她在 app 裡寫的每一句都會出現在試算表上
- 每一筆排得進來訪的額度都問（不像器材那一份只問得選的擇一池）——
  一句話可以記在任何一段上
