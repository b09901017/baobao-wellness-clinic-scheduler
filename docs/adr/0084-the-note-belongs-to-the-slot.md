# ADR-0084：「記一句」記在時段上，收在一顆夾板後面

日期：2026-09-09
狀態：已接受
推翻：`SPEC.md` 第 5.3 節那句「`note` 是這一天的，不是某一個時段的」

## 背景

她 2026-09-09：

> 不要是一整天的，我就覺得你好像沒有懂我的意思。我希望是每一筆都可以有
> 他的記一句，而不要是一整天的（不要管 SPEC §5.3 明寫什麼，以我這次說的
> 為主）。我希望這一筆這個時段點進去就是看到這筆只有這筆相關的資訊。

SPEC 第 5.3 節當時寫的理由是「她記的東西通常是『這次來訪』的事，不是
『這一段』的事」。那句話是**推測**，而她現在直接回答了。

## 決定

### 一、`slot.note`，上限沿用 `NOTE_MAX`（200）

`visit.note` **留在資料上不刪**（舊資料靠它），但不再寫入。

### 二、舊資料在她下次存那一筆時搬到第一段

`withSlotNotes()`，跟 `withSlotStatuses()` 同一個路口（`data/visits.js`
的 `save()`）、同樣冪等。

**搬不是複製。** 複製到每一段的話一句話會出現三次，而她改了其中一段之後
另外兩段還是舊的 —— 那是三份會對不起來的資料。搬完 `visit.note` 是 null，
往後沒有人再寫它。

搬到**第一段**（照陣列順序）：那一句多半是壓表當下記的，而壓表是從第一段
開始壓的。她從三個選項裡選了這一個（另外兩個是「每一段都顯示」與
「直接不顯示」）。

### 三、畫面：一顆夾板，三種狀態

```
① 沒有字      抬頭列右邊一顆淡的夾板，**零額外高度**
② 點下去      就地展開 textarea，自動聚焦，夾板轉主色
③ 有字收起    夾板主色 + 底下一行淡字，點那一行也展開
```

她的原話：「不用每個都給記一句的輸入框，就是有需要的時候點一個 icon
或是什麼再展開填就好，不然感覺會很占版面…要簡潔直觀，而且閱讀起來舒服，
有呼吸感。」

**收起來不是藏起來。** 這是這個樣式表自己的規矩（`app.css` 的 `.advanced`：
「摺疊的標題要講出裡面被動過幾樣 —— 收起來的東西不能安靜地生效」）。

**icon 是 `book`，而且不是這一輪挑的**：日曆那一列右邊早就有一顆
（`noteMarks()` 的 `aria-label="有記的話"`），是她 2026-09-04 選的。
另外挑一顆的話她要學兩次「哪個圖示代表我寫了字」。
`manual`（攤開的書）是備忘錄／SOP，**不可以拿來用**（ADR-0067）。

### 四、四個入口共用 `ui/components/slotNote.js`

來訪編輯器每一段、壓表記錄卡、待辦中心那一句「問過了、客人還沒回」。
展開的行為只有一份 —— 兩份的話遲早有一邊忘了改 `aria-expanded`。

### 五、`visit.followupNote` 是另一回事，形狀不動

那一句（「禮拜一再問問」）記的是「這通電話追到哪了」，而電話一天打一通，
一位客戶好幾天的來訪還共用同一句。**但它的輸入框也收成同一顆夾板**
（她 2026-09-09 第 5 點）。

> **這推翻了它原本的理由，而原本那個理由也是她給的**（2026-08 那一輪）：
> 「直接是一個輸入框，不是一顆『加備註』按鈕 —— 她人在 LINE 裡，多一次
> 點擊就會變成『算了等一下再記』，然後就忘了。」
>
> 兩件事都成立，差別是**現在那一列上有幾樣東西**：那時候一列只有名字與
> 天數，現在還有課程、段數與那幾顆動作，而她看到的是一頁二十列各帶一個
> 空輸入框。

## 後果

- **日曆那一列的夾板順手修對了。** 它以前讀整筆的 `visit.note`，所以一天
  三段只在其中一段記了字，**三列都會亮**。現在逐段算（舊資料退回整筆 ——
  那時候整天共用一句本來就是事實）。
- **domain 開始擋長度了。** 以前只有 `maxlength`，而貼上一大段字時瀏覽器
  會直接截斷，她看不出被截掉了。
- **壓表不再預填同一天既有那一筆的 note** —— 那是別段的字。
- 讀取卡片印的是**那一段**的那一句（只畫一段時，ADR-0080）。
- 試算表**這一輪不動**：她還在想「同一天多句要怎麼標」。`SYNC_FORMAT` 沒有
  變，她不必回 Google 重貼。

## 其他做法（她看過並選了現在這個）

**舊資料在每一段都顯示（灰色、不能改）。** 一句話出現五次，正是她說的視覺疲勞。

**舊資料直接不顯示。** 乾淨，但她以前寫的東西就看不到了。
