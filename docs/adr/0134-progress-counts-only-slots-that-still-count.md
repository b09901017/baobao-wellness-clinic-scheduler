# ADR-0134：進度追蹤與「這個月」只講還算數的段

日期：2026-10-07
狀態：已接受
延伸：[ADR-0081](./0081-the-slot-carries-the-lifecycle.md)（時段才是原子單位）、
[ADR-0089](./0089-the-day-is-only-a-heading.md)（一天只是抬頭，每一段自己是一列）、
[ADR-0061](./0061-a-cancelled-visit-is-drawn-but-dimmed.md)（取消的在日曆上畫出來、暗掉、不算數）。舊的一個字都不改。

## 背景

進度追蹤（`#/customers/progress`）與客戶詳情的「這個月」共用同一份資料（`domain/progress.js`）。
那一支從第一天起就寫著「取消不在裡面」，畫面上的 `?` 也寫「取消掉的時段不畫」。

但它濾的是**整筆**取消的來訪（`isActive()`）。逐段取消（ADR-0081）之後，一天裡只取消其中一段時那一段照樣畫出來
（寫「已取消」）、照樣算進「N 段」，而 ○△✓✗ 四個數字沒有「取消」那一格 —— 「3 段」底下是 ○1 ✓1，加不起來。
2026-10-07 逐條驗證時重現的。

問她要哪一種，她回：

> 照你的建議 採 (A)。這個頁面的核心目的是回答「這個人這個月實際上做了多少」，而取消的段實際上並未發生

## 決定

**取消的段在這兩頁不畫、不算。** 濾在 `domain/progress.js` 的 `dayFor()`：

- 一段取消了就不收；**未到的照畫** —— 那一段發生過（人沒來），而且它有自己的符號。
- 濾完一段都不剩的那一天不留抬頭；一天都不剩的那一位歸到「這個月沒有排」。
- 每一段帶著的 `index` 照舊是它在 `visit.slots` 裡**原本的位置**（先編號再濾）—— 畫面拿它開那一段。

日曆不動：取消的那一段在日曆上照樣看得到、暗掉（ADR-0061）。「那一格本來有人、後來取消了」是她在日曆上要看的事，
不是這兩頁要回答的事。

## 沒有選的

- **照畫，另外多一個「取消 N」的數字**：加得起來，但這一頁變成在講「這個月發生過哪些事」，而她問的是「做了多少」。
