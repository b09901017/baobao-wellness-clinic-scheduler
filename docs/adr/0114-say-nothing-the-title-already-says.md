# ADR-0114：跟標題講同一件事的說明直接不畫，連 `?` 都不要

日期：2026-09-24
狀態：已接受
推翻：[ADR-0072](./0072-a-row-on-the-todo-centre-is-only-a-title.md) 的前提「一句都不會真的消失」的一部分。
舊的一個字都不改。

## 背景

ADR-0072（9/04）把待辦總覽上的十三句說明搬到「點進去那一頁的第一行」，敢做的理由是
「一句都不會真的消失」。9/12 那幾句又收進 `?`（`ui/components/tip.js`）。
9/24 下午（`.scratch/asks-2026-09-24/issues/09`）系統寫在任務身上的那一句
（「有一段取消了，回去把 Abovee 上壓的那個時段放掉」）也從常駐字收進種類旁邊的 `?`。

她 2026-09-24 晚上：

> 有一些tooltip是完全不必要的，不要卡在標簽之間很奇怪，而且有些根本其實不用那些說明
> a追蹤健檢報告那邊的待辦，不需要提醒"健檢做完了，去問報告出來沒" 這是多餘的話
> b簽療程單那邊寫的"有幾段到現在還是.....沒來就打叉"看不懂且沒必要，是多餘的
> c改時間/取消"2026-09-08的來訪取消了....放掉"不需要，是多餘的

列出同一種的其他幾顆問她，她回「清單 B 全部拿掉可以，但是C先不用，目前感覺沒有影響版面」。

## 決定

**標題已經講了的那一句，拿掉，不是收起來。** 資料上的字不動（`task.note` 照樣存著），只是不畫。

拿掉的：
- 任務身上系統寫的那一句（`autoGenerated` 的 `note`）—— 分類頁、依客戶抽屜、客戶詳情三個地方
- 簽療程單卡上「有幾段到現在還是待確認…」、簽療程單與跟客人確認時間兩頁的標題
- 逾期／今天／明天／改時間取消四頁的標題
- 任務種類那一頁的標題：追蹤健檢報告、寄報告給醫師、約二返、寫紀錄、打電話、Abovee
- 依客戶抽屜「跟客人確認時間」「簽療程單」兩列；確認抽屜「X 的 N 段」；客戶詳情「還沒有任務。」；壓表那張卡

**留著的**：Examine（「預約作業 → 查核 → 已報到」）與耀聖（「右下角 → 未報到 → V」）。
那兩句是**另一個系統上要按哪幾下**，標題講不出來 —— 跟「死線是今天」不是同一種。
設定頁與欄位旁的功能說明（她的清單 C）這一次不動；帶 ⚠ 的提醒本來就是紅線（`tests/tip-red-lines.test.js`）。

## 為什麼不是收得更深

`?` 不佔版面，但它佔**注意力**：一顆夾在「種類」與「N 項」兩顆標籤中間的 `?`，
她每一次掃那一列都要跳過它一次，而點開來講的是標題已經講過的事。
收起來是為了「偶爾需要」的話；這幾句她說不需要。

## 後果

- 確認抽屜那一顆本來就講錯了（「確認之後會自動排進日曆」—— 壓好就已經在日曆上），一起消失
- CLAUDE.md「任務什麼時候產生」那一列原本要求四句文案跟著規則改，現在只剩壓表「加這一筆」底下那一句與 `consequences.js`
- 以後有人想「補一句說明」到這幾個地方，先回來讀這一支
