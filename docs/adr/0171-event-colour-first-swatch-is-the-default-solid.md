# ADR-0171：行事備註的顏色 —— 第一顆是那一類本來的顏色、實心；重複的那一色不列；休假每一顆都畫斜線

日期：2026-11-05
狀態：已接受
推翻（只限新增／編輯行事備註那張表的色票；舊的一個字都不改 —— 慣例見 `docs/agents/domain.md`）：

- [ADR-0040](./0040-a-personal-event-picks-its-own-colour.md) Consequences 最後一點（「不挑」那一顆做成**空心圈**，因為實心的話會跟六顆裡同色那一顆一模一樣）：
  第一顆改成實心的預設色，六顆裡跟它同色的那一顆**不列**

ADR-0040 其餘照舊：名單借 `MARK_COLORS`、存名字不存色碼、沒挑（`null`）跟著類別、顯示寬容存檔嚴格、
休假的斜線不跟著顏色走、撞到來訪狀態的色相不擋、`--evcolor-*` 一組值。

延伸：[ADR-0039](./0039-six-things-on-the-calendar-need-six-colours.md)（休假的斜線紋講的是「我不在」）。

## 背景

那張表的顏色一排是：一顆空心圈（「跟著類別」，存 `null`）＋ 六顆實心點（灰綠茶紅藍紫）。
休假時第一顆身上掛著 `.kind-leave`，斜線畫在整顆按鈕底上，其他六顆是實心的。她 2026-11-05：

> 新增行事備註那個表單，的顏色選擇的部分，為什麼第一個都很奇怪，會是一個空心圈圈？
> 能不能一致，像是實心的就都呈現實心，斜線的，所有顏色選擇就都呈現斜線的樣子，不要也是實心的

> 就直接拿掉，讓第一顆就是紫色的實心阿不能嗎？… 同理選休假也是每個都一樣如果是預設的顏色那就擺第一個，
> 為甚麼要把他擺的到最後面 再第一個預設有一個空心的同顏色的?? 不理解?

ADR-0040 的理由（實心會跟同色那一顆一模一樣，空心講的是「這不是一個顏色選擇」）是對的，但它解的是
「兩顆一樣」；她看到的是「第一顆跟其他的不一樣、而且同一個顏色出現兩次」。把重複的那一顆拿掉，兩件事一起解掉。

## 決定

1. **第一顆＝那一類本來的顏色**（行事備註紫 `--event-personal`、休假霧藍 `--event-leave`，就是日曆上沒挑顏色時那一類的顏色），**實心**，
   選它存 `null` —— 跟以前「跟著類別」是同一個值，舊資料不用搬，`validateEvent()`、Rules、日曆那一側一個字都不改
2. **六色裡跟那一類重複的那一顆不列**：行事備註不列紫（`violet`）、休假不列藍（`blue`）。
   哪一色算重複只寫在 `domain/events.js` 的 `CATEGORIES`（每一類的 `sameAs`），列哪幾顆只問 `colourChoices()`
3. **這一筆現在存的就是被拿掉的那一色**（以前挑了紫的行事備註；挑了藍再把類別切成休假）：那一顆**照樣列出來、是選著的**。
   不列的話她打開一筆以前挑紫的，看起來像沒挑；一存檔也不會變（存的還是 `violet`），但畫面上講的跟資料不一樣。切類別不把 `color` 清成 `null`
4. **選休假時每一顆都畫斜線**（含第一顆），斜線畫在那個圓點上 —— 色票上講的跟日曆上的休假一樣：顏色是她挑的、斜線是「我不在」

## 為什麼不是別的做法

- **六顆之外再加一顆、第一顆照舊是預設色**：同一個顏色兩顆，就是她問的「不理解」那一句
- **把類別本來的顏色換成六色裡的紫與藍**（值合成一個）：日曆上沒挑顏色的每一筆都會變色，而那兩組值是分開調的（ADR-0039 的六種東西要分得開、ADR-0040 的 `--evcolor-*` 壓字的對比）。
  這一輪只改色票，不改日曆
- **斜線疊 `--stripe-leave`**：那個 token 是 20% 的霧藍，疊在 20px 的實心深色點上幾乎看不到 —— 跟日／週那一列的色棒同一個理由（`app.css` 的 `.kind-leave .timerow__bar`），
  圓點上自己一份：缺口用底色挖穿

## Consequences

- 色票的新規則都限在行事備註那一組（`.swatches--event`）底下：`.swatch` 跟客戶備註（`marks.js`、`notesEditor.js`）與設定頁警示（`masterList.js`）共用。
  `.swatch--auto`（空心）**還在**：設定頁警示選「空心」填法時整排都畫空心 —— 那正是她要的「一致」
- 行事備註要不要多幾個顏色**不在這一次**：她 11/5 問過「之前說不能有更多顏色是什麼意思」，那是 ADR-0040「六個的理由」的設計選擇，不是做不到；之後另外問她
