# ADR-0176：試算表的版面 —— 欄不凍結、上下那幾塊整頁寬、數字四欄全白＋一條窄空白欄

日期：2026-11-05
狀態：已接受
延伸：[ADR-0161](./0161-sheet-remembers-fingerprints.md)（`LAYOUT_VERSION` 4 → 5，部署後每一頁重畫一次）
推翻：ADR-0175 的第 1 點（前五欄凍結、所有合併停在第五欄以內、應有～剩餘淡灰底＋表頭淺一階＋剩餘右邊一條粗線）與第 5 點的「抬頭的病歷號只寫號碼」那一格（號碼搬到名字那一格）

## 背景

ADR-0175 的版面貼到 staging 之後，她 11/5 晚看著真的那一份說了四點（截圖有真名，不收進來；原話在 `.scratch/sheet-push-gaps/issues/14`）：
分裂感太重、不要那條凍結線、不要全部擠在 A～E；號碼要放在名字旁邊、一樣大；那層灰色太醜；營養品那一行要有日期。
灰色那一點主控畫了三種（`.scratch/sheet-push-gaps/mock-count-columns-2026-11-05.html`，假資料），她挑了 **A：全白＋一條窄空白欄**。

## 決定

1. **欄不凍結**，列照舊凍結到矩陣表頭（第 5 列）。最上面四列（提醒、名字、購買名稱＋合計、產生時間）與下面「買過什麼」「營養品」「備註」「來訪紀錄」
   **又是整頁寬**（`width`：矩陣與 FINISHED 那一塊比較寬的那一個）—— 長的一行幾乎不再折行。
2. **號碼接在名字後面**：名字那一格寫「客戶A　1234」（全形空白隔開、同一個 18 號粗體）；名字底下那一行只剩購買名稱、會籍、合計。
3. **應有～剩餘四欄不塗底色**、表頭跟其他表頭同色；斑馬紋與狀態色（已完成綠、已排未上黃、剩餘 ≤ 0 紅）照舊。
   **剩餘與第一個日期中間一條窄空白欄**（第 6 欄、8 像素寬、沒有字、沒有框線、白底，表頭那一格也白）—— 日期從第 7 欄（G）起。
   矩陣的框線分兩塊畫（療程項目～剩餘、日期那幾欄），剩餘右邊那條粗線拿掉。
4. **營養品那一行最前面是購買日**（`0901`，跟「買過什麼」同一種寫法）：`syncBundle()` 的 `products` 每一筆多送 `purchasedAt`；沒有購買日的不印。
5. **不升 `SYNC_FORMAT`**：新的 `.gs` 收舊的包照畫（沒有 `purchasedAt` 就從名字開始）、舊的 `.gs` 不讀 `purchasedAt`。`LAYOUT_VERSION` 4 → 5。

## 為什麼

- **凍結的代價她看了才知道**：ADR-0175 選凍結時寫的代價是「下面那幾塊只剩約 440 像素寬、長的折成兩三行」。真的畫出來，左邊一條窄窄的欄位擠滿字、
  右邊大片空白，中間一條凍結線 —— 她叫它「分裂感」。往右捲日期時療程名字會不見（凍結要解的那個問題又回來了），但她寧可這樣。
- **空白欄而不是顏色或線**：三種都把數字四欄跟日期分開；全白＋空白欄不多一種顏色、不多一條線，最安靜（她說過「資訊疲勞」，ADR-0175 背景）。
- **號碼跟名字一樣大**：她找人是看名字＋號碼，號碼縮在下一行的小字裡要多看一眼。

## 沒有選的

- **淡藍底**（示意圖 B）、**深一階的表頭＋細線**（示意圖 C）：都還是多一種顏色。
- **把 FINISHED 跟著往右移一格**：它在矩陣底下另外幾列，不會壓到日期；她舊表上就在 K 欄（ADR-0024），照舊。
