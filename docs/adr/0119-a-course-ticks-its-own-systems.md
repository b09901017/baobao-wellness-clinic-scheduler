# ADR-0119：課程自己勾壓哪幾個系統

日期：2026-10-05
狀態：已接受
推翻：`SPEC.md` 第 5.5 節「任務規則綁在**類別**上，不逐課程設定」那一句。
延伸：[ADR-0041](./0041-the-sheet-is-the-registration.md)（壓表就是登記）、
[ADR-0027](./0027-registration-tasks-wait-for-the-customer.md)（確認之後才長）、
[ADR-0097](./0097-confirming-is-per-slot-too.md)與 [ADR-0107](./0107-a-registration-task-knows-which-slots.md)（掛號逐段）、
[ADR-0091](./0091-a-cancel-task-knows-which-slots.md)（取消逐段）。舊的一個字都不改。

## 背景

課程主檔上只有一格「任務類別」，四選一，每一種是一組寫死的「壓表在哪＋客人確認之後去哪幾個」：

| 類別 | 壓表在 | 確認之後 |
|---|---|---|
| A 門診 | Abovee | Examine、耀聖 |
| B 健檢 | Examine | —— |
| C 療程、不用掛號 | Abovee | —— |

所以「只壓 Abovee＋耀聖」這種組合做不出來。她 2026-10-05：

> 每個課程都要可以自己選：壓表壓哪幾個系統、要不要簽療程單、要不要寫紀錄、診間、哪一科的醫師、別稱…。之後都還要能改

> 其他課程我自己也不熟，所以設計要讓我之後自己加得進去、改得動，不要現在一次建滿。

功醫門診是第一門要用到它的（三個系統都要壓），而她之後自己加的課會是哪一種組合，現在沒有人知道。

## 決定

**課程多一格 `systems`：`['Abovee', 'Examine', '耀聖']` 的子集合。** 設定頁那個四選一的下拉換成三個勾。

推導只寫在 `domain/taskRules.js`：

| 問什麼 | 哪一支 | 怎麼算 |
|---|---|---|
| 這門課動到哪幾個系統 | `systemsOf(course)` | 勾過就照勾的；沒勾過照類別推；找不到這門課回 `null` |
| 壓表壓在哪 | `bookingSystemOf(course)` | 勾了 Abovee 就是 Abovee；沒勾 Abovee、勾了 Examine 就是 Examine |
| 客人確認之後長哪幾種 | `tasksForCourse(course)` | 其餘勾起來的，扣掉壓表那一個 |

驗證：Abovee 與 Examine 至少勾一個 —— 壓表一定要有一個地方，而耀聖只收確認之後的登記。

**以前讀類別的每一個地方都改成傳課程、問這幾支**（掛號逐段、取消逐段、讀取卡片的歸屬、
待辦中心「壓表登記」、取消與改期的確認框）。沒有任何一處再自己比 `category`，
`tests/course-systems.test.js` 掃原始碼盯著。

## 為什麼沒有遷移

**沒勾過的課程照舊從類別推**，讀的時候退回（跟 `slotStatus()` 同一個作法）。既有資料一筆都不搬：

- 種子每一門課填的 `systems` 跟它的類別推出來的一模一樣，有測試逐一比
- 舊課程在設定頁打開時三個勾照 `systemsOf()` 畫好，什麼都不改就存一次，算出來的一個字都不會變
- `category` 留在資料上、表單不再改它 —— 它現在只是沒勾過的課程的退路（與 ADR-0058 醫師那一條的退路）

寫一支遷移把每一門課補上 `systems` 也做得到，但那要在正式站跑一次寫入，而換來的只是「少一條退路」。
讀的時候退回的代價是 `systemsOf()` 多三行。

## 「不知道」要回得出來

找不到那門課（主檔被刪了）時，兩個呼叫端要往相反的方向倒，所以 `systemsOf()` 回 `null` 而不是空陣列：

- **取消時猜 Abovee**（`bookingSystemsForVisit()`、`cancelTasksFor()`）：那筆來訪存在就代表壓過了，
  不猜的代價是一個時段永遠佔在那裡而畫面上什麼都沒說
- **「壓表登記」那一列不算數**（`customersToBook()`）：它問的是「還要不要壓」，猜錯的方向是把一位該壓的客戶整個從清單上抹掉

兩邊都倒向「寧可多講一句」。這不是新規則，是 2026-08 就有的兩個方向，這一次只是讓它們問同一支。

## 改了一門課的勾法之後

**已經長出來的任務不追溯。** 下一次那一筆來訪被存時照新規則比對（還沒做的、已經不需要的會被收掉；
做過的留著）—— 跟以前改類別的行為一樣。取消時「壓在哪就收哪」照改完之後的勾法；那一段勾過的 Examine／耀聖照舊收。

## 順帶改掉的

- 待辦中心「壓表登記」把擇一池寫死成 C 類（＝ Abovee）。現在問那一池推得出的課程（ADR-0075），推不出來才退回 Abovee
- 設定首頁「任務規則綁在課程的類別上 … 不逐課程設定」那一摺拿掉了 —— 那是一句不再成立的話

## 後果

- 她可以替任何一門課勾出任何一種組合，不用改程式
- `category` 變成一格只讀的歷史欄位。新增的課程表單照那一組的預設帶一個值進去（`courseDefaultsFor()`），
  但算數的是 `systems`
- 類別那幾個字母（A／B／C）從畫面上消失了：清單那一行灰字改成「Abovee 壓，確認後 Examine、耀聖」
