# ADR-0102：新增客戶那一頁的提醒收成 ⚠，存檔前再講一次

日期：2026-09-17
狀態：已接受
推翻：`.scratch/quieter-screens/issues/08` 紅線 5 的一部分 ——「`customers.js`、`flags.js` 整支不准 import 說明泡泡」
延伸：[ADR-0086](./0086-two-confirms-before-saving.md)（存檔前那一道）

## 背景

上一輪（說明收成 `?`）畫了五條紅線，其中一條是**會改變寫入結果的警告不可以收進泡泡** ——
她沒點開就等於沒看到，而她已經按下去了。為了守那一條，`tests/tip-red-lines.test.js`
把 `customers.js` 與 `flags.js` **整支檔案**列為不准 import 泡泡。

但那兩支檔案裡真正的紅線只有兩句（`flags.js` 的禁忌紅框 `noticeBlock`、`customers.js` 的
「數量 0 不會展開任何額度」），整支禁掉的結果是同一支檔案裡純說明的那幾段一起被卡住，
新增客戶那一頁擠滿常駐的灰字與一張「提醒」卡。

她 2026-09-17：

> 突然發現我覺得新增一個客戶的介面UIUX好醜，希望可以重新設計，而且我發現"field__hint"
> 竟然沒有變成tooltip?難怪版面好擠，資訊太多太雜，以及最下面的card card--flat提醒，
> 我覺得可以變成三角形警示提醒的icon的tooltip

> 關於 新增客戶畫面重畫，以及 field__hint 為什麼沒變成泡泡 不管那就寬那支測試的禁令，
> 照我這次說的，底部的「提醒」卡也tooltip掉連那兩句都不要禁

> i 同名提醒照上面那樣做（姓名欄旁的 ⚠，存檔前再講一次），可以

## 決定

1. `customers.js` 與 `flags.js` **從「整支不准 import 泡泡」那份名單拿掉**。
   `flags.js` 的禁忌紅框（`noticeBlock`）不動 —— 它在壓表與來訪編輯器，不在這一頁
2. 新增客戶那一頁的說明全部收成 `?`；提醒收成 **⚠**（`tip(…, { kind: 'warn' })`），
   **貼在它講的那一格旁邊**，只在真的有事時出現：
   - 同名 → 姓名欄
   - 沒電話也沒 LINE → 電話欄
   - 選了方案、數量打 0 → 數量欄
3. **存檔前再講一次**：`warnings()` 有東西時走 `confirmReview()`（ADR-0086 第一道），
   句子照抄 domain 的（`fieldWarnings()` 與 `warnings()` 是同一支算的）

## 為什麼接得住

紅線 5 擋的是「她按下去之前沒看到」。同名與沒聯絡方式這兩句，**按下去之前一定會跳出來**
—— ⚠ 只是把常駐的那一份收起來，最後一道沒有收。

數量 0 那一句沒有進存檔前那一道：它不是「可能建錯人」，是「她自己打了 0」，
而「照樣建得起來、方案不展開」本來就是她要的（「購買方案的數量可以是0，因為有人會單買加購的療程」）。
⚠ 貼在她剛打的那一格旁邊，看得到。

## 後果

- `tests/tip-red-lines.test.js` 的名單少兩支；`tests/fewer-words.test.js` 的 `FIELD_HINT_KEEP`
  裡 `flags.js` 降到 0
- `flags.js` 是客戶詳情編輯表單共用的，那一頁的永久限制與合作機構也跟著變乾淨
- 打字時只換那一顆 ⚠，不重畫整頁（ADR-0038）
- 表單抽成 `ui/components/customerForm.js` 的 `mountCustomerForm()`：拍訂購單（issue 09）
  的小鉛筆把它開在一層裡、事先填好
