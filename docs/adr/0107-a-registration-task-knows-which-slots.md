# ADR-0107：掛號的待辦也逐段長

日期：2026-09-23
狀態：已接受
延伸：[ADR-0091](./0091-a-cancel-task-knows-which-slots.md)（取消類逐段）、
[ADR-0097](./0097-confirming-is-per-slot-too.md)（確認逐段）
推翻：`domain/taskRules.js` 的 `tasksForVisit()` 檔頭那一句「同一次來訪裡有多個時段時，
同名任務只產生一次 —— 她不需要為了同一天掛兩次 Examine」（沒有 ADR，寫在程式註解裡）

## 背景

同一天早上一段復能、10:00 一段門診，兩段都談定、Examine 已經掛好。客人說門診改到下午：
取消 10:00 → 長「取消 Examine」（對的）→ 補排 15:00 → 客人說可以 → **Examine、耀聖一張都不長**
（2026-09-23 實跑，`.scratch/prelaunch-audit-2026-09-23/issues/02`）。
她被叫去 Examine 取消 10:00 的號，卻沒有人叫她替 15:00 掛新的號。

原因是掛號那一族「一天一種一張」：那一天已經有一張 Examine（不管屬於哪一段）就不再長。
取消那一族 2026-09-13 已經改成逐段（ADR-0091），掛號那一族沒跟上。

她的兩句話：

- 2026-09-13：「Examine 上是一段登記一筆，不會是一天一筆，只是為了畫面呈現不要那麼多資訊所以才合在一起」
- 2026-09-23（問她同一天兩段 A 類）：**掛兩筆，待辦一張**

## 決定

**掛號那一族（Examine、耀聖）的待辦記得它掛的是哪幾段（`slotIndexes`）。
一段談定了、還沒被任何一張蓋到，才長新的一張；同一次存檔談定的幾段收成同一張。**

- 長不長只在 `domain/taskRules.js` 的 `newRegistrations()`；確認抽屜那一句也走它（ADR-0070）
- 還沒掛（沒勾）的那一張，蓋的段有幾段取消了 → 縮成只剩還要掛的那幾段；全部取消了 → 收掉
- 取消一段時「掛過了沒」問**那一段自己那一張**勾了沒 —— 同一天兩段只掛了一段，取消沒掛的那一段不長「取消 Examine」
- 讀取卡片上一張掛號待辦屬於哪一段，照它的 `slotIndexes`（`domain/todoFlow.js`）
- 沒有 `slotIndexes` 的舊任務當成蓋住整天（`cancelSlotsOf()`，同 ADR-0091）：舊資料存一次一張都不多長

## 後果

- 同一天可以有兩張 Examine（早上掛好的、下午補排還沒掛的）。整天那一張讀取卡片兩張都列
- 段落位置穩得住的前提跟 ADR-0091 一樣：既有的段不移除、新的接在尾巴
- 舊資料上補排的那一段不會長（舊的那一張蓋住整天）—— 2026-09-23 之後長出來的都帶 `slotIndexes`
