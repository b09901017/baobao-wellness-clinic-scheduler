# ADR-0111：未到只能退回簽療程單

日期：2026-09-24
狀態：已接受
延伸：[ADR-0097](./0097-confirming-is-per-slot-too.md)（長按選單的狀態那幾顆問那一段）、
[ADR-0060](./0060-a-row-answers-two-gestures.md)（長按是捷徑）
推翻：狀態機第一版（`239f5a7`，2026-08-18）的 `no_show → confirmed / cancelled`。
**那一條從來沒有 ADR，也找不到她說過的話** —— 測試名只寫著「未到可以改回已確認 —— 只有已完成是鎖死的」。
也推翻 ADR-0097 的 issue 14 那一層「整筆也要准」的交集（理由見下）。

## 背景

她 2026-09-24：

> 在日曆那邊，我忘記我怎麼操作的，但是有時候未到的我長按，竟然可以把他變成客人以同意？

「有時候」的一半是那一層交集：整天都未到時兩層都准 → 長出「客戶說可以」；那天有人做了一段
（整筆已完成）就被擋。另一半在 `.scratch/asks-2026-09-24/issues/01`（沒有自己 status 的舊資料，
改一段整天跟著變）。

問她未到之後還該有哪條路，她說：

> 未到可以改成退回簽療程單之類的，或可以改成其實有到這樣

## 決定

- `TRANSITIONS.no_show = ['confirmed']`。**`no_show → cancelled` 拿掉** —— 人沒來是已經發生的事；
  真的要取消（她記錯了、那天其實是客人打來取消的），先退回再取消。
- 長按未到的那一段只有一顆：**「退回簽療程單」**（id `reopen`）。寫進去的是那一段 `confirmed`、
  `attended` 清成 `null`；那一天回到簽療程單的清單上，「其實有到」在那裡打勾（ADR-0025：
  已完成／未到是逐段的結果，只在那張抽屜上記）。它**不叫「客戶說可以」** —— 那是給還沒問過客人的段的。
- 長按選單**每一顆都問那一段自己的狀態**：待確認 → 客戶說可以；未到 → 退回簽療程單；
  開著（待確認／已確認）而且日子到了 → 去簽療程單；開著 → 改這一段、取消這一段；
  已完成、已取消 → 一顆都沒有。
- 批次取消（`cancellableSlots()`）只給開著的段。

## 為什麼整筆那一層交集可以拿掉

ADR-0097 issue 14 加那一層，擋的是「客人做了一段就走的那一天（整筆已完成），長按沒做的那一段按
『客戶說可以』，已完成的那一天被退回已確認、不用填更正理由」。現在那一段唯一的一顆是「退回簽療程單」，
**只動它自己**：已完成那一段原封不動、照樣鎖著（鎖也改成問那一段，同一輪的 issue 03）、次數照樣扣著。
整筆被推回「已確認」是推導的結果（有一段又開著了），不是把已完成那一段改掉。

## 後果

- 按錯未到之後的回頭路從「客戶說可以」換成「退回簽療程單」→ 再到簽療程單打勾，多一步，但兩步都在講真話
- 一段未到的那一天不會再出現在批次取消的清單上
- 未到那一段長按不再有「改這一段」（它已經結案了；要改先退回）
