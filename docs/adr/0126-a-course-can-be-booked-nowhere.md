# ADR-0126：一門課可以哪個系統都不用壓

日期：2026-10-06
狀態：已接受
推翻：[ADR-0119](./0119-a-course-ticks-its-own-systems.md) 的那一句驗證「Abovee 與 Examine 至少勾一個 —— 壓表一定要有一個地方」。
延伸：[ADR-0041](./0041-the-sheet-is-the-registration.md)（壓表就是登記；認不得的課照舊猜 Abovee）、
[ADR-0091](./0091-a-cancel-task-knows-which-slots.md)（取消逐段）、[ADR-0121](./0121-a-course-can-be-uncounted.md)（不算次數）。舊的一個字都不改。

## 背景

ADR-0119 讓每一門課自己勾壓哪幾個系統，但留了一條驗證：三個都不勾存不下去。當時的理由是
「一門哪裡都不壓的課不存在」，所以 `systemsOf()` 把空的 `systems` 當成「沒勾過」退回類別去推，
推不出來就猜 Abovee。

她 2026-10-06：

> HRV也是不算次數的，通常會是我想邀客戶來體驗送的，就會讓他當天做完HRV後然後接著功醫門診聽報告

問她 HRV 是不是三個系統都不用壓，她回：

> 問題 6：目前先皆不用壓，不用指派診間或人員…

Abovee 上沒有 HRV 這門課（她 10/5 給的清單）。硬勾 Abovee 的話：取消一段 HRV 會長一張假的「取消 Abovee」；
待辦中心「壓表登記」把它算成要壓；存檔前照樣問「在 Abovee 壓好了嗎」。

## 決定

**`course.systems` 是明確的空陣列（`[]`）＝這門課哪個系統都不用壓。** 設定頁就是三個勾都不勾。

「沒有那一格」與「空陣列」是兩件事，而且分得出來：

| `course.systems` | 意思 | `systemsOf()` |
|---|---|---|
| 沒有這一格（`undefined`／`null`） | 2026-10-05 以前的舊課程，沒勾過 | 照類別推（ADR-0119，不變） |
| `[]` | 她說不用壓 | `[]` |
| 找不到這門課 | 不知道 | `null`（ADR-0119，不變） |

推導照舊只在 `domain/taskRules.js`：

- `bookingSystemOf(course)`：不用壓的課回 **`null`**。認不得的課照舊猜 Abovee
- `tasksForCourse(course)`：`[]`
- `describeSystems(course)`：`不用壓`

驗證改成：**要嘛一個都不勾，要嘛 Abovee／Examine 至少一個。** 只勾耀聖照舊擋 ——
耀聖只收確認之後的登記，沒有地方壓表卻有確認後的登記講不通。

## 「不用壓」與「不知道」往不同的方向倒

ADR-0119 寫了「找不到這門課」時兩個呼叫端要往相反的方向倒。現在是三種：

| | 取消時（`cancelTasksFor()`、`bookingSystemsForVisit()`） | 待辦中心「壓表登記」（`customersToBook()`） |
|---|---|---|
| 壓在某個系統 | 收那個系統 | 那一區有她；這個月壓過就沒有 |
| **找不到這門課** | **猜 Abovee**（那筆來訪存在就代表壓過了，ADR-0041） | 那一段不算壓過 |
| **不用壓** | **不長**（它沒有壓過，沒有東西要放掉） | 那一筆額度不算要壓；那一段也不算壓過任何系統 |

「猜 Abovee」是給**認不得**的課的，不是給她明講不用壓的。把兩個混在一起的話，
要嘛 HRV 取消時長假的待辦，要嘛主檔被刪掉的那幾筆從此不長取消待辦 —— 後者正是 ADR-0041 要補的洞。

## 存檔前那一道確認

那一道問的是「已經在 X 壓好表了嗎？」。兩件事一起改（`consequences.js`）：

1. **只看這一次新加的那幾段**（`bookingSystemLabel()` 多收一個「第幾段」）。以前看那一天的每一段：
   她先排了功醫門診、再併一段 HRV 進去，抬頭照樣問 Abovee —— 而那正是她說的典型用法
2. **新加的每一段都不用壓 → 換一個抬頭**（「記錄這一段？」）、確認鈕從「已確認，記錄」換成「記錄」。
   沒有東西要她先去壓，問「壓好了嗎」是一句沒有答案的話。底下那幾行後果照講（記到日曆、待確認、不算次數）

抬頭與確認鈕的字都由 `bookingConsequences()` 回，壓表與來訪編輯器兩個入口不自己寫死。
改期那一道（`rebookConsequences()`）同樣：新那一段不用壓時抬頭是「改到新的時間？」。

## 為什麼沒有遷移、既有資料會不會被誤讀

`systems: []` 在這之前**存不下去**（驗證擋）、種子每一門都非空、資料健檢補的是種子的值 ——
既有資料庫上沒有任何一筆空陣列會被重新解讀成「不用壓」。

## 她手滑把三個都取消掉

存得下去，而那門課從此不長取消待辦、不問壓好了嗎。**不另外跳確認框**（同 ADR-0114：少一句她不會看的話）；
設定 → 課程 清單那一行灰字寫「不用壓」，編輯表那一排的 `?` 講一句。新課程的空白表單預設勾著 Abovee，
不會因為沒碰那一排就變成不用壓。

## 後果

- HRV（種子在 2026-10-06 那一輪的 issue 03 補）排得進去、取消得掉，一張壓表類的待辦都不長
- `bookingSystemOf()` 的回傳值多了 `null`。**新增一個呼叫端要接得住** —— 那一句「在 X 壓好了嗎」、
  那一張「取消 X」、「壓表登記」那一格都不可以印出 `null`
- 拍 Abovee 的「app 有、這次照片上沒有」（ADR-0129）靠 `bookingSystemOf(course) === 'Abovee'` 決定哪幾段該在照片上 ——
  不用壓的課不會被喊「沒拍到」
