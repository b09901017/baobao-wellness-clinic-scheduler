# ADR-0141：人員的顯示名是全名、多一格簡寫；全名跟著合併檔進來

日期：2026-10-09
狀態：已接受
推翻：`SPEC.md`「治療師與醫師」那一段與 `calendar-sheet-merge` 的 `SKILL.md` 寫的「她想記全名就填在『Abovee 上的寫法』，**顯示名不要改** —— 合併檔靠顯示名對人」

延伸：[ADR-0079](./0079-the-equipment-decides-who-and-the-rooms-have-no-four.md)（診間的全名與簡寫，照它的做法）、

## 背景

10/8 上線前健檢她的回答：

> ・人員的全名要怎麼放？ → 人員多一格「簡寫」，顯示改成全名、簡寫照你設定｜我最希望的是顯示名是全名，人員多一格簡寫，並且要有一支小工具可以幫我先預設好所有人的簡寫(就是現在的顯示名)以及把 21 位全名一次填進 staging 和正式站的「Abovee 上的寫法」，但是可以匯入合併檔或是載入種子資料的時候一並更新上去，就是不知道能不能不要寫進公開的程式碼，但是可以放入資料庫之類的，或是放在合併檔一起匯入也可以

她在健檢時問的：

> 醫師的名字為什麼只有一個字？我都給了完整的清單，拍照不是應該預設就認得嗎？

repo 是 public，所以種子只放她口述的叫法（醫師的姓、治療師的名字）。人員主檔沒有簡寫這一格（診間、器材、課程、品項都有）。
直接把顯示名改成全名的話：合併檔匯入拿名字一字不差去對 → 58 段的治療師或醫師留空；拍 Abovee「差一個字也算」只比 `aboveeNames` → 全名抄錯一個字就一位都不認。

## 決定

### 一、主檔：`name` 是全名，`shortName` 是簡寫（選填）

- 沒填簡寫就印全名（`naming.js` 的 `nameOf()` 本來就這樣退回）。
- **整份人員一起比、不分角色**：簡寫不可以跟別人的簡寫或全名一樣，全名也不可以是別人的簡寫（`validators.staff()`）。
  合併檔匯入靠簡寫認出「這一位」，連他是醫師還是治療師都是從認到的那一筆讀的 —— 分角色比的話一位醫師與一位治療師可以同一個簡寫，匯入就分不出來。
- 種子一個字都不改：種子的 `name` 就是她口述的叫法，改名之後它變成那一位的簡寫。

### 二、哪裡印哪一個（照診間那一套）

| 印簡寫 | 印全名 |
|---|---|
| 日／週那一列（含那一列的撞期句）、讀取卡片、試算表的 `二返(…)` 與 n返 括號裡的醫師 | 其餘全部：三個入口的丸子、撞期與錯誤訊息、確認框、壓表、拍 Abovee、批次取消、設定頁、試算表來訪紀錄、稽核 |

取名字只走 `nameOf(row, 'short')` 與 `fullNameOf(row)`，掃原始碼的測試（`tests/staff-short-name.test.js`）盯著沒有人再從人員那一筆直接讀 `.name`。
來訪只存 `therapistId`／`doctorId`，沒有人名的快照 —— 改名之後日曆、試算表、稽核全部跟著變。

### 三、比對：改名之後每一條都還認得

- 拍 Abovee（`staffFrom()`）：Abovee 上的寫法 → **全名一模一樣** → 「醫師看開頭、治療師看結尾」改拿**簡寫**問 → 知道角色時全名或寫法差一個字。
  「只有一位符合才算」不變。
- 資料健檢「治療師與醫師少了幾位」：她主檔上那一位的簡寫等於種子的名字 → 同一位，不建、不列。
- 合併檔匯入（`resolveAssignments()`）：名字對不到時比簡寫，**剛好一位**才算。所以「先改名再匯」「先匯再改名」「匯到一半重試」三種順序都對得到。

### 四、全名怎麼進資料庫：跟著合併檔，不寫直接打資料庫的工具

全名只活在 `.local/references/staff-names.json`（不進版控），`merge.mjs --staff-names` 把它帶進合併檔的 `staff` 那一段（`baobao-merge/v6`）。
匯入頁用 app 自己的寫入路改主檔（有驗證、有稽核），**staging 與正式站是同一個動作**。她要的「先看不寫」＝匯入頁的摘要卡，在按「開始匯入」之前就列出會改哪幾位。

不選「直接打資料庫的小工具」：要正式站的金鑰，而且多一條「漏打 `--project` 就上正式」的指令（lessons 九）；合併檔本來就只在 `.local/`、本來就有真名。

## 代價

- 切換那天產檔要記得帶 `--staff-names`。忘了的話事後再貼一次帶名單的檔就好（客戶全部同名跳過、只剩人員要改時「開始匯入」照樣按得下去）。
  **那一趟只改人員、不寫雜事**（2026-10-09 審查補的）：那份檔案的行事備註、休假、待辦預設又全部勾著，而它們上一次就寫進去了 ——
  第一版照寫，整份雜事會多一份。確認框與按鈕上面那一句會講「這一趟不寫雜事」。
- 匯入頁算每一段是誰，拿的是**人員改完之後**的主檔（人員是先寫的）。拿改之前的算的話，她自己先打了全名、還沒填簡寫的那一位
  對不到檔案上寫的原本那個名字，那一段的治療師留空 —— 「先改名還是先匯哪個順序都對得到」就少了這一種（同一次審查補的）。
- 之後新進的人沒有這條路：她在 設定 → 治療師與醫師 自己打全名與簡寫。
