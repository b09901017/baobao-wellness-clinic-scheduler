# ADR-0080：點一段，讀取卡片就只畫那一段

日期：2026-09-08
狀態：已接受
延伸：ADR-0018（四個畫面共用一支讀取卡片）、ADR-0020（先給看的再給改的）

## 背景

她 2026-09-08：

> 我如果同一天建立客戶A INDIBA以及ILIB…我在日曆點開詳情的時候，
> 為甚麼我點的是復能(INDIBA)，但是卻會一次呈現三個復能(INDIBA)、
> 復能(超磁場)、靜脈(IL)？

排班的原子單位是**來訪**（SPEC 第 4.4 節）：同一位客戶同一天壓第二次時，
壓表那一頁會併進同一筆來訪。所以她眼裡的「三筆」在資料庫上是
**一筆來訪、三個時段**。

日／週檢視那一份清單一直是**一段一列**的，`domain/calendar.js` 的
`agendaFor()` 也一路算出了 `slotIndex` —— 只是畫成按鈕的那一下把它丟掉了：

```js
open: `visit:${r.visitId}`,          // ← 只有 visitId
```

**這不是資料壞掉，是那一下把「我點的是哪一段」丟掉了。**

## 決定

**一、`data-open` 帶上是哪一段，四個接線的地方走同一支 `parseOpen()`。**

```
note:<id>           event:<id>           visit:<id>:<第幾段>
```

四個地方會拆這個字串（抽屜點一下、抽屜長按、週／日點一下、週／日長按），
所以拆法只有一支 —— 四份 `split(':')` 遲早有一份忘了取第三格，而症狀就是
這個 bug 又長回來。有一支測試盯著「沒有人自己 split」。

**二、「畫哪幾段」是一條規則，寫在 domain。**

`domain/visits.js` 的 `slotsToShow(visit, focusSlot)`。兩條刻意的退路：

- **沒指定就是全部。** `undefined` 是「沒有人告訴我是哪一段」，不是「第 0 段」
  —— 另外三頁（客戶詳情、待辦中心、進度追蹤）列的本來就是整筆來訪，
  它們一個字都不用改。
- **指到一個不存在的段落也退回全部。** 畫成空白的話她會以為那一筆壞了，
  而畫太多只是回到修好之前的樣子。兩種錯法的代價差很多。

**三、卡片底下留一條看得到的路。**

「這一天還有另外 2 段 —— 看全部」。按了就地重畫（`card.update()`），
不重開一張卡 —— `openCard()` 第一行就是 `closeCard()`，重開等於畫面閃一下
（ADR-0073 為那個閃爍付過帳）。

少了那一行，這個修法會從「看太多」變成「看不到」：「這天他還來做什麼」
是她會問的問題。

**四、長按那一列時，選單抬頭講清楚底下那幾顆動的是整筆。**

她長按的是一列，但「取消這一筆」取消的是那一天全部（來訪的狀態是整筆的）。
只在真的不只一段時才講 —— 每一次都寫「共 1 段」等於把那一行變成裝飾。

**五、月檢視也改成一段一條色條。**

以前是一筆一條、只印第一段的名字 —— 她那天做了 INDIBA、SIS 與 ILIB，
月檢視上只看得到 `IN(30)`。改成 `domain/calendar.js` 的 `monthBars()`：
id 一段一個（`layoutMonth()` 拿它當 key），順序照那一段的開始時間
（`domain/events.js` 新增的 `sortKey` 那一層）。

`visitNames()` 的去重在這裡**刻意不用**：同一天兩段點滴就是兩條，
那正是她要看到的。那一支留給 LINE 草稿，在那裡去重仍然是對的。

## 為什麼

**ADR-0018 沒有被推翻。** 讀取卡片仍然是四個畫面共用的同一支 ——
多了一個選填參數，沒帶就照舊。另外三頁列的是整筆來訪，它們是對的。

**規則寫在 domain 才測得到，也才只有一份。** 「畫哪幾段」如果寫在
`visitReadHtml()` 裡面，那四個呼叫端就各自有機會傳錯。

## 後果

- 日／週那一列的 `data-open` 從兩格變三格，既有的 E2E 選擇器要改成前綴比對。
- `layoutMonth()` 的 `maxLanes` 是 3：一天三段再加一件待辦，第四件會收進
  「+1」。她知道並且選了。**不要順手把 lane 加到 4** —— 那一格的高度是
  整個月檢視的版面基準。
- 全站掃過一次，一列一段卻給整筆的**只有日／週檢視這一處**：客戶詳情的
  來訪紀錄、待辦中心的「詳情」、進度追蹤那三頁列的都是整筆來訪。

## 其他做法

**點一列就只畫那一段，不給「看全部」。** 她同一天真的排了三段，而
「這天他還來做什麼」是她會問的問題 —— 那會把問題從「看太多」換成「看不到」。

**把同一天的第二筆壓成另一筆來訪（不併）。** 那會推翻 SPEC 第 4.4 節，
而且「一天一筆來訪」是狀態、療程單、待辦全部掛著的那一層。
