# ADR-0175：試算表的版面 —— 前五欄凍結、器材與記一句不再多一列、備註上色

日期：2026-11-05
狀態：已接受
延伸：[ADR-0024](./0024-the-sheet-mirrors-her-old-one.md)（照抄她舊表的骨架：療程項目 × 日期的矩陣、TODO 在 A 欄、FINISHED 在 K 欄 —— 骨架照舊）、[ADR-0161](./0161-sheet-remembers-fingerprints.md)（`LAYOUT_VERSION` 加一，部署後每一頁重畫一次）
推翻：ADR-0096 的「記在當天那一列的下面」—— 記一句改成那一格的附註

## 背景

試算表推送變快之後（`.scratch/sheet-push-gaps` 第二輪），她 11/5 晚看著真的那一份說了六點（截圖有真名，不收進來）：
日期被擠到第二行、應有～剩餘跟日期分不開、療程項目沒有順序、營養品不知道怎麼放、備註想分行上色、
以及「有點資訊疲勞，認知過載，但也說不上來哪裡可以改」。主控畫了示意圖（`.scratch/sheet-push-gaps/mock-layout-2026-11-05.html`，假資料），
她改了幾點之後「都照建議」。逐點的原話與做法在 issue 08～12。

## 決定

1. **應有～剩餘跟日期分開**：那四欄淡灰底、表頭淺一階、剩餘右邊一條粗線；**前五欄凍結**（往右捲日期時療程名字與次數一直在左邊）。
   凍結線不能穿過合併儲存格，所以**所有合併都停在第五欄（剩餘）以內**：最上面幾列與下面「買過什麼」「營養品」「備註」「來訪紀錄」
   每一行只合併到剩餘那一欄，長的折行、那一列跟著長高。
2. **器材併進那一格**（「✓ IN」），**記一句改成那一格的附註**（Google 試算表的「附註」，右上角小黑三角，滑過／點一下才看得到）—— 矩陣不再夾註記列。
   資料（`equipmentNotes`／`slotNotes` 的 `rowIndex`＋`dateIndex`）一個字都沒變，`.gs` 畫的時候併。
3. **每一位的療程項目照「已完成＋已排未上」多到少排**，一樣多的照原本的先後；沒有額度的那幾列（n返、送的／體驗、額度被刪的）照舊在最下面。
   **在 `.gs` 排、不在 `syncBundle()` 排**：只是畫的順序，月底對帳照 `syncBundle()` 的列順序對額度，兩邊都不用動。
4. **營養品一筆一行**（像「買過什麼」），沒給完的那一行淡黃；**備註一則一列**，用她在 app 裡替那則短備註挑的顏色（淡色版），永久限制那一行淡紅。
   顏色要知道每一則短備註挑的是哪一色 —— 每一頁多送一份 `noteLines`（`notes` 照舊送）；`.gs` 沒拿到就照 `notes` 一行一列、淡灰。
5. 其餘：日期欄 58 → 78、格線藏起來、名字 14 → 18 號、抬頭的病歷號只寫號碼、待辦區的日期寫成文字（不讓 Google 認成日期格）。
6. **不升 `SYNC_FORMAT`**：新舊兩邊都合得來（新的 `.gs` 收舊的包照畫、舊的 `.gs` 不讀 `noteLines`）。`LAYOUT_VERSION` 3 → 4。

## 為什麼

- **凍結而不是只畫粗線**：她要的是「另外前五欄凍結」；只畫線的話日期一多往右捲，療程名字就不見了，又回到要往回捲對列的老問題。
  代價是下面那幾塊只剩約 440 像素寬、長的一行要折成兩三行 —— 那幾塊是「往下看」的，不是「往右看」的。
- **註記列拿掉**：ADR-0096 時記一句很少，夾一列在額度底下是最不會漏看的放法；現在幾乎每位都有，夾列讓一位的矩陣高一倍，
  而她那一句通常只在對帳時要看。備註收得起來、看得到有（小黑三角），點了就是全文。器材那一列同理：一格只差兩三個字，併進去就好。
- **每位各自排而不是固定順序**：她自己說「每個人長排的課程也不同」—— 固定順序的話，有人最常做的那一門會被排到第七列。

## 沒有選的

- **改 `syncBundle()` 的列順序**：一次性客人那一輪也改它，月底對帳也照它的順序對額度 —— 改了兩邊都要跟、還要想要不要升格式。
- **器材與記一句另開一欄**：日期欄是她看習慣的骨架（ADR-0024），多一欄就是每一天多一欄。
- **整頁改用 Sheets API 一個請求畫**（估整份重畫 125 秒 → 30～40 秒）：版面先定，之後要改寫只要寫一次。
