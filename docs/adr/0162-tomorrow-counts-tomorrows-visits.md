# ADR-0162：「明天」也算明天還開著的那幾天（點下去開讀取卡片，不開簽單抽屜）

日期：2026-10-19
狀態：已接受
推翻：[ADR-0152](./0152-today-counts-close-and-dated-notes.md) 決定 1 的「明天＝……（明天的來訪還簽不了）」那一格。ADR-0152 其餘照舊。

## 背景

ADR-0152 讓「今天」算進今天要簽的療程單，「明天」刻意不算 —— 明天的來訪還簽不了。她 10/19 問「明天」為什麼沒有簽療程單，聽完理由之後：

> 但我想要今天和明天是一樣的誒，就是納入簽療程單和綁明天的日曆待辦，綁明天的日曆待辦，確實已包含了但是沒有簽療程單誒?
> ……也想請你幫我修復明天次數納入簽療程單這點

她要的是「明天有什麼要做」這個數字跟今天長得一樣；ADR-0152 擋的是「明天的被簽掉」，那一半照樣要擋。問她點下去去哪：

> 可以，確實不能開簽療程單的抽屜，免得還沒做就被簽成做完

## 決定

1. 「明天」那一格多一塊：**明天還開著（待確認／已確認、還有段開著）的那幾天**，一位一天一件 —— 同今天那一塊的切法，
   只在 `domain/visits.js` 的 `visitsComingTomorrow()`（跟 `visitsToClose()` 共用一段身體，只換日子）。
2. 它放在 `todoBuckets()` 的 **`coming`**，不放 `close`：簽療程單那一列、簽療程單那一頁、抽屜照舊只讀 `visitsToClose()`（`date <= today`）。
3. 點下去開**讀取卡片**（待辦中心本來就有的那一張，只給看），不帶到簽療程單那一頁、不開抽屜。
4. 讀的那一側：`data/visits.js` 的 `listUnclosed(today, { tomorrow: true })` 多撈一天，**只給三顆大數字那兩處**（首頁、點進去那三頁）；
   簽療程單那一頁照舊 `listUnclosed(today)`。多撈的那一天拿去簽的地方都還過一次 `visitsToClose()`，所以就算傳錯也簽不到明天的。

## 沒有選的

- **明天的放進 `close`、在畫面上擋**：`close` 那一塊點下去就是開抽屜，擋在畫面上等於兩條路各擋一次，漏一條就是她說的「還沒做就被簽成做完」。
- **把 `visitsToClose()` 的閘門放寬到明天**：它同時是簽療程單那一列與抽屜的名單。
