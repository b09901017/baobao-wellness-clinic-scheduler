# ADR-0151：待辦首頁畫哪幾列由她選 —— 一直顯示／有才顯示／不顯示

日期：2026-10-18
狀態：已接受
延伸：[ADR-0043](./0043-the-todo-centre-follows-the-flow.md)（照流程分段）、[ADR-0072](./0072-a-row-on-the-todo-centre-is-only-a-title.md)（一列只有標題與數字）、
[ADR-0028](./0028-asking-for-times-is-a-todo-row-not-a-queue.md)、[ADR-0041](./0041-the-sheet-is-the-registration.md)（提醒不是任務）。舊的一個字都不改。

## 背景

首頁的每一列都是「有東西才畫」：任務種類那幾列從還沒做的任務收集出來，全部做完那一種就不在了；
「問這輪的時間」「壓表登記」那兩列身上永遠有人。她 10/18：

> 問時間和壓表現在不是我必須做的事……有時候會覺得首頁這樣太多東西了，資訊過載了……
> 寫紀錄，追蹤健檢報告等等那些所有人都做完了，這個區塊就會消失，這樣我就沒有入口可以去把這個待辦已完成的人勾回未完成……
> 所以可能就可以設定，長期顯示，有人再顯示，都不顯示等等

點進去那一頁（`#/todo/<種類>`）本來就有「已完成」分頁可以勾回來 —— 少的只是首頁上那一個入口。

## 決定

1. **每一列三種**：一直顯示／有才顯示（以前的行為）／不顯示。名單是 `domain/todoFlow.js` 的 `HOME_ROWS`，順序就是 `FLOW`（她做事的順序）：
   問這輪的時間、客戶填好的時間、壓表登記、跟客人確認時間、Examine、耀聖、簽療程單、寫紀錄、追蹤健檢報告、寄報告給醫師、約二返、改時間／取消。
2. **預設**：問這輪的時間、壓表登記＝不顯示；其餘＝有才顯示。
3. 一列畫不畫、畫成什麼樣只問 `rowView()`：一直顯示而 0 件 → 淡的一列、數字寫 0（壓表登記照舊沒有數字），照樣點得進去；它不算「下一步」。
4. **三顆大數字照算藏起來的**（她：「藏起來的是那一列，不是那件事；點『逾期』看得到」）。「依客戶」那一頁不受影響。
5. 不顯示的那三列（問時間、客戶填好的時間、壓表登記）**連資料都不讀**（`homeLoaders()`）—— 各多讀三四份，而首頁她一天開十幾次。
6. 設定存在 `config/app` 的 `todoRows`（手機與 iPad 同一份、有稽核），**只存跟預設不一樣的**（`storedRowShows()`，同 `messageTemplates`）。
   畫面在 設定 → 待辦首頁，總覽最底下一行小字「調整顯示哪幾列」連過去。
7. 已經拿掉的種類（打電話、Abovee）與她手動加的種類**不給設定**：有舊資料就照舊畫在那一段最後面，等於永遠有才顯示。

## 沒有選的

- **存在這一台裝置上（localStorage）**：她手機與 iPad 都在用，一台藏了另一台沒藏，她會以為那件事不見了。
- **藏起來的不算進三顆數字**：數字跟點進去那一頁會差幾件（ADR-0070 那一種），而她要的只是首頁少幾列。
- **只做兩種（顯示／不顯示）**：「顯示」要嘛永遠有那幾列空的 0，要嘛回到「做完就沒入口」—— 她要的正是兩種都能挑。
