# ADR-0152：今天／明天算進簽療程單與有日期的隨手記，逾期算進前幾天沒簽完的

日期：2026-10-18
狀態：已接受
延伸：[ADR-0044](./0044-a-dated-note-goes-on-the-calendar.md)（有日期的隨手記上日曆）、[ADR-0001](./0001-scheduling-queue-state-is-derived.md)（簽療程單是推導的）、
[ADR-0110](./0110-both-todo-drawers-decide-some-slots.md)（簽療程單三態）、[ADR-0059](./0059-a-supplement-purchase-is-one-record-handed-over-once.md)（營養品的提醒是一筆隨手記）。
**ADR-0044 那張表「過了會怎樣」那一格的「不進任何數字」由這一支補一句**：過了照舊不進任何數字；還沒過、掛今天或明天的進「今天」「明天」。

## 背景

首頁三顆大數字只數 `tasks`（系統長出來、有死線的任務）。簽療程單是從來訪推導的、不是任務（ADR-0001），
日曆上的待辦是有日期的隨手記（ADR-0044）—— 兩種都不在裡面。她 10/18：

> 待辦首頁那邊"今天，明天"的數字為甚麼沒有包含到簽療程單，這不是今天要做的事嗎，還有像是在日曆綁定當天的todo，好像都沒算進去？
> 希望也可以算進去這樣我點他就知道今天，明天有麼要做，然後如果在日曆綁定當天的todo今天沒勾也沒關係，他不算逾期

前幾天沒簽完的療程單她選「算逾期」。

## 決定

1. 三格的組成只寫在 `domain/todoFlow.js` 的 `todoBuckets()`，**首頁的數字與點進去那一頁的清單讀同一支**：
   - 逾期＝死線過了的任務＋日子過了、還有段開著的簽療程單（`visitsToClose()`，一位一天一件）
   - 今天＝死線今天的任務＋今天的簽療程單＋掛今天、還沒勾的隨手記
   - 明天＝死線明天的任務＋掛明天、還沒勾的隨手記（明天的來訪還簽不了）
2. **有日期的隨手記過了不進任何一格**。ADR-0044 擋的是「它變成紅字逾期」，她要的是「進今天／明天、不進逾期」—— 兩件不衝突。
3. 營養品的提醒也是有日期的隨手記，所以它也進今天／明天（那天要交付）；勾它照舊走 `note.prepareToggle()`，先問給了哪些。
4. 點進去那一頁分三塊：待辦／簽療程單／隨手記，空的不畫；簽療程單那一列帶到 `#/todo/close` 並開那一天的抽屜（`leaveFor()`），
   不在這一頁開抽屜。「已完成」那一格照舊只有任務。
5. 跟客人確認時間**不算進去**：它沒有日子，首頁那一列自己有數字。「依客戶」那一頁的數字不動。

## 沒有選的

- **前幾天沒簽完的算今天**：她選了逾期 —— 那一天已經過了，留在今天會讓「今天」永遠歸不了零。
- **隨手記過了也進逾期**：她明講不要。
- **在三頁裡直接開簽療程單的抽屜**：那一張抽屜跟著簽療程單那一頁的 ctx 重畫，搬一份過來就是兩份會長得不一樣的抽屜。
