# ADR-0182：拍照畫面出不來就照舊黑著，不換頁

日期：2026-11-08
狀態：已接受
推翻：[ADR-0173](./0173-camera-shows-only-a-real-picture-and-sign-in-loads-google-on-tap.md) 的「拍照：有影像才算開好，沒有就退回」那一半。登入那一半照舊。

## 背景

ADR-0173 之後，她 iPad 主畫面那一顆打開拍照，幾秒後換成「相機開了，但畫面一直出不來」那一頁；再補「點這裡開取景」（手指按下去那一刻才播）也一樣。
那一頁最下面那一行（11/8 她截圖）是：主畫面、相機開著（480×640）、影片一格都沒收到、`play()` 一直沒回 —— 相機在送，播放器收不到，不是被擋。
那一刻 iPad 上另有 app 在用麥克風（右上角的橘色標誌），是不是原因沒有驗證。

她 2026-11-08：

> 會不會手機也可能某一次壞掉就不能了，我覺得就維持最之前那樣子好了畫面黑就黑，下面還是可以點系統相機就不要有那個等三秒換頁面了，就之前那樣就好

## 決定

拍照那一層回到 ADR-0173 之前的樣子：拿到相機、`play()` 回了才顯示取景；沒回就一直黑著，**不換頁、不再要第二次相機、沒有「點這裡開取景」、沒有那一行狀態**。底下那一排（相簿、快門、系統相機）本來就一直在。
只多留一件：**畫面還沒出來時快門不拍**，講一句「畫面還沒出來，改按右邊的『系統相機』拍」—— 不然截出來的是一張黑的，送去辨識只是白花一次。

## 為什麼

- 「失敗過一次就記住、以後直接退回」會讓一台平常好好的手機因為某一次卡住就再也看不到取景（她擔心的就是這個）；「等幾秒換一頁」在她 iPad 上又沒救到東西，只是多一頁
- 系統相機在她 iPad 上拍得起來，黑著的時候底下那一顆就是出路

## 後果

- iPad 主畫面那一顆照舊看不到取景，用系統相機拍；原因不知道（可能是 iPad 主畫面模式本身，也可能跟當時別的 app 在用麥克風有關）
