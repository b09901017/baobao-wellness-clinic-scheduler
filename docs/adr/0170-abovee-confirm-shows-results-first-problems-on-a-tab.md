# ADR-0170：拍 Abovee 辨識完先一眼看完 ——「辨識結果」只有列與短標記，「發現問題 N」才講為什麼

日期：2026-11-03
狀態：已接受
推翻（只限拍 Abovee 的確認層；舊的一個字都不改，舊的那幾支「狀態：」那一行也不加註記 —— 慣例見 `docs/agents/domain.md`）：

- [ADR-0138](./0138-abovee-warnings-show-on-collapsed-rows.md) 決定第 4 點（收著的那一行畫前兩句＋「還有 N 句」）：收著的列改成一個短標記，整句搬到「發現問題」那一頁與點開的那一列。
  第 1、2、3、5 點不變（哪幾種算「不點開也要看得到」只寫在 `mustSee()`、照來源分、每一列只畫自己的、存檔前那一道講「其中 N 段有提醒」）
- [ADR-0129](./0129-abovee-photo-checks-what-is-missing.md)「畫面」那一段最後一句（沒有多出來的段時只留那一行「對過 …」）：沒有就不畫

延伸：[ADR-0153](./0153-abovee-absent-checks-people-on-photo.md)（「照片上的 ○○ 還沒認出是誰，先沒對」那一句放在哪）、
[ADR-0104](./0104-many-slots-from-one-photo.md)（確認層就是第一道、存檔前只問一次 —— 不變）、
[ADR-0074](./0074-a-contraindication-warns-it-does-not-block.md)（禁忌只提醒不擋 —— 不變）。

## 背景

確認層一次把所有東西攤在同一頁：照片 → 兩張怎麼對上的那一句 → 「要改的」→「要你看」→「日子過了還沒結案」→
「app 有、這次照片上沒有」（**沒有的時候也有一句**「對過 … 都在這次的照片上」）→ 一天一塊。每一列底下還有好幾行提示
（還差一步、ADR-0138 收著也畫的那一兩行紅字、為什麼沒先勾、名字差一個字、讀不到全部來訪 …）。她 2026-11-03：

> 能不能不要上面那段話，像是"對過 11/2 09:30–11/4 10:00 每一位在 app 上的段：都在這次的照片上。"，
> 我知道拍完照辨識後會有要檢查以及提出不同或是需要看的地方，但是有點會讓板面太亂，讓我認知負荷過載，
> 我在想能不能有一個切換功能，像是首頁那個總覽/依客戶那樣，在照片下方可以切換 …
> 就是那健檢出來，"要你看"，不一樣等等怪怪的地方，能不能切換之後才看到，
> 然後我剛拍完照辨識完我希望出現的畫面就是如圖那樣，不要有說明文字

我提的方案（「全部」／「要你看 N」、列上只留一個紅點）她回：

> 「全部」/「要你看 N」我希望名稱改寫「辨識結果」/「發現問題N」
>
> 你說「全部」裡那一列不寫字，只留一個紅色小點，我覺得一樣可以有提醒，簡短的，像是⚠ 撞期 ⚠ 次數不夠⚠ 禁忌 +1⚠ 過期⚠ 品項⚠ 重疊⚠ 健檢等等，
> 一列有好幾個提醒時，只寫最要緊的那一個，後面接「+1」字是紅的、短的，掃過去一眼就看得到，又不會像現在一樣每列底下多一兩行

先後我回她「禁忌 → 次數不夠 → 撞期 → 重疊 → 過期 → 品項 → 健檢」，她接受。

## 決定

### 一、照片底下一個切換，兩頁只畫目前那一頁

樣子照首頁的「總覽／依客戶」（`.seg`）。**不進網址**（看法不是位置）、不推一層；預設「辨識結果」。
**只畫目前那一頁**：兩頁同時在畫面上的話，同一列會出現兩次（`data-abl-row` 重複，換一位、點開、重畫都只認得第一份）。
抬頭那一行（「新的 N 段・已經記了 N 段 …」）與底下那一條（「勾起來的有 N 段還差一步，點開補上」）兩頁都在 —— 她沒劃掉。

### 二、「辨識結果」：一天一塊、每一列都在、一行說明都沒有

- **每一列都在它那一天**，連「要你看」的那幾列也回到它那一天（時間前面不用再印日期）
- 列上那一行：時間、名字、課程＋治療師／醫師／診間、小標（新的、已經記了 …）、**紅字短標記**（見三）
- **不畫任何說明句**：「對過 … 都在這次的照片上」、兩張怎麼對上的那一句、每一列底下的提示行都不畫。
  **點開一列照舊全部看得到**（點開的那一列底下那幾行與點開的那一塊，跟以前一樣）

### 三、紅字短標記：一列一個，最要緊的那一個＋「+N」

**哪幾種有標記**：ADR-0138 那幾種（`mustSee()`：會改變寫入結果的提醒）＋拍 Abovee 自己另外放進「不點開也要看得到」的三種，
再加「還差一步」。不是 `mustSee()` 的（還沒選治療師、二返排在健檢之前 …）**沒有標記**，照舊點開才看。

| 短字 | 從哪裡來 |
|---|---|
| 禁忌 | 器材對客戶的警示（`notice`）、合併扣課另一台的警示 |
| 次數不夠 | 排完會超過總次數（`entitlement` 的超用） |
| 撞期 | 撞到那一天別的來訪（`conflict`） |
| 重疊 | 同一筆裡自己跟自己重疊（`overlap`） |
| 過期 | 排在到期之後（`entitlement` 的到期） |
| 品項 | 品項跟買的不一樣（`ivMismatch`） |
| 健檢 | 健檢不是我排的、其實扣得到或接得上（`examNotMine`）；照片寫課程完成、二返接的健檢還沒做完 |
| 體驗 | Abovee 上寫體驗、這一段照扣 |
| 狀態 | 照片上的預約狀態記成別的（還沒到就寫完成、讀不出來、兩張不一樣 …） |
| 提醒 | 上面都對不到的（**不是不畫** —— 新加一種 `mustSee()` 忘了給短字時，她照樣看得到有事） |
| 還差一步 | 勾著、存不下去（`problems`） |

- **先後就是這張表由上到下**，一列只寫最上面那一個，後面接「+N」
- **N 算種不算句**：兩句撞期是一種；「禁忌」兩個來源算一種。N ＝ 這一列不同的短字有幾個，減掉寫出來的那一個
- 超用與到期以前是同一種來源（`entitlement`），現在那一圈每一句多帶一格 `kind`（`over`／`expired`）分得出兩個字 ——
  不拆成兩種來源（拆的話 `mustSee()` 與每一個比來源的地方都要動）
- 短字與先後**只寫在 domain 一支**（`aboveeImport.js` 的 `warningTag()`）；畫面只畫它回的字，不自己比來源
- 只有會寫進去的列有標記（勾著的、照片要改的那幾件勾著的）—— 同 ADR-0138：沒勾的列不會寫進去

**為什麼這樣還守得住紅線**（`CLAUDE.md`「畫面上一段常駐的說明」：會改變寫入結果的警告不可以收進要點開才看得到的地方）：
紅線要的是「她沒點開也知道這一列有事」。短標記做到這一件：收著的列一定畫得出那個紅字，而且最要緊的那一個寫在上面。
整句一個動作就到（切到「發現問題」或點開那一列），按「記錄」之前那一道確認框照舊把句子列出來（ADR-0138 第 5 點）。

### 四、「發現問題 N」：那一頁有什麼、N 怎麼數

那一頁由上到下：照片層級的問題 → 要改的 → 要你看 → 有提醒的 → 日子過了還沒結案（收著）→ app 有、這次照片上沒有。
列底下那幾行提示照以前的畫法畫（這一頁就是給她讀句子的），時間前面印日期（這一頁不照日期分）。
**「有提醒的」就是辨識結果上有紅字短標記、又不在要你看裡的那幾列**（連「還差一步」）—— 標記與整句一對一：
她在辨識結果看到一個 ⚠，切過來一定找得到那一列的整句。

| 那一頁的一塊 | 算幾件 |
|---|---|
| 照片層級：沒拍到「預約狀態」那一欄、左右兩張列數不一樣、沒有姓名那一欄 | 一種一件 |
| 要改的 | 照列數（同抬頭的「要改 N 段」：收成一行的「補上治療師／診間」照它管的列數算） |
| 要你看、日子過了還沒結案 | 一列一件 |
| 有提醒的（有紅字短標記、不在要你看裡的；「還差一步」也是） | 一列一件 |
| app 有、這次照片上沒有 | 照段數；「照片上的 ○○ 還沒認出是誰，先沒對」（ADR-0153）算一件；沒有對（列不是照時間排、讀不到日期）算一件 |

- **同一列出現在兩塊只算一件**（例：對不上又有治療師要改的那一列，同時在「要改的」與「要你看」）—— N 講的是有幾件事要她看，不是畫了幾行
- **記好了的列不算、也不列**：這一頁是還沒處理的。在這一頁按「記錄」記好之後那幾列就離開這一頁
- 兩張照片正常配上（左右兩半照列的順序對上）**不畫**：那是說明，不是問題
- **0 件時那一顆灰掉、按不下去**：灰掉就是「檢查過了、沒事」—— 所以 ADR-0129 那一句「都在這次的照片上」不用再畫。
  「沒有對」不一樣：那時候 0 件不等於沒事，所以照講、算一件
- 在「發現問題」那一頁時 N 變成 0（最後一件也處理了）→ 回到「辨識結果」
- 數法與那一頁列哪幾件**只在 domain 一支**（`aboveeImport.js`）；畫面照它回的畫，N 就是它算的那一個數

## 沒做的

- **紅點不寫字**（我原本的提案）：她說「一樣可以有提醒，簡短的」—— 一個點分不出是禁忌還是品項，她還是要點開才知道要不要緊
- **要你看的那幾列在辨識結果另外標**：她要的就是「切換之後才看到」；那一頁有幾件寫在那一顆上（「發現問題 3」）
- **整句收進 `tip()` 的小泡泡**：紅線不准（`tests/tip-red-lines.test.js`）

## 後果

- 剛辨識完、什麼事都沒有：畫面上只有照片、切換（「發現問題」灰掉）、一天一塊的列。一句說明都沒有
- 有事的列：辨識結果那一列課程右邊一個紅字（`⚠ 撞期`、`⚠ 禁忌 +1`）；整句要切到「發現問題」或點開
- 壓表、來訪編輯器的提醒畫法不變（ADR-0138 本來就只管拍 Abovee 這一層）
- 測試：`tests/tip-red-lines.test.js`、`tests/abovee-warnings-in-sight.test.js` 改成釘新的保證 ——
  收著的列一定畫得出短標記、整句在「發現問題」與點開之後
