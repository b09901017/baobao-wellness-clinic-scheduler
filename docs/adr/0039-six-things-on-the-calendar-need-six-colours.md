# 日曆上有六種東西要分辨，所以狀態色不再借用語意色

`tokens.css` 原本把來訪狀態做成**別名**，指到既有的語意色：

```css
--visit-pending: var(--soon);      /* 今明黃 */
--visit-confirmed: var(--slate);   /* 霧藍 */
--visit-done: var(--accent);       /* 墨綠 */
--visit-no-show: var(--overdue);   /* 逾期紅 */
```

當時寫下的理由很誠實，而且在當時是對的：

> 刻意做成別名指到既有的語意色 —— 深色模式那邊已經幫它們換過一輪，
> 這裡再抄一份就會有一份忘了改。

## 它是怎麼壞掉的

同一份 `--slate` 還有另一個主人。`app.css`：

```css
.kind-leave { --kind-fg: var(--slate); }   /* 休假 */
```

也就是說，**「休假」與「已確認的來訪」是同一個 `#5b7a8c`，一個像素都不差。**
月檢視上一條霧藍的色條，可能是「這天客人確認要來」，也可能是「這天我不在」——
兩件事的意思完全相反，而畫面上長得一模一樣。

這不是誰決定的。它是「借用語意色」這個作法的算術結果：日曆上要分辨的東西有
**六種**（待確認、已確認、已完成、未到、個人行程、休假），而可以借的語意色
只有四五個。少的那一兩個一定會撞，而且**撞了不會有任何錯誤訊息** ——
它只會安靜地變成一個看起來很正常的畫面。

使用者用了幾輪之後才講出來：

> 個人行程以及休假的顏色不要和來訪的〔待確認／已確認／已完成／未到〕衝突，
> 要很明顯的區別

## 決定

**這六種各有各的色值，不再是別名。** 深色那一份跟著自己寫一遍 ——
那正是別名原本要省掉的工，現在拿它換六個分得開的顏色。

| | 色相 | 淺色字／底 | 深色字／底 |
|---|---|---|---|
| 待確認 | 琥珀 | `#995400` / `#fbeacd` | `#e8a94a` / `#3a2c14` |
| 已確認 | 靛藍 | `#1c5fa8` / `#dde9f8` | `#7fb3e8` / `#16283a` |
| 已完成 | 墨綠 | `#17714b` / `#d5efe2` | `#6fc79a` / `#123024` |
| 未到 | 硃紅 | `#c0271a` / `#fbdedb` | `#f08a7c` / `#3a1e1a` |
| 個人行程 | 紫 | `#6b3fa0` / `#eae0f8` | `#b899ec` / `#251c3a` |
| 休假 | 灰青 ＋ 斜線紋 | `#4f6b7d` / `#e4ebf0` | `#9db4c4` / `#1e2a33` |

字對底一律 ≥ 4.5:1（深色 ≥ 6:1）。色條上是 11px 的中文，這個門檻不是形式，
是算過的 —— 憑眼睛挑會挑出兩個「看起來夠深」但其實是 3.8 的顏色。

`--slate` 沒有別的用途了，一併刪掉：留著一個沒人用、而且註解寫著
「個人行程裡的休假那一類」的 token，下一次有人會照那句話把它用回來。

### 休假不搶色相，改用紋路

色相輪上塞六個彼此分得開的顏色，最後兩個一定會擠在一起。而休假本來就不是
同一類東西 —— 其他五種講的是「這裡有一件事」，休假講的是「這幾天我不在」。

所以休假走中性的灰青，加一層 45° 斜線紋。它比第六個色相準確，
而且在色弱的情況下照樣成立。整條圖案收成 `--stripe-leave` 一個 token：
它出現在三個地方（月檢視色條、日曆頂端的篩選丸、壓表小日曆的「你休假」），
斜線的角度或粗細在其中一處不一樣，就不像同一件事了。

## 這一組是全站的，不可能只鮮豔一頁

使用者要的是「日曆這一頁」變鮮豔。**四個來訪狀態色做不到只改一頁。**

`CLAUDE.md` 的連動表寫著：來訪狀態的顏色只改一處，「日曆、客戶詳情、試算表
全部讀它」，理由是「同一位客戶在兩個畫面顯示成不同顏色，她不會知道哪個算數」。

所以這一支的改動會跟著出現在客戶詳情的日期卡、進度追蹤、壓表卡片上的徽章。
**這是對的，不是妥協** —— 一個代表「未到」的顏色本來就該在每一頁都長一樣。

不會跟著變的東西比會變的多：米白的頁底、墨綠的主要按鈕、茶色的次要強調、
備註的六色小丸全部沒動。動的是**狀態色那一組**，不是色系。

## Consequences

- 深色模式從此有兩份色票要維護。忘了改深色那一份的症狀是「深色底下某個狀態
  變成看不見的深色」—— 比別名時代的失敗模式明顯，但也真的要記得改。
- `--tea` 從「已排未上」的顏色變回單純的次要強調色（個人行程改用紫）。
  它還在用，只是不再代表任何一種來訪狀態。
- 顏色對比度沒有自動測試。這一輪是寫一支一次性的腳本算 WCAG 比值、
  再用瀏覽器把六種同時畫出來看確認的，那支腳本沒有進版控
  （它需要瀏覽器，而這個專案刻意沒有相依套件）。下一次調色請照樣算一次。
