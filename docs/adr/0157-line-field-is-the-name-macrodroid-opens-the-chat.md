# ADR-0157：客戶的 LINE 那一格存「LINE 上的名字」；打開對話交給手機上的 MacroDroid

日期：2026-10-19
狀態：已接受
推翻：[ADR-0156](./0156-long-notes-and-the-notes-order.md) 的「LINE 點了開他的 LINE」那一條（網址原樣開、ID 開 `line.me/R/ti/p/~<ID>`）。0156 其餘照舊
延伸：[ADR-0055](./0055-she-can-switch-to-dark-herself.md)（記在這一台裝置）、[ADR-0060](./0060-a-row-answers-two-gestures.md)（另外有一條點得到的路）

## 背景

ADR-0156 讓客戶詳情備註那一段的 LINE 丸子點了開 `line.me/R/ti/p/~<ID>`，或她貼的加好友網址。
那要客人開放「允許利用 ID 加入好友」，或她一位一位去要加好友的連結。她 10/19：

> 我發現line她並沒有url可以直接連到對話，所以我想使用MacroDroid巨集協助我完成

> 能不能幫我把原本存的LINE ID 或加好友的網址這個換掉就好，畢竟之前以為可以用LINE ID打開，但是我不想要還要每個客戶問邀請連結或lineid 所以基本上我這個就是改存名字可以嗎 ?

LINE 沒有「用名字打開跟某位好友的對話」的網址。她自己設計了一個 MacroDroid 巨集：打開 LINE 的聊天清單 → 點搜尋 → 貼上名字 → 點那一位 → 點「聊天」→（要的話）貼上訊息；
也在手機上用網址列打 `http://127.0.0.1:8080/line?name=…` 驗過叫得到。

## 決定

1. **那一格存她 LINE 好友清單上看到的名字。** 欄位代號照舊 `customer.lineId`：沒有舊資料要保留（她：「我目前應該是沒有任何人的網址或id」），
   換代號要動每一個讀它的地方、備份、稽核，換來的只有風險。網址與 ID 那條路**整個拿掉**，不留相容（她：「都刪掉」）
2. **打開對話交給 MacroDroid 的 HTTP Server Request 觸發條件**（手機上的本機伺服器，`127.0.0.1`），app 在背景敲一次門、把名字與訊息放在網址參數裡。
   **不走 Webhook**（`trigger.macrodroid.com`）：那一條經過別人的雲端，客戶的名字與確認訊息會送出手機
3. **兩個入口、一個巨集**：客戶詳情點 LINE 只打開對話；跟客人確認時間、問這輪的時間的「打開 LINE」接著把訊息框裡**她改過之後的字**貼上。
   app 一律帶 `msg`（沒有就是空的）—— MacroDroid 的區域變數兩次執行之間會留著，沒帶的話上一位的訊息會被貼進下一位的對話
4. **巨集永遠不按送出。** LINE 搜尋是照名字比的，同名的好友會點錯人；她看一眼對話上方的名字才自己按
5. **開關記在這一台裝置。** 只有她的 Android 手機裝了 MacroDroid。沒勾的裝置（iPad、電腦）**一次都不敲本機的門**
   （不然 Chrome 會在一台沒有 MacroDroid 的裝置上跳「區域網路」的權限），改成複製（名字或訊息）＋打開 LINE 的聊天清單，讓她自己搜尋貼上
6. **叫不到就講出來、走同一條退路**；等太久只講一句、不開 LINE —— Chrome 第一次叫本機位址時會停在「允許存取區域網路」那個框上，那時開 LINE 會蓋住那個框
7. 程式放在自己的資料夾（`public/js/integrations/`）—— 她：「可以寫在一個獨立的資料夾」。它不 import 畫面，只被畫面叫

## 為什麼不是別的

- **多一格「LINE 上的名字」、ID 那一格留著**：第一段提過，她不要（她要的就是不用再問 ID）
- **Webhook**：多一個第三方看得到客戶名字與訊息、要網路、手機的 device id 放哪裡都是一個要藏的東西（repo 是 public）
- **把訊息放剪貼簿、巨集從剪貼簿貼**：Android 10 起背景 app 讀不到剪貼簿；巨集第 5 步貼名字也會蓋掉它
- **巨集按送出**：省一下，換來的是送錯人的那一次收不回來

## 後果

- 名字要跟她 LINE 上的寫法一字不差（她幫好友改過名字的，照改過的打）。表單那一格的 `?` 講這一句
- `no-cors` 拿不到狀態碼：手機上任何伺服器回應都算「叫到了」（path 打錯也算）。所以設定頁有「試一次」，app 叫到時也講一句，她回到 app 看得到「app 以為叫到了」
- 巨集的 path（`line`）、兩個變數（`name`、`msg`）是 app 與她手機之間的約定，寫在 `docs/MacroDroid設定.md` 與 `integrations/lineMacro.js` 兩處
- **Gemini 語音記隨手記這一輪不做**（她 10/19：「Gemini 那個功能就先不用做」）：第三方 app 接 Gemini 要走原生 Android 的 AppFunctions（2026/5 仍是 private preview）；
  繞 Google Tasks 的話說法要記得帶關鍵字、而且有「Gemini 說建好了其實沒有」的回報。理由在 `.scratch/line-macrodroid-2026-10-19/spec.md`
