# MacroDroid 設定：一按就打開客戶的 LINE 對話

這一份教你在**手機**上把 MacroDroid 設好，讓 app 裡的兩個按鈕直接打開客戶的 LINE 對話：

- **客戶詳情 → 備註那一段的「LINE」**：打開他的對話，停在那裡
- **待辦 → 跟客人確認時間／問這輪的時間 →「打開 LINE」**：打開他的對話，再把訊息框裡的字**貼上**（不會送出）

為什麼這樣做、有哪些取捨：[ADR-0157](./adr/0157-line-field-is-the-name-macrodroid-opens-the-chat.md)。

> **截圖不要放進這份文件**：畫面上會有好友的名字（這個 repo 是公開的）。

---

## 一、客戶身上先填好「LINE 名字」

客戶詳情 → 名字旁邊的「編輯」→「LINE 名字」那一格，打**你 LINE 好友清單上看到的那個名字**。

- 一個字都不能差：你幫他改過名字的，照改過的打
- 前後的空白 app 會自己拿掉

## 二、MacroDroid 那一側

### 1. 先開兩個權限

- MacroDroid → 設定 → **無障礙服務（UI 互動）** 打開。巨集要靠它點 LINE 的畫面
- 系統設定 → 應用程式 → MacroDroid → 電池 → **不受限制**（或「不最佳化」）。不然手機省電時會把它關掉，app 就叫不到它

### 2. 觸發條件：HTTP Server Request（HTTP 伺服器請求）

新增巨集 → 觸發條件 → **HTTP Server Request**：

| 欄位 | 填什麼 |
|---|---|
| Path（路徑） | `line` |
| Send Response（傳送回應） | **要勾**。沒勾的話 app 等不到回應，會講「MacroDroid 沒回應」 |
| 連接埠 | 在「HTTP Server Settings」裡，預設 `8080`。改了的話 app 的設定頁也要改成一樣的 |

**不要用 Webhook (URL) 那一種**：那一條經過 MacroDroid 的雲端，客戶的名字和訊息會送出手機。

### 3. 兩個區域變數

巨集裡建兩個**字串**區域變數，名字一模一樣：

- `name`：要找的那位的 LINE 名字
- `msg`：要貼上的訊息（客戶詳情點 LINE 時 app 會傳空的）

app 每一次都兩個一起傳。**`msg` 空的就不要貼** —— 巨集的變數會留著上一次的值，所以 app 一定會傳一個空的 `msg` 過來蓋掉它。

### 4. 動作

照你原本設計的那幾步，加幾個保險：

1. **開啟網站**：`https://line.me/R/nv/chat`
2. **等待 1500 毫秒**（LINE 沒在背景時要比較久才出來；之後的等待 500 毫秒通常夠）
3. **UI 互動 → 點擊 → 文字內容「包含」`搜尋`**
4. 等待 500 毫秒
5. **UI 互動 → 貼上 → 自訂文字 `{v=name}`**，勾「**直接設定文字**」（不經過剪貼簿 —— 經過的話會把 app 先幫你複製的那一份訊息蓋掉）
6. 等待 500 毫秒
7. **UI 互動 → 點擊 → 文字內容「符合」`{v=name}`，略過前 1 個符合項目**（第一個符合的是搜尋框裡你剛打的字）
8. 等待 500 毫秒
9. **UI 互動 → 點擊 → 文字內容「符合」`聊天`**
10. **如果 `msg` 是空的 → 停止巨集**（客戶詳情那一種到這裡就好）
11. 等待 500 毫秒
12. **UI 互動 → 點擊輸入框**（用「Identify in app」：照它說的去 LINE 對話畫面點一下輸入框，它會自己抓好）
13. **UI 互動 → 貼上 → 自訂文字 `{v=msg}`**，勾「直接設定文字」

每一個「點擊」都建議把 **Click Result** 設成「等點完」、把成功與否存進一個布林變數；**點不到就跳一則訊息（例：「找不到 {v=name}」）然後停止** ——
不然找不到人的時候，後面的貼上會貼到別的地方。

**不要加「送出」那一步。** 同名的好友會點錯人；看一眼對話上方的名字，再自己按送出。

## 三、app 那一側

**設定 →「打開 LINE 對話」**（記在這一台裝置上，只有手機要勾）：

1. 勾「這台手機裝了 MacroDroid」
2. 連接埠跟 MacroDroid 的一樣（預設 8080）
3. 「用哪一位試」打一位好友的 LINE 名字 → 按「**試一次**」

第一次按，Chrome 會問「允許存取區域網路上的裝置」→ **允許**。
手機應該跳到 LINE、找到那一位、貼上一則三段、三百來字的測試訊息（跟一則真的確認訊息一樣長）。看四件事：

- 有跳過去（叫得到）
- 中文沒有變成亂碼
- 三段之間的空行還在、第二段那幾行各自一行（換行有留著；確認訊息就是一段一行）
- 最後一句「看到這一句就代表整段都貼上了」也在（長的訊息貼得完）

看完把那一則刪掉就好，它不會自己送出。

## 四、沒裝 MacroDroid 的裝置（iPad、電腦）

那一格不要勾。點 LINE 或「打開 LINE」時，app 會：

- 客戶詳情：複製他的 LINE 名字、打開 LINE → 你在搜尋貼上
- 確認時間／問這輪的時間：複製訊息、打開 LINE → 搜尋那個名字、打開對話貼上
