# 操作手冊

給沒看過這個系統的人。從頭走一遍：客戶進來 → 問時間 → 壓表 → 掛號 → 到院 →
健檢的後續 → 收工前檢查。

> **這份文件只講「按哪裡」。** 為什麼這樣設計在 `SPEC.md` 與 `docs/adr/`，
> 詞的定義在 `CONTEXT.md`。同一件事只寫在一個地方，這裡看到的連結都是指過去的。

## 零、先認得五個畫面

底部有五個分頁，每一個回答一個問題：

```
┌──────────────────────────────────────────────┐
│                                              │
│               （內容區）                      │
│                                              │
├────┬────┬────┬────┬────────────────────────┤
│待辦│客戶│壓表│日曆│設定                     │
└────┴────┴────┴────┴────────────────────────┘
```

| 分頁 | 你在這裡問的問題 |
|---|---|
| **待辦** | 現在有幾件事、哪一件最急 |
| **客戶** | 這個人還剩幾次、這個月哪天來 |
| **壓表** | 這個月還有誰沒排、先排誰 |
| **日曆** | 這一天塞不塞得下、那一筆要改 |
| **設定** | 主檔、資料健檢、備份、已刪除的東西 |

**待辦那一頁的右上角還有一顆「備忘錄」**，通到你自己寫的流程與心得
（[第六節](#六備忘錄--sop)）。它不佔分頁 —— 那五格是你每天都在按的。

兩條要先記住的規矩：

1. **改一筆來訪只有日曆一個入口。** 待辦中心、客戶詳情、進度追蹤上點開的
   卡片都是**唯讀**的，沒有鉛筆。要改就回日曆找那一天。見
   [ADR-0056](./adr/0056-only-the-calendar-can-change-a-visit.md)。
2. **系統只記錄決定，不替你做決定。** 所有的檢查都是提醒，**一條都不擋** ——
   它會講出「這樣排會超過總次數」、「這位客戶有體內金屬」，但不會擋住你。見
   [ADR-0002](./adr/0002-app-records-decisions-it-does-not-make-them.md)
   與 [ADR-0074](./adr/0074-a-contraindication-warns-it-does-not-block.md)。

## 一、核心作業路徑

### 步驟 1　新增客戶

**客戶 → 右下角的加號**

填名字（其餘都可以之後補）。同一張表單底下有一塊「她買了什麼」：

- 買**方案**（例：筋骨強身）→ 選方案 + 數量，底下的項目會自動展開成**額度**
- 買**單項** → 一項一項加

> **加購那張表全站只有一份**（`ui/components/buy.js`），三個入口
> （客戶詳情的「加購」、新增客戶的「加一項」、批次建立的「微調」）
> 長得一模一樣。

買**健檢**的時候多一格「金額等級」（0.75 萬、8 萬、12 萬…），
它只影響顯示名稱，不影響流程。

### 步驟 2　健檢一買，二返自動跟著出現

存檔之後回客戶詳情看那一排額度卡，你會看到**多了一張「二返（8 萬健檢）」**，
次數跟健檢一樣多。

那是自動的：買幾次健檢就有幾次二返
（[ADR-0022](./adr/0022-followup-entitlements-are-expanded-in-pairs.md)）。
**不要自己再加一筆** —— 加了會變成兩筆，而次數會對不起來。

舊客戶身上如果沒有配到，健檢那張卡底下會出現一句
「⚠ 這筆健檢還沒有對應的二返額度」加一顆「補一筆二返額度」，按它就好。

### 步驟 3　問這一輪的時間

**待辦 →「問這輪的時間」**

```
問這輪的時間
   ‹   9 月   ›            ← 上一月 / 下一月，往前往後都走得到
   25 位客戶

[ 還沒發連結 8 ]  [ 已經發出 5 ]

還沒發連結
  客戶A   從來沒問過・還剩 4 次        [ 產生 9 月的連結 ]
  客戶B   還沒問 9 月・上次 7/28 問的   [ 產生 9 月的連結 ]

已經發出
  客戶C   9/1 發出           ⏳ 等待回覆     [重發]
  客戶D   9/1 填好           ✍ 已填寫時段    [ 去收下 ]
  客戶E   9/1 收下           ✓ 已確認排定

▸ 9月已經問到了 3 位
```

三件事要知道：

- **月份切得動**，而且**產生的連結帶的就是你選的那個月**（按鈕上印著）。
- **「還剩幾次」不是門檻。** 身上 0 次的人照樣列得出來 ——
  你可能就是要先把時間問起來，再談加購。
- **已經發出那一格不會有人消失。** 客戶填完、你收下之後，那一列還在，
  只是徽章換成「已確認排定」。

兩條路可以問：

| 路 | 怎麼做 |
|---|---|
| **發連結** | 按「產生 X 月的連結」→ 底下出現一則可以直接貼到 LINE 的訊息 → 按「複製 LINE 訊息」 |
| **自己問** | 在 LINE 上問完，去那位客戶的詳情頁，「不能的時間」那一段按「記一次」 |

> 那一則訊息的**用字改得動**：設定 → LINE 回覆模板。見底下的「八、要貼給客戶的那六則話」。

### 步驟 4　收下客戶填的

**待辦 →「客戶填好的時間」**

客戶填完**不會自動生效**。你看過、按「收下」，它才變成那位客戶的
**本輪可用性**（[ADR-0032](./adr/0032-what-the-customer-fills-in-waits-in-an-inbox.md)）。
收下之後系統會給你一則回覆客戶的訊息。

### 步驟 5　壓表

**先去 Abovee 把時段佔住，再回這個系統記。**
這個系統看不到同事在 Abovee 上壓了什麼，它不取代 Abovee。

**壓表 → 選月份 → 開始這一批**

```
9 月　已壓 5 / 23
┌─────────────────────────────────┐
│  客戶A                      ‹ › │   ← 左右滑換下一位
│  復能 剩 11 ・ 8萬健檢 剩 1      │
│  9月不能的時間  ［禮拜一］［9/17］│
│  可用 21 天                      │
│  ────────────────────────────── │
│  9 月小日曆（點一天）             │
│  做什麼  [復能 剩11] [＋ n返]    │
│  幾點開始 [09:00][09:30]…        │
│  器材    [INDIBA][超磁場][雷射]  │
│  治療師  [治療師甲][治療師乙]     │
│                                  │
│         [ 加這一筆 ]             │
└─────────────────────────────────┘
```

按下「加這一筆」會跳一個確認框，問「已經在 Abovee 壓好表了嗎？」
並且**把接下來會發生的事列出來**。那不是廢話 —— 那是你唯一一次
看得到「這一下會產生哪幾張待辦」的地方。

存進去的來訪狀態是**待確認**（琥珀色）。

### 步驟 6　跟客人確認時間

**待辦 →「跟客人確認時間」**

用 LINE 問完客人，回來按那一列的打勾 → 跳出確認畫面，把這個人所有的時段
攤開 → 三條路：

| 客人說 | 你按 |
|---|---|
| 都可以 | 確認 → 那幾筆變成**已確認**（靛藍），**掛號的待辦這時候才長出來** |
| 這兩天可以、那天不行 | 逐筆標「客人說不行」，其餘照樣成立 |
| 還沒回 | 在那一列寫一句（例：「禮拜一再問問」），那一列**留著**，只是看得出問過了 |

> **掛號的待辦要等客人說可以才長。** 壓完一晚上二十幾位就立刻多出幾十件待辦，
> 而其中一部分等客人說不行就會被收掉。見
> [ADR-0027](./adr/0027-registration-tasks-wait-for-the-customer.md)。

### 步驟 7　去掛號

**待辦 → Examine／耀聖**

- Examine：預約作業 → 查核 → 已報到
- 耀聖：右下角 → 未報到 → V

在系統這一側：勾起來 → 按「把勾起來的標成完成」→ 確認。
勾掉的**不會消失**，它移到「已完成」那一格，點回來就拿得回來。

也可以走**待辦 →「依客戶」**：點一位客戶，從底部滑出一張抽屜，
那個人身上的事全部在裡面，勾完往下甩掉就換下一位。

### 步驟 8　客人來了 → 簽療程單

**待辦 →「簽療程單」**

點那一筆 → 逐段勾「這一段做了」→ 送出。

**次數是這一刻才扣的。**（[SPEC 第 4.2 節](../SPEC.md)）
客人做了兩段、第三段就走了是會發生的，所以是逐段勾，不是整筆。

二返（與加約的三返、四返）**不用簽療程單** —— 那一次是回院聽報告，
沒有療程可以扣。但**那一筆照樣要在這裡結案**，卡片上會寫明。

## 二、健檢那一條鏈

這是整個系統唯一的**鏈式**待辦，也是最容易漏的一段。

```
健檢結案
   │
   └─ 21 天後死線 ──▶ ① 追蹤健檢報告      「報告出來了沒」
                            │
                         勾掉它
                            │
              ┌─────────────┴─────────────┐
              ▼                           ▼
   ② 寄報告給醫師                 ③ 約二返
   「寄一份給看報告的那位醫師」      「回去跟客人約聽報告的時間」
   死線 勾掉那天 +7                死線 勾掉那天 +7
                                            │
                                    去壓表（按那一列的「去壓表」，
                                            項目會先選好）
                                            ▼
                                  那一筆健檢從此不再出現在待辦上
```

**勾掉「追蹤健檢報告」那一下會長出兩張，不是一張。** 兩張的死線一樣，
因為它們是同一個動作的兩半。

三個常見的誤會：

- **「約二返」勾得掉，但勾掉不等於真的約了。** 那一列右邊有一顆徽章寫著
  「已約 9/3 14:00」或「還沒約」。還沒約就勾掉的話，確認框會多問你一次。
- **二返約好了，「寄報告給醫師」還在，那是對的。** 那是兩件事 ——
  約時間跟寄報告誰先誰後都可以，兩張各自勾。見
  [ADR-0065](./adr/0065-two-things-happen-when-the-report-arrives.md)。
- **報告那一張可以拿回來。** 在「已完成」那一格點一下就退回上一站，
  另外那兩張會跟著收起來 —— 這是對的，不是壞掉。

### 加約三返、四返……

客人聽不懂、想再聽一遍時才會有。**不需要先加購**，只要他名下有一次
**已完成的健檢**就約得了，也**沒有次數上限**。

從**壓表**或**日曆**加：

```
做什麼  [復能 剩11] [8萬健檢 剩1] │加約│ [＋ n返 不扣次數]
                                            ↓ 點下去
第幾返   [三返][四返][五返]…              ← 預設是下一個沒用過的
這是哪一次健檢的　一定要選
         [7/13  二返]  [8/20  二返・三返]  ← 已經有幾返會標出來
```

三件要知道的事：

1. **它不扣任何次數。** 存檔前的確認框會講出這一句。客戶身上的數字一個都不會變。
2. **一定要選是哪一次健檢的。** 沒有它，試算表上那一場沒有位置可以印。
3. **掛號的待辦、要不要簽單、選不選醫師，全部跟二返一模一樣。**

> 一位**什麼次數都用完**的客戶不會出現在壓表的卡片牆上（那面牆答的是
> 「這個月還有誰要排」）。那種情況從**日曆**加：點那一天 →
> 抬頭的「＋」→ 新增來訪 → 選那個人。

試算表上會長這樣，接在那一次健檢的欄位底下：

```
                        │ 7/13 │ 8/20 │
8萬健檢       1  1  0  0 │  ✓  │      │
二返（8萬健檢）1  1  0  0 │      │  ✓  │
                        │8/8 二返(醫師甲) │
                        │9/20 三返(醫師乙)│
```

## 二之二、客人走了之後要寫的那一份

有些課程做完之後，要去曜聖補一份文字紀錄。目前是**二返**與**營養師諮詢**。

那一張待辦叫「**寫紀錄**」，而它跟其他任務有兩個地方不一樣：

| | Examine、耀聖 | 寫紀錄 |
|---|---|---|
| 什麼時候出現 | 你勾掉「跟客人確認時間」之後 | 你在「簽療程單」那一頁**把那一場結案**之後 |
| 死線 | 來訪日的**前一天** | 來訪**那一天** |

所以流程是：客人來 → 簽療程單（結案）→ 待辦上多一張「寫紀錄」→
去曜聖打完 → 回來勾掉。

**要哪些課程長出這一張，你自己設定**：設定 → 課程 → 那個課程 →
打開「客人走了之後要補一份紀錄」。它跟「來訪當天要請客人簽療程單」
是兩件事，兩個都要就兩個都勾。

**怎麼確認那個勾有沒有打開？** 兩個地方看得到：

- 設定 → 課程，那一列的灰字會多寫「**要寫紀錄**」。
- 「簽療程單」那一頁點開那一筆，底下的預告會寫「**待辦會多一張「寫紀錄」**」。
  沒有那一句，就是那個課程的勾還沒打開。

**三返、四返……也照著走。** n返 借的就是二返那一個課程，所以你在二返上打開
那個勾，三返做完一樣會長出「寫紀錄」。設定裡不會有一個叫「三返」的課程 ——
那是對的。

> 人**沒來**（標成未到）的話這一張不會長出來 —— 沒有紀錄要寫。
> 規則見 [ADR-0066](./adr/0066-a-record-is-a-task-that-is-born-after-the-visit.md)。

## 三、日曆上的七種顏色

日曆上會出現七種東西，**顏色已經用完了**，所以有兩種靠形狀分：

| 看到什麼 | 是什麼 |
|---|---|
| 琥珀色 | 來訪・**待確認**（壓好了，還沒問過客人） |
| 靛藍色 | 來訪・**已確認**（客人說可以了） |
| 墨綠色 | 來訪・**已完成**（來了、簽了單、次數扣掉了） |
| 硃紅色 | 來訪・**未到** |
| 淡紫色（可以自己挑顏色） | **行事備註**（你自己的事，例：公出、演講） |
| **斜線紋** | **休假**（那幾天整片排不進去） |
| **方框勾勾** | **待辦**（就是掛了日期的隨手記） |

灰掉又劃線的是**已取消**的來訪 —— 它畫在那裡是為了讓你看得出
「那個時段本來有人」。

顏色與符號只寫在一個地方（`domain/visits.js` 的 `STATUS_VIEW`），
所以日曆、客戶詳情、試算表三個地方永遠一樣。見
[ADR-0039](./adr/0039-six-things-on-the-calendar-need-six-colours.md)、
[ADR-0045](./adr/0045-the-calendar-has-four-kinds.md)。

## 四、待辦、任務、隨手記、備忘錄差在哪

四個詞很像，但它們是四種東西。分清楚才知道「這件事會不會有人提醒我」。

| | 誰產生的 | 有死線嗎 | 勾得掉嗎 | 上日曆嗎 | 例子 |
|---|---|---|---|---|---|
| **任務** | 系統（來訪產生的） | **有** | 是 | **不** | 到 Examine 掛號 |
| **隨手記** | 你自己打的 | 沒有 | 是 | **掛了日期就會** | 下次記得帶健保卡 |
| **備忘錄** | 你自己整理的 | 沒有 | **不** | **不** | 點滴當天要檢查什麼 |
| **待辦** | —— | —— | —— | —— | 是一個範圍更大的詞，見下 |

任務的死線有**兩種**：掛號那一族是來訪日的**前一天**，
「寫紀錄」那一族是來訪**那一天**（[第二之二節](#二之二客人走了之後要寫的那一份)）。

**「待辦」要看上下文，而且刻意保留兩個意思**（因為你本來就這樣講）：

- **待辦中心（首頁）上的一列** —— 那一頁列的不只任務：「問這輪的時間」
  「壓表登記」「跟客人確認時間」「簽療程單」都是**推導出來的**，
  它們沒有死線、也不存在資料庫裡。
- **日曆上的一類** —— 那一類**只有掛了日期的隨手記**。

要指某一種的時候講得具體一點：「任務」「日曆上的待辦」「待辦中心那一列」。
**「備忘錄」不是「隨手記」的別名** —— 隨手記是一件會被勾掉的小事，
備忘錄是一份不會消失的流程（[第六節](#六備忘錄--sop)）。
完整定義在 [CONTEXT.md](../CONTEXT.md)。

### 隨手記怎麼記

三秒內要記完，所以有三個入口：

- 首頁最底下那一塊（直接打一行字）
- **右下角那顆鉛筆泡泡**（點下去鍵盤自己上來，送出之後不關掉 ——
  你一次常常記三件事）
- 日曆上點一天 → 新增待辦

掛日期是**選填**的。掛了就出現在日曆的「待辦」那一類，勾掉了在日曆上畫成刪除線。
**那個日期不是死線**：過了只有字變色，不會變紅字、也不進「逾期」那顆數字。

## 五、刪掉的東西去哪裡了

**這個系統永不硬刪除。**（[SPEC 第 6.1 節](../SPEC.md)）

刪掉只是標記，**設定 → 已刪除項目**裡還原得回來。破壞性的操作一律走
二次確認，而且會把後果列出來（刪幾筆、會影響什麼）。

另外兩個工具在設定裡：

- **資料健檢** —— 把整個資料庫掃一次，把對不起來的列出來。
  它**只顯示不亂改**：正解不需要判斷的那幾項才有「修正」可以按。
  （注意：這裡的「資料健檢」跟課程的「健檢」完全無關，不可以簡稱。）
- **變更紀錄（稽核）** —— 每一次寫入的前後值，改不掉也刪不掉。
  出事的時候唯一能回溯的東西。

還有一個每天會用到的：**待辦中心最底下的「看今天做了什麼」**。
它是稽核紀錄的白話版，回答「有沒有漏掉登記」，往前最多翻七天。

## 六、備忘錄 / SOP

**你自己整理的流程與心得。它不會變成要勾的待辦，只是隨時翻得到。**

入口在**待辦那一頁的右上角**。

### 寫一份

右下角那顆 **＋** → 打標題 → 選填「掛哪些課程」與「掛哪些合作機構」→
在大框框裡寫，**一行寫一件事**。存起來。

一份就這幾樣：**標題、掛哪些課程、掛哪些合作機構、內容**。沒有章節、
沒有分類、沒有時機 —— 就像一般手機上的備忘錄。

### 這一頁怎麼用

```
備忘錄 / SOP                          🔍     ← 按一下才長出搜尋框
● 營養點滴   外檢   復健科流程                ← 點一顆，直接滑到那一張
╔═══════════════════╗ ╔═══════
║ 營養點滴        ✎ ║ ║ 外檢          ← 鉛筆：就地改，不換頁
║ ───────────────  ║ ║ ────
║ 飯後打針          ║ ║ 要帶⋯
╚═══════════════════╝ ╚═══════
          · ● · ·                              ← 現在是第幾張
                              ( ＋ )           ← 加一份
```

- **左右滑**換一張。旁邊露出來的那一條就是下一張。
- 上面那一排**丸子就是全部的標題**，點一顆直接跳過去。
- **鉛筆**點下去，那一張就地變成可以改的樣子，改完按「存起來」。
  刪掉也在那裡面。
- **放大鏡**點開才有搜尋框，打字會同時篩卡牌與丸子。再點一次收起來，
  篩選也跟著清掉。

### 它會出現在哪裡

要自己浮出來，那一份得**掛到課程或合作機構**。掛課程的看那一段做什麼、
掛合作機構的看這位客戶是誰帶來的 —— 兩種只要有一邊對上就浮出來。
外檢這種系統裡沒有的項目就不用掛，寫在標題就好 —— 它照樣查得到，
只是不會自己冒出來。

浮出來的是那一份的**前四行**，剩下的寫成「還有 N 行」。
所以**最重要的寫在最前面**。

```
日曆 → 點某一天 → 點那一筆來訪
┌────────────────────────────────┐
│ 客戶A                      ✎ ✕ │
│ 9/1(二)・客戶已確認             │
│ ┌────────────────────────────┐ │
│ │ 10:30–11:30                │ │
│ │ 營養點滴・點滴8A            │ │
│ └────────────────────────────┘ │
│ ┃營養點滴              看整份 ›│ │  ← 這一塊
│ ┃ · 飯後打針（通知客人）       │ │
│ ┃ · 預約系統註記：血管難打     │ │
│ ┃   還有 1 行                  │ │
└────────────────────────────────┘
```

「飯後打針（通知客人）」就寫在點滴那一份的**第一行** ——
你在「跟客人確認時間」那一頁打訊息的時候，它就在那一列底下。
**不用另外開一種要勾的任務。**

### 幾條規矩

- **勾不掉。** 這一頁上一個勾選框都沒有 —— 它不是第二個待辦中心。
- **不上日曆。** 上日曆的是有日期的**隨手記**，那是另一種東西。
- **綁課程或合作機構，不綁人。** 「點滴要注意什麼」對每一位客人都一樣、
  「自然美帶來的怎麼收費」對那一家的每一位都一樣；不一樣的那些
  是客戶身上的**警示**（見下）。
- 刪掉的一樣進「已刪除項目」，還原得回來。

見 [ADR-0067](./adr/0067-a-playbook-is-read-not-ticked.md) 與
[ADR-0069](./adr/0069-a-memo-is-one-box-of-text.md)。

## 七、客戶身上的標記

**永久限制底下分兩層**，差別在系統拿它做什麼：

| 層 | 例子 | 系統做什麼 | 壓表卡片牆上 |
|---|---|---|---|
| **警示** | 體內金屬（紅・實心）、血管難打、第一針 | 什麼都不擋 | 畫，顏色與填法你自己挑 |
| **其餘** | 固定禮拜五不行 | 什麼都不擋 | **不畫** |

編輯客戶時，警示是**一排點得到的丸子**，其餘是自由輸入。

**要出現在壓表卡片牆上，就得用上面那一排的丸子** —— 打在「其他限制」那一欄
的字不會出現在那裡（一張卡上十個字等於全都沒有重點）。

要加一個新的警示：**設定 → 警示 → 新增**。那一頁還可以挑顏色與填法
（實心／空心）—— 最該一眼看到的挑實心，其餘挑空心。加完之後，
每一位客戶的編輯畫面上那一排就會多一顆。

> **這裡沒有任何一種會擋東西。** 2026-09-06 之前「體內金屬」會讓超磁場與
> 高能量雷射整個點不下去；現在它只會在你選了那一台的時候跳一句提醒，
> 並且建議改用 INDIBA。你自己說過「只要儀器不要在金屬的上方或附近」就做得了。
> 見 [ADR-0074](./adr/0074-a-contraindication-warns-it-does-not-block.md)。

> 客戶身上存的是**字**不是編號。所以你在主檔上把「血管難打」改成別的名字，
> 已經標過的那幾位客戶身上還是舊的那個字 —— 要到那個人身上重選一次。

### 合作機構（自然美）

跟警示分開的另一個欄位，因為它不是限制。客戶身上打上「自然美」之後，
那顆丸子會在**每一個看得到他名字的地方**出現：壓表卡片牆、待辦中心、
客戶詳情、客戶清單。

**它不會產生任何待辦** —— 那顆丸子就是全部的提醒。壓完表看到它，
就去跟對方的專員說一聲。

要加一家：**設定 → 合作機構 → 新增**。
見 [ADR-0076](./adr/0076-a-memo-can-hang-on-a-partner.md)。

**標記一位客戶**：客戶詳情 → 鉛筆 → 「合作機構」那一排 → 點「自然美」→ 存起來。
存完那顆丸子就跟著他的名字走。

## 七之二、加購

額度那一段的抬頭有三顆：**買過什麼**、**加購方案**、**加購**。

### 加購單項

按「加購」→ 第一排選買了什麼。

**「復能」跟「ILIB」永遠並排**，不管你在設定裡把課程排成什麼順序。

**選了「復能」之後會多兩排**：

```
買了什麼   …（復健科醫師門診）（健檢）（復能）（ILIB）… ｜ 商品（營養品）
哪一種     （三選一）（四選一） ｜ 單買一台（INDIBA）（SIS）（高能量雷射）
幾分鐘     （30 分鐘）（60 分鐘）
           會變成「復能-SIS(60)」
幾次       [ 5 ]  +1  +5  +10
```

單買那一排**只有復能自己那三台**。ILIB 不在裡面 —— 它在上面那一排自己有一顆。

**名字自己組出來**，你一個字都不用打。全站只會出現這**六種**：

```
復能-三選一(30/60)    復能-四選一(30/60)
復能-INDIBA(30/60)    復能-SIS(30/60)    復能-高能量雷射(30/60)
ILIB(30/60)
```

要自己取名的話展開「進階設定」裡的「顯示名稱」—— 打了之後就不會再自動跟。

> **看不到「四選一」那一顆？** 那是因為器材主檔裡還沒有 ILIB 那一台
> —— 四選一就是三選一再加上它。開 **設定 → 資料健檢**，
> 「器材主檔少了一台」那一列按一下就建好了。

「幾分鐘」那一排有哪幾顆，在**設定 → 課程 →「可選時長」**改
（填 `30、60` 就是這兩顆）。沒填的課程整排不出現。

到期日也在進階設定裡：（不到期）（半年）（一年）（自己選），**預設不到期**。

### 加購一整個方案

按「加購方案」→ 選方案 → 買幾套。底下會列出它會建立哪幾筆，
每一項一個 `[−] N [＋]`：

- **改成 0 就是不要那一項**，那一列會變灰、寫「不建立」
- 改過的那一列會寫「方案本來 20 次」
- 最底下一顆「＋ 加一項」，開的是上面那一張加購表

**方案範本一個字都不會變。** 這幾個數字只影響這一位客戶這一次。

### 買過什麼

按「買過什麼」看得到他當初買了哪幾套方案、加購了什麼。微調過的那一組
會標「微調過」，逐項寫出「方案本來幾次」。

**這一頁只有一件事改得動：購買日期**（因為你記錄的日期跟他真的買的那一天
常常不同）。點那個日期就地改，改的是**整組** —— 一次購買那幾筆一起變。

## 七之三、同一個東西的三種寫法

**設定 → 名稱怎麼寫。**

**三種寫法，三種讀者。** 這是理解這一頁的唯一一句話：

| 誰在看 | 看到什麼 | 例 |
|---|---|---|
| **你**（加購、客戶詳情、壓表、試算表） | 當初**買了什麼** | `復能-三選一(30)` |
| **你**（月曆、日曆點開） | 那天**做了什麼**：器材＋幾分鐘 | `SIS(30)` |
| **客戶**（LINE 草稿） | **只有課程** | `復能`、`靜脈雷射` |

月曆那個分鐘**只有復能與 ILIB 會出現** —— 只有它們有 30 與 60 兩種規格，
而那是兩筆不同的額度。健檢永遠是 120 分，寫出來只是把那一格擠掉一個字。

### 這一頁上面就是那六種

一種一列，每一列印出「月曆怎麼寫」與「LINE 草稿怎麼寫」，右邊當場預覽：

```
復能-三選一      月曆 IN/SIS/高能量雷射   LINE 復能
                （名字跟著那天用的器材走）
復能-四選一      月曆 …/IL                LINE 復能/靜脈雷射
復能-INDIBA      月曆[ IN  ]              LINE 復能
復能-SIS         月曆[     ]              LINE 復能
復能-高能量雷射   月曆[     ]              LINE 復能
ILIB            月曆[ IL  ]              LINE[靜脈雷射]
```

**前兩列只給看。** 三選一與四選一是一種**買法**，不是一個東西 ——
它們在月曆上寫什麼，跟著那天用了哪一台走。要改就改底下那三列。

底下另外一區是**其他課程**（健檢、營養點滴…），一列兩格。

**器材那幾列只有「月曆」一格**，沒有 LINE —— 貼給客人的那一句本來就不寫
是哪一台，那一格填了也不會出現在任何地方。

**這一頁不改全名。** 要改去設定 → 課程／設定 → 器材 ——
改全名會動到主檔清單、方案範本與稽核紀錄，那不是這一頁的事。

### 兩格名字的分工

| | 是什麼 | 誰讀它 |
|---|---|---|
| **全名** | 你叫它什麼（`SIS`、`INDIBA`、`高能量雷射`） | 額度的名字（`復能-INDIBA(60)`） |
| **月曆**（別稱） | 那一格塞得下的縮寫（`IN`） | 月曆、日曆點開那一筆 |

所以 INDIBA 那一台兩格不一樣：額度上寫 `復能-INDIBA(60)`、月曆上寫 `IN(60)`。
SIS 與高能量雷射本來就夠短，月曆那一格留空就好（留空＝用全名）。

### ILIB

| | 寫什麼 |
|---|---|
| 全名（額度、試算表） | `ILIB` |
| 月曆（你自己記） | `IL` |
| LINE 名（貼給客戶） | `靜脈雷射` |

> **月曆寫的是那天真的做了什麼，不是當初買的那一筆。** 買的是
> `復能-四選一(60)`，那天壓了 SIS：月曆寫 `SIS(60)`、
> LINE 草稿寫 `復能`、試算表扣四選一那一列並在它底下註記 `SIS`。
>
> **那一段扣的是哪一筆，點開就看得到**：時間那一行底下寫「扣 復能-四選一(60)」。
> 四個畫面（日曆、客戶詳情、待辦中心、進度追蹤）都有。

## 七之四、診間怎麼選

**空間有三種，一間 4 號都沒有：**

| 類型 | 有哪幾間 | 月曆上寫 |
|---|---|---|
| 治療室 | 治2、治3、治5、治8 | 治2、治3… |
| 點滴室 | 點滴2、3、5、6、7、8、9、10 | `.2`、`.3`… |
| VIP室 | VIP2、3、5、6、7 | `vip2`、`vip3`… |

**沒有床位這一層了** —— 一間就是一個資源。

排班時**常用的那幾間排在最前面**，其餘收在「其他診間」底下（點開就有）：

| 排這個 | 最前面是 |
|---|---|
| EECP | 治5、治8（而且**只能**排這兩間） |
| ILIB | `.10`、治2、治3 |
| 營養點滴 | 八間點滴室 |

**那是順序不是限制**（EECP 除外，它有硬限制）。要改順序去
**設定 → 課程 →「常用診間」**，勾起來的排最前面。
簡寫在**設定 → 診間 →「簡寫」**改。

### 哪些課程要選誰／哪裡

| 要什麼 | 哪些 |
|---|---|
| 物理治療師 | 復能（INDIBA／SIS／高能量雷射）、物理治療師諮詢 |
| 治療室 | 營養點滴、EECP、ILIB |
| 醫師 | 門診類（復健科、心臟科、二返） |
| 都不用 | 健檢、體適能、身體組成分析、營養諮詢 |

**買了三選一或四選一時，要選誰是「挑了器材才知道」的** ——
挑之前那兩排都不會出現，只有一句「先選上面那一台」。
挑了 INDIBA／SIS／高能量雷射 → 治療師；挑了 ILIB → 治療室。

## 八、要貼給客戶的那六則話

**設定 → LINE 回覆模板**

全站會產生「複製給客人」的字只有六則，全部在這一頁改得動。改完立刻生效，
下一次按複製拿到的就是新的字。

| 這一則 | 哪裡按得到 |
|---|---|
| 問這一輪的時間 | 待辦 →「問這輪的時間」；客戶詳情 → LINE 訊息 |
| 問這一輪的時間（附表單連結） | 同上，**產生連結之後自動換成這一則** |
| 收到他填的時間，回一句 | 待辦 →「客戶填好的時間」 |
| 問壓好的時間可不可以 | 待辦 →「跟客人確認時間」；客戶詳情 |
| 來訪前提醒 | 客戶詳情 → LINE 訊息 |
| 臨時空出一格，問誰要補 | 待辦 → 時段反查 |

### 大括號那幾個東西不要刪

`{name}`、`{month}` 這種是**會被換掉的洞**：貼出去之前，系統會把 `{name}`
換成那位客戶的名字、`{month}` 換成月份。框底下那一排丸子就是這一則吃得到的
洞 —— **點一下就插在游標那裡**，不用自己打。

打錯字（例如把 `{name}` 打成 `{Name}`）的話，那五個字會原樣印在訊息裡。
那是刻意的：看得到就知道自己打錯了，安靜地少一個稱呼你反而找不出原因。

### 兩個特別的

- **`{courses}` 與 `{course}` 自己帶一個「的」**。有課程名時是「營養點滴的」，
  沒有時整個消失。所以模板上寫「有{courses}課程」就好，不要再寫一次「的」。
- **`{slots}` 是好幾行，要讓它自己佔一行**。它印的是壓好的**每一段**，
  時間寫的是**幾點到幾點**（客戶要知道的是那天待多久，不是幾點報到）：

  ```
  9/3(四) 14:00–15:00 復能
  9/17(四) 10:00–11:00 營養點滴
  9/17(四) 11:15–12:15 復能
  ```

  同一天不同時段的都會各自一行。接在句子中間的話，第二行之後會黏到後半句上。
  匯入的舊來訪沒有時間，那一行就只有日期與課程（不會印「時間不詳」）。
- **有連結的那一則不要再問「哪幾天不方便」**。給了連結還用問的，客戶會改用
  打字回你，那條連結就白給了。

### 備忘錄裡貼進來的 (emoji)(加1)

從 LINE 複製過來的字會帶著 `(emoji)`、`(加1)` 這種代碼。**貼上的那一刻自動換掉**：
`(emoji)` → 🐻、`(1)`／`(加1)` → 1️⃣。全形的「（emoji）」也認得。

已經存在框裡的代碼（這個功能之前就打進去的）貼上那條路蓋不到 ——
那時候 emoji 那一排的最前面會出現一顆 **「清掉貼圖代碼」**，按了才清。
沒有代碼的時候那一顆不會出現。

**自己打的不會被動到**：只有貼上會清，而且只認 `(emoji)` 與數字，
你自己的「（乾淨度）」「（通知客人）」一個字都不會變。

### 改壞了怎麼辦

每一則右上角有「回復預設」，整頁最底下有「全部回復預設」（會問一次）。
**只存你改過的那幾則**，所以沒動過的那幾則之後跟著系統一起更新。

一則刪光是存不下去的 —— 那會讓你按下複製時拿到一則空訊息。

## 九、升上去之後要做一次的幾件事

這幾輪（2026-09-06 ～ 09-08）改了資料的形狀，有些事系統**不會替你做** ——
它們是你的判斷，或者要在另一個地方按。

**設定 → 資料健檢**跑一次，把這幾列各按一下。**順序有一個地方要注意**：
「器材的名字」要在「復能額度還叫舊名字」**之前**按。

| 那一列 | 按下去會發生什麼 |
|---|---|
| 器材主檔少了一台 | 把 ILIB 那一台建起來。**「四選一」那一顆就是少了它才按不出來** |
| **器材的名字跟建議的不一樣** | 「超磁場」改名成 `SIS`、INDIBA 的月曆縮寫填成 `IN`。**先按這一列** —— 額度的名字是從器材的全名組出來的 |
| 復能額度還叫舊名字 | 既有客戶身上的 `復能`、`復能 - 三選一（60）` 改成 `復能-三選一(60)`。**你自己打過的名字一個字都不會動** |
| **課程的指派跟建議的不一樣** | 健檢、體適能、身體組成、營養諮詢、門診、二返六個不再要你選診間 |
| **診間清單跟建議的不一樣** | 建起 VIP2～VIP7、刪掉治7／治9／治10／ILIB4、把點滴室的簡寫填成 `.2`～`.10`。**刪掉那幾間之後，已經排在那裡的舊來訪印不出診間名字**（那幾筆本身一個字都不會動，而且刪掉的診間在「已刪除項目」裡還原得回來） |
| **來訪上還記著床位** | 把舊來訪身上的點滴8 A／B 清掉。清完之後同一間同一個時間排了兩個人才會被標成撞期 |
| 器材上的提醒詞不在警示名單裡 | 把「體內金屬」補進警示主檔，客戶身上打了那個字才畫得出來 |
| 課程沒填可選時長 | 復能與 ILIB 填上 `30、60`，不然「幾分鐘」那一排不出現、月曆也分不出 30 與 60 |

按完之後再去這兩頁確認一次：

- **設定 → 器材**：替每一台各選一次「用這台算哪一個課程」—— 前三台選復能、
  ILIB 選 ILIB。沒選的話復能四選一排不出 ILIB 那一段。
- **設定 → 課程**：ILIB 那一筆的「別稱」是 `IL`、「LINE 名」是 `靜脈雷射`；
  EECP 與 ILIB 的「常用診間」照上面第七之四那張表。

（主檔改名不會動到已經排好的那幾段上的名字 —— 那是刻意的，
歷史紀錄留著當時寫的字。）

還有一件跟試算表有關的，見 [STAGING.md](./STAGING.md) 的上線檢查表：
**回 Google 試算表把那支指令碼重新貼一次並重新部署**。不做的話試算表會停止更新。
