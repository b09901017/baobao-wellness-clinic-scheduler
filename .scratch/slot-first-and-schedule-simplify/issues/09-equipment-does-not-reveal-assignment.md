# 選了器材，治療師／診間那一排沒有跟著出現

Status: todo
來源：使用者，2026-09-08（需求三 1b）
動工前先讀：`docs/adr/0075`、`0079`、`ADR-0038`（不要整頁重畫）

## 她要的

> 然後我選器材也沒有跟著產生選治療師或診間？這個問題還是沒有解決 幫我全域搜查
> 到底是哪邊出問題。為什麼壓表那邊可以，但這邊卻不行？他們的不是共用同一個邏輯嗎？

## 根因：**domain 確實共用，接線沒有**

`assignsFor()` 兩邊都呼叫（`tests/visits.test.js:1269` 還有一條原始碼掃描
盯著沒有人自己比 `assigns`）。壞掉的是**它什麼時候被重算**：

| | 壓表 | 來訪編輯器 |
|---|---|---|
| 器材那一排 | 自己刻的 `[data-equipment]` 按鈕 | `f.chips({ …, **quiet: true** })`（`visitEditor.js:598`） |
| 點下去之後 | `afterEquipmentPick()` 比 `assignKeyOf()`，變了就重畫那一塊（`schedule.js:1817`） | `quiet` = **不派 `change`** → `paint()` 不跑 → 那一排永遠不出現 |

`quiet: true` 是 `f.chips` 的「選了不重畫」開關（`form.js:261`）。
在醫師、診間、治療師那幾排上是對的（換它們不影響別的欄位）；
**在器材上是錯的** —— ADR-0075 讓器材開始決定課程之後就錯了，只是沒人回頭改。
`git log -L` 顯示這個 `quiet` 是 `<select>` 時代留下來的。

**同一個原因讓醫療禁忌那句提醒也不會跳**：`noticeBlock()` 跟器材同一次重畫。

## 決定

**一、器材那一排拿掉 `quiet: true`。** 換了器材本來就要重畫：課程變了、
要指派的東西變了、禁忌提醒變了，三件事都跟著它。

**二、額度那一排本來就沒有 `quiet`，維持不動。**（這解釋了為什麼她覺得
「有些連動有、有些沒有」。）

**三、不做壓表那種局部重畫。** 來訪編輯器的 `change` 監聽本來就整張重畫，
而它一次只有一到數段、不是二十幾張卡。為了這一顆再引入一套局部重畫，
等於在第二個地方複製 ADR-0038 的機制。**但要確認 `note` 那一格的豁免還在**
（`visitEditor.js:257` 那段註解：打字時重畫會把送出按鈕換掉）——
issue 05 換成 textarea 之後那條豁免要跟著改名。

## 測試

- 選一台器材 → `assignsFor()` 從 `null` 變 `'therapist'` → 治療師那一排出現
- 四選一從 SIS 換成 ILIB → 治療師那一排消失、診間那一排出現，
  而且**舊的 therapistId 被清掉**（不然一段 ILIB 會帶著治療師存進去）
- 換器材 → 禁忌提醒那一塊跟著換
- 三選一裡換一台（課程沒變）→ 治療師那一排還在，選好的人沒被清掉
- 原始碼掃描：`s${i}-equip` 那一組沒有 `quiet`
