## 兩個箭頭是怎麼來的

`paintStart()` 那一列同時給了兩個：

- 標記上寫死的 `${icon('right', { size: 17 })}`（`schedule.js:252`）
- `.row-link::after { content: '›' }`（`app.css:4162`）

丸子版本兩個都不要 —— 一顆按鈕不需要箭頭說明它可以按。

## 決定

```
壓表                                        批次取消 ›

  ┌────────┐  ┌────────┐  ┌─────────────┐
  │  9 月  │  │ 10 月  │  │ 11 月       │
  └────────┘  └────────┘  └─────────────┘

                                        時段反查 ›
```

跨年時第三顆是：

```
  ┌─────────────┐
  │  1 月       │
  │  2027       │     ← .monthpick__year，比月份小兩階、淡一階
  └─────────────┘
```

- 一橫排、等寬、`flex: 1`，手機上三顆剛好塞得下
- **年份只在跟第一顆不同年時才印**。每一顆都印年份等於把它變成裝飾
- 拿掉：`<span class="num dim">2026-09</span>`、`card__title` 的「要壓哪個月」、
  `card__note` 那兩行、`page__lead` 的「一個人壓完再換下一個」
- 「臨時空出一格？」那張卡也精簡成一行連結（那兩行 `card__note` 是說明文字）
- 新 class `.monthpick` / `.monthpick__one` / `.monthpick__year`，
  顏色全部用既有 token，**不新增 token**（不必動 `tokens.css` 兩份）
