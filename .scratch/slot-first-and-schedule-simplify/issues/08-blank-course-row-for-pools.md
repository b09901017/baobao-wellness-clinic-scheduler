# 擇一池多一排空白的「課程」

Status: done
來源：使用者，2026-09-08（需求三 1a）

## 她要的

> 我選復能四選一 三選一什麼的 為什麼會多一個空白的「課程」

## 根因：少一個等號

`visitEditor.js:403`：

```js
${nth || courseChoices.length === 1 ? '' : f.chips({ label: '課程', options: courseChoices… })}
```

擇一池的 `courseChoices` 是 **`[]`** —— 課程由器材推出來，所以刻意不給選（ADR-0075）。
而 `[].length === 1` 是 `false`，於是走進去畫了一排 **options 空的丸子**：
一個「課程」標籤加一列什麼都沒有的空白。

上面那段註解自己寫著這一條當初是為了 n返 加的（「以前這裡只問 `length === 1`，
於是 n返 會多出一排空的課程」），**修的時候只補了 `nth` 那一半**。

## 決定

`=== 1` 改成 `<= 1`，並把 `nth` 那個特例收進同一句話 ——
判準本來就是「選項不到兩個就不畫」，`nth` 只是它的一個例子。

## 測試

- 擇一池（`courseChoices` 是 `[]`）→ 那一排不畫
- 一個選項 → 不畫（既有行為）
- 兩個以上（四選一的 single 額度？不，是 `coursesForEntitlement` 回兩個課程的池）→ 畫
- n返 → 不畫（既有行為，不可以退化）
- 原始碼掃描或 DOM 斷言：畫出來的 `chiprow` 裡不會有零顆丸子
