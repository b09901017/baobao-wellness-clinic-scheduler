# 「記一句」搬到時段上，收在一顆 ▤ 後面

Status: done
來源：使用者，2026-09-09（第三題）
動工前先讀：`SPEC.md` 第 5.3 節（要改）、`ui/views/calendar.js` 的 `noteMarks()`

## 她要的

> 不要是一整天的…我希望是每一筆都可以有他的記一句…我希望這一筆這個時段點進去
> 就是看到這筆只有這筆相關的資訊

> 新增時段的時候不用每個都給記一句的輸入框，就是有需要的時候點一個 icon
> 或是什麼再展開填就好，不然感覺會很占版面…要簡潔直觀，而且閱讀起來舒服，有呼吸感

**SPEC 第 5.3 節寫著 `note` 是「這一天的」。她明確說以這次為準。**

## 決定

### 一、`slot.note`，上限沿用 `NOTE_MAX`（200）

`visit.note` **留在資料上不刪**（舊資料靠它），但**不再寫入**。

### 二、舊資料走 A 方案：她下次存那一筆時搬到第一段

跟 `withSlotStatuses()` 同一個位置、同一個時機（`data/visits.js` 的 `save()`
是唯一路口）。新增一支 `withSlotNotes(visit)`：

```
visit.note 有字，而且沒有任何一段有 note
  → 搬到第一段（照陣列順序，不是第一個活著的段），visit.note 清成 null
其餘  → 一個字都不動
```

**冪等**：搬過一次之後 `visit.note` 是 null，再存不會再搬。有測試釘著。

匯入那條路不走 `save()`，但**匯入的來訪本來就沒有 note**，所以不必補。

### 三、畫面：一顆 ▤，三種狀態

icon 是 `book` —— **她 2026-09-04 就替「記的話」挑了這一顆**
（`calendar.js:586` 的 `aria-label="有記的話"`）。不要另外挑一顆。

```
① 沒有字     抬頭列右邊一顆淡灰的 ▤，零額外高度
② 點下去     就地展開 textarea，自動聚焦，▤ 轉主色
③ 有字收起   ▤ 主色 + 抬頭底下一行淡字，點那行也展開
```

**收起來不是藏起來。** `app.css:4595` 那條規矩：「摺疊的標題要講出裡面被動過幾樣
—— 收起來的東西不能安靜地生效。」所以有字的時候一定看得到。

### 四、共用元件 `ui/components/slotNote.js`

兩個入口共用：來訪編輯器的每一段、壓表記錄卡的那一段。
`html()` 給欄位、`wire()` 接展開 —— 跟 `ui/components/note.js` 與 `buy.js`
同一個形狀（呼叫端只回答「哪一塊要重畫」）。

壓表那一頁現在那個永遠攤開的 `<label class="field">這一次記一句</label>`
（`schedule.js:1169`）換成它，並且**不再預填 `sameDay?.note`** ——
那是別段的字。

### 五、`visit.followupNote` 不動

那一句（「禮拜一再問問」）記的是「這通電話追到哪了」，而電話是一天打一通。
它長在待辦中心那一列上，不在時段詳情裡，兩者不會被搞混。
**但它的輸入框也收成同一顆 ▤**（她 2026-09-09 第 5 點）。

### 六、順手修好日曆那顆 ▤

`domain/calendar.js:181` 現在是 `hasNote: Boolean(visit.note)` —— 一天三段
只有一段有字時，**三列都會亮 ▤**。改成讀那一段自己的 `slot.note`
（舊資料退回 `visit.note`，那時候整天共用一句本來就是事實）。

## 測試

- `withSlotNotes()`：搬到第一段、清掉 `visit.note`、冪等、已經有段 note 時不動
- `slot.note` 超過 200 字擋下來（`validateVisit()`）
- `agendaFor()` 的 `hasNote` 逐段算；舊來訪退回整筆
- `visitReadHtml()` 印的是那一段的 note，不是整筆的
- 壓表存一段 → 那一段帶著 note，同一天既有那幾段的 note 一個字都沒動
- 原始碼掃描：`ui/` 底下沒有人自己讀 `visit.note` 來畫輸入框
