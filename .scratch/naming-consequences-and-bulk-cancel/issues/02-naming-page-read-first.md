# 名稱怎麼寫：先給看，點鉛筆才展開那一列

Status: done
來源：使用者，2026-09-08（需求 2）
動工前先讀：`ui/views/naming.js` 整支、`docs/adr/0077`、`docs/adr/0078`

## 她要的

> 以簡潔、具有呼吸感的排版，呈現所有既有課程的「一般名稱」、「月曆簡寫」、
> 「LINE 寫法」。此檢視狀態不呈現大量輸入框，不造成視覺負擔。
> 每個課程項目右側均配置一個「鉛筆編輯圖示」，點擊該項目後，僅針對該項目原地展開編輯。

## 兩種狀態

**讀（預設）** —— 一列三欄，一個輸入框都沒有：

```
復能-INDIBA                                    ✎
月曆  IN(30/60)      LINE  復能
```

**改（點了鉛筆）** —— 就地展開，其餘每一列維持讀的樣子：

```
復能-INDIBA                                    ✕
月曆  [ IN        ]   LINE  復能（這是課程的字）
預覽  月曆 IN（30／60 會接在後面） ｜ LINE 復能
[ 存起來 ]
```

**一次只展開一列。** 展開第二列時第一列自己收起來 —— 兩列同時開著就回到
現在那個「滿頁輸入框」的樣子。

## 她這一輪定下來的：器材那幾列的 LINE 格「畫出來但只給看」

ADR-0077 說貼給客人的那一句不講是哪一台機器，所以器材沒有 `lineName`。
但那三列（單買 INDIBA / SIS / 高能量雷射）**看得到它們的 LINE 寫法**——
就是「復能」，也就是課程的字。

所以：**印出來，不給輸入框**，旁邊一句「這是『復能』這個課程的字，
要改在下面『其他課程』那一區」。

- ADR-0077 不推翻（那一格仍然存不進器材）
- 她看得到完整的三種字（需求 2 要的「全項目支援」）
- 不會填了一個永遠不會出現在任何地方的欄位（ADR-0077 拒絕過的那件事）

## 前兩列（三選一／四選一）維持只給看

它們是一種**買法**，背後沒有一筆主檔可以存字（ADR-0078 第五點）。
讀的狀態下它們跟其他列長得一樣，只是沒有鉛筆。

## 存檔時機改掉

現在是 `focusout` 就存。改成**按「存起來」才存** —— 就地展開之後
焦點會在兩個輸入框之間跳，`focusout` 會存兩次，稽核紀錄多一筆沒有意義的。

## 不要動的

- 預覽仍然走 `domain/naming.js` 的 `slotName()`，這一頁只印（既有的規矩）
- 打字**不重畫**，只就地換預覽的字（會洗掉輸入法組字狀態）
- 整頁的預覽都要跟著換：改了 SIS 的別稱，上面「三選一」那一列也要變
- 全名不在這一頁改

## 測試

- 改了別稱之後，上面兩列整組的預覽跟著變（既有測試延伸）
