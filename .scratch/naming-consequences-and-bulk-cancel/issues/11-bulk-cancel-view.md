## 一、先解一個架構衝突

**ADR-0056：改得動一筆來訪的只有日曆**，而且「留一條繞過去的路，
等於那個決定只做了一半」。這一頁會取消來訪，所以它**推翻了 ADR-0056**。

要一支新 ADR 講清楚為什麼這一個例外成立：

- ADR-0056 擋的是「不小心改到」（待辦中心、客戶詳情、進度追蹤那三頁的列
  順手加一支鉛筆）。這一頁**是一個明確的、只做一件事的入口**，
  跟日曆的長按選單是同一種東西：她知道自己要來取消
- 真正的情境是**出國、請假** —— 一次十幾段，走日曆要點三十幾下
- 但**只給取消，不給改**。改一筆仍然只有日曆

## 四、要共用的東西，一個都不要另外寫

| 要什麼 | 走哪一支 |
|---|---|
| 那一段叫什麼 | `domain/naming.js` 的 `slotName(…, 'short')` |
| 狀態顏色與標籤 | `domain/visits.js` 的 `STATUS_VIEW` |
| 取消之後會發生什麼 | `domain/consequences.js` 的 `cancelConsequences()` |
| 逐段取消怎麼寫 | `domain/visits.js` 的 `applyStatus(v, 'cancelled', { slotIndex })` |
| 寫入 | `data/visits.js` 的 `save(next, customerVisits)` |
| 月曆格線 | `domain/calendar.js` 的 `layoutMonth()` / `WEEKDAY_HEADERS` |
| 清單模式的版面 | `ui/views/progress.js`（她指名比照那一頁） |
| 換月 | `ui/components/monthnav.js` |

**「哪幾段選得起來」是一條規則，寫進 domain**：
`domain/visits.js` 新增 `cancellableSlots(visit)` —— 已完成、未到、
已取消的那幾段選不起來（`canTransition()` 說了算，不要在畫面上另外列一份）。

## 五、確認框

一次列出**全部**要取消的日期與課程明細，然後接 `cancelConsequences()`：

```
取消王小明的 6 段？

  9/3  10:30 SIS(30)
  9/3  11:30 IL(30)
  9/10 09:00 健檢(120)
  …

會發生什麼
  這 6 段的時段會退回去，次數也會還回來
  待辦會多一張「取消 Abovee」、一張「取消 Examine」—— 回去把那些時段放掉
  還沒做完的「Examine」會被收掉
  改期不是改日期，是取消後重新排一筆
  十秒後自動同步到試算表
```

**後果那幾行一個字都不要自己寫** —— 走 `cancelConsequences()`，
逐筆算完去重（同一種只講一次）。這正是需求 6 講的那件事。

## 六、寫入要一筆一筆存，而且要擋得住半途失敗

**不要開一個新的批次寫入 API。** 走既有的 `visitsData.save()`，
一筆來訪一次。六段分佈在四筆來訪就是四次寫入。

- 每一次都 `toast.withSaveState()` 帶 `key`（`tests/save-guards.test.js` 盯著）
- **中途失敗要講出來**：「取消了 4 筆，還有 2 筆沒成功」，
  而且**已經成功的不要回滾** —— 那幾筆是真的取消了
- 存完重新讀那一位，畫面跟上

## 七、長按多選

`ui/components/actions.js` 的 `wireLongPress()` 已經有了，共用它。

- 長按一天 → 進多選模式，那一天整天選起來，抬頭換成「選了 N 天」
- 多選模式下**點一下就是選／取消整天**（不再展開）
- 退出多選：右上角一顆「完成」，或按返回鍵（走 `pushLayer()`）

**多選模式要看得出來**：整頁上緣一條色帶＋一句「點日期整天選起來」。
沒有提示的模式切換是這個 app 不做的事。

## 八、動畫（點到為止）

- 月曆某一天展開／收起：`grid-template-rows` 0fr → 1fr，`--motion-base`
- 長按進多選：那一格 `scale(0.96)` 一下彈回，`--motion-fast`
- 勾選：核取方塊本身的漸變，不要整列閃
