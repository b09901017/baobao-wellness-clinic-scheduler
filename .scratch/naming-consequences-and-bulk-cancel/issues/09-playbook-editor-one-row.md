# 備忘錄編輯：掛課程與掛機構收成一行，存檔鈕不再被擠下去

Status: done
來源：使用者，2026-09-08（需求 8）
動工前先讀：`ui/views/playbook.js` 的 `editCardHtml()`、
CLAUDE.md 那一列「備忘錄編輯那張卡的版面」

## 她要的

> 新增合作機構支援後，表單垂直高度被拉長，導致「儲存按鈕」被擠到視窗下方
> 需要額外滾動。將「掛課程」與「掛機構」重構至同一行，採用分段切換按鈕或 Tabs。

## 現在的高度長什麼樣

```
標題                    一行
掛哪些課程（標籤＋一排丸子）  兩行
掛哪些合作機構（標籤＋一排丸子） 兩行   ← 2026-09-08 加的，就是它把存檔鈕擠下去了
內容 textarea             flex: 1 1 0
emoji 那一排              一行
存起來／取消／刪掉         一行
```

## 要做的

兩排合成一排，上面一個 Segmented Control 切換：

```
掛在哪    [ 課程 ]  [ 合作機構 ]        ← 分段切換，一行
          ( 復能 )( 健檢 )( ILIB ) …    ← 只畫選中那一種的丸子，一行
```

省下**兩行**：一個標籤 ＋ 一排丸子。

### 三件不可以做的事

1. **兩種都要能同時掛。** 切換的是「現在在編哪一種」，不是「這一份只能掛一種」。
   切過去之後前一種選了什麼**不可以被清掉** —— 兩個 `<input type="hidden">`
   都留在 DOM 裡（`f.splitMulti()` 讀的就是它們），只是丸子那一排換掉。
2. **選了幾個要看得到。** 沒選中的那一顆分段鈕上印數字（`合作機構 1`），
   不然切過去之前她不知道那邊有東西。
3. **沒有合作機構時整個分段控制不畫**，直接畫課程那一排（維持現況）——
   一顆永遠按不下去的分頁只是噪音（`editCardHtml()` 既有的規矩）。

### `.pbcard--edit > *` 那一條不要動

CLAUDE.md 寫著：卡片裡除了內文那一格，每一項都 `flex: none`，
內文是唯一的 `flex: 1 1 0`。分段控制與丸子那一排是新的直接子元素，
**要被那一條蓋到** —— 少一條就會被 flex 壓扁（`.emojirow` 被壓成 2px 發生過）。

`f.chips()` 吐的是 `.fieldgroup`，已經被蓋到了；新的分段控制要確認也是。

### 高度由 `.pbdeck[data-editing]` 給死，不要用 JS 撐 textarea

## 動畫（需求裡「精心設計」那一段）

切換那一下：丸子那一排 `opacity` 120ms 淡入，**不要滑動**——
一排丸子橫著滑進來會跟它自己的橫向捲動打架（`sheet.js` 的 `SIDEWAYS` 那一段
為這件事付過帳）。分段鈕的底色用 `--motion-fast` 漸變。

  E2 盯兩個 hidden input 都留在 DOM 裡（拿掉節點的話她切一下就把掛好的
  課程清光了），存完回頭讀 `courseIds` 確認
- 切到合作機構再切回來，課程選的那幾顆還在
- 存檔之後兩種都寫進去了
- 沒有合作機構時不畫分段控制
