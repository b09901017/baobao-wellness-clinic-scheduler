# 客戶詳情的任務不能切換未完成／已完成

Status: todo
來源：她的三件事，2026-08-25（`../spec.md`）
動工前先讀：`../../asks-2026-08-25/issues/08`、`ui/views/home.js` 的 `paintTasks()`

## 症狀

她的原話：「客戶詳細資料那邊的任務 希望任務這邊也是可以切換，已完成和未完成」。

待辦中心上個月已經分成兩格了（`../../asks-2026-08-25/issues/08`：勾掉的不消失，
在「已完成」那一格點回來就好）。客戶詳情這一段沒有跟上 —— 它把兩種混在同一串裡：

```js
${[...openTasks, ...tasks.filter((t) => t.done)].slice(0, RECENT_TASKS).map(taskRow)}
```

未完成的排前面，但只印六筆。一位做完十次療程的客戶，那六格會被已完成的塞滿，
而她要看的「還沒做的那兩件」被擠到「看全部」裡面去了。

## 要做成什麼

跟待辦中心**同一個樣子**（`.seg` 那一排），不要另外設計一種：

```
任務   2 未完成                                    看全部
┌─────────────┬─────────────┐
│  未完成 2   │   已完成 9  │
└─────────────┴─────────────┘
☐ Examine        死線 9/1
☐ 耀聖           死線 9/1
```

- 分頁狀態存在模組層，**不進網址**（跟待辦中心的 `taskTab`、隨手記那一頁
  同一個判斷：它是看法，不是位置）。
- **每次進這一頁重設成「未完成」**，跟 `showVisits` / `detailMonth` 一樣 ——
  她開這一頁十次有九次問的是「他還有什麼沒做」。
- 一筆任務都沒有的時候不要畫那一排（兩個空格子看起來像壞掉的東西），
  照舊只留那一句「還沒有任務。客人確認時間之後，該做的系統登記會自動產生。」
- 換分頁**只重畫那一段**，不是整頁（ADR-0038：她剛剛展開的來訪紀錄不能被捲回最上面）。
  所以那一段要包進一個自己的容器，跟「這個月」那一塊（`[data-monthblock]`）同一個作法。
- 「看全部」那張面板列的是**現在這一格**的全部，不是兩格混在一起。
  面板抬頭要講出是哪一格（「全部任務・未完成」）。

## 勾掉之後停在哪一格

勾掉一筆會 `reload(ctx)`（整頁重讀）。**分頁狀態要活過那一次重讀** ——
她在「未完成」那一格勾掉一筆，畫面應該還停在「未完成」，只是少了一列。
所以那個變數不能在 `reload()` 裡被重設，只在 `render()`（真的重新進這一頁）時重設。

`showVisits` 與 `detailMonth` 現在就是這個形狀，照抄即可。

## 驗證

- `npm test`
- 瀏覽器：客戶詳情（挑一位有勾掉過任務的）→ 任務那一段有兩格 →
  預設停在「未完成」→ 勾掉一筆 → 還停在「未完成」，那一筆跑到「已完成」去 →
  切到「已完成」點它一下 → 拿得回來
- 展開來訪紀錄之後再切分頁 → 來訪紀錄**還是展開的**，畫面沒有捲回最上面
