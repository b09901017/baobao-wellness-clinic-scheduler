# 「這個月」裡有下個月的東西，而且卡牌看不出全貌

Status: done
來源：使用者，2026-08-24（spec.md 的 b）
確認過（2026-08-24）：**只看選中的那個月**
動工前先讀：`SPEC.md` 第 8.5 節、`docs/adr/0025`、`domain/progress.js`

## 原話

> 「這個月的呈現方式，目前是用卡牌嘛，我希望改用清單，就像是客戶那頁
> 『看這個月的進度』那邊呈現的一樣，就是一張卡牌呈現所有資訊…而且我希望你也好好檢查，
> 他說這個月，為什麼會有下個月的預約資訊跑進來？我希望這邊呈現可以切換不同月份」

## 為什麼有下個月的

`ui/views/customerDetail.js` 的 `visitStrip()`：

```js
.filter((v) => isActive(v) && (v.date.startsWith(month) || v.date > today))
```

後面那半句把**今天以後的所有來訪**都拉進來，不分月份。SPEC 第 8.5 節原本寫的
就是「本月與之後的來訪」，所以程式沒有寫錯 —— 是**標題只寫「這個月」**，
而規格與標題從一開始就對不起來。

她的決定是：**標題說哪個月就只有哪個月。**

## 要做什麼

### 1. 抬頭可以換月份

```
◀   2026 年 8 月   ▶            4 天・6 段
```

- 預設今天所在的月。
- 左右箭頭換月，**不換頁、不重讀整頁**（只重畫這一段）。
- 換到有東西的月份與空的月份都要好看（空的寫「這個月沒有排」）。
- 箭頭 44px。手勢左右滑**可以有，但不是必要** —— 這一段只有幾列高，
  滑到它上面的機會不大。

### 2. 卡牌改清單，照「看這個月的進度」那一頁的樣子

`#/customers/progress`（`ui/views/progress.js` + `domain/progress.js`）已經有
她要的那個長相：

```
8/6(四)    14:00–15:00  營養點滴          ✓ 已完成
8/13(四)   14:00–15:00  營養點滴          ✓ 已完成
8/28(五)   14:00–15:00  營養點滴          △ 已確認
```

一天一組、一組裡一段一列、每一段有**自己的狀態**（`○ 待確認 / △ 已確認 /
✓ 已完成 / ✗ 未到`，ADR-0025）。

**共用 `domain/progress.js`，不要在客戶詳情裡再排一次。** 那一支已經做完
「一位客戶 × 一個月 → 分天分段」這件事，而 `CLAUDE.md` 的連動表寫著狀態的
顏色與符號只有一份。動工時看它現在的介面吃什麼參數 —— 如果它是為了
「所有客戶的這個月」寫的，抽一支只吃一位客戶的出來，兩邊共用。

### 3. 那一列可以點

進度追蹤那一頁是**唯讀的**（連鉛筆都沒有，SPEC 第 8.5 節），
但客戶詳情這一段點一筆應該要能看那一筆。**點一筆浮出讀取模式的卡片**
（跟日曆同一支 `visitReadHtml()`，`views/calendar.js` 已經匯出了），
卡片上有鉛筆才進編輯器。

理由跟 ADR-0020 一樣：她點一筆的十次有九次只是要確認那天幾點做什麼。

### 4. 抬頭右邊那句摘要

現在是 `monthLine()` 產的「4 次・1 筆等回覆」。換月份要跟著換，
而且改成講**天數與段數**（`4 天・6 段`）—— 進度追蹤那一頁就是這樣寫的，
兩邊用同一句話。

## 一起要檢查的

- 這一段的資料來源是 `ctx.visits`（整位客戶的全部來訪，已經在記憶體裡），
  換月份不需要再讀一次 Firestore。**確認一下** —— 如果它只讀了最近幾筆，
  換到三個月前就會是空的，那要改成換月份時去讀。
- 取消掉的時段不畫（跟日曆與進度追蹤一樣，時段已經還回去了）。
- 顏色走 `domain/visits.js` 的 `STATUS_VIEW`，一個都不要自己寫。

## 驗證

- `npm test`
- 瀏覽器：一位這個月有四天、下個月有兩天的客戶 → 這個月只看到四天，
  往右一格看到下個月那兩天
- 瀏覽器：同一天兩段狀態不一樣（做了一半就走）要分得出來
- 瀏覽器：點一筆浮出卡片，按鉛筆進編輯器

## Comments

**2026-08-24 —— done。** 卡牌換成清單，共用 `views/progress.js` 的
`dayHtml()` 與 `tallyHtml()` —— 她要的就是「跟看這個月的進度那邊呈現的一樣」。

`buildProgress()` 是照 customerId 分組的，這裡只有一位，所以把那一位的來訪
全部認成同一個 id 餵進去。比抽一支「只吃一位客戶」的新函式便宜，
而且不會有第二份分天分段的邏輯。

**只看選中的那個月**，`|| v.date > today` 那半句拿掉了。SPEC 第 8.5 節
「本月與之後」跟著改。換月份**只重畫那一塊**（ADR-0038）——
重畫整頁會把她剛剛展開的來訪紀錄捲回最上面。

點一筆改成浮出讀取卡片（共用日曆的 `visitReadHtml()`），鉛筆才進編輯器。
那條規矩（ADR-0020）本來就跟在哪一頁點的沒有關係。
