# 動工前問她的十件事 —— 全部有答案了

Status: resolved
問於 2026-09-08，答於同一天

---

## A1　拼法：**INDIBA**（維持現狀）

主檔、種子資料、`docs/` 一個字都不用改。月檢視簡寫補上 `IN`。

---

## A2　「一般」那一種寫法**整個拿掉**

她的原話：

> app 中只會出現 在額度那邊寫復能-三選一(30)，月曆寫 SIS(30)，草稿寫復能

**她的模型只有三種字，而程式裡有四種。** 多出來的那一種叫「一般」
（`slotName(..., 'full')`），印的是 `復能(SIS)`，只活在三個地方：

| 哪裡 | 現在 | 改成 |
|---|---|---|
| 日曆 日／週檢視那一列的副標 | `復能(SIS)・芝寧` | `SIS(30)・芝寧` |
| 點開一段的讀取卡片（四頁共用） | `復能(SIS)` | `SIS(30)` |
| 來訪編輯器每一段的抬頭 | `復能(SIS)` | `SIS(30)` |

所以 `NAME_CONTEXTS` 從三種變**兩種**：`short`（她自己看）與 `line`（貼給客人）。
第三種字是**額度的名字**，那不是 `slotName()` 算的，是 `poolName()` + `timedLabel()`。

**讀取卡片兩行合起來剛好就是完整的一句話**（`扣 …` 那一行 2026-09-07 才加的）：

```
10:30–11:00
SIS(30)・芝寧
扣 復能-三選一(30)
```

### 連帶要修的一個洞

單買 ILIB 的那一段**身上沒有器材**（ILIB 課程的 `requiresEquipment` 是 false），
所以現在 `short` 印出來是 `IL`，**沒有後面那個數字** —— 而她的表寫的是
`ILIB(30/60) -> IL(30/60)`。分鐘要改成「**這個課程有兩種以上規格就接**」，
不管那一段有沒有器材。

## A6b　器材的全名改成「她叫它什麼」（追問，2026-09-08）

做到一半發現她列的第三種對不上：INDIBA 在**額度**上要寫 `復能-INDIBA(60)`、
在**月曆**上要寫 `IN(60)`，而器材主檔只有兩格（全名、別稱），兩邊都讀別稱。

當面問了她，選項與她的答案：

| | 額度 | 月曆 | 她選了 |
|---|---|---|---|
| **全名改成她叫它的名字** | `復能-INDIBA(60)` | `IN(60)` | ✅ |
| 額度也寫縮寫 | `復能-IN(60)` | `IN(60)` | |
| 主檔不改名、額度讀全名 | `復能-超磁場(60)` | `IN(60)` | |

所以**器材主檔的「超磁場」改名成 `SIS`**，`poolName()` 的後半改讀全名，
別稱那一格從此只給月曆。既有資料庫靠資料健檢的「器材的名字跟建議的不一樣」
跟上（兩格要同時還停在舊的才報）。

> 這一條 2026-09-08 當天沒有寫進這一份 —— 決定只留在 ADR-0078，
> 而複查的時候「下一個人會去找的地方」找不到它。補在這裡。

## A9　治7、治9、治10、ILIB4 **直接刪掉**

## A10　床位**連舊資料一起清掉**

她選的，而且知道那是一次不可逆的改寫。

- 主檔那一頁不再給填床位，`roomSlots()` 一間就是一個選項
- **既有來訪身上的 `bed` 一併清空**（只有排進點滴8 的那幾筆有）
- 清空之後 `conflictWarnings()` 的 `sameRoom` 自然退化成只比 `roomId`，
  也就是「同一間同一個時間有兩個人」會被標出來 —— 那正是取消床位之後對的行為
