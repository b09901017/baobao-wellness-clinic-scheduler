# UI/UX 改版

現有畫面功能都在，但視覺是預設值：系統字體 + 一個藍 + 一組灰階，emoji 當導覽圖示，
每一塊內容都包在同一張白卡裡。結果是一頁上所有東西看起來一樣重要 ——
「復能剩 12/20」跟旁邊的說明文字字級只差 3px，而前者才是她真正在找的東西。

改的是**視覺語言與版面資訊層級**。路由、流程、業務規則不動。

設計稿（可直接看、可自己改）：`design/` 底下的 `.dc.html` 與 `canvas.json`，
用 `/design` skill 產生的 canvas 發佈成 Artifact。

## 設計語言

| | 現在 | 改成 | 為什麼 |
|---|---|---|---|
| 底／卡片 | `#f7f7f8` / `#ffffff` 中性灰 | `#f4f2ef` / `#fffdfb` 暖白 | 一整天盯著看，純灰白偏冷 |
| 強調色 | `#3d6ce0` 藍 | `#17605d` 深松綠 | 臨床感；藍在醫療介面上太像連結 |
| 第二色 | 無 | `#a8552b` 陶土 | 只給喜好程度（★），不與狀態色搶 |
| 狀態色 | 紅／黃／綠 | 同樣三支，改成暖底 | 角色不變（SPEC 8.1），只調到同一組色溫 |
| 字 | 系統字全包 | 中文維持系統字，數字另外自帶等寬字 | 時間與次數要對得齊，1 和 7 不能長得像 |
| 導覽圖示 | emoji | 內嵌 SVG 線性圖示 | emoji 在 Android 與 iPad 上長得不一樣，而那是她每天看最多次的五個東西 |

## 四條版面規則

1. **數字先被看到** —— 剩幾次、哪一天、幾點用 24–30px 等寬字，其餘一律降級。
2. **卡片只包物件** —— 一位客戶、一個時段才是一張卡。區塊改用留白與細分隔線，不再白卡疊白卡。
3. **狀態色只講狀態** —— 紅只給逾期與醫療禁忌，黃只給今明與等回覆。平常整頁是安靜的。
4. **主要動作固定在拇指構得到的地方** —— 手機上「已壓表」「標成完成」壓在導覽上方。

## 沒有動的東西

- 不出建議時段（ADR-0002）。版面只負責把資訊攤開。
- 醫療禁忌仍是唯一的硬性阻擋，而且永遠展開不可摺疊。
- 手機版壓表綜覽一列仍然只放姓名＋喜好、剩餘次數、可用天數、最強的一個理由標籤（SPEC 8.2）。
- 三段斷點與 44px／16px 的觸控規則照舊。

## 落地順序（等設計方向確認後才動工）

1. `public/css/tokens.css` 換一組值（顏色、字級、新增等寬數字字族）。
2. `public/css/app.css` 元件層：卡片、列、標籤、meter、chip、導覽。
3. 一頁一頁調 view，順序：待辦 → 壓表 → 來訪編輯器 → 客戶 → 日曆 → 時段反查 → 設定。
4. 導覽圖示換 SVG（`views.js` 的 `icon` 欄位改吃 SVG 字串）。
5. 收尾：`SPEC.md` 第 8 章跟著更新；推翻既有決定的地方補 ADR。

每一步都要跑 `npm test`；動到 `public/` 底下的檔案要同步 `public/sw.js` 的 `SHELL` 與 `VERSION`。
