`views/customers.js` 已經是那個樣子：

```html
<div class="page__row">
  <h1 class="page__title">客戶</h1>
  <span class="footlinks footlinks--inline">
```

**導覽列一個字都不動。** 五格變六格會讓每一格從 20% 掉到 16.6%，

```js
register('/playbook',     { title: '備忘錄', nav: false, render: playbook.render });
register('/playbook/:id', { title: '備忘錄', nav: false, render: (el, id) => playbook.renderOne(el, id),
                            titleFor: … });
```

排版的四個決定，每一個都指得出理由：

| 決定 | 為什麼 |
|---|---|
| 內文用 `--text-lg`（比一般內文大一級）、`line-height: 1.9` | `tokens.css` 開頭那條「縮小的是包裝，不是資料」。這一頁上**全部都是資料** —— 她是低頭看這台、手在做另一件事的時候在讀它 |
| 一行一個項目，前面一個細圓點，**不用 `<ul>` 的預設樣式** | 她寫的每一行本來就是一件事。自動編號會讓她以為順序是規定的 |
| 節與節之間 `--space-6`，節內 `--space-2` | 距離講的是關係。三節之間看起來要像三塊，不是一整片 |
| 標題用襯線（`--font-serif`） | 全站的層級語言（`tokens.css` 的「襯線標題拉開層級」）。這一頁的標題是唯一的地標 |

**這一頁沒有任何勾選框、沒有進度、沒有百分比。** 一放勾選框它就變成第二個
待辦中心，而她指名「不需要變成打勾任務」。

## 動畫：四個，就四個

`tokens.css` 已經有三段時長與一條曲線，**一個新值都不加**：

| 哪裡 | 用什麼 | 為什麼是這一段 |
|---|---|---|
| 章節展開／收合 | `grid-template-rows: 0fr → 1fr` + `opacity`，`--motion-base` | base 是「剛剛發生了什麼」。用 grid 的 `fr` 而不是猜 `max-height` —— 猜小了長的那一節會被切掉，猜大了收起來會慢半拍 |
| 卡片與章節列按下去 | `transform: scale(0.985)` + `--surface-2`，`--motion-fast` | fast 是「按到了沒」。跟 `.actionrow:active` 同一組值，長按選單已經是這個手感 |
| 清單分組進場 | 淡入 + 上移 6px，`--motion-base`，`animation-delay: calc(var(--i) * 30ms)` | **只給前四段**（`--i` 上限 3）。第五段開始沒有延遲，不然她捲下去的時候整頁都在動 |
| 分類丸子 | 借既有的 `.chip` 過場 | 已經有了，不要寫第二份 |

不做的：頁面之間的轉場、視差、章節的展開箭頭旋轉超過 180 度、任何 `slow`
以上的東西。**閱讀頁上唯一會動的是章節，其餘一律靜止。**

`prefers-reduced-motion` 由 `app.css` 底部那一段對 `*` 生效（`tokens.css` 的
註解已經寫了），**這一輪不要各自再寫一次**，也**絕對不要用 `setTimeout` 等動畫播完**
—— 那條路繞得過那一段。

### 為什麼不用 `<details>`

`<details>` 在 iOS Safari 上展開是瞬間的，動不了（`::details-content` 還太新）。
所以章節做成 `<button aria-expanded>` + 一個 `grid-template-rows` 的包裝層。
`[hidden]` 不能用（它是 `display: none`，動不起來），改用高度為 0 的那一格。

首頁那一塊「看今天做了什麼」用的仍然是 `<details>`，**不要順手一起改** ——
那一塊是「展開才載入」，不是「展開要好看」。

## 編輯：`pushScreen()` 原地換掉，不換頁

跟客戶詳情的編輯一樣（ADR-0048）：`ui/nav.js` 的 `pushScreen()` 讓返回鍵退得回
閱讀模式，而不是整個離開這一份備忘錄。

編輯表單：

```
標題        [ 營養點滴                    ]
分類        [ 點滴          ]   ← 既有的分類做成可點的丸子，也可以自己打
掛哪些課程   復能 靜脈 (營養點滴) 二返 …    ← 多選丸子，選填
────────────────────────────────
第 1 節   [事前▾]  [ 前情提醒            ]  ↑ ↓ ✕
          ┌────────────────────────────┐
          │ 飯後打針（通知客人）          │
          │ 預約系統註記（第一針或血管難打）│
          └────────────────────────────┘
＋ 加一節
────────────────────────────────
                      [ 取消 ]  [ 存檔 ]
```

- 「加一節」與上下移只動那一塊 DOM，**不重畫整張表單** —— 重畫會把她游標的位置
  與還沒送出的字弄掉（ADR-0038 是為了閃爍，這裡是為了不弄丟東西，更嚴重）。
- 存檔走 `toast.withSaveState()` 並**傳 `key`**（`tests/save-guards.test.js`
  會掃出漏掉的）—— 這是一顆會建立新資料的按鈕。
- 刪除放在編輯畫面最下方、二次確認、講出後果（SPEC 第 6.5 節）。
  軟刪除，所以「已刪除項目」還原得回來（`ui/views/trash.js` 要多認得一種）。
