## `CONTEXT.md`

新增兩個詞條，各自要有 `_Avoid_`：

**臨床提醒** —— 永久限制底下、什麼都不擋、但壓表時要一眼看得到的那一類。
與醫療禁忌的界線（會不會真的擋掉器材）、與備註的界線（備註不影響任何行為、
也不畫在壓表卡片牆上）。`_Avoid_`：注意事項、標記、tag、特殊狀況。

**備忘錄** —— 她自己整理的流程與心得，綁課程不綁人，不會變成要勾的東西。
`_Avoid_`：手冊、筆記、便條、注意事項。要有一行界線指回隨手記
（備忘錄綁課程不綁人、不上日曆、勾不掉）。

修改兩個詞條：

**隨手記** —— `_Avoid_` 那一行**拿掉「備忘錄」**（2026-09-03 她決定的，見 issue 04），

## `CLAUDE.md` 的「容易漏掉的連動」

這張表是這個專案最常被讀的東西。這一輪要加四列（**加，不是改既有的**）：

| 改了這個 | 一定要一起檢查 |
|---|---|
| 客戶身上的標記（`flags` / `marks`） | 三層各有各的畫法與各的家：醫療禁忌在器材主檔、**臨床提醒在 `config/clinicalFlags`**、其餘自由輸入。三層的畫法只寫在 `ui/components/flags.js` 的 `alertChips()`，壓表卡片牆與待辦的「壓表登記」共用（ADR-0046、0064） |
| 健檢那條鏈 | 報告勾掉的那一刻長**兩張**：寄報告給醫師、約二返（ADR-0065）。「寄報告」走在 `owed()` 閘門**外面** —— 進去的話，二返一約好它就會被默默收掉 |
| 任務什麼時候產生 | 現在有**兩個**閘門：`acceptsNewTasks()`（客人確認後，掛號那一族）與 `acceptsRecordTasks()`（來訪做完後，紀錄那一族）。UI 上講這件事的文案要跟著改 |
| 備忘錄的內容或它掛到哪些課程 | 規則只在 `domain/playbook.js`。哪一節會自己浮出來由 `whenForVisit()` 決定，**兩個入口共用 `ui/components/playbookHint.js`**。它綁課程不綁人；它**不上日曆**，也不會變成待辦（ADR-0067） |

`data/backup.js` 那一列要補一句：`playbooks` 也在名單上了。

## `docs/操作手冊.md`

它的規矩是「**一條業務規則都不定義**，規則一律用一行連結指回 `SPEC.md` 或 ADR」。
所以這裡加的是**動線**，不是規則：

- 怎麼加一個臨床提醒，以及它會出現在哪一頁
- 拿到健檢報告之後那兩張待辦各要做什麼
- 怎麼寫一份備忘錄、怎麼讓它自己在日曆上浮出來

## `docs/常見問題.md`

每一條三段（看到什麼、為什麼、怎麼辦）。這一輪至少五條，
**全部是我們在做的時候就知道會被問的**：

1. 我打了「血管難打」四個字，壓表卡片牆上為什麼沒有？
   （打在自由輸入欄了 → 那一欄是第三層，要用上面那一排丸子）
2. 我把主檔上的「血管難打」改名了，客戶身上的那顆為什麼變不見了？
   （存的是字串不是 id → 到那位客戶身上重選一次）
3. 「寄報告給醫師」為什麼有些健檢有、有些沒有？
   （這一支上線前就在「約二返」那一站的舊資料不補產生 → ADR-0065）
4. 二返都約好了，「寄報告給醫師」怎麼還在？
   （那是兩件事，故意的）
5. 備忘錄那一塊在日曆上沒出現？
   （那份備忘錄沒掛課程，或那一節的時機對不上今天）

## `docs/邊界測試清單.md`

刻意沒有 happy path。這一輪要加的極端情境：

- 主檔上把「血管難打」停用之後，既有客戶身上那顆長什麼樣
- 一位客戶身上十二則備註 + 三個臨床提醒 + 兩個禁忌，卡片牆上那一列會不會爆版
- 追蹤報告勾掉 → 拿回來 → 再勾掉：兩張待辦不可以變成四張
- 同一天兩個健檢（她說理論上不會，但資料上做得到）
- 一份備忘錄二十節、每節兩千字，閱讀頁捲不捲得動；展開收合會不會卡
- 備忘錄掛的課程被刪掉之後，那一份備忘錄還打不打得開
- 離線時存一份備忘錄：`toast` 那一句**不可以說「失敗」**（`ui/toast.js` 的 `PENDING_MS`）
