## 為什麼會這樣

- 「問這輪的時間」「客戶填好的時間」「壓表登記」三列是等資料回來才補的，數字 0 時 `askGroupRow()` 等回 `''`；
  任務種類那幾列是 `overviewHtml()` 從**還沒做的任務**（`tasksData.listOpen()`）收集 `kinds` 畫出來的 —— 全部做完，那一種就不在 `kinds` 裡，那一列不畫，
  空掉的段由 CSS 的 `:has()` 收掉。
- 點進去那一頁（`renderGroup(el, kind)`）本來就有「已完成」分頁可以把勾掉的勾回來，網址 `#/todo/<種類>` 也一直在 —— 只是首頁上沒有那一列就沒有入口。

## 要做的

- **一份「首頁上有哪幾列」的名單在 domain**（`todoFlow.js`，跟 `FLOW` 同一份順序）：問這輪的時間、客戶填好的時間、壓表登記、跟客人確認時間、Examine、耀聖、簽療程單、寫紀錄、追蹤健檢報告、寄報告給醫師、約二返、改時間／取消。
  已經拿掉的種類（`RETIRED_KINDS`）與**她手動加的、認不得的種類**（`stageOf()` 回 `before`、`orderOf()` 排最後那一種，`todoFlow.js:86-94`）**都不在名單上**：有舊資料就照舊畫在那一段最後面（等於永遠「有才顯示」）
- 每一列三種：`always`（一直顯示）／`auto`（有才顯示，現在的行為）／`hidden`（不顯示）。**預設**：問這輪的時間、壓表登記 = `hidden`；其餘 = `auto`。
  判斷「這一列畫不畫、畫成什麼樣」只有 domain 一支（輸入：那一列的 id、現在幾件、設定）—— 畫面不自己比
- 設定存在 `config/app`（例如 `todoRows: { ask: 'hidden', … }`，只存她改過的、沒存的照預設 —— 同 `messageTemplates` 的作法，之後改預設她沒動過的會跟著）；
  `FIELD_LABELS` 補中文名；備份與還原本來就涵蓋 `config/app`（確認一次 `scripts/restore-backup.mjs`）
- 設定頁多一頁「待辦首頁」：照流程分段列出每一列、每一列一個三選一（分段切換的長相）。**總覽最底下一行小字連到那一頁**（「調整顯示哪幾列」）
- `always` 而且 0 件：畫成淡的一列、數字寫 0（壓表登記照舊沒有數字，ADR-0041），點得進去 —— 任務種類點進去是 `#/todo/<種類>`，那一頁的「已完成」分頁就是她要的入口；
  簽療程單、跟客人確認時間 0 件時點進去是空的那一頁（那兩頁本來就有空狀態，確認一下字是對的）
- `hidden`：總覽上那一列不畫；那一段整段都沒東西時段落照舊收掉。**三顆大數字照算**（她選的）；「依客戶」那一頁不受影響
- 「下一步」那顆小丸子（`markNext()`）不落在 0 件的列上
- 「問這輪的時間」「客戶填好的時間」「壓表登記」設成 `hidden` 時**連資料都不要讀**（`loadAsk()`／`loadInbox()`／`loadBook()` 各多讀三四份，首頁她一天開十幾次）——
  「要跑哪幾支 loader」寫成一支純函式（輸入設定、輸出要讀哪幾份），單元測試量它；**E2E 量不到網路請求**（Firestore 走同一條長連線，過目查到的）
