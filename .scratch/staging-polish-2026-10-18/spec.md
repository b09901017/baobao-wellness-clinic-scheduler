## 第一段談定的（她選的答案）

| 題 | 定案 |
|---|---|
| 藏起來的那一種待辦逾期了，「逾期」還算嗎 | **照算**。藏的是那一列，不是那件事；點「逾期」看得到 |
| 前幾天沒簽完的療程單 | **算逾期** |
| 今天／明天 | 今天＝今天到期的待辦＋今天要簽的療程單＋掛今天、還沒勾的隨手記；明天＝明天的待辦＋掛明天的隨手記。**掛日期的隨手記過了不進逾期**（她：「今天沒勾也沒關係，他不算逾期」） |
| 拍 Abovee 照片上的人數 | 1 位 → 只對他；**2 位 → 只對那兩位**；3 位以上 → 當成拍大家的、照舊對每一位。判斷看**照片上的字**（病歷號或名字，差一個字算同一位），不是看認不認得出來 |
| 復原那條 | 往左或往下滑掉；**停 12 秒**（SPEC 6.3 的「5–10 秒」跟著改） |
| EECP | **只留一門 EECP**：約的時候 60／20、預設 60、不是送的／體驗；選 20 → 預設體驗、選體驗 → 預設 20；拍 Abovee 的 `EECP20` → EECP＋20 分＋體驗。**「EECP體驗」那一門從種子刪掉、不留停用的** |
| 點滴8、VIP7（沒床位的那兩間） | **一樣刪掉、不留停用的**（她：「包含你說的點滴8，vip7…一樣，沒有舊資料的問題」）。推翻 ADR-0127 的「留著、停用」那一段 |
| 舊資料怎麼辦 | **合併檔一開始就是新的**（她：「不要在靠資料健檢處理，一開始匯入時就應該是好的」）。她回第 2 題時說「除了資料健檢多一列之外」—— 所以資料健檢**也**多一列給還留著舊主檔的資料庫（staging 現在那一份），但那是保險，不是正路。staging 等這一輪合進去之後 `npm run staging:reset` 重來 |
| 資料健檢 | 「資料過期」改名「**還沒問這輪方便的時間**」；它與「匯進來的額度還叫舊表的名字」**只是提醒**：收成一行、預設不展開、不算「要你看」、每個人底下不印說明 |
| 長備註 | 是**備註的長版本**，不是第四種東西（ADR-0067 擋的就是「綁客戶的東西第四種」）。有標題、一大塊字。客戶頁上面多一個入口（跟「看這個月的進度」「停用的客戶」並排），進去一疊左右滑的卡、搜尋人、選人寫 |
| 客戶詳情的備註那一段 | **電話、LINE、長備註、短備註四種一起排順序**（她：「有些短備註我也會希望可以排到前面，電話，line有些人我也希望可以排到後面」），拖曳排（編輯旁一顆「調整順序」）。電話點了撥號；**LINE 點了打開他的 LINE**（標題就寫 LINE）；電話與 LINE 用符合 app 風格的 icon（自己畫，跟 `icons.js` 同一套線條，不用官方商標） |
| 長備註的設計 | **單獨一段先做可以點的手機版原型**（設計 skill、假名字），她看過才接線 |
| 上 staging | **段一的小畫面先單獨一支 PR**，早點讓她點到；其餘做完一起上 |
| issue 怎麼過目 | 照平常：唯讀 subagent 過目 → 主控對重的幾條 → 直接分段 |
| 圖 8 那一次 | 她印象中照片上只有一位，「但好像確實有沒認出來的人」—— 跟查到的原因一致（`photoBounds()` 要每一列都認出來才收窄） |

## 我自己定的（她沒講、照她的用法一定會撞到的）

- 待辦首頁的設定存在 `config/app`（手機與 iPad 同一份，跟排序權重同一個地方，有稽核）；**「依客戶」那一頁不受影響**（藏的只是總覽上那一列）
- 「一直顯示」的那一列沒事時畫成淡的 0；壓表登記本來就沒有數字（ADR-0041），一直顯示時照舊沒有數字
- 「客戶填好的時間」也能設定，預設「有才顯示」（客戶真的填了是要收的）
- 已經拿掉的那幾種（打電話、Abovee）不給設定：有舊資料就照舊列在最後面
- 「送的／體驗…」收起來時那一顆寫出選了哪一門並保持亮著 —— 當初做成收不回去的理由（「收起來看起來像取消選取」，`giftFold.js` 檔頭）還成立，這樣兩邊都顧到
- 「照片上寫的是」：同一次確認層裡她打開過的那幾列，重畫時保持打開；關掉確認層就忘了
- 復原那條：「儲存中…」與「失敗、重試」那兩種**不給滑**（失敗要看得見，SPEC 6.9）；「已經存在這台裝置上了」那一句也不給滑（那一句沒有逾時、是她要知道的狀態，上面有 `.netbar`）
- 合併檔或 Abovee 只寫「點滴8」「VIP7」、沒寫哪一床：**診間留空、那一列講一句請她選**（Abovee 5–10 月 353 列、合併檔 10/17 那一份都沒有這種，只是退路）
- EECP 的「體驗排幾分」做成課程上的一格（設定 → 課程），不是寫死 EECP —— 之後別門課要一樣的行為她自己填
- 長備註**不進試算表**（`customer.notes` 那份純文字鏡像只放短備註，ADR-0019）；**不畫在壓表卡片牆、讀取卡片**（那裡只放警示與短備註）
