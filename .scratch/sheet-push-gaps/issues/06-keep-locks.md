## 做法

- `render()` 讀的那一段先判 `keepLock`（`keepsLock()`）：有 API 那一份 → 剛好一道、說明一樣、網域不能改、只有我（`locksOk()`，跟 `_data` 同一套）；
  沒有 → 剛好一道（再問說明與名單要多讀好幾次，不問）
- 對了：`resetSheet()` 不拆、畫完不重上。不對（沒有鎖、兩道、說明不同、名單有別人）：照舊拆了重上
- 新建的分頁照舊上鎖
