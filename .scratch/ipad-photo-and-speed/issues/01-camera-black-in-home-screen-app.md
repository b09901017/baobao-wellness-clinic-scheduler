# 主畫面那一顆拍照一片黑：有畫面才顯示、沒畫面退回系統相機

Status: done（PR 進 develop；她 iPad 上還沒試）
動工前先讀：`public/js/ui/components/camera.js` 的 `startStream()`／`showFallback()`／`shoot()`；E2E `37-camera`（C1 拿不到相機、`fakeCamera()` 用 canvas 給影像）

## 為什麼

`startStream()` 拿到相機之後 `await video.play()`，回了才加 `cam--live`（影像本來是 opacity 0）。
iPad 主畫面那一顆有問權限、她按了允許，所以 `getUserMedia()` 是回了的；畫面黑而 Safari 分頁正常 →
多半是主畫面模式下 `play()` 一直沒回（`cam--live` 永遠不加），或回了但沒有影像。兩種都**沒有逾時**，
所以黑著、也不退回「改用系統相機」—— 而系統相機在她 iPad 上是好的。
綠色四個角一直都畫（只有退回時收起來），不代表相機活著。

## 做法

1. 不等 `play()` 的 Promise：叫了就好，**有影像才加 `cam--live`**（`requestVideoFrameCallback` 或 `currentTime` 在走）
2. 3 秒沒影像 → 關掉、換一組不指定解析度的再試一次（猜 4K 的要求在主畫面模式下拿不到畫面；試了不壞）
3. 再 3 秒還是沒有 → 退回（同一塊、兩顆），那一句改講「相機開了，但畫面一直出不來」
4. 還沒有影像時快門不拍（不然拍到一張黑的送去辨識）
5. 被拒、沒有相機照舊馬上退回（那一句不變）

## 判準

- E2E `37`：C1（拿不到相機）照舊；`fakeCamera()` 有影像的那幾支照舊 `cam--live`
- 新的一支：相機給了但一格影像都沒有 → 幾秒後退回、講「畫面一直出不來」、試了兩次
- **她的 iPad 上**（測試版）：主畫面那一顆打開拍照 → 看得到取景，或幾秒後換成「畫面一直出不來」＋兩顆
