# 抽屜不用自我介紹

Status: done

## 原話

> 「然後其實也不用說明 不用說『5 件事。點一筆看細節，要改再按鉛筆。』
> 就如同截圖 1 那樣乾淨簡潔」

## 要做什麼

`openDay()` 現在傳給 `openSheet()` 的 `note` 有兩種：

```js
note: n
  ? `${n} 件事。點一筆看細節，要改再按鉛筆。`
  : '這天還沒有東西 —— 但同事在 Abovee 壓的看不到，空的不代表真的空著。'
```

**前者拿掉。** 「點一筆看細節」是她每天做十次的事，寫出來只是佔一行；
件數清單自己數得出來。

**後者不能拿掉，但要換位置。** SPEC 第 8.6 節最後一段明講這一頁要說出
「同事在 Abovee 壓的看不到，空的不等於有空」，那是防止她把日曆當可用時段表用的
唯一一句話。把它從抬頭底下的 `note` 搬進**內容區的空狀態**裡（`dayHtml()`
現在已經有一句「沒有排東西」，換成這一句），這樣：

- 有東西的那一天：抬頭底下什麼都沒有，直接是清單。
- 空的那一天：清單的位置上就是那句話，而且只在真的空的時候出現。

順帶一提，`dayHtml()` 那句「`8/14` 沒有排東西。」裡的日期可以拿掉 ——
抬頭就寫著那一天了。

## 一起要檢查的

- `sheet.setNote('')` 在編輯器掛進來時本來就會被呼叫，不受影響。
- 其他抽屜的 `note` **不在這一條的範圍內**（隨手記泡泡那句「客人臨時說的
  小要求」還有用，那一頁她一週開不到一次）。這一條只動日曆那一天的。

## 驗證

- 瀏覽器：有東西的那一天，抬頭底下直接接清單，沒有多一行
- 瀏覽器：空的那一天，那句 Abovee 的提醒看得到
