# 那一天的清單全是框框，主體應該是名稱

Status: done
來源：使用者，2026-08-24（spec.md 的 c）
動工前先讀：`SPEC.md` 第 8.0 節「縮小的是包裝，不是資料」、`docs/adr/0039`

## 原話

> 「抽屜的清單呈現我也希望不要用框框框起來的感覺，可以如截圖 1，
> 就是沒有任何的框框，主體是名稱，旁邊小小的才是時間」

## 現在長什麼樣

抽屜裡的內容是 `dayHtml()`，一筆來訪是 `.timerow`：時間欄、一條 3px 色棒、
一整塊 `.timerow__body`，而那一塊在 `app.css` 裡有底色、圓角與內距 ——
就是一張卡片。一天五筆就是五張卡片，卡片之間再加間距，於是**框線與留白
佔掉的高度比字還多**。

她的參考截圖裡一筆是這樣：

```
08:00   ▌ 心超
09:00
```

沒有卡片、沒有底色。左邊一小欄兩行的起訖時間（淡、小、等寬），一條細色棒，
右邊名稱用正常字級。分隔靠留白，不靠框。

## 要做的事

### 1. 一筆長這樣

```
 09:30  ▌ 客戶A                              已完成
 10:30    靜脈・治3
```

- **時間欄**：兩行（起、訖），`--text-2xs`、`.num`（等寬）、`--text-mute`。
  它是索引，不是資料。
- **色棒**：留著，寬度不變。它是「這是哪一種、到哪一步了」唯一的線索
  （ADR-0039 那七種要分辨的東西），拿掉的話狀態就只剩右邊那顆徽章。
- **名稱**：`--text-md`，正常字重到 600。**這是這一列的主體**。
- **第二行**（課程・診間・治療師）：`--text-xs`、`--text-dim`，跟現在一樣。
- **狀態徽章**：留在右邊。她掃這一頁有一半是為了「這筆客人回了沒」。
- **底色、圓角、邊框全部拿掉。** 分隔用垂直內距（上下各 `--space-3`），
  需要的話最多一條 `--border-soft` 的髮絲線 —— 先做沒有線的版本看看。

### 2. 這是抽屜裡與整頁日檢視共用的

`dayHtml()` 同時餵給「點一天滑出來的抽屜」與「頂端切到日檢視的整頁」。
兩邊用同一份 —— 同一天的同一筆在兩個地方長得不一樣，她會以為是兩種東西。

### 3. 週檢視跟著改

`weekHtml()` 現在一天包一張 `.card`，裡面每一筆又是一顆 `.note` 按鈕
（另一種框）。改成同一套列的文法：一天一段，段的抬頭是日期＋星期，
底下是同樣的「時間欄＋色棒＋名稱」列。**卡片可以留在「一天」這一層**
（那是分組，不是分隔每一筆），但一筆一顆按鈕的框要拿掉。

## 要小心的

- **點擊區還是 44px**（SPEC 第 8.0 節）。沒有框不代表按不到 —— 用 `padding`
  把整列撐開，整列都是那顆按鈕，不要只有名字可以點。
- 沒有框之後**按下去的回饋**要補上（`:active` 給一層 `--surface-2` 的底色），
  否則她會不知道自己有沒有點到。這在觸控上比在桌機上重要得多。
- `.timerow` 目前也被日檢視的行事備註列（`eventRow()`）用，一起改。
- 撞診間／治療師的那條 `.warn` 提示留著，它本來就該顯眼。

## 驗證

- `npm test`
- 瀏覽器：一天有五筆（含兩筆同客戶）→ 抽屜裡掃得完，不用捲
- 瀏覽器：整頁日檢視與抽屜長一樣
- 瀏覽器：週檢視七天
- 深色模式兩邊都看 —— 拿掉底色之後深色模式最容易變成一團黑

**2026-08-24 —— done。** `.timerow` 整組重寫：底色、邊框、圓角全部拿掉，

- **`:active` 一定要有。** 沒有框之後，「這裡按得動」在觸控上沒有任何線索
  （沒有 hover 可以先告訴她）。按下去給一層 `--surface-2`。
- **色棒一列一條，不是一條貫穿整天的脊椎。** 第一版沒有留間距，上下兩筆的
  色棒接在一起，兩筆看起來像同一段。加了 `margin: 3px 0`。
- **週檢視的卡片留在「一天」那一層。** 那是分組不是分隔每一筆，
  拿掉的是一筆一個框（原本的 `.note` 按鈕）。

`dayHtml()` 同時餵給抽屜與整頁日檢視，所以兩邊自動一致 —— 這是它原本就
寫對的地方。
