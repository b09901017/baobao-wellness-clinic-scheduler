# 總覽上的一列只有標題

Status: done
來源：使用者，2026-09-04（spec.md 的第一）
動工前先讀：`docs/adr/0028`、`0033`、`0043`、`SPEC.md` 第 8.1 節

## 原話

> 我希望不要有多餘的說明文字，像是總攬的那 7 個步驟中的每個子項目都有說明，
> 其實不用，就留標題，像是問這輪時間，客戶填好的時間等等就好，
> 不需要多餘的說明，會讓畫面很亂

## 現在畫面上有幾句

`ui/views/home.js` 的 `overviewHtml()` 每一列都帶一句 `note`：

| 段 | 一列 | 現在那一句 |
|---|---|---|
| ① | 問這輪的時間 | 其中 N 位已經發出連結，在等他填・點進去可以換月份 |
| ① | 客戶填好的時間 | 客戶自己填的，看過就收下 |
| ② | 壓表登記 | 9月還沒排到的人 |
| ③ | 跟客人確認時間 | 壓好了、還沒問過本人 |
| ④ | Examine | 預約作業 → 查核 → 已報到 |
| ④ | 耀聖 | 右下角 → 未報到 → V |
| ④ | （已取消的種類） | 這個類別已經取消了，這是舊資料 |
| ⑤ | 簽療程單 | 來了、單簽了就打勾，次數這時才扣 |
| ⑥ | 寫紀錄 | 客人走了，去把紀錄補上 |
| ⑥ | 追蹤健檢報告 | 健檢做完了，報告通常兩三週出來 |
| ⑥ | 寄報告給醫師 | 報告拿到了，寄一份給要看報告的那位醫師 |
| ⑥ | 約二返 | 報告拿到了，還沒約聽報告的時間 |
| ⑦ | 改時間／取消 | 要回頭取消舊登記 |

十三句，全部同時在畫面上。段落標題另外七個。她要的是「接下來做什麼」，
而畫面回答的是「這十三種各自是什麼意思」—— 那是第一次用的人的問題，
不是第三百次用的人的問題。

## 一句都不會真的消失

這是這一支敢做的唯一理由。**每一句在點進去那一頁的第一行都還在**
（`GROUPS[].lead` 與 `renderGroup()` 的 `meta.lead`）：

```
confirm: '壓好了、還沒問過本人。問完回來按打勾。'
close:   '客人來了、療程單簽了就打勾。次數是這時候才扣的。'
cancel:  '來訪取消後，要回去把已經做掉的登記收回來。'
（已取消的種類）: '這個類別已經取消了 —— 底下是舊資料，不會再長出新的。'
```

`KIND_NOTES`（Examine 那幾句）也**不刪**，它是 `renderGroup()` 那一頁的
`meta.lead` 的來源。同一組字另外還住在 `docs/操作手冊.md` 第 190–191 行
與 `CONTEXT.md` 的「Examine」「耀聖」兩條。

換句話說：**操作說明搬到她真的要操作的那一頁**，總覽只回答「有幾件、哪一段」。

## 要做什麼

### 1. `groupRow()` 拿掉 `note`

```js
function groupRow({ href, label, n, danger = false, faded = false, reminder = false })
```

**參數整個拿掉，不是傳空字串。** 留著參數等於留著一條路，下一個人會再塞一句
進來，而這一頁就是這樣長出十三句的。`.grouprow__note` 這個 class 由
`components/note.js`（給營養品那一格的 hint）與 `views/calendar.js`
（卡片牆上的永久限制）共用，**CSS 不刪**。

### 2. 三支推導的列跟著改

- `askGroupRow()`：`sentCount` / `never` 那一整段算式拿掉，只留 `n`。
- `inboxGroupRow()`：只留標題與 `n`。
- `bookGroupRow(today)`：只留標題（它本來就沒有數字）。
  **`monthLabel(today)` 拿掉之後 `today` 這個參數就沒人用了**，一起清掉。

### 3. 已取消的種類：一整句換成一顆小標記（2026-09-04 她決定的）

那一句「這個類別已經取消了，這是舊資料」換成標題旁邊一顆小丸子：

```
打電話  舊資料                                    3  ›
```

- `groupRow()` 多一個 `tag`（只有這一種列會傳），畫成 `.grouprow__tag`：
  `--text-2xs`、`--text-mute`、一圈淡框，**跟數字分開站**。
- **不佔一整行** —— 這一支要拿掉的就是那一行；一顆丸子是「這一列跟別列不同」，
  一整行是「讓我解釋給你聽」，她要的是前者。
- 點進去第一句話仍然是完整版：「這個類別已經取消了 —— 底下是舊資料，
  不會再長出新的。勾掉就不會再出現。」

`tag` 這個參數**只給這一種列**。它不是 `note` 改個名字 —— 一顆丸子放不進
「預約作業 → 查核 → 已報到」，這個限制本身就是護欄。

## 這一支推翻了 ADR-0033 的一半

ADR-0033 的原話是「一個數字後面配一句話，比兩個互相矛盾的數字好懂」，
講的就是「問這輪的時間」那一句。**要解釋的那件事沒有變**（那個數字沒有減掉
已經發出連結的人），變的是解釋它的地方：

2026-09-02 之後點進去那一頁分成三區（**還沒發連結／已經發出／這個月已經問到
了**），「已經發出」那一區每一列還帶著 `等待回覆`／`已填寫時段`／`已確認排定`
三顆徽章之一。**那一區是那句話的完整版**，而且它就在那個數字的後面一次點擊處。

`docs/常見問題.md` 第 236 行「我明明問過這個人了，『問這輪的時間』怎麼還列著他？」
也是同一件事的第三個家。同一句話現在有三個地方在講，總覽上那一句是最沒用的
一個 —— 它出現在她**還沒問這個問題**的時候。

要補一支 ADR（見 issue 05）。
