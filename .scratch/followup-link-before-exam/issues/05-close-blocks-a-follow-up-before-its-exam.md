## 她要的

> 3. 二返比健檢先簽完成：簽二返時，所接的健檢沒做完就擋（現在存檔驗證只擋還開著的段，要補）。

## 範圍

- 一支 domain 判斷「這一段現在能不能簽成做了」：接的那一次健檢 `usedAndDone()`，**或同一次結案裡健檢那一段也打 ✓**；
  沒連結的照舊簽得下去（`01` 第 6 條）。抽屜、`closeConsequences()`、`closeVisit()` 共用。
- `closeVisit()` 自己也擋（ADR-0111 的形狀：改狀態的那一支動手前自己問）—— 擋下來的那一段當成「先不結」。
- 抽屜：那一列 ✓ 按不下去＋一句「接的那一次健檢（M/D）還沒做完」；「全部做了」跳過它、講跳過了幾段。✗ 照樣按得下去。

## 判準

- 二返先 ✓、B 還沒做完：✓ 按不下去、講出原因；「全部做了」跳過它；`closeVisit()` 收到 ✓ 也不動它。
- 同一張抽屜 B ✓＋二返 ✓（同一天的兩段）可以。
- 沒連結的二返照舊簽得下去、照舊扣一次。
- 抽屜那一句「會扣 N 次」與存完的 toast 照舊同一支（`chargedOnClose()`）—— 擋下來的那一段不算進去。

## 做完時留下的

- `followups.js` 的 `cannotClose(visit, index, picks, { entitlements, visits })`（一段）與 `closeBlocks()`（一張抽屜裡打了 ✓ 卻簽不下去的）。
  二返問它配的那一筆健檢、n返（沒有額度）問有配二返的那幾筆健檢（不 import `nthFollowup.js` —— 那一支 import 這一支）。
  接的那一次不在手上那一份裡、沒連結、認不出是哪一種的都不擋（不知道就不擋）。
- `closeVisit(visit, attended, at, guard)` 的第四個參數：帶了就把擋下來的 ✓ 當成先不結。只有簽療程單抽屜傳（`applyClose()`，拿剛讀回來的全部來訪）；
  `applyStatus()` 整天那一條（`to === 'done'`）沒有任何畫面在用，沒傳。
- `closeConsequences()` 先擋過再講每一句；被擋的那一段多一句「健檢（M/D）還沒做完 —— 這一段先不結」—— **畫面上 ✓ 按不下去，所以平常看到的是「還有 1 段先不結」**，那一列自己講原因（`data-close-blocked`）。
- 抽屜：`pickRow()` 多 `yesOff`；「全部 ✓」的 keys 跳過簽不下去的；畫之前把已經不成立的 ✓ 拿掉（同一天健檢的 ✓ 拿掉時）。抽屜補讀之前（`customerVisits` 還沒讀到）不擋，存的那一下重讀再問。
  `.slotpick__btn:disabled` 一條 CSS。
