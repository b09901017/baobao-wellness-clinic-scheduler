# 二返排在接的那一次健檢之前：提醒、不擋

Status: done
Blocked by: 02

## 她要的

> 4. 改二返日期排到健檢之前：只提醒不擋。

## 範圍

- `assignmentWarnings()` 多一句（warning）：「二返排在接的那一次健檢（M/D）之前」。同一天比開始時間。只講還算數的段。
- `mustSee()` 不收（不改變寫入結果）—— 寫進「做完時留下的」。

## 判準

- 二返排在 B 之前：提醒、照樣存得下去；同一天二返的開始時間早於健檢也講；之後的不講。
- n返 也接得到未來的健檢 → 同一句（不然兩排長得一樣、規則不一樣）。

## 做完時留下的

- `visits.js` 的 `examAfter()`：別天比日期、同一天比開始時間（健檢那一筆還活著的第一段健檢）。二返問它配的那一筆、n返 問每一筆健檢額度。
  接的那一次不在手上、日期或時間壞了就不講。提醒落在 `assign` 那一圈（`assignmentWarnings()`），**不進 `mustSee()`**（不改變寫入結果）。
- n返 那一句的名字用返數（「三返 排在…」），二返用課程名。
- 只有單元測試（E2E 沒有另外量）：句子走 `validateVisit()` 的 warnings，三個入口都經過它。
