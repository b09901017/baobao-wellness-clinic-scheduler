# 客戶詳情那一句：做完、約了、還沒約三個數字

Status: todo
Blocked by: 02

## 她要的

> 4. 不算，我的想法是二返完成才算 ? 這樣合理嗎?

落成（`01`）：畫面的字與系統的帳分開 ——「健檢做完 N 次：二返做完 a 次、約了 b 次（M/D…）、還沒約 c 次」，「做完」才是做完。
`owed()` 照舊把約了的算進去（02 只扣接在沒做完的健檢上的）。

## 範圍

- `describePair()` 回三個數字與那一句；`owed` 欄位照舊（呼叫端用它決定要不要畫成提醒的樣子）。
- 約了的那幾場帶日期（最多列幾個，其餘「…」）。
- 「還沒約」＝`owed()`（跟「約二返」那張待辦同一個數），不是自己再算一次。

## 判準

- 健檢做完 2 次、二返做完 1 次、約了 1 次 → 「二返做完 1 次、約了 1 次（M/D）、還沒約 0 次」之類，三個數字加起來講得通。
- 先約好、接在還沒做完的健檢上的那一場：算「約了」、不算「做完」；健檢做完 N 次那個 N 不含它的健檢。
- 沒有二返額度的不畫（照舊回 null）。
