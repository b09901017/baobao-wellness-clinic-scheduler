# n返：試算表要印在健檢那一欄底下

Status: 動工中
來源：她的四件事，2026-09-02（`../spec.md`）
前置：issue 03
動工先讀：ADR-0024（試算表照著她的舊表）、ADR-0010／0013（推出去的是報表不是服務）、
CLAUDE.md 的 `SYNC_FORMAT` 那一列

## 她要的

> 試算表紀錄的部分就是，和二返一樣紀錄在健檢預約的下面，有二返(...) 三返(...)

現在 `domain/sheetReport.js` 的 `followupNotes()` 產生一排
`{ dateIndex, text }`，兩條路（手動貼上與自動推送）共用它，
`.gs` 那一側把它們寫在**同一列**上、對到那一次健檢的日期欄：

```
療程項目   應有 已完成 已排未上 剩餘 | 7/13 | 8/20 | 9/20 |
8萬健檢      2    2      0      0   |  ✓  |  ✓  |     |
二返（8萬健檢）2   1      1      0   |     |     |  △  |
                                    |9/20 二返(夏)|      |     ← 這一列
```

## 要做成什麼

同一格裡把那一次健檢底下的**每一返照順序列出來**，換行分隔：

```
                                    | 9/20 二返(夏)  |
                                    | 10/8 三返(李)  |
                                    | 四返()        |
```

`.gs` 那一側寫那一格時本來就有 `setWrap(true)`，所以換行不用改它。

### **不動 `SYNC_FORMAT`**（這是這個 issue 最重要的一句）

`followupNotes()` 回傳的形狀（`{ dateIndex, text }[]`）一個欄位都不變，
變的只有 `text` 的內容。所以：

- `sheets/readonly-report.gs` **不用重貼、不用重新部署**
- `SYNC_FORMAT` 維持 3，`SUPPORTED_FORMAT` 維持 3，
  `tests/sheet-script.test.js` 那一條守衛照樣過

CLAUDE.md 對這件事的警告很具體：格式對不上時「app 照樣推、`.gs` 整包拒收，
而且畫面上看起來跟推好了一模一樣」。為了一個換行讓她回 Google 試算表
重貼一次腳本，代價完全不成比例。

另一個作法是讓 `.gs` 一返一列（`followupNotes` 多一個 `row` 欄位），
排版好看一點，但那**是格式變更**，要她重貼＋重新部署。
除非她說想要，否則走換行那一條。

### 順序與空括號

- 照 `n` 由小到大：二返 → 三返 → 四返
- **還沒約的 n返 不會出現**。二返有「`二返()`」這個空括號的寫法（她自己的寫法，
  意思是「這件事還沒做」），因為二返是一定要約的；n返 是加約的，
  「沒有三返」是常態不是待辦，印一個空的 `三返()` 等於每一位客戶的表上
  都多一行永遠做不完的事
- 括號裡是醫師（`staffById`，跟二返同一支）；還沒定就印 `三返()` ——
  這一種空括號是有意義的：那一場**已經約了**，只是醫師還沒定

### 實作位置

`domain/sheetReport.js` 裡 `followupNotes()` 現在的那一圈**維持原樣**
（它是二返的，走 `pairsOf()` 與 `bookingsByExam()`），
後面接一段從 `domain/nthFollowup.js` 的 `followupsOfExam()` 拿到的 n返，
再照 `dateIndex` 收攏成一格。

收攏那一段要小心：現在手動貼上那條路是
`for (const note of notes) line[COUNT_COLS + note.dateIndex] = note.text;`
—— **後面的會蓋掉前面的**。所以收攏一定要在 `followupNotes()` 裡面做完
（同一個 `dateIndex` 只回一筆，`text` 裡面有換行），兩條路才會長一樣。
這一支的檔頭就寫著「兩條路必須長一樣，同一份報表因為走哪條路而長得不同，
她會以為其中一條壞了」。
