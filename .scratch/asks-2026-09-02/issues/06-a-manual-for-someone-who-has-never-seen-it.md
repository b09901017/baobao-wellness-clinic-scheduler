# 給沒看過這個系統的人的一本手冊

Status: 動工中
來源：她的四件事，2026-09-02（`../spec.md`）
動工先讀：`CLAUDE.md` 的「文件分工」那張表

## 為什麼這件事有一個陷阱

CLAUDE.md 第一條規矩是「**同一件事只寫在一個地方**」，而一本操作手冊
天生會把 SPEC、CONTEXT、ADR 的內容再講一次。所以先把界線畫死：

| 檔案 | 只放 | 這一輪新的 |
|---|---|---|
| `SPEC.md` | 需求、資料模型、業務規則、畫面規劃 | 不動（除了 n返 的欄位與 8.1 節那一列） |
| `CONTEXT.md` | 詞是什麼 | 新增「n返」 |
| `docs/adr/` | 為什麼這樣決定 | 兩支新 ADR |
| `docs/STAGING.md` | 怎麼操作**環境** | 不動 |
| **`docs/操作手冊.md`** | 怎麼操作**這個 app**：一步一步、給沒看過的人 | 新增 |
| **`docs/常見問題.md`** | 「我按了 X 為什麼沒有 Y」 | 新增 |
| **`docs/邊界測試清單.md`** | 上線前要親手點過的極端情境 | 新增 |

三份新文件**一條業務規則都不定義**，它們只描述「畫面上按哪裡」，
規則一律用一行連結指回 SPEC 或 ADR。這樣規則改了不會有兩份互相矛盾的說法。

## 一、`docs/操作手冊.md`

繁體中文，寫給**沒有技術背景、也沒看過這個系統的同事**。用 CONTEXT.md 的詞，
不用它標 _Avoid_ 的同義詞（那份詞彙表存在的理由就是這個）。

一條主線走完，每一步都寫「你會看到什麼、你要按哪裡、按完會發生什麼」：

```
新增客戶
  → 加購（方案或單項；健檢要選金額等級）
  → 系統自動配好二返的額度            ← 這裡連 ADR-0022
  → 問這輪的時間（發連結 / 自己問）
  → 收下客戶填的
  → 壓表（Abovee 上先佔住，回來記進 app）
  → 跟客人確認時間                     ← 這一步之後才長出掛號待辦，連 ADR-0027
  → Examine / 耀聖 掛號
  → 客人來了 → 簽療程單（次數這時候才扣）
  → 健檢做完 → 追蹤健檢報告 → 約二返    ← 連 ADR-0042
  → 客人說想再聽一次 → 加約三返         ← 這一輪新的
  → 試算表自己更新
  → 收工前看「今天做了什麼」
```

每一段配一張**用文字畫的畫面草圖**（就是這幾份 issue 裡那種），
不放截圖 —— 截圖會過期，而過期的截圖比沒有截圖糟。

另外三小段：
- **這七種顏色分別是什麼**（日曆，連 ADR-0039／0045）
- **待辦、任務、隨手記差在哪**（CONTEXT.md 那三條的白話版）
- **哪些東西刪得掉、刪掉去哪裡找**（設定 → 已刪除項目，SPEC 第 6.1 節）

## 二、`docs/常見問題.md`

只收**「我按了 X 為什麼沒有 Y」**這一種。每一條三行：現象、原因、怎麼辦。
初版從程式碼裡已經寫下理由的那幾處抄過來（那些都是真的發生過的）：

- 我勾了「跟客人確認時間」，怎麼還是沒有 Examine 的待辦？→ 要**確認**之後才長（ADR-0027）
- 我在客戶詳情點來訪那一列，怎麼進不去編輯？→ 改一筆來訪只有日曆一個入口（ADR-0056）
- 我把二返約好了，「約二返」那張待辦怎麼還在？→ 那一段要指到是**哪一次健檢**的
- 我改了試算表，怎麼被蓋回去了？→ 那是唯讀報表，改要回 app（ADR-0010）
- 同一個月的「不能的時間」怎麼有兩份？→ 資料健檢會列出來，她自己刪（ADR-0053）
- 我按了儲存，出現「還沒送出去」？→ 離線了，資料在這台裝置上，連上網會自己補送
- 三返沒有扣次數，是不是壞了？→ **沒壞，n返 本來就不扣**（這一輪新的）
- 表單連結客戶說打不開／填過了？→ 一條連結只能填一次，改法是重發一條

## 三、`docs/邊界測試清單.md`

她指名**不要 happy path**。所以這一份只列「新手最容易踩、而且踩了會留下壞資料」
的情境。每一條四欄：怎麼做、預期行為、驗收標準、對到哪一條規則。

分五組（每組 6–10 條）：

**A. 連點與競態**
- 連按兩下「產生表單連結」→ 只能產生一條（`withSaveState` 的 `key`）
- 抽屜裡連點兩下同一張待辦 → 只寫一次
- 兩台裝置同時勾同一張待辦 → 不會變成一勾一反勾
- 壓表面板連點兩下「存」→ 只有一筆來訪

**B. 日期的邊界**
- 在**過去的月份**記一次「不能的時間」→ 存得下去（`AHEAD` 從 `i=0` 起算就是為了這個）
- 在過去的日期排一筆未來狀態的來訪
- 跨月的來訪：8/31 排一筆、9/1 排一筆，壓表挑到的是哪一份可用性（ADR-0036）
- 月底最後一天發出的連結，隔天還打不打得開（`expiryOf()` 刻意寬鬆）
- 閏年 2/29、月底 31 號的月份切換

**C. n返（這一輪新的）**
- 一位**還沒有任何健檢**的客戶 → 那顆丸子不出現
- 健檢排了但**還沒結案** → 沒有候選可以接，畫面要講出來，不是一片空白
- 同一次健檢**連續加三個 n返** → 預設值一路變成三、四、五返
- 加了 n返 之後**去把那一次健檢取消掉** → 資料健檢要看得見這件事
- n返 存檔之後客戶詳情的次數**一次都沒有變**
- 二返與 n返 在同一天同一筆來訪裡

**D. 網路與離線**
- 飛航模式下勾一張待辦 → 八秒後那一句**不可以寫「失敗」**
- 離線時抽屜裡勾三筆 → 回線上之後三筆都在
- 弱網（DevTools Slow 3G）切換月份 → 不可以出現半份名單

**E. 資料看起來壞掉的時候**
- 主檔把一個課程刪掉，用過它的客戶還在不在「壓表登記」那一列
- 額度被刪掉之後，那幾筆來訪在客戶詳情長什麼樣
- 客戶填完表單之後她才重發一條新連結
- 同一位客戶同一個月兩份「不能的時間」
