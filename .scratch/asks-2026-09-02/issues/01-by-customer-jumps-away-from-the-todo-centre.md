# 待辦中心「依客戶」點一位客戶就跳走了

Status: done
來源：她的四件事，2026-09-02（`../spec.md`）
動工前先讀：ADR-0043（待辦中心照流程分段）、ADR-0048（多一層就多一步退得掉的路）、
ADR-0056（只有日曆改得了一筆來訪）、SPEC 第 8.1 節

## 症狀

待辦中心 →「依客戶」→ 點任何一列：

`views/home.js` 的 `byCustomerHtml()` 畫的是
`<a href="#/customers/{id}">`，所以一點就**離開待辦中心**，落在客戶詳情頁。
她要在那裡把任務找出來（那一頁的任務區在整頁的下半段、還分未完成／已完成兩格），
勾完之後按返回鍵回到待辦中心 —— 而回來的是**重新畫過的一頁**，
「依客戶」那個看法沒有存進網址（`tab` 是模組變數），所以她會落回「總覽」。

她的原話：「打斷管理師批次處理待辦事項的操作節奏」。

一位客戶處理完要五步：點 → 捲 → 勾 → 返回 → 再切回「依客戶」。二十幾位就是一百步。

## 要做成什麼

點一列**不換網址**，從底部滑出一張抽屜（`components/sheet.js` 的 `openSheet()`，
全站共用的那一支，桌機寬度 ≥900px 時 CSS 自己變成置中對話框）。

```
┌─────────────────────────────────┐
│  ▁▁                             │   ← 抓把手，往下甩掉
│  王小明                      ✕  │
│  身上還有 3 件事                 │
├─────────────────────────────────┤
│  ☐ Examine                      │
│    9/14(日)・復能、營養針        │   ← 跟客戶詳情同一支 taskRow()
│    死線 9/13                 詳情›│
│  ☐ 約二返                        │
│    9/3(三)・8萬健檢              │
│    還沒約 · 死線 9/10        去壓表│
├─────────────────────────────────┤
│  跟客人確認時間 2 筆         去確認›│   ← 不是勾選框，見下面
└─────────────────────────────────┘
```

### 為什麼是抽屜而不是就地展開

就地展開（像可用性的「以前問過的」）要她在一份會變長變短的清單裡上下找位置，
而這一頁的清單本來就是照「還有幾件事」排序的 —— 勾掉一筆順序就變了。
抽屜把「我現在在處理誰」釘住，關掉才回到清單。

抽屜吃返回鍵（`openSheet()` 內建 `pushLayer()`，ADR-0048），也吃往下甩。

### 每一列長什麼樣：**直接用客戶詳情那一支**

`views/customerDetail.js` 的 `taskRow(t, visit)` 已經是她點名要的那個樣子
（種類正常粗細、`9/1(日)・二返` 淡一級、死線丸子、右邊「詳情 ›」），
而且日期走 `domain/taskRules.js` 的 `taskLine()`。

**把那一支抽到 `ui/components/tasklist.js`**，客戶詳情與這張抽屜共用。
不共用的話這一輪就多了第三份任務列的寫法（待辦中心那一頁自己還有一份，
那一份是多選勾選框，用途不同，先不動它）。

抽屜這一側多兩樣客戶詳情沒有的：

- 「約二返」那幾列右邊多一顆「去壓表」（首頁那一頁已經有 `bookFollowup()`，
  抽到共用時把它當成呼叫端傳進來的動作，不要在元件裡判斷種類）
- 「還沒約 / 已約 9/3」那顆徽章（`bookingStateForTask()`，同一份資料）

### 「跟客人確認時間」那一列**不是勾選框**

它不是任務，勾掉它等於走完整條確認動線（把所有時段攤開、逐筆退回、
產生取消任務）—— 那是 `#/todo/confirm` 那一頁的工作，硬塞進抽屜會變成
抽屜裡再開一張抽屜，而 `sheet.js` 同一時間只留一張。

「簽療程單」一模一樣：勾掉它是 `closeVisit()` 逐段記結果（ADR-0025），
不是一個布林值。

所以那兩列長得像路：`跟客人確認時間 2 筆　去確認 ›`、
`簽療程單 9/1 的來訪　去收尾 ›`，點下去關掉抽屜並換頁。
**這是這張抽屜裡僅有的兩個會換頁的動作**，而且它們換到的是
「做這件事的地方」，不是「這個人的資料頁」——
她原本的抱怨正是被丟到後者。

### 抽屜裡列哪些（她 2026-09-02 決定：**連「簽療程單」也列**）

三種：

1. **任務**（含取消類）—— 勾選框，可以直接勾
2. **跟客人確認時間** —— 一條路，連到 `#/todo/confirm`
3. **簽療程單**（`visitsToClose()`）—— 一條路，連到 `#/todo/close`

所以 `byCustomerHtml()` 那顆數字要**跟著改成三種相加**。數字與清單不一致
是這一頁踩過的錯，清單多一項就一定要先改數字。

`render()` 已經讀了 `unclosed`，`paint()` 已經算了 `toClose`，
所以這一件不用多讀任何一份資料 —— 把 `toClose` 一起傳進 `byCustomerHtml()` 就好。

**兩條路要長得像路，不能長得像勾選框。** 抽屜裡分兩段，中間一條分隔線：
上面是勾得掉的，下面是「要去別的地方做的」，各自有一行小字說明為什麼不能在這裡勾。

## 勾掉一筆之後會發生什麼

### 樂觀更新

`toast.withSaveState()` 已經是這件事的唯一入口（`ui/toast.js`），
它處理了「離線時 Firestore 的寫入 Promise 既不 resolve 也不 reject」那一條 ——
逾時走 `PENDING_MS` 換一句**不可以說「失敗」**的話。這一支不要繞過它。

畫面上先動：那一列立刻劃掉（`.note--done`）、抽屜的抬頭數字減一、
底下那張卡片的徽章減一。寫入失敗就把那一列翻回來，並用 toast 講出原因。

`withSaveState()` 的 `key` 要傳（`tests/save-guards.test.js` 會掃）——
這裡不是「建立新資料」的按鈕，但抽屜裡連點兩下會送兩次
`setDone`，而第二次會把 `doneAt` 覆蓋掉。

### 全站要跟著更新的是哪些

先講清楚，免得做多餘的事：

| 畫面 | 要不要同步 | 為什麼 |
|---|---|---|
| 待辦中心底層（卡片、總覽三顆數字） | **要** | 同一頁，同一份 `ctx.tasks` |
| 客戶詳情 | 不用特別做 | 另一條路由，進去時 `render()` 重讀 |
| **日曆** | **不用做，而且不可以做** | **任務不上日曆**（ADR-0044、0045、CONTEXT.md 的「待辦」）。日曆上的「待辦」是 `notes` 裡有日期的那幾筆，不是 `tasks`。這裡沒有第二份資料要同步 |
| 進度追蹤 | 不用 | 同客戶詳情 |

所以「全站關聯響應」實際上只有一件事要做：**勾完之後這一頁自己要對**。

做法是勾完就地更新 `ctx.tasks`（把那一筆的 `done` 改掉）再 `paint(ctx)`，
**不是整頁重讀** —— 重讀會讓她在抽屜開著的時候看到底下閃一下，
而且 `loadAsk()` / `loadBook()` / `loadInbox()` 那三份會再跑一次
（三次 collection group query，見 `render()`）。

### 一個真的會出事的地方：勾掉「追蹤健檢報告」會長出「約二返」

`data/tasks.js` 的 `setDone()` 收的是**任務本身不是 id**，而且會連著跑
`followupOpsAfterTaskChange()`，把「約二返」那一張寫在同一個 commit 裡
（ADR-0042）。所以抽屜勾掉一張「追蹤健檢報告」之後，這位客戶身上會
**多一張新的任務**，不是少一張。

就地更新那一段一定要處理這件事，否則她會看到數字從 3 變成 2，
關掉抽屜再打開又變回 3。做法：這一種勾完之後重讀 `tasksData.listOpen()`
（只有這一種），其餘的走就地更新。

## 動畫

抽屜的滑入／甩出是 `sheet.js` 既有的，不重寫。這一輪只加兩樣：

- **按壓回饋**：卡片列 `:active` 時 `transform: scale(.985)`，120ms。
  跟長按選單那幾顆共用同一組變數（見 issue 07）。
- **勾掉的過場**：`.note__box` 打勾 140ms 淡入、整列文字 180ms 變灰＋劃掉。
  不要位移、不要高度動畫 —— 那一列不會消失，位移只會讓她以為點錯了。

## 驗證

- `npm test`
- 瀏覽器：待辦 →「依客戶」→ 點一位有兩張任務的客戶 → 抽屜滑出 →
  勾一張 → 立刻劃掉、抬頭數字減一 → 甩掉抽屜 → 底下那張卡片的數字也減一 →
  進客戶詳情看得到那一張在「已完成」那一格
- 返回鍵：抽屜開著按返回 → 關掉抽屜，**不換頁**
- 勾一張「追蹤健檢報告」→ 抽屜裡當場多一張「約二返」
- 離線（DevTools）勾一筆 → 八秒後出現「還沒送出去」那一句，**不可以寫「失敗」**
