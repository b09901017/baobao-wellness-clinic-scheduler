# 加購健檢沒得選金額等級

Status: todo
來源：她的十二件事，2026-08-25（`../spec.md`）
動工前先讀：`CONTEXT.md` 的「健檢」、`docs/adr/0022`、`docs/adr/0003`

## 症狀

她的原話：「關於加購方案 + 健檢，加購健檢的話要多一個選項是這個是幾萬的健檢，
有 8、12、0.75 的健檢。」

客戶詳情 → 額度 → 加購 → 選「健檢」→ 存下去，那一筆就叫「健檢」。
她手上的健檢有金額等級之分，兩筆都叫「健檢」的話客戶詳情頁分不出哪一筆是哪一筆
——而**那正是 `followupDraft()` 的註解已經寫過的問題**（二返那一筆為此帶上了
來源的名字），只是健檢那一端沒有補上。

`CONTEXT.md` 早就寫了這件事：

> **健檢**：健康檢查課程。有金額等級之分（例：0.75 萬、12 萬），
> **等級只影響顯示名稱與價格，不影響流程與任務。**

## 她的決定（2026-08-25）

在「額度上的一個欄位／固定三個/每個等級各開一個課程」三種裡，
她選了**額度上的一個欄位，而且可以自己加**。

## 要做成什麼

加購時，選了一個**有配二返的課程**（`followupCourseId` 有值 —— 不寫死「健檢」
兩個字，主檔上她隨時改得了名字）就多出一排丸子：

```
買了什麼   [ 復能 ] [ 靜脈 ] [ 健檢 ]✓ [ 營養點滴 ] [ 復能（三選一池）]
幾萬的     [ 0.75萬 ] [ 8萬 ]✓ [ 12萬 ] [ 其他… ]
幾次       [ 1 ]  +1 +5 +10
```

- 選了等級，顯示名稱自動變成「**8萬健檢**」（她沒有自己改過名字的話）。
- 「其他…」展開一個文字欄，打什麼就是什麼（「5萬(心臟)」）——
  她選的就是「可以自己加」。
- 等級存在額度上（`tier`），**不影響任何流程與任務**：`taskRules.js`、
  `followups.js`、`entitlements.js` 一行都不用改。
- 配出來的二返自動叫「**二返（8萬健檢）**」—— `followupDraft()` 本來就抄
  來源的 `label`，所以這一段不用動。
- 已經有的健檢額度沒有 `tier`，照舊顯示它的 `label`。**不補、不猜** ——
  猜一個金額出來比空白糟。

## 價格

`SPEC.md` 第 5.3 節的 `entitlements` 沒有價格欄位，整個 app 也不碰錢
（她的方案文宣才有）。所以這一輪只做顯示名稱那一半，`tier` 這個欄位留著，
之後真的要記價格時它就是掛點。

## 做了什麼

- `domain/entitlements.js`：`TIER_PRESETS = ['0.75萬', '8萬', '12萬']`、
  `tieredLabel(tier, courseName)`、`validateEntitlement()` 認得 `tier`
- `ui/views/customerDetail.js` 的 `buyFields()`：多那一排丸子（只在選到
  有二返配對的課程時出現）
- `firestore.rules`：`entitlements` 多一個選填的 `tier`
- `SPEC.md` 第 5.3 節的 `entitlements` 補一行

## 驗證

- `npm test`（`tests/domain.test.js` 的 `tieredLabel` 與 `validateEntitlement`）
- 瀏覽器：客戶詳情 → 加購 → 點「健檢」→ 出現「幾萬的」那一排 → 選 8萬 →
  顯示名稱自動變「8萬健檢」→ 加購 → 卡片上寫著「8萬健檢」，
  底下自動多一筆「二返（8萬健檢）」
