## 症狀

待辦 → Examine（耀聖、追蹤健檢報告、改時間／取消 都一樣）：
勾幾筆 → 按「把勾起來的標成完成」→ **那幾筆直接從清單上不見了**。

她的原話：

> 我希望能夠像隨手記那邊一樣，可以分未完成和已完成切換，勾起來按下確認後
> 可以跳出一個中間提示框，說移到已完成，然後是被劃掉槓掉的，然後一樣可以清除
> 然後這個和隨手記看全部那邊一樣我希望已完成那邊可以有日期，就是一樣是條列式
> 往下不過會有今天(完成的) 幾月幾號等等，然後都可以清除

隨手記在 `.scratch/todo-declutter/issues/08`（「勾掉的不該消失，她會勾錯」）
已經改成這樣了，任務那幾頁沒有跟上 —— `data/tasks.js` 只有 `listOpen()`，
畫面根本拿不到已完成的那些。

## 要做成什麼

**兩格切換**，跟 `#/todo/notes` 同一個 `.seg`：

```
[ 未完成 5 ] [ 已完成 12 ]
```

**已完成那一格照完成日期分段**，新的在上面：

```
今天
  ☑ 王小明  Examine     14:20 完成       🗑
  ☑ 陳小美  Examine     11:05 完成       🗑
8/24(日)
  ☑ 林小華  Examine                      🗑
─────────────────────────────
        [ 清掉這 12 筆 ]
```

- 每一列劃掉（`.note--done`，跟隨手記同一個樣子）
- 點一列可以拿回來（勾錯了要點得回來）
- 垃圾桶只在已完成的那幾列上出現 —— 還沒做的要刪就先勾掉再刪，兩步比誤刪好
- 「清掉」走軟刪除（SPEC 第 6.1 節），設定 → 已刪除項目 還原得回來

**勾完之後的提示框**

置中的 `confirmAction()`，不是右下角的 toast：

```
        把 3 筆標成完成？
  ─────────────────────────
   王小明・Examine
   陳小美・Examine
   林小華・耀聖
   它們會移到「已完成」，不會消失
   勾錯了可以點回來
  ─────────────────────────
      [ 取消 ]  [ 標成完成 ]
```

## 資料層要補的

`data/tasks.js` 多一支 `listDone(limit)`：`where('done','==',true)` +
`orderBy('doneAt','desc')` + `limit`（預設 200 —— 她要看的是最近做完的，
不是全部歷史；試算表報表要全部的話走既有的 `listAll()`）。

需要 `(deletedAt, done, doneAt desc)` 複合索引 → `firestore.indexes.json`
與 `SPEC.md` 第 5.4 節都要補（CLAUDE.md 的連動表）。

## 「已完成」那一格算哪些

跟未完成那一格用**同一個 `match`**（`renderGroup()` 裡那張 `filters` 表），
所以逾期／今天／明天這三種「照死線切」的分組，在已完成那一格也是照死線切的。
那是對的：她在那三頁問的是「這個死線的事情做完了沒」。
