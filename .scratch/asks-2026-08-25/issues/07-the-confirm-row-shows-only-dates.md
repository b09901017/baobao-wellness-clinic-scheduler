# 「跟客人確認時間」只看得到日期

Status: done
來源：她的十二件事，2026-08-25（`../spec.md`）

## 症狀

待辦 → 跟客人確認時間，每張卡片上那一排丸子只有日期：

```
王小明
壓了 5 段・已等 2 天
[ 9/14 ] [ 9/23 ]
```

她的原話：「我希望除了日期可以簡寫名稱，不用時間沒關係，就寫
9/14(一) 復能、營養針  9/23(三) 復能 就好。」

那一排是她**打電話之前最後看到的東西**，而她要講的正是「禮拜一做復能跟營養針」。
現在她得先按打勾把面板叫出來才看得到課程。

## 要做成什麼

```
王小明
壓了 5 段・已等 2 天
[ 9/14(一) 復能、營養點滴 ] [ 9/23(三) 復能 ]
```

- 星期照 `shortDate()`（她的日期一律帶星期）
- 同一天同一個課程只印一次（那天做兩節復能就是「復能」，不是「復能、復能」）
- 課程名讀 `slot.courseName`（來訪身上的快照，主檔改名不影響已經排出去的）
- 一個時段都沒有的來訪印「N 段」當退路 —— 印空白會讓那顆丸子看起來壞了

## 做了什麼

`domain/visits.js` 多一支 `visitCourseLabel(visit)`，`ui/views/home.js` 的
`confirmCard()` 用它。放 domain 不放畫面：「這一筆來訪講人話是什麼」
客戶詳情的來訪列（`visitRow()`）已經自己算過一次一模一樣的東西，
兩份遲早會有一份忘了去重。
