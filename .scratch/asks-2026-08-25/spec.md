# 十二件她點下去才發現的事

來源：使用者，2026-08-25（同一天稍早那一輪是 `../code-audit-2026-08-25/`）
動工前先讀：`CLAUDE.md`、`SPEC.md`、`CONTEXT.md`、`docs/adr/`

## 為什麼要這一輪

上一輪是我們自己掃出來的；這一輪是她把 app 打開、真的用了一遍之後列的。
兩份的形狀完全不一樣，值得記下來：

- 上一輪抓到的是**資料寫錯**（勾掉的待辦被改回未完成、一鍵修正按不動）。
- 這一輪抓到的幾乎全是**畫面沒把它知道的事講出來**：
  「不能的時間」沒說是哪個月、「以前問過的」一攤開就是一整片、
  待辦列上看不出那天要壓幾項、勾掉的任務直接消失。

只有兩件是真的壞掉：客戶詳情的換月份箭頭會跳到「記一次」（issue 04），
以及勾掉「追蹤健檢報告」不會長出「約二返」（issue 09）。兩件的成因是同一種：
**有一段狀態活得比畫它的那一頁久**（一個是殘留的事件監聽，一個是只在存來訪
時才跑的同步）。

## 這一輪的主軸：把月份講出來

她問時間的節奏是「月底那一兩個禮拜問下個月」，所以**一份「不能的時間」＝
一個月**。這件事 ADR-0036 已經決定了（壓表挑哪一份要看在壓哪個月），
但**畫面從來沒把月份印出來** —— 紅框框只寫「不能的時間」，「記一次」也不問
是哪個月，於是同一個月會被記兩份，而壓表只挑得到其中一份。

issue 01／02 把這件事補完：標題帶月份、記一次先問改哪一個月還是新增哪一個月、
一個月只留一份、改完之前先把差異講出來。決定寫成 ADR-0053。

## 她的三個決定（2026-08-25）

| 問題 | 她選的 |
|---|---|
| 一週從哪一天開始（三個畫面對不起來） | **全部改成週一開始** |
| 健檢的金額等級怎麼存 | **額度上的一個欄位，可以自己加**（等級只進顯示名稱，ADR-0054） |
| 同一個月已經有兩份「不能的時間」 | **資料健檢列出來，她自己刪**（不自動合併） |

## 這一輪之後留下來的東西

- 三支 ADR：0053（一份不能的時間＝一個月）、0054（健檢等級是額度的欄位）、
  0055（深色模式她自己切得動）
- `graphify-out/`：整份程式碼＋文件的知識圖（2070 個節點、5588 條邊、
  138 個社群）。`graphify query "…"` 問得到「誰呼叫誰」與「這個決定寫在哪」。
  它是 build artifact，`.gitignore` 擋著不進版控。
