# 資料健檢呼叫一個上一輪拿掉的函式

Status: done
來源：使用者，2026-08-25（spec.md）
動工前先讀：`SPEC.md` 第 6.6、8.7 節、`docs/adr/0007`、`0049`

## 症狀

設定 → 資料健檢 → **這一頁出錯了：rememberRun is not defined**

掃描本身跑完了（那是 `await` 在前面的事），死在要把結果記起來的那一行 ——
所以她連「掃出什麼」都看不到。

## 原因

7c4f348 照 ADR-0049 拿掉背景掃描時，把 `runIfDue()`、`lastBadge()`、
`rememberRun()`、`readLastRun()` 與 `LAST_RUN_KEY` 一起刪了。`runIfDue()`
裡面那個呼叫跟著走，但 `render()` 裡還有第二個，沒被看到。

## 要做什麼

把 `render()` 裡那一行拿掉就好，**不要**把 `rememberRun()` 補回來：
ADR-0049 拿掉它的理由是「寫進 localStorage 然後沒有人讀它」，現在讀它的
那顆徽章已經不存在，補回來等於把那段程式原封不動地重新種一次。
