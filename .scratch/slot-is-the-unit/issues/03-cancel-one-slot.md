# 長按取消只取消那一段，要整天要自己再點一次

Status: todo
PR: 1（地基）
來源：使用者，2026-09-08（需求 5b）
動工前先讀：`docs/adr/0060`（長按是捷徑不是唯一的路）、`docs/adr/0070`（後果只能講真的會發生的事）

## 她要的

> 長按某一筆來訪項目執行取消時，**僅能取消被選中的該筆時段來訪**，
> 嚴禁一次連帶將該客戶當天的所有時段預約全部取消！

## 要做的事

`domain/visits.js` 的 `visitActions(visit, { today, slotIndex })`：

- 帶了 `slotIndex` 而且那一天不只一段 → 兩顆：
  **「取消這一段」**（預設、排在上面）與「取消一整天（N 段）」
- 只有一段、或沒帶 `slotIndex` → 維持現在那一顆「取消這一筆」

**「取消這一段」排在上面**：她長按的是一列，而一列就是一段 ——
最常按的在最上面（`visitActions()` 既有的規矩）。

`domain/consequences.js` 的 `cancelConsequences({ visit, slotIndex })`：
一段與一整天講的話不一樣。

- 一段：`「SIS(30)」這一段會退回去，次數還回來`、
  `那一天剩下的 2 段不受影響`
- 一整天：現在那幾句一字不改

## 上限六顆

`openActions()` 最多六顆（含「先不要」）。現在來訪最多五顆，多一顆剛好滿。
**「客人來了，去簽療程單」與「取消這一段」不會同時出現**（前者要日子到了、
狀態是待確認或已確認；後者任何時候都在），所以實際上最多五顆——
動工時要拿真的資料點一次確認。

## 每一顆都要另外有一條點得到的路（ADR-0060）

長按是捷徑。「取消這一段」的另一條路是**來訪編輯器的狀態卡逐段**
（見 `issues/05`）。

## 測試要蓋到的

- `visitActions(v, { slotIndex: 1 })` 在三段的來訪上有「取消這一段」
- 一段的來訪不長出那一顆（那時候兩顆是同一件事）
- `cancelConsequences({ slotIndex })` 一個字都沒有講到「整天」
- E2E：日／週那一列長按 → 取消這一段 → 另外兩段還在
