# 「今天做了什麼」給「寫紀錄」自己一段

Status: proposed
來源：上一輪留下來的問題，她 2026-09-04 回答「好啊可以另外開一段給它」
動工前先讀：ADR-0062（回顧是稽核紀錄的白話版）、`domain/dayReview.js` 的 `STAGES`

## 現在的樣子

勾掉一張「寫紀錄」會落進第 ④ 段「登記掛號」，因為那一段的判斷是：

```js
match: (e, f) => collectionOf(e) === 'tasks'
  && f.some((x) => x.key === 'done' && x.after === true),
```

**任何**一張任務被勾掉都算「登記掛號」。段落名在講一件它收不到的事 ——
跟「取消與改期」當初漏掉改期是同一種毛病，那一次已經修過一遍了。

## 決定

新增一段「寫紀錄」，排在⑤簽療程單後面：她的流程就是**做完 → 簽單 → 補紀錄**。

```
① 問到時間  ② 壓表  ③ 跟客人確認  ④ 登記掛號  ⑤ 簽療程單
⑥ 寫紀錄 ←  ⑦ 取消與改期  ⑧ 日曆與待辦  ⑨ 客戶與額度  ⑩ 設定  ⑪ 其他
```

### 分段的順序不能為了比對而換

`STAGES` 那一段的規矩是「**由上到下比，第一個對上的算數**」，而順序就是
她的流程順序。「寫紀錄」排在⑤後面，但它會被④先接走 —— 所以修的是**④**，
不是把新的一段插到前面去：

```js
// ④ 登記掛號
match: (e, f) => isTaskTicked(e, f) && kindOf(e) !== RECORD_TASK_KIND,
```

把「這一則是不是勾掉一張任務」與「那張任務是哪一種」各抽成一支小函式，
兩段共用。這樣陣列的順序還是流程的順序，讀的人不用在腦袋裡重排一次。

### 種類從哪裡來

稽核那一則的 `before` 是**整份舊文件**（`data/repo.js` 的 `commit()` 寫的），
所以 `e.before.kind` 拿得到。不用多讀一次任務，也不用多寫一個欄位
（ADR-0062：**不可以為了這一頁多寫任何一筆資料**）。

## 順手看到但這一輪不做的

同一段④現在也收著「約二返」「寄報告給醫師」「追蹤健檢報告」——
那三種也不是「登記掛號」。但她問的是「寫紀錄」，而多開三段會讓這一頁
從十段變成十四段，那反而更難掃。**記在這裡，等她說那三種也想分開再說。**

## 連動

| 會動到 | 為什麼 |
|---|---|
| `domain/dayReview.js` | `STAGES` 多一段、④多一個條件 |
| `tests/day-review.test.js` | 兩種分組（照人、照流程）都要成立；一則都不可以掉 |

`TILES`（頂端那一排數字）**不加**：那四格是「壓了幾筆、簽了幾張單、登記幾筆、
記了幾件」，都是量大的東西。寫紀錄一天一兩張，給它一個大數字反而在說它很多。

## 驗收

- 單元：勾掉一張「寫紀錄」→ 落在「寫紀錄」那一段，不在「登記掛號」
- 單元：勾掉一張 Examine → 還是落在「登記掛號」
- 單元：**取消勾選不算做了**（④原本那條註解要繼續成立）
- 單元：照人分組時那一則也在，而且只出現一次
