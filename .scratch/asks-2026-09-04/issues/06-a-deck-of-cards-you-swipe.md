# 備忘錄的畫面：一疊可以左右滑的卡牌

Status: proposed
來源：她實測回報第三項，2026-09-04（`../spec.md`）
動工前先讀：ADR-0038（壓表那一頁不整頁重畫）、ADR-0060（長按是捷徑不是唯一的路）、
`ui/views/schedule.js` 的 `.deck`（壓表卡片牆已經有一疊卡的先例）

## 她要的

> 備忘錄要是像卡牌一樣可以左右滑動的，然後也有所有的清單可以快速選，就顯示標題。
> ……然後可以有鉛筆點擊修改。然後我希望「加一個備忘錄」會是以浮動小泡泡的形式
> 出現在這頁的右下角。……原本「寫一份」那個按鈕我覺得可以做成放大鏡的圖示，
> 點開之後可以快速搜尋，不然這面就只要有卡牌以及清單丸子，也不需要太多的說明文字。
> 背景要是有設計過像是備忘錄感覺的那種卡牌，動畫絲滑流暢，沉浸式。

**畫面上沒有一句解說文字。** 現在那兩句（「你自己整理的流程與心得。不會變成
要勾的待辦，隨時翻得到。」與空白頁那三行）她已經讀過一次了，之後每天看到
只是佔位置。空的時候留一句，有東西之後一句都不留。

## 五個互動

### 一、左右滑（scroll-snap，不自己寫手勢）

```css
.pbdeck { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; }
.pbdeck__card { flex: 0 0 88%; scroll-snap-align: center; }
```

**不自己接 touchmove。** 原生捲動在 iOS 上有慣性、有回彈、有橡皮筋，
自己寫的永遠差一截 —— 而她那句「絲滑」講的就是那一截。
旁邊露出 12% 的下一張，那是「還有東西」唯一誠實的講法（比小圓點更早被看到）。

目前是第幾張用 `IntersectionObserver` 認，**不用 scroll 事件**：
scroll 在 iOS 上捲動時會被節流，圓點會跟不上手指。

### 二、丸子清單 → 滑到那一張

`scrollIntoView({ behavior: 'smooth', inline: 'center' })`。
選中的那一顆只改 `aria-pressed`，**整頁不重畫**（ADR-0038 的同一條）。

### 三、鉛筆 → 就地編輯

點鉛筆，**那一張卡在原地變成編輯的樣子**：標題輸入框、課程丸子、一個大的
`textarea`、存檔／取消／刪掉。不換頁、不開抽屜 —— 換頁會讓她失去「我正在
看第三張」這件事，而那正是卡牌的全部價值。

編輯中把 `scroll-snap-type` 關掉，不然鍵盤一上來、版面一縮，
瀏覽器會把她捲到別張去。

### 四、放大鏡 → 展開搜尋

抬頭右邊一顆圖示。點下去長出一列輸入框（`grid-template-rows: 0fr → 1fr`，
跟待辦抽屜同一招），打字即時篩選**卡牌與丸子兩邊**。
清空或再點一次就收起來。

### 五、右下角泡泡 → 加一份

`.fab` 那一支已經有了（首頁的隨手記、日曆都在用）。按下去在最後面加一張
空白卡、滑過去、直接進編輯狀態、游標停在標題上。

## 卡牌長什麼樣

沉穩診所那一套已經定好了，這一頁只挑三件事來用：

| | 用什麼 | 為什麼 |
|---|---|---|
| 卡面 | `--surface` 純白，浮在 `--bg` 暖白紙底上 | 這一頁全部是要讀的字，紙要比背景亮 |
| 上緣 | 4px `--tea-soft` 的一道 | **這一頁唯一的裝飾。** 便條紙的黏邊，一眼認出「這是一疊便條」 |
| 標題 | `--font-serif`、`--text-xl`、底下一條 `--border-soft` 細線 | 全站襯線抬頭的同一套 |
| 內文 | `--text-lg`、行距 1.85、`white-space: pre-wrap` | ADR-0067 那條「這一頁上全部都是資料」照舊。她低頭看這台、手在做另一件事 |

**不加第二種裝飾。** 沒有橫線紙紋、沒有摺角、沒有第二個顏色 ——
一疊便條紙的樣子由「白卡 + 茶色黏邊 + 露出下一張」三件事講完，
再多一件就變成貼圖。

進場只有一次淡入上移（`--motion-base`、`--ease-out`），
`prefers-reduced-motion` 由 `app.css` 那道全域夾住，這裡不再寫一次。

## 路由

`#/playbook` 是這一疊。`#/playbook/:id` **保留** —— 日曆卡片上的「看全部」
指著它 —— 但它現在只是「這一疊，開在那一張」，不是另一頁。
少一頁就少一個回不去的地方。

## 刪掉一份

在編輯狀態裡（跟隨手記同一條：要刪就先進編輯）。**不做長按選單** ——
ADR-0060 要求每一顆都要另外有一條點得到的路，而這一頁只有一顆，
那條路本身就夠短了。
