# 「寫紀錄」沒有長出來，以及設定裡為什麼沒有 n返

Status: done
來源：她實測回報第二項的前兩問，2026-09-04（`../spec.md`）
動工前先讀：ADR-0066（紀錄是來訪之後才長出來的任務）、ADR-0063（n返 不是額度）、
`domain/taskRules.js` 的 `acceptsRecordTasks()`

## 她看到的

> 我發現二返以及 n返 我勾完簽療程單後（客人確認來）是沒有預設會有產生紀錄的 todo。
> 然後我發現設定那邊的課程沒有 n返？還是其實我設定二返就等於 n返？

## 第一問：這不是 bug，是那個課程上的勾沒有打開

`domain/taskRules.js` 的規則是：那一場**做完**（`status === 'done'`）
而且來訪裡有一段的課程勾了 `needsRecord`，才長「寫紀錄」。

第一個條件她滿足了（簽療程單就是結案）。第二個條件是**課程主檔上的一個勾**：

```
設定 → 課程 → 二返 → 「客人走了之後要補一份紀錄」
```

`domain/seed.js` 裡二返與營養師諮詢都是 `needsRecord: true`，
但**她的資料庫是這個欄位存在之前建立的**，那幾筆課程身上根本沒有這個欄位，
讀出來是 `undefined` → 不長。種子只在全新環境跑，不會回頭補既有資料
（那會是無聲改她的設定，ADR-0002）。

所以修法不是改程式，是**讓她找得到那個勾**。

### 要做的三件小事

1. **課程清單那一行摘要要講出來。** 現在是「30 分 · 選診間 · A 類」，
   看不出哪幾個課程會長出「寫紀錄」。加一個字尾，她掃一眼就知道哪幾個開著。
2. **`docs/常見問題.md` 補一條。** 三段式：看到什麼（簽完療程單沒有長出寫紀錄）、
   為什麼（那個課程沒有勾）、怎麼辦（設定 → 課程 → 勾起來）。
3. **結案抽屜那一句預告已經寫好了**（`closeConsequences()` 會說「待辦會多一張
   『寫紀錄』」）—— **不用改**。反過來說，那一句沒出現就是那個勾沒打開，
   它本來就是這件事的指示燈，只是她還不知道要看它。這一句寫進常見問題裡。

## 第二問：設定裡的「二返」就是 n返 用的那一個

n返（三返、四返…）**不是一個課程**，也不是一種額度。它借二返那一個課程：

```js
// domain/nthFollowup.js
export function nthSlotFields({ nth, examVisitId, courseId }) {
  return {
    entitlementId: null,       // 排不進任何額度，不扣任何次數
    courseId: courseId ?? null, // ← 二返那一個課程
    courseName: nthLabel(nth),  // 「三返」是快照，不是主檔上的名字
    followupNth: nth,
    followupForVisitId: examVisitId ?? null,
  };
}
```

所以**二返課程上的每一個設定都會套用到 n返**：時長、任務類別、要不要簽療程單、
要不要寫紀錄。她把二返的那個勾打開，三返做完也會長出「寫紀錄」——
因為 `recordTasksForVisit()` 問的是 `coursesById[slot.courseId].needsRecord`，
而 n返 的 `courseId` 就是二返。

**這件事現在畫面上一個字都沒講**，所以她只能用猜的。做法：課程編輯器裡，
如果這個課程是某個課程的「做完之後還要再約一次的課程」（也就是它就是二返），
在那一頁加一行提示 —— 提示掛在條件上，不是每個課程都印一句廢話。

## 為什麼不改成「確認之後就長出寫紀錄」

她的原話把「客人確認來」放在括號裡，所以要先把兩個時機分清楚：

| | 掛號那一族（Examine、耀聖） | 紀錄那一族（寫紀錄） |
|---|---|---|
| 什麼時候長 | 客人**確認**之後 | 那一場**做完**之後 |
| 為什麼 | 要去外部系統登記，人確定要來才登記 | **沒做完就沒有東西可以寫** |

ADR-0066 已經記著這件事，而且它有一個現在還在保護她的後果：來訪從已完成
被改回已確認、或改成未到時，那張還沒勾的「寫紀錄」會被收掉。改成確認就長，
等於未到的客人身上也會長出一張要她去寫紀錄的待辦。**不改。**

## 驗收

- E2E：課程沒勾 `needsRecord` → 結案不長「寫紀錄」；勾了 → 長出來，死線是來訪那一天
- E2E：三返結案 → 一樣長出「寫紀錄」（證明它跟著二返的設定走）
- 手動：設定 → 課程 → 二返，那一行摘要看得出「要寫紀錄」
