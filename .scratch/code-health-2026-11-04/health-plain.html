#1

兩台同時改同一位客戶，次數會少算一次

中
發生什麼
在日曆打開「新增來訪」（或「改這一段」）之後，畫面記住的是打開那一刻這位客戶有哪些來訪。按存檔時，它用這份舊名單去算額度剩幾次。中間如果用另一台加了一段，這一段就被漏算。
比喻
像你拿著早上印的名單去對帳。中午別人加了一位，你不知道，結帳時就少算一位。
會看到
客戶卡片和壓表上的「剩 N 次」多了一次。資料健檢會抓到，按「修正」就回來。如果兩段剛好排在同一天，還會多出「同一天兩筆來訪」。
為什麼別處沒事
壓表、日曆長按、批次取消、拍 Abovee 都是在按下去那一刻重讀一次。只有來訪編輯器偷懶沒重讀。
位置
ui/views/visitEditor.js:1643（refreshCustomerVisits）
分頁 A（當成 iPad）
分頁 B（當成手機）
10:00打開「新增來訪」，選客戶A，先不要存
.

10:02替客戶A排另一天，扣同一筆額度，存好
10:05回來按存。用的還是 10:00 那份名單

額度上記的「已排」
3

怎麼重現（開兩個分頁就行）

  1. 分頁 A：日曆 → 點下週三 → 右上 ＋ → 新增來訪 → 選客戶A。選一筆還有剩的額度，記住是哪一筆。不要按存。
  2. 開分頁 B（同一個網址）：日曆 → 點下週五 → ＋ → 新增來訪 → 選客戶A，選同一筆額度，存好。
  3. 回分頁 A，按存（中途問「先看一下」或「壓好表了嗎」都按下一步）。
  4. 設定 → 資料健檢。

看到這個就是重現了：「次數對帳」那一項出現客戶A，寫著「計數欄位是…已排未上 N，從來訪重算是…已排未上 N+1」。
加碼：第 2 步也選下週三的話，「同一天有兩筆來訪」那一項也會出現客戶A。

#2

資料健檢的「補上二返額度」連按，會多出一筆

中低
發生什麼
資料健檢的修正按鈕在寫入期間沒有鎖住。「補上二返額度」每按一次就產生一個全新的編號，所以第二次不是蓋掉第一次，而是又建一筆。
會看到
客戶身上出現兩筆一樣的二返額度，二返次數變成兩倍。「器材提醒詞補進警示名單」也會多一個重複的字。
小矛盾
同一支檔案裡「補課程」「補器材」特地用固定編號，註解寫著「隨機生的話會再建出第二台」。這兩種卻沒照做。
位置
ui/views/health.js:806（沒有防連按）、data/health.js:503（每次新編號）

怎麼重現

  1. 先做出一個要補的狀況：客戶 → 找一位額度裡有健檢的假客戶 → 點那一筆二返額度 → 刪除這筆額度。
  2. 瀏覽器開開發者工具 → Network → 把速度調成 Slow 3G（本機太快，不調慢來不及連按）。
  3. 設定 → 資料健檢 → 「二返額度」那一列 → 補上二返額度 → 修正。
  4. 畫面還顯示「修正中…」的時候，再按一次同一顆 補上二返額度 → 再按 修正。
  5. 回到那位客戶的詳情頁。

看到這個就是重現了：額度裡有兩筆二返，次數都一樣。

#3

資料健檢「重算次數」寫的是掃描當時的數字

低中
發生什麼
掃描那一刻算好的數字，按「修正」時直接寫進去，不會重算。掃完之後在別台替那位客戶排了一段，再回來按修正，就把舊數字寫回去了。同一頁的其他幾種修正都有「先檢查有沒有被改過」，只有這種沒有。
位置
data/health.js:484

怎麼重現

  1. 照第 1 條做到資料健檢出現「次數對帳」那一列，先不要按修正。
  2. 另一個分頁替同一位客戶、同一筆額度再排一段，存好。
  3. 回到資料健檢那一頁直接按 修正，再按一次「重新掃描」。

看到這個就是重現了：剛修好的那一列又出現，差一次。

#4

營養品「記交付」連按，紀錄會多一行

低
發生什麼
按鈕沒有防連按，兩次用的都是同一份舊資料，同一次交付被記兩行。「給了沒」的判斷不會錯，只是試算表上可能看到重複的一行。
位置
ui/views/customerDetail.js:1395、data/notes.js:132
重現
網路調成 Slow 3G，在客戶詳情營養品那一包「記交付」連按兩次，再看試算表報表的交付那一欄。
#5

常見問題有一題還在講舊畫面

文件

那一題叫「我點的是其中一段，為什麼跳出來三段？」（docs/常見問題.md:1030-1046）。

文件說卡片底下有「這一天還有另外 2 段 —— 看全部」。長按的按鈕會動到整天，選單抬頭寫「這一天共 3 段」。
畫面其實沒有「看全部」那一行。長按的每一顆只動那一段，抬頭只寫「日期・狀態・第 N 段」。

重現：日曆找一天同一位客戶有三段的，長按其中一段，看選單最上面那一行。
