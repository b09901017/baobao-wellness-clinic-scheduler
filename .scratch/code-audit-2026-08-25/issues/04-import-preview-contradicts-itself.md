# 匯入預覽同一頁自打嘴巴

Status: done
來源：全庫掃描，2026-08-25（`../spec.md`）
動工前先讀：`SPEC.md` 第 6.10 節、`docs/adr/0027`、`0029`

## 症狀

貼一份合併檔，裡面有一筆日期在今天之後的來訪，而那一筆是**復能**（C 類）。
`#/settings/merge` 的預覽上：

> 來訪裡有 **1** 筆的日期在今天之後，會建成 **已確認** ⋯⋯

兩段之後：

> 已經發生的那些**不會產生任何待辦任務** ——
> **這次沒有還沒發生的來訪**，所以一筆待辦都不會長出來。

同一頁，隔兩段，講反的。按下「開始匯入」之後的二次確認框裡也有同一句。

## 原因

`ui/views/mergeImport.js` 的 `runCard()` 那一句是看 `tasks` 分支的，而
`tasks` 是 `countNewTasks()` 算出來的「會長幾張登記待辦」——
**它跟「有沒有未來的來訪」是兩件事**。C 類（復能、靜脈、EECP、營養點滴，
也就是她大部分的量）確認之後本來就沒有後續登記（`taskRules.js` 的 `RULES`），
所以 `tasks === 0` 而 `s.future > 0` 是很正常的組合。

## 做了什麼

抽一支 `noTaskWhy(s, tasks)`，三條路各講各的：

- `tasks > 0` → 「還沒發生的那些會，這次是 N 筆」
- `tasks === 0 && s.future > 0` → 「還沒發生的那 N 筆都是不用另外掛號的課程」
- `s.future === 0` → 「這次沒有還沒發生的來訪」

二次確認框那一句同步改。
