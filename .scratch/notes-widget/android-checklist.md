# Android「隨手記」手動驗收清單（草稿，段七 11/6）

她照順序點。**A 段 HTC「隨手記（測試）」（staging）**、**B 段 三星「隨手記」（正式站，A 段她說可以才裝 —— 段九）**。
會寫入的那幾步記在 staging（staging 上記的不搬，記完可以自己清掉）。誰走過、走到哪寫在每一段最後。

## A. HTC 測試版

### A0 換成派送的那一支（第一次）
1. 信箱裡 Firebase 寄來的「隨手記（測試）」邀請信 → 用手機的 Chrome 開 → **開始使用**（登入收信的帳號）
2. 照畫面下載 **App Tester** → 手機問「允許安裝不明來源的應用程式嗎？」→ 設定 → **允許這個來源** → 返回 → 安裝
3. 桌面上已經有一支「隨手記（測試）」（段七用筆電裝的同一版）→ **App Tester 會寫「已安裝」，不用動**。
   以後派送新版：App Tester → 隨手記（測試）→ 更新（設定、登入、桌面上的小工具都留著）
   - 手機上若是筆電裝的**開發版**（debug 鑰匙）：先長按圖示 → 解除安裝 → 再從 App Tester 裝；**解除安裝會把小工具一起拿掉，要重放**

### A1 登入與放小工具
1. 打開「隨手記（測試）」→ 用 Google 登入 → 選平常登入排課系統的帳號 → 看到還沒勾的清單
2. 按「把小工具放到桌面」→ 跳出的框裡**看得到小工具的樣子**（標題、＋、灰的麥克風、三列）→ 加入
3. 長按「隨手記（測試）」圖示 → 小工具 → 預覽是標題、＋、灰的麥克風、三列（不是空白）。
   剛裝好或剛更新時若寫「無法載入小工具」：是桌面程式還拿著舊版，重開機（或過一陣子）就好

### A2 看清單
1. 桌面上的小工具：標題「隨手記」＋數字，數字＝排課系統首頁隨手記那張卡的數字（連在一起的一組算 1）
2. 順序：今天的在最上面 → 日期過了的（日期是逾期的字色、不是紅底）→ 沒日期的 → 以後的
3. 連在一起的那一組只有一列，旁邊「共 N 天」
4. 點「隨手記」那幾個字 → 打開排課系統的隨手記那一頁
5. 把小工具拉小 → 少列幾筆、字沒有擠在一起；拉大 → 多列幾筆

### A3 記一筆（寫入）
1. 點 ＋ → 後面桌面變暗、鍵盤自己跳出來、框貼在鍵盤上面
2. 打一個客戶的姓 → 選字之前不跳；選了字跳出名字丸子 → 點一位 → 框裡換成全名、「掛給誰」變成他
3. 點 今天 → 記下來 → 卡收掉、小工具上今天最上面多一筆、數字 +1
4. 排課系統（網頁）→ 隨手記那一頁看得到同一筆、掛給同一位
5. 再點 ＋ 打幾個字 → 點卡外面 → 問「剛剛打的字要丟掉嗎？」→ 點那一句外面 → 字還在 → ✕ → 丟掉 → 什麼都沒記

### A4 勾掉與拿回來（寫入）
1. 點剛剛那一筆的勾選框 → 劃線 → 3 秒內再點 → 拿回來、沒有離開
2. 再勾一次、等 3 秒 → 離開、數字 −1 → 網頁上那一筆在已完成
3. 連在一起的一組勾一次 → 網頁上那幾天全部勾掉

### A5 點字的選單（寫入）
1. 點一筆的字 → 選單：做完了，勾掉／改日期／掛給誰／改文字／複製到別天／先不要（跟網頁長按那一筆同一組、同一個順序）
2. 改日期 → 改成今天 → 小工具上那一筆搬到今天那一段
3. 改文字 → 改幾個字 → 存 → 小工具與網頁都換了（**段六沒在 HTC 走過這一條**：adb 打不出中文）
4. 複製到別天 → 點兩天 → 複製到 2 天 → 小工具那一列「共 3 天」；再點那一列 → 複製到別天 → 最上面「拆開這一天」→ 那一天自己一列
5. 營養品的提醒：點字 → 選單沒有「複製到別天」；點勾 → 打開排課系統那一筆問「給了哪幾款」

### A6 在網頁記的，小工具多久看得到
1. 網頁記一筆 → 小工具上還沒有 → 點 ＋ 再關掉 → 出現
2. 什麼都不做放 20 分鐘 → 網頁再記一筆 → 小工具自己出現（手機睡著時可能更晚）

### A7 深色淺色
1. 長按「隨手記（測試）」圖示 → 「小工具改成深色」→ 小工具馬上變深色 → 再長按 → 「改成淺色」→ 換回來

### A8 更新
1. 段九派送新的一版之後：App Tester → 更新 → 桌面上的小工具自己重畫（不停在轉圈）

## B. 三星正式版（段九：A 段她說可以才裝）

照 `docs/STAGING.md`「第一次裝到手機」（正式站那一支）→ 照 A1～A7 再走一次，另外看：
- 小工具背後是**模糊的**桌布（One UI 7 以後）
- 三星鍵盤打注音，選字之前不跳客戶
