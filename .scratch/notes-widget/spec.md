## 談定的（共識表，她 11/6 說「對進 kickoff」）

### 一、原生 Android 桌面小工具

- **另寫一支 Android app**，手機上叫「**隨手記**」（暴富日常的圖示加一支小筆）。網頁 app（PWA）做不到桌面小工具；Android 小工具本身放不了打字框，所以輸入是一張**浮在桌面上的卡**（透明背景的 activity，Google Tasks、簡潔待辦同一招）。
- **兩個版本可以同時裝**：「隨手記（測試）」接 staging、裝 HTC U23 Pro；「隨手記」接正式站、HTC 點過才裝三星。
- 更新走 **Firebase App Distribution**（免費、有通知）；**不放 GitHub 公開下載**（repo 是公開的）。不上 Google Play。
- 登入：第一次用同一個 Google 帳號登入一次（同一個 Firebase 專案、同一個帳號＝同一個 uid，白名單不用改）。
- 沒網路也記得下來（Firestore Android SDK 的本機快取，連上補傳）。
- 安裝檔由 GitHub Actions 建，簽章鑰匙放 GitHub Secrets。
- 開發：她同意在筆電上裝 **Android 指令列工具＋SDK**（不裝 Android Studio、不跑模擬器），HTC 開 USB 偵錯接筆電，Claude 自己裝、自己截 HTC 的畫面檢查。**HTC 接的是 staging，畫面上有真名：截圖只留在她電腦裡，不進 repo、不進 PR。**

**小工具樣子：D 半透明便利貼**（`mockups/` 的第一組 D）
- 三星 One UI 7 以上：真的毛玻璃（One UI Home 替半透明、root 是 `@android:id/background`、`widgetStyle`/`widgetSize` 有宣告的小工具模糊桌布；**三星沒寫在文件裡，要實機試**）。HTC：半透明、不模糊。
- 透明度先固定一個在她桌布上字看得清楚的值，不做滑桿。
- 右上角＋（記一筆）與麥克風（**這一輪不會動**，語音下一輪；這一輪先不畫或畫成灰的 —— 看樣子定稿時她說哪一種），下面全部是清單（可以上下滑）。
- **清單順序**：今天（連在一起的那一組只要有一天是今天也算）→ 日期過了還沒勾的 → 沒有日期的 → 以後的（越近越上面）；每段裡照記的先後、新的在上面；段跟段之間一條很淡的線、不寫標題。
- 點勾選框＝勾掉（劃線，3 秒後才離開；3 秒內再點一下回來）。點字＝浮出那一筆的選單（改字、改日期、掛給誰、複製到別天、拿掉日期；連在一起的多「拆開這一天」）—— 跟 app 裡長按一樣；小工具上沒有長按（長按是手機拿來搬小工具的）。點「隨手記」標題＝打開網頁 app 的隨手記那一頁。
- **營養品的提醒**：在小工具上點勾 → 打開網頁 app 問「給了哪幾款」再勾（規則只在網頁 app：`domain/products.js`，在 Kotlin 再寫一份遲早對不上，交付紀錄就進不了試算表）。

**按下「記一筆」：2 浮起一張卡**（`mockups/` 的第二組 2）
- 後面桌面調暗（Android 12 以上做得到就再模糊一點），卡貼在鍵盤上面。
- 輸入框**一打開 2 行高、字多了長到 4 行**，再多在框裡捲；字比 app 裡的大一號。不一定要跟 app 裡「記一筆」長一樣。
- 今天／挑日期／掛給誰／給營養品排一排；**給營養品點了打開網頁 app 的「記一筆」並展開給營養品**。
- 打名字跳出客戶（見三）。記好之後卡片收掉，新的那一筆出現在小工具上。
- **開工前先把 D＋2 合起來畫一次給她看，她點頭才開始寫 Android 的畫面。**

### 二、複製到別天（預設連在一起）

- 長按選單（小工具上是點字跳出的選單）多一顆「複製到別天」→ 小月曆，一次點好幾天 → 每一天各多一筆。底下一個開關「連在一起：勾一天，其他天一起勾」，**預設打開**。
- 帶過去的：文字、掛給誰；一律是還沒勾的。**營養品的提醒不給複製**。
- 連在一起時：

| 對其中一筆做了什麼 | 連在一起的其他天 |
|---|---|
| 勾掉 | 全部一起勾掉（過去的、還沒到的都算） |
| 拿回來，還沒做 | 全部一起拿回來 |
| 改文字、改掛給誰 | 全部一起改 |
| 改日期 | **只改這一天** |
| 刪掉 | **只刪這一筆** |
| 長按 →「拆開這一天」 | 這一天拿出來，以後各勾各的 |

- **怎麼列**：清單類（首頁那張卡、隨手記那一頁、客戶詳情、小工具）**一組一列**，日期那一顆寫最近要到的那一天（今天或之後最早的；全部過了寫最後一天、過期的顏色），旁邊「共 N 天」；長按選單最上面列出是哪幾天。**日曆、逾期／今天／明天那三頁每一天各一列**（那幾頁本來就照日子看）。首頁「隨手記 16」那個數字一組算 1。
- 沒連在一起的（開關關掉）就是各自獨立的幾筆。

### 三、打名字跳出客戶、「掛給誰」可以搜尋

- 在記一筆的打字框打「王」→ 框下面（鍵盤上方）一排名字開頭是「王」的客戶；點一位 → 框裡的「王」換成全名、游標接在後面，**同時自動掛給他**。
- 打注音時等選好字才找（composition 中不跳）。
- 已經掛給 A 又點了 B → 改成掛給 B。名字從框裡刪掉 → 掛給誰**不自動拿掉**（按「✕ 不掛了」）。
- 列的人＝「掛給誰」的名單（一次性客人也列，標「一次性」）。
- 「掛給誰」打開的名單最上面一個搜尋框，一邊打一邊篩，**名字或病歷號**（比法 `nameHas()`／`chartNoHas()`）。
- **有「掛給誰」的入口都有**：首頁那張卡、右下角泡泡（首頁與隨手記那一頁都是這一顆）、日曆的待辦編輯器，小工具的輸入卡也有。
  客戶詳情那一格固定掛那一位，**不做**（在那裡點別人等於把這筆從他身上拿走；主控 11/6 照她「點了就掛給他」推出來的，第一輪答的「五個入口」以這條為準）。
  長按的「掛給誰」（`askCustomer()`）也加搜尋框。
- **掛很多人：不做**（backlog）。

### 四、小的

- **長按提示**：首頁「隨手記」那張卡、隨手記那一頁的標題旁邊各一顆 `?`（`tip()`），點了才出來：「點一下勾掉；長按可以改日期、改字、掛給誰、複製到別天」。不加「⋯」。
- **首頁那張卡加「給營養品」**；今天／挑日期／掛給誰／給營養品**四顆排一排**，放不下（例如選了日期字變長）才換到第二行。

### 五、鍵盤蓋住輸入框（bug）

- 全螢幕（`display: fullscreen`，ADR-0147）下鍵盤跳出來，「記一筆」抽屜被整張蓋住，往上拉整頁跟著跑。要：輸入的那張卡跟著鍵盤往上，看得到在打什麼。
- **全站會叫出鍵盤的地方一個一個查**（抽屜、卡片、搜尋框），一起修。

## 查過的事實（11/6）

- Android 小工具（RemoteViews／Glance）不支援 EditText；做法是點了開一個對話框樣式／透明的 activity。
- Android 12 以上小工具可以放勾選框（CompoundButton），直接在桌面勾。
- 小工具本身不能模糊背後的桌布；**三星 One UI 7+ 由桌面替它模糊**（條件：半透明背景 alpha 1–254、root id `@android:id/background`、provider 宣告 `widgetStyle="colorful"` 與真的 `widgetSize`；非官方，見 github.com/thatjoshguy67/blur-widget-demo 的 wiki）。視窗（輸入卡）後面的模糊是官方 API（Android 12+ `setBackgroundBlurRadius`／blur behind，看硬體支不支援）。
- 網頁 app：manifest 是 `display: fullscreen`；VirtualKeyboard API（`navigator.virtualKeyboard.overlaysContent`、`env(keyboard-inset-height)`）Chrome Android 94+ 支援，全螢幕模式下的行為要實機確認。
- 她的筆電：有 JDK 21（`C:\Program Files\Microsoft\jdk-21…`），沒有 Android SDK、沒有 adb；C 槽剩 179 GB。
