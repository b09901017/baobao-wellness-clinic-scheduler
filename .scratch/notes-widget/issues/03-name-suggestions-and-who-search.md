## 她要的

> 你誤會我的意思了，我不是想做隨手記搜尋，我其實想做的搜尋我點了掛給誰後可以搜尋人名。多補充一點，我有時候會直接在記一筆的內容寫人名，像是王小明回電，我希望可以直接我輸人名的時候可以一邊打字一邊篩，例如我打王
> 下面就跳出王小明，然後我點了之後，輸入框直接跳出王小明我只要在打回電就好，如果我點了就也順便幫我掛給他，可以嗎 ?

（原話裡她舉的是一位真的客戶，這裡換成王小明；測試與文件一律用王小明。）

談定的細節（她 11/6「可以照這樣做」）：注音選字中不跳；掛了 A 再點 B → 改掛 B；名字從框裡刪掉 → 掛給誰不自動拿掉；列的人＝「掛給誰」的名單；掛很多人不做。

## 要做的

- **純函式**（`domain/customers.js` 或 `domain/notes.js`，看 import 方向）：`nameSuggestions(text, caret, customers)` →
  `{ from, to, matches }`：游標前面那一段（往前到空白或標點為止）**最長的、是某位客戶名字開頭的尾巴**（打「請王小」→ 用「王小」）；`matches` 是名字以它開頭的客戶（全名完全一樣的排第一、再照名字；最多 6 位）。
  比法跟 `nameHas()` 同一套（全形半形、空白、大小寫）—— 但這裡是「開頭」不是「包含」，寫清楚
  - 那一段已經是某位的全名、而且他就是現在掛的人 → 不跳
- **畫面**：輸入框底下（鍵盤上方、丸子那一排上面）一排客戶丸子；點一位 → 把那一段換成全名、游標放在全名後面、框保持聚焦（**鍵盤不能收起來**）、`wireWho` 的 `set(customer)`
  - 注音：`compositionstart`～`compositionend` 之間不找（`e.isComposing`）；`compositionend` 之後找一次
  - 丸子一點下去框會失焦 → 用 `pointerdown` ＋ `preventDefault()` 擋住失焦（或點完馬上 `focus()`，iOS 要同步）
  - 沒有符合的 → 那一排不佔位置
- **「掛給誰」的名單加搜尋框**：打開名單時最上面一格，一邊打一邊篩（名字 `nameHas()` 或病歷號 `chartNoHas()`）；搜尋框聚焦時鍵盤跳出來（01 修好的讓開要照樣成立）
- 三個入口共用（接在 `wireWho` 旁邊，一支接線），不要各寫一份
- **長按的「掛給誰」**（`note.js` 的 `askCustomer()`，約 `:688`）是**另一份名單**：它濾掉停用的客戶（`wireWho` 不濾）。也加同一個搜尋框；
  兩份名單要不要統一（停用的列不列）—— 照現狀各自保留，寫進「做完時留下的」；跳出客戶那一排用 `wireWho` 那一份（spec：「列的人＝掛給誰的名單」）
- **選了一包營養品時**（`give()`：掛給誰那一排藏起來、字自動填）：跳出客戶那一排**不出現**，點了也不可以掛人（那一包已經決定是誰）
