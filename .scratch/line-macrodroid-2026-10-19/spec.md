## 策略

- **欄位代號不換**：資料庫照舊是 `customer.lineId`，**意思換成「她 LINE 好友清單上顯示的名字」**。改代號要動讀它的每一處、Rules、備份、稽核，而且沒有舊資料要保留，換代號只換來風險。SPEC 與 CONTEXT 寫清楚
- **怎麼叫 MacroDroid**：MacroDroid 的 **HTTP Server Request** 觸發條件（本機伺服器，預設 port 8080），app 從頁面背景 `fetch('http://127.0.0.1:<port>/line?name=…&msg=…', { mode: 'no-cors' })`。
  **不走 Webhook**：那條路經過 `trigger.macrodroid.com` 的雲端，客戶的名字與訊息會送到第三方；本機那條不出手機
- **`msg` 一律帶**（情況 a 帶空字串）：MacroDroid 的區域變數兩次執行之間會留著，沒帶的話上一次的訊息會被貼進下一位的對話。巨集照 `msg` 是不是空的決定停在第 9 步還是做到第 11 步
- **永遠不按送出**：她看一眼對話上方的名字才自己按（同名的好友會點錯人）
- **開關記在這一台裝置**（`localStorage`，同主題 ADR-0055 的理由）：只有她的 Android 手機裝了 MacroDroid，iPad 要走複製那條路
- **程式放 `public/js/integrations/`**（她：「可以寫在一個獨立的資料夾」）：`lineMacro.js` 一支。它**不 import `ui/toast.js`**（toast 在 node 裡 import 不起來），提醒由呼叫端傳 `notify` 進來 —— 這樣單元測試叫得到整條路
- **碰到既有程式的只有**：LINE 那一格的意思（`customerNotes.js`、兩張編輯表單、稽核欄位名）、客戶詳情那顆 LINE 丸子、`ui/components/message.js` 的訊息框（多一顆「打開 LINE」）、設定頁一段、`sw.js`、`related.js`

## 查到但沒驗證的

- Chrome 從 https 頁面叫 `127.0.0.1` 第一次會問「允許存取區域網路裝置」（Local Network Access）。她驗過的是網址列直接打，不是頁面背景叫 —— **設定頁的「試一次」就是為了這個**（同時驗中文與換行有沒有原樣到巨集那一側）
- `fetch` 叫不到（MacroDroid 沒開、被系統砍掉、Chrome 擋下來）會 reject；叫到了回 opaque response。逾時當成叫不到
