# 「客人來了嗎」就是「簽療程單」，而二返不用簽

Status: done
來源：使用者，2026-08-23
動工前先讀：本資料夾的 `spec.md`、`SPEC.md` 第 4.2、8.1 節、
`CONTEXT.md` 的「療程單」、`docs/adr/0025`

## 原話

> 「多一個簽診療單的 todo ⋯⋯ 一個是來的當天要請客人簽診療單的 todo
> （完成這個 todo 後會產生下面那個記得追蹤報告）」
> 「除了二返不用簽，其他都要簽（包含門診和下面那四個，都要簽）」

確認過：**跟現在的「客人來了嗎」是同一件事，改名就好。**

## 現況

待辦上那一列叫「客人來了嗎」，說明是「簽了療程單就打勾，次數這時才扣」。
`CONTEXT.md` 已經寫死了這件事：

> 「簽了療程單」和來訪的「已完成」講的是同一件事，不是兩件。

所以它本來就是簽療程單那一件事，只是名字沒講出來。真正缺的是兩件：

1. 名字沒講出「要做什麼」（她看到的是一個問句，不是一個動作）
2. **二返不用簽單這件事系統不知道**

## 要做什麼

### 課程主檔多一個欄位

`needsTreatmentForm`，布林，**預設 `true`**。

- 為什麼是課程上的欄位而不是類別推導的：二返是 A 類（掛號跟門診一模一樣），
  卻是唯一不用簽單的。用類別推不出來，用名字比對是舊 Apps Script 靜默失效的
  那條老路（`docs/legacy/README.md`）。
- `domain/seed.js`：只有 `course-followup`（二返）填 `false`，其餘不填
  （沒有這個欄位就是要簽）。
- 設定頁的課程表單加一個勾選框：「來訪當天要請客人簽療程單」，預設打勾。
  說明寫「幾乎每一種都要簽 —— 目前只有二返不用」。
- `domain/masterData.js` 的課程驗證要認得這個欄位。
- **舊資料沒有這個欄位 ＝ 要簽。** 不做搬移，`?? true` 就對了。

### `domain/visits.js`

新增純函式（跟 `visitsToClose()` 放在一起）：

```js
/** 這一筆來訪裡，哪幾段要請客人簽療程單。 */
export function formSlots(visit, coursesById)

/** 整筆都不用簽（例：只有二返的那一天）。 */
export function needsNoForm(visit, coursesById)
```

判斷讀 `coursesById[slot.courseId]?.needsTreatmentForm ?? true`。
**認不得的課程當成要簽** —— 少簽一張單是實際損失，多問一次不是。

### 待辦那一列與那一頁

- 首頁那一列：`客人來了嗎` → **`簽療程單`**，說明改成
  `來了、單簽了就打勾 —— 次數這時候才扣`
- `#/todo/close` 那一頁的標題與導言跟著改
- **每一張卡要標清楚**：
  - 有要簽的段 → 那幾段的課程名旁邊一個小標記，卡上一句「請客人簽療程單」
  - 整筆都不用簽（二返） → 「二返・不用簽單，來了就打勾」
  - 混合（同一天有二返也有復能） → 只標要簽的那幾段
- 結案抽屜（逐段勾做了／沒做）**完全不動**。次數還是在這裡扣，
  逐段記照舊（ADR-0025）。要簽單的那幾段在抽屜裡也標一下就好。

### 客戶詳情與進度追蹤

進度追蹤那一頁一段一列，已經在印課程名與狀態符號。要不要簽單**不進那一頁** ——
那一頁是唯讀的對帳畫面，講的是「發生了什麼」，不是「還要做什麼」。

## 一起要檢查的

- `SPEC.md` 第 8.1 節分類表、第 7 節（規則清單要多一條「除了二返，每一個課程
  都要簽療程單」）
- `CONTEXT.md` 的「療程單」：把「**每一個課程都要簽**」改成
  「除了二返，每一個課程都要簽」
- `views/home.js` 的 `headline()` 裡「還沒結案」那句話
- `tests/visits.test.js`、`tests/master-data.test.js`

## 不做

- **不把簽療程單做成一張真的任務。** 它沒有獨立於結案的生命 —— 簽了單就是
  這一次做完了，而那件事已經有一個地方記（來訪狀態）。做成兩個地方，
  就會出現「單簽了但沒結案」這種只存在於資料庫裡的狀態。
- 不改次數的算法。
- 不因為「不用簽單」就把那一筆從清單上拿掉 —— 門診一樣要結案、一樣要扣次數。

- 瀏覽器：`#/todo/close` 上一筆只有二返的來訪寫著「不用簽單」，
  勾完照樣扣次數

## Comments

**2026-08-23 —— done。** 兩件值得記著：

- **函式叫 `needsForm()` 不叫 `needsTreatmentForm()`**，跟欄位同名的話
  `needsTreatmentForm(course)` 與 `course.needsTreatmentForm` 在讀 code 時
  會混在一起 —— 而它們的答案不一樣：欄位是 `undefined` 時函式回 `true`。
- **`formSlotIndexes()` 回索引不回時段。** 呼叫端要的是「第幾段要標」，
  而時段本身沒有 id，回時段就得在畫面上再比對一次。

`badge--form` 用最輕的一級（外框而不是實色）：一整天四段裡通常四段都要簽，
四顆重色徽章等於沒有徽章 —— 這一頁要看得出來的是**哪一段不用**。
`.card__note` 那一句才是講整筆的（「門診，不用簽單 —— 來了就打勾」）。

SPEC 第 7 節規則 8 第三點還寫著「A 類的四個任務」，那是舊的 —— 那一整條在
`issues/04` 會重寫，一起改。
