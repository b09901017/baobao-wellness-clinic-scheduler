# 待辦上要看得到「這個月還有誰沒壓表」

Status: done
來源：使用者，2026-08-23
動工前先讀：本資料夾的 `spec.md`、`issues/01`、`SPEC.md` 第 8.1、8.2 節、
`docs/adr/0001`、`0028`

## 原話

> 「提醒我這個月還有誰沒壓表（這是有改動的地方）這時候希望 todo 寫**壓表登記**，
> 然後壓表分兩種一個是健檢（只需要直接去 examine 登記）一個是除了健檢之外的
> （就是去 Abovee）⋯⋯ 然後壓表其實算是提醒而已」

形狀她選了：**一列，點進去分兩區**。

## 現況

「這個月還有誰沒排」這件事只有在**開了壓表批次之後**才看得到（卡片牆上的
「還沒壓」篩選）。待辦首頁上沒有它 —— 她的第二步在首頁上是空的。

ADR-0028 已經替「問這輪的時間」做過同一件事：那也是推導的、沒有死線的，
但它是流程的第一步，所以它該在首頁上。這一支照同一個模子做第三步。

## 要做什麼

### `domain/scheduling.js` 新增 `customersToBook()`

純函式，跟 `customersToAsk()` 並排。

```js
export function customersToBook({
  customers, entitlementsBy, visitsBy, coursesById, targetMonth,
})
```

一位客戶一列，回傳：

```js
{
  customerId, customerName, priority, flags,
  systems: [
    { system: 'Examine', pools: [{ label, remaining }] },   // 健檢那一區
    { system: 'Abovee',  pools: [{ label, remaining }] },   // 其他那一區
  ],
}
```

判斷（**按系統分，不是按課程分**）：

- 某一個系統要出現在這一位身上 ⟺ 他有**對應到那個系統**的額度且剩餘次數 > 0，
  **而且**這個月沒有任何一筆用到那個系統的來訪。
- 一個額度對應哪個系統：查它的課程的類別，走 `taskRules.bookingSystemFor()`。
  擇一池沒有 courseId（ADR-0005），它對應的是「需要選器材的課程」＝ 復能 ＝ Abovee。
- 兩區都符合的客戶**兩區都出現**，那是對的：健檢跟復能是兩件要分別去壓的事。
- 停用的、軟刪除的客戶不列。

**剩餘次數用 `entitlements.js` 的 `counts()` 現算還是讀計數欄位？**
讀計數欄位（ADR-0004：清單頁讀快取）。這一列是提醒，不是對帳。

### 待辦首頁那一列

- `label`：`壓表登記`
- `note`：`這個月還有 N 位沒排`，健檢那一區有人時改成
  `其中 M 位是健檢，直接去 Examine`
- `n`：**客戶數**，不是系統數 —— 她問的是「還有幾個人要處理」。
  同一位兩區都有只算一次。
- 0 位就整列不畫（同 `askGroupRow()`）
- 跟「問這輪的時間」「客戶填好的時間」一樣**後補**：頁面先畫完，這一列等資料回來
  再填進 `[data-book]`。它要多讀一次來訪（這個月的），不要為了它讓整頁多等一輪。

### `#/todo/book` 那一頁

```
← 待辦
壓表登記
這個月還有 8 位沒排。壓好了回來按「這位壓完了」，他就會出現在「跟客人確認時間」。

┌ 直接去 Examine ─────────────────┐
│ 王小明   健檢 2                  │
└─────────────────────────────────┘
┌ 去 Abovee ──────────────────────┐
│ 王小明   復能 11・靜脈 6         │
│ 客戶A    復能 3                  │
└─────────────────────────────────┘

[ 開始壓 8 月的表 ]  → #/schedule
```

- 兩區各一個小標題，空的那一區不畫。
- 一位客戶一列：姓名 ＋ 剩餘次數泡泡（`poolchip`，跟壓表卡片牆同一顆）。
  醫療禁忌的紅丸照樣要出現（永久限制不可摺疊，SPEC 第 4.3 節）。
- 點一位 → 客戶詳情。
- 底下一顆按鈕跳進壓表（`#/schedule`）。
- **月份就是這個月**（`todayISO().slice(0,7)`），標題要講出來 ——
  「還沒問 8 月的時間」那一課（ADR-0036）在這裡一樣成立。

## 不做

- **不做成佇列**（ADR-0028 的同一個理由）：這一列不排序、不計分。
  「先壓誰」是壓表那一頁的事，這裡只回答「還有誰」。
- 不在這一頁記錄任何東西 —— 壓表要在壓表那一頁做。
- 不因為「還沒問到時間」就把人從這一列拿掉：她有時候會先壓再問。
