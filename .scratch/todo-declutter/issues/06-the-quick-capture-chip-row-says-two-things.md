# 泡泡上「掛給誰」旁邊永遠站著一顆「不掛了」

Status: todo
來源：使用者，2026-08-24（spec.md 的 f）
動工前先讀：`.scratch/quick-capture/issues/01-a-note-should-not-need-a-scroll.md`

## 原話

> 「有關那個隨手記的飄浮泡泡，他寫掛給誰，可以不掛，旁邊又寫不掛了，好怪？
> 就寫掛給誰就好，然後點開掛給誰後才會出現不掛了，而且應該要是淡紅色的小丸」

## 這是一個 CSS bug，不只是設計問題

`quickBody()` 寫的是：

```html
<button class="chip chip--sm" data-whoclear hidden>不掛了</button>
```

它**本來就該是藏起來的**，而且 `showPicked()` 只在真的選了人之後才把
`hidden` 拿掉。但 `app.css` 的 `.chip` 是：

```css
.chip { display: inline-flex; ... }
```

作者寫的 `display` 會蓋掉瀏覽器內建的 `[hidden] { display: none }`，
所以那顆丸子**從第一秒就站在那裡**。`app.css` 裡已經為 `.fab__menu`、
`.drawer__note`、`.toast`、`.notedate__picked` 各補過一次同樣的修正，
而且都留了註解 —— 這是這個 repo 反覆踩到的同一顆釘子。

## 要做什麼

### 1. 一次修掉，不要再補第五個

在 `app.css` 靠近頂端的地方加一條全域的：

```css
[hidden] { display: none !important; }
```

`!important` 在這裡是對的：`[hidden]` 是瀏覽器層級的語意，任何一條
`display` 都不該打贏它。加完之後把散在各處那四條個別的修正**刪掉**，
並在那條全域規則上寫清楚它取代了什麼（不然下一個人會再補第六條）。

**改完全站都要看一遍** —— 有可能某個地方正靠著「`hidden` 沒生效」在運作。
這是這一條唯一有風險的部分。

### 2. 文案改成「掛給誰」

`掛給誰？可以不掛` → `掛給誰`。「可以不掛」是廢話：不點它本來就是不掛。

### 3. 選了人之後那顆丸子的樣子

選了人之後，「掛給誰」那顆丸子的字換成客戶名字（現在就是這樣，維持）。
旁邊出現的「不掛了」改成**淡紅色的小丸**：

- 用 `--mark-red` / `--overdue` 那一組的淡底色（`app.css` 已經有
  `--danger-soft` 之類的 token，動工時挑一個既有的，不要新開色）。
- 文字可以只留一個 `✕`，或者「✕ 不掛了」。**先做「✕ 客戶名字」那種
  可刪除的丸子** —— 那是全站已經有的形狀（客戶備註的丸子右邊就是一顆叉叉，
  `app.css` 的 `.mark__x`），借過來就不用發明第三種。
- 感應範圍照樣 44px（`.mark__x` 已經處理過這件事，可以照抄）。

## 驗證

- `npm test`
- 瀏覽器：泡泡一打開只有一顆「掛給誰」
- 瀏覽器：選了人 → 變成名字 + 一顆淡紅的叉叉；按叉叉 → 回到「掛給誰」
- 瀏覽器：**全站掃一遍 `[hidden]`** —— 待辦首頁、日曆、壓表、客戶詳情、
  設定，確認沒有東西因為那條全域規則消失或多出來
