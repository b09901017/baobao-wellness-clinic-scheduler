# 隨手記那一頁應該是一份清單，不是又一張表單

Status: todo
來源：使用者，2026-08-24（spec.md 的 g）
動工前先讀：`CONTEXT.md`（隨手記）、`CLAUDE.md` 的連動表（四個地方共用
`ui/components/note.js`）

## 原話

> 「隨手記點全部進去看到的，應該直接要是清單，而不是還可以記，不論掛給誰
> 或是掛日期在 todo 那頁就可以呈現了，而且我希望的呈現方式不要是很制式的框框，
> 就像那個飄浮泡泡出來的那樣是標籤小丸的方式」

## 現況

`#/todo/notes`（`renderNotes()` / `paintNotes()`）最上面是一整張新增表單：
文字欄、客戶下拉選單、日期欄、一顆「記一筆」。底下才是依客戶分組的清單，
一組一張 `.card`。

她說得對：**記東西有兩個更快的入口**（右下角泡泡、首頁那一格），
而這一頁是她點「全部」進來的 —— 她要的是看，不是記。

## 要做什麼

### 1. 新增表單整個拿掉

那一頁只剩清單。右下角**留一顆泡泡**（跟首頁同一顆，`quickFab()` + `openQuick()`
已經是共用的了）—— 這樣「在這一頁想記一筆」還是三秒做得到，
而畫面上不再有一張她九成用不到的表單。

### 2. 一列改成小丸的樣子

現在一列是 `note.row()`，包在 `.card` 裡、依客戶分組。改成：

```
☐  記得幫王小明問週六有沒有位子     ⟨王小明⟩ ⟨8/25⟩
☑  下次帶健保卡                      ⟨客戶A⟩
```

- 左邊一顆勾（點擊區 44px），中間是那句話，右邊是**掛在它身上的那幾件事
  做成小丸**：客戶一顆、日期一顆。沒掛的就沒有那顆丸。
- 丸子的樣式借泡泡那一組（`.chip chip--sm`）與客戶備註那一組，
  **不要新開第三種**。
- **依客戶分組拿掉**（`groupByCustomer()` 在這一頁不再用）—— 客戶變成一顆丸，
  分組就多餘了，而且分組會讓「沒掛客戶的那一堆」被推到最下面，
  那些偏偏是最容易忘的。改成一份平的清單，`sortNotes()` 的順序（新的在前）。

### 3. 版面不要卡片

整頁一份清單，列與列之間用髮絲線或留白，不要一列一張白卡 ——
跟 `.scratch/calendar-drawer/issues/03` 是同一個判斷。

## 一起要檢查的

- **`CLAUDE.md` 的連動表**：「隨手記的欄位或那一列的樣子 → 四個地方共用
  `ui/components/note.js`」。這一條改的是**列的樣子**，所以首頁那張卡、
  客戶詳情、日曆上的待辦編輯器都會跟著變。**那正是我們要的** ——
  但改完四個地方都要看過。
- 日曆上待辦的讀取卡片（`openNoteCard()`）用的是自己的版型，不受影響。
- `groupByCustomer()` 如果只剩這一頁在用，就跟著刪；還有別人用就留著。
