# 勾掉的隨手記應該劃掉，不是消失

Status: done
來源：使用者，2026-08-24（spec.md 的 h）
動工前先讀：`SPEC.md` 第 6.1 節（永不硬刪除）、6.3 節（復原）、
`docs/adr/0044`、`domain/notes.js` 的 `sortNotes()`

## 原話

> 「我也希望隨手記的那邊不是點掉之後就沒了，而是可以先用槓化掉的感覺，
> 然後可以再全部那邊，有一個滑動開關可以看到已完成和未完成，
> 然後可以有小垃圾桶的標籤，可以刪掉已完成的隨手記，
> 並且也要有可以一鍵刪除所有已完成的隨手記的按鈕」

## 為什麼現在會消失

`domain/notes.js` 的 `sortNotes()` 註解寫著「勾掉的不馬上消失，因為她會勾錯 ——
看得到才點得回來」，那個判斷是對的。**但 data 層根本沒把它們撈回來**：

```js
export function listOpen() {
  return repo.list(PATH, { wheres: [where('done', '==', false)], ... });
}
```

首頁與 `#/todo/notes` 兩邊都用 `listOpen()`，所以勾掉的當場不見。
**日曆上是對的**（`listBetween()` 含已勾掉的，畫成刪除線）—— 兩個畫面對同一件事
的行為不一致。

## 要做什麼

### 1. 撈得到已勾掉的

`data/notes.js` 補一支 `listAll()`（不帶 `done` 條件，一樣排除已刪除的），
`#/todo/notes` 改用它。**首頁那一格繼續用 `listOpen()`** —— 首頁那一格只有四列，
它要回答的是「還有什麼沒做」。

如果 `listAll()` 需要新的複合索引，`firestore.indexes.json` 要補
（`CLAUDE.md` 的連動表）。

### 2. 勾掉了留在原地畫刪除線

`ui/components/note.js` 的列：`done` 時文字加 `text-decoration: line-through`、
淡一級，那一顆勾變成 `☑`。**跟日曆上完全一樣**（`app.css` 的 `.kind-todo--done`
已經有這組樣式，借過來或抽共用）。

順序照 `sortNotes()`：沒勾的在上（新的先），勾掉的沉到最下面。**那支已經寫好了**，
只是一直沒有資料餵給它。

### 3. 一個切換：未完成／已完成／全部

`#/todo/notes` 頂端一組分段切換（`.seg`，跟待辦首頁的「總覽／依客戶」同一個）。
她說「滑動開關」，但全站已經有分段切換這個形狀，**不要為了兩個狀態再發明
一個開關**。三格還是兩格：

- 先做**兩格：未完成／已完成**。預設「未完成」。
- 「全部」先不做 —— 勾掉的沉在最下面本來就看得到，三格會讓她多一個要想的東西。
  她要再補。

切換不重讀資料、不進網址（跟首頁「總覽／依客戶」同一個判斷：它是看法，不是位置）。

### 4. 刪掉一筆

已勾掉的那幾列右邊多一顆小垃圾桶。走 **`notesData.remove()`（軟刪除）**，
不是真的刪 —— SPEC 第 6.1 節「永不硬刪除」，刪掉的東西在
「設定 → 已刪除項目」還原得回來。文案上不用解釋這件事，但要走 `toast.withSaveState()`
讓她**復原得回來**（SPEC 第 6.3 節）。

**只有已勾掉的才有垃圾桶。** 還沒做的東西要刪，先勾掉再刪 —— 兩步比誤刪好。

### 5. 一鍵清掉全部已完成

「已完成」那一格底下一顆「清掉這 N 筆」。**要二次確認**（SPEC 第 6.5 節，
破壞性操作），確認文案要講出筆數。

一筆一個 commit（跟批次建客戶同一個作法，SPEC 第 8.5 節），
中間失敗就停下來講清楚刪了幾筆、哪一筆失敗，已經刪掉的不退回去。
**復原要能一次退回整批**，如果 `domain/undo.js` 支援不了整批就退而求其次：
清單重畫時把剛剛刪掉的那幾筆列出來、附一顆「全部還原」。動工時看 `undo.js`
現在的形狀決定。

## 一起要檢查的

- 客戶詳情頁的隨手記（`notesBlock()`）用的是 `openFor()`，只列沒勾的。
  **這一輪先不改** —— 那一頁是「這個人身上還有什麼沒做」。但列的樣子會跟著
  `issues/07` 一起變，確認勾掉的那一瞬間不會怪怪的。
- 日曆上的待辦已經是「勾掉畫刪除線」，改完之後三個畫面終於一致了。
- `tests/notes.test.js` 補：`listAll()` 的行為、刪除是軟刪除。

## 驗證

- `npm test`
- 瀏覽器：勾一筆 → 它劃掉並沉到最下面，**沒有消失**
- 瀏覽器：切到「已完成」看得到它，切回「未完成」看不到
- 瀏覽器：垃圾桶刪一筆 → 復原按得回來 → 設定的已刪除項目裡也還原得回來
- 瀏覽器：一鍵清掉 → 有二次確認、講出筆數
