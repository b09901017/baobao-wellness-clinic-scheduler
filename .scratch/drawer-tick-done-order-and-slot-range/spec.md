# 她 2026-09-05 回報的三件

來源：使用者，2026-09-05。三件事互不相干，只是同一輪講的。

## 原話

> **第一**：我發現日曆的 todo 勾掉他會問確認，然後我按確認之後他又會立刻跳出
> 要不要收回？而且就算我關掉這個收回，在這天的抽屜上他還是顯示沒被勾掉，
> 要我重新整理後才會勾掉。我希望是我勾掉然後按確定後，他就直接勾掉，
> 而且不要跳出要不要收回的確認。
>
> **第二**：隨手記的看全部那邊的已完成，我希望由上到下的排序是我剛勾掉到我更
> 之前勾掉的排序，就是最上面的應該是我剛勾掉的，而不是這個 todo 日期最近的。
>
> **第三**：設定那邊 LINE 回覆模板的「問壓好的時間」的那個模板中的 `{slots}`
> 這個參數，我希望時間可以寫完整，就是不是只寫幾點開始，而是幾點 - 幾點。

## 三件各自是什麼

| | 症狀 | 真正的位置 | 這一輪的 issue |
|---|---|---|---|
| 一 | 日曆抽屜勾一件待辦要按兩張卡片，而且抽屜不跟著變 | `ui/views/calendar.js` 的 `openNoteCard()` | `01` |
| 二 | `#/todo/notes`「已完成」照建立時間排，不照勾掉的時間 | `domain/notes.js` 的 `sortNotes()` | `02` |
| 三 | 確認訊息只印開始時間 | `domain/messages.js` 的 `slotLines()` | `03` |

第三件是純 domain 的一行；第二件是一個排序鍵；**第一件才是這一輪真正的工**，
而它是兩個 bug 疊在一起看起來像一個。

## 三件都不動的東西

- **「復原」那顆 toast 不拿掉**（`ui/toast.js` 的 `saved()`）。它是 SPEC 第 6.3 節
  要求的，而且是**寫入之後**的安全網，不是**寫入之前**的確認 —— 跟她說的
  「不要跳出要不要收回的確認」是兩件事。見 `01` 的〈她說的「收回」是哪一個〉。
- **`prepareToggle()` 一行都不改。** 營養品的提醒勾掉之前要先問「給了哪些」，
  五個入口共用那一支（`ui/components/note.js`）。
- **`visitReadHtml()` 一個字都不改。** 那一支是四個畫面共用的（ADR-0018、0056）。
