## ADR

**建議補一支 `0073-a-read-card-closes-when-its-one-action-happened.md`**，講 `01`：

> 一張讀取卡片上唯一的那個動作真的發生之後，卡片自己收掉；**沒有真的發生就
> 留在原地。** 判準是寫入那一層回報的結果，不是按鈕上寫了什麼。

值得一支的理由是**它有一個真的代價**：營養品沒給完那一次，她按了「勾掉」而
畫面不關 —— 看起來像沒反應。那一次的替代方案（一律關掉）比較順，但會讓畫面
說一件資料庫沒有發生的事，而那是 SPEC 第 6.9 節與 ADR-0070 同一條線上的東西。
不寫下來的話，下一個嫌它不順的人會把那個 `if` 拿掉，而 J-E9 紅掉時他只會看到
一支「怪測試」。

`02` 與 `03` **都不補 ADR**：`02` 是隨手記去對齊任務那幾頁既有的規矩（`SPEC`
第 995 行），`03` 是同一個決定（2026-09-04「客戶要知道的是那天待多久」）的
下半段，理由寫在 `slotLines()` 的檔頭就夠了 —— 跟 2026-09-04 那一次一樣。
