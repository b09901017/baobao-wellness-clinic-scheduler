# 表單：點進去要看得出這一頁在幹嘛

Status: todo
來源：使用者，2026-08-24
動工前先讀：`SPEC.md` 第 8.0、8.2、8.3、8.5 節、`docs/adr/0002`、`0018`、`0038`

## 原話

> 「有關很多需要填寫的表單，都很不直觀，不知道要幹嘛…課程等等的時間從…到…
> 可以放一起，然後治療師或其他填寫的表單內容可以不要用方框下拉選單嗎，
> 這樣好制式的感覺，幫我設計其他的，就是會有總資訊太多，很多表單我看了就不想填，
> 不知道為甚麼，點進去也沒辦法很直觀的知道這頁這表單是甚麼意思
> （**我不需要更多的說明文字，這樣更雜亂，我希望的是直觀的 UIUX**）
> 或是有些其實也應該是呈現資訊而不是點進去就是修改畫面？」

## 她要先看到哪幾個變好（2026-08-24 確認）

1. 來訪編輯器（排課程、時段、治療師、診間）→ `01`
2. 額度：加購與調整次數 → `02`
3. 客戶詳情點進來訪／任務之後的那一頁 → `03`

設定頁的主檔表單（診間、治療師、器材、課程）**這一輪不做**，她沒有選。

## 三條共同的診斷

### 一、下拉選單在這個 app 裡是個異類

SPEC 第 8.2 節寫著「課程／時段／器材／治療師／診間**全部用點的**，備註才要打字」，
壓表那一頁照做了（`.chip` 那一組丸子）。**第 8.3 節的來訪編輯器範例也是丸子**：

```
  器材  [INDIBA] ~~超磁場~~ ~~高能量雷射~~
  治療師 [騰崴]    診間 [治3]
```

但實作用的是 `f.select()`。所以這不是「她想要新設計」，
是**實作跟規格從一開始就不一樣**，而她現在指出來了。

丸子比下拉好的實際理由（不只是好看）：

- **看得到有哪些選項**。下拉要點開才知道有三個還是三十個。
- **被禁忌擋掉的器材看得見**。下拉選單裡那一行 `✕ 超磁場（體內金屬，不可使用）`
  只有點開才看得到，而 SPEC 第 4.3 節要求醫療禁忌**永遠可見、不可摺疊**。
- **少一次點擊**。她一個晚上要記二三十筆。

### 二、「不知道這一頁是什麼意思」不是缺說明，是缺主體

她明講不要更多說明文字。表單看不懂通常是因為**每一個欄位都長得一樣重要**：
十個一模一樣的方框上下疊，眼睛找不到「這一頁在講的那件事」。

作法是給每一張表單一個**主體**（她要決定的那件事）與一圈**背景**
（其餘的、通常不用動的）。主體大、在最上面；背景收小、往後排、
沒填的時候甚至不出現。

### 三、有些畫面本來就該先給看的

她問「有些其實也應該是呈現資訊而不是點進去就是修改畫面？」——
**這個 app 早就有這條規矩了**，只是沒有貫徹：ADR-0020 的「點一筆先浮出讀取模式
的卡片，右上角的鉛筆才進編輯器」，那是日曆上的行為。客戶詳情點一筆來訪
直接落進編輯器，是同一件事的兩種做法。

## 不在這一輪範圍內

- 設定頁的主檔表單。
- 匯入那幾頁。
- 客戶新增／編輯表單（她沒有提，而且它剛改過）。
