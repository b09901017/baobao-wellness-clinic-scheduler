# 加購復能：哪一種 → 幾分鐘，名字自己跟著變

Status: 已完成
Blocked by: 03

## 她說的

> 課程加購那邊可以只有復能，然後點了之後可以接者選選是三選一，四選一，或是單一的
> 哪一項，然後接者選幾分鐘30或60，都是可以用丸子呈現

> 然後ILIB點了之後可以選30或60分鐘，然後名稱都要跟者變(像是幾萬健檢那樣)

> 如果買了sis(60)x5 + 復能(30)四選一 x10 + ILIB(60)x20 這樣，那他們就是分開的

「幾分鐘」那一排從**課程主檔的「可選時長」**長出來（2026-09-06 確認），
不寫死課程名字。

## 要做什麼

### 一、課程主檔加「可選時長」

```js
{ …, durationMin: 60, durationChoices: [30, 60] }
```

選填。填了才會在加購畫面出現那一排丸子；沒填就用 `durationMin`，
跟今天一模一樣。種子裡只有兩個課程有：復能 `[30, 60]`、ILIB `[30, 60]`。

驗證（`masterData.js`）：每一個都是大於 0 的整數、去重、最多六個、
**`durationMin` 要在裡面**（不然預設值是一個她選不到的數字）。

設定 → 課程那一頁多一格：`可選時長　用頓號分隔`，走 `f.parseList()` 再轉數字。

### 二、「買了什麼」那一排

`ui/components/buy.js` 的第一排只改一顆字：

```
復能（三選一池）  →  復能
```

`POOL_PICK` 這個常數不動 —— 它是「這一顆不是課程」的意思，跟名字無關。

### 三、選了復能之後的第二排：「哪一種」

五顆，而且**沒有一顆寫死名字**：

| 丸子 | 值 | 從哪來 |
|---|---|---|
| 高能量雷射 | `eq-laser` | 器材主檔裡 `courseId` 指到復能的那幾台，一台一顆 |
| 超磁場 | `eq-sis` | 同上 |
| INDIBA | `eq-indiba` | 同上 |
| 三選一 | `__pool_course__` | 上面那幾台**全選** |
| 四選一 | `__pool_all__` | 全部還活著的器材 |

所以之後她新增第五台器材時，「四選一」自動變成五台 —— 而名字也會自己跟著叫
「復能五選一」（見下）。不必改程式。

### 四、第三排：「幾分鐘」

從那一筆額度對到的課程的 `durationChoices` 來。復能池 → 復能課程；
單買 ILIB → ILIB 課程。沒有 `durationChoices` 的課程整排不出現。

### 五、名字自己跟著變

三支純函式進 `domain/entitlements.js`（**不是 `buy.js`**：`buy.js` 的上半段
沒有一行碰 DOM，但這幾支連試算表與資料健檢都要用）：

```js
/** 一筆復能額度叫什麼。1 台 → 器材名；N 台 → 「復能N選一」。 */
export function poolName(optionEquipmentIds, equipment) { … }

/** 加上時長：'超磁場' + 60 → '超磁場(60)'。沒有時長就不加括號。 */
export function timedLabel(name, durationMin) { … }
```

接法跟 `tieredLabel()`（8萬健檢，ADR-0054）、`itemisedLabel()`（營養點滴 - 雪顏亮彩）
是同一種東西，所以它們住在一起。

`buy.js` 的 `autoLabel()` 接上去：

| 買了什麼 | 名字 |
|---|---|
| 復能・三選一・60 | `復能三選一(60)` |
| 復能・四選一・30 | `復能四選一(30)` |
| 復能・超磁場・60 | `超磁場(60)` |
| ILIB・60 | `ILIB(60)` |
| 健檢・8萬 | `8萬健檢`（不變） |
| 營養點滴・雪顏亮彩 | `營養點滴 - 雪顏亮彩`（不變） |

**她自己打過的名字不覆蓋** —— `keptLabel()` 那一條規則一個字都不改。

### 六、`payload()` 要帶 `durationMin`

它已經帶了。但 `blank()` 的 `durationMin: null` 在選了有 `durationChoices` 的
課程時要**預設帶課程的 `durationMin`**，不要讓她一定得點一下才存得下去。

## 三個入口一起

CLAUDE.md：「她賣了什麼給客戶」那張表只寫在 `ui/components/buy.js`，三個入口共用
欄位與**接線**。這一輪新增的那兩排丸子（`poolPick`、`durationMin`）要進
`buy.js` 的 `DETAIL_CHIPS`，否則**只有客戶詳情那一張表會跟著改名**，
另外兩張換了丸子名字不動 —— 那正是「其他…」那一格漏了兩次的同一個形狀。

三個入口：客戶詳情的「加購」、新增客戶的「加一項」、批次建立「微調」裡的「加一項」。

## 種子的方案項目跟著改名

| 方案 | 現在 | 改成 |
|---|---|---|
| 筋骨強身 | `復能` 12 次 | `復能三選一(60)` 12 次 |
| 筋骨強身 | `靜脈` 20 次 | `ILIB(60)` 20 次 |
| 8萬方案 | `復能` 20 次 | `復能三選一(60)` 20 次 |
| 8萬方案 | `靜脈` 12 次 | `ILIB(60)` 12 次 |

**既有客戶身上的額度不跟著改**（額度是購買當下的快照，ADR-0003）。
改名那條路在 `09`。

## 不做的

- **不做「復能」這個課程的加購。** 點了復能一定要再選一種 —— 選不出來的那一筆
  額度在壓表時沒有器材可以選。`buy.validate()` 要擋：「還要選一種復能」。
- **不讓她自己打時長。** 「進階設定」那一格本來就打得了（客戶詳情那張表），
  這一排丸子是捷徑不是唯一的路（同 ADR-0060 的判準）。

## 測試

- `tests/buy.test.js`：五種「哪一種」各自吐出正確的 `optionEquipmentIds`；
  換丸子時名字跟著變、她打過的名字不被覆蓋；只選復能沒選種類 → 擋。
- `tests/domain.test.js`：`poolName()` 對 1 台／3 台／4 台；`timedLabel()` 沒有
  時長時不加括號。
- `tests/master-data.test.js`：`durationChoices` 的驗證四條。
- `tests/number-fields.test.js`：新的時長欄位 `min`／`step` 要跟 domain 講同一句話。
- `tests-e2e/`：加一支或延伸 `01-products.spec.js` —— 三個入口都買一次
  `超磁場(30)`，三邊存進去的形狀要一樣。
