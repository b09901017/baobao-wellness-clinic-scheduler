## 她說的

> 我想要放我目前的xlsx 以及.ics 以及一些圖片（客戶資料+方案圖片）應該放哪？
> 不能上傳！

> 我希望claude code幫我開一個資料夾放一些先關檔案像是xlsx .ics 圖片等等，
> 然後我等等上傳圖片也希望他幫我重新命名，然後理解，但這是下一步了

## 放哪

`.local/`。**它已經在 `.gitignore` 裡**（`/.local/`），而且那一條的註解寫的正是
這件事：「別名表裡是真實客戶姓名，跟匯出的 TSV、報告一樣不進版控」。
`.claude/skills/calendar-sheet-merge` 本來就用這個資料夾。

不要開新的資料夾名字 —— 多一個要記得加進 `.gitignore` 的地方，
而漏掉一次就是真實客戶健康資訊進了版控，那是這個專案的第一條鐵則。

```
.local/
  references/
    README.md      這裡放什麼、為什麼不進版控、清掉之前先確認她自己留了一份
    xlsx/          寶寶客戶進度總表.xlsx …
    ics/           TimeTree 匯出.ics
    images/        方案文宣、客戶資料的截圖
```

## 驗證

建好之後跑一次，**印出來給她看**：

```
git check-ignore -v .local/references/xlsx/any.xlsx
```

有輸出就是擋住了。這一步不是形式 —— `.gitignore` 那一段的註解自己就寫著
「驗證方式」，因為擋沒擋住從畫面上看不出來。

## 下一步（她說「這是下一步了」）

她放上來之後我要做的：

1. **先看，不猜。** 逐份列出讀到了什麼（幾張工作表、幾個欄位、日期範圍、
   圖片上是什麼），**列出對不起來或看不懂的地方向她問**，不自己通靈。
2. 圖片重新命名成看得懂的（`方案-筋骨強身-01.jpg` 這種），
   **檔名裡一個真實客戶姓名都不可以有**。
3. `.ics` + `.xlsx` 那條路已經有 skill 了（`calendar-sheet-merge`），
   不要自己從頭寫解析。

## 不做的

- **不把任何一個檔案複製進 `docs/`。** `docs/` 進版控。
- **不做 `docs/references/`。**（我第一版的建議是錯的：那個路徑進版控，
  而她的檔案裡有真實客戶姓名與健康資訊。）
- **這一步不讀檔案。** 她還沒放上來。
