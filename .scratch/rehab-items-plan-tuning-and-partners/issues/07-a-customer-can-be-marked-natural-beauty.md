# 合作機構主檔，客戶可以標記自然美

Status: 待確認

## 她說的

> 有些會想要和自然美一起約 就是我壓完之後要去問自然美這天能不能搭配自然美的
> 要能夠在壓表那邊顯示

> 客戶可以標記自然美，就是如果生成todo，不用特別生出一個自然美的todo，
> 而是只要有自然美的標註，都要顯示，不論是在todo那邊或是壓表那邊

2026-09-06 確認：**新開一份「合作機構」主檔**，而且**完全不生任務，只有標記**。

## 為什麼是主檔而不是自由輸入

程式裡不寫死「自然美」三個字。這個 repo 為字串比對付過帳 ——
`domain/followups.js` 的檔頭記著舊 Apps Script 用課程名稱做包含比對、
一改名就靜默失效。合作機構之後會不會多一家，她自己在設定裡加就好。

## 為什麼不塞進既有的三種

| 既有 | 為什麼不行 |
|---|---|
| 永久限制第二層（警示） | 自然美不是臨床的事。混進去之後那一排丸子就不再只回答一個問題 |
| 永久限制第三層（其餘） | 第三層**刻意不畫在壓表卡片牆上**（ADR-0046），而那正是她要看到它的地方 |
| 備註 | ADR-0019：備註不影響任何行為。而這個標記要讓備忘錄浮出來（`08`） |

## 要做什麼

### 一、`config/app/partners`

```js
{ name, active, deletedAt }     // '自然美'。<= 12 字，跟警示同一個理由：卡片牆上要掃得完
```

`MASTER_TYPES` 加 `partners`，`MASTER_LABELS` 是「合作機構」。
種子一筆：`{ id: 'partner-nb', name: '自然美' }`。

`config/{docId=**}` 在 `firestore.rules` 已經是萬用路徑，這一份**不用開洞**。

### 二、客戶身上

```js
partners,   // ['自然美']。**存字串不是 id**
```

存字串跟永久限制同一個理由（CLAUDE.md）：主檔改名不會搬既有客戶 —— 那是刻意的，
改名的人要自己回來重選。

`firestore.rules` 的 `validCustomer()` 補一條形狀檢查：
`(!d.keys().hasAny(['partners']) || d.partners is list)`，跟 `marks` 一樣的深度。

`domain/customers.js` 加：

```js
/** 這位客戶掛了哪幾家。主檔上沒有的字照樣回 —— 掉出畫面比顯示一個陌生的字糟。 */
export function partnersOf(customer) { … }
```

### 三、畫在哪

**四個地方共用一支** `ui/components/flags.js` 的 `partnerChips()`。
那一支已經是「跟著客戶名字出現的那一排丸子」的家，檔頭要補一段講清楚它現在
管兩種東西：警示（永久限制）與合作機構（不是限制）。

| 畫面 | 位置 |
|---|---|
| 壓表卡片牆 | 名字那一行，接在警示丸子後面 |
| 待辦中心的每一列 | 客戶名字後面 |
| 客戶詳情 | 永久限制那一排旁邊 |
| 客戶總覽的卡片 | 名字那一行 |

畫法：`.flag--partner`。**跟警示長得不一樣**（不同顏色、加一個小圖示或前綴），
因為它們回答的是兩種問題 —— 一個是「這個人做起來要注意」，一個是
「這一次要多跟一家講一聲」。色票在 `tokens.css`，**淺色與深色兩份都要有**。

### 四、客戶編輯表單

`ui/components/flags.js` 的 `mount()` 底下多一排丸子（複選），
在「其他限制」那一格底下、自成一個 `fieldgroup`：

```
合作機構　這位客戶要跟誰一起約
(自然美)
壓完表記得跟他們的專員說一聲。不會產生任何待辦。
```

那句 hint 要寫，因為她問過「如果生成todo」—— 畫面要主動講出它**不**會生。

## 不做的

- **不生任何任務。** 她 2026-09-06 選的。所以 `domain/taskRules.js`、
  `domain/todoFlow.js`、`domain/followups.js` 一行都不改，
  `TASK_KINDS` 也不多一種。
- **不上日曆。** ADR-0045：日曆上是七種，色相已經用完了。自然美是客戶身上的
  標記，不是日曆上的一類東西。
- **不改 `visitReadHtml()`。** 四個畫面共用（ADR-0018、0056）。
  來訪讀取卡片上要不要出現自然美，接在**外面**（同備忘錄那一塊的作法）。
- **不做「這一次要不要搭配自然美」的逐次勾選。** 標記綁的是人，不是那一次來訪。
  之後她真的需要逐次記，那是隨手記的工作。

## 測試

- `tests/customers.test.js`：`partnersOf()` 對空的、對主檔上沒有的字。
- `tests/master-data.test.js`：`validate('partners')` 擋空名字、擋同名、擋超過 12 字。
- `tests/domain.test.js`：種子有一筆合作機構。
- `tests-e2e/`：一位帶自然美標記的客戶，在壓表卡片牆與待辦中心兩頁都看得到那顆丸子。
