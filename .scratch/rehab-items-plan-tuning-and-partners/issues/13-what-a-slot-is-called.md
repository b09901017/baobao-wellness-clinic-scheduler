# 一段要唸成什麼：全名、別稱、LINE 三種寫法

Status: 待確認
Blocked by: 03

## 她說的

> 日曆以及要通知客戶的line草稿等等，就是要寫特定哪一項，而不是說甚麼三選一四選一，
> 而是特定什麼可以寫復能(sis) 或是ILIB這樣，這樣客戶和我才清楚

> 月檢視寫器材名，其餘寫全名，然後其實可以器材名寫 "SIS" 以及全名寫"復能(SIS)"，
> 然後設定可以多一個名稱檢視表？就是可以設定課程的全名以及別稱(像是月檢視這邊呈現的)
> 以及如果是line草稿要怎麼寫名稱等等

> 不管那筆額度是四選一，三選一還是單買，就寫那天真的做了甚麼，
> 然後ILIB不要變成ILIB(ILIB) 很怪

## 為什麼這一支存在

日曆上寫「復能」、LINE 草稿上寫「復能」，而她那天真的做的是超磁場 ——
**客戶看不懂，她過幾週也認不出來**。額度叫什麼是「當初買了什麼」，
時段叫什麼是「那天做了什麼」，兩件事。

而三個地方能放的字數差很多（月檢視一小條、讀取卡片一整列、LINE 一句話），
所以是**一份資料三種寫法**，不是三份資料。

## 要做什麼

### 一、課程與器材各自有三格名字

```js
{
  name,        // 全名。必填。'復能' / '超磁場'
  shortName,   // 別稱。選填，空的退回全名。'SIS'
  lineName,    // LINE 草稿用。選填，退回**別稱**再退回全名
}
```

`lineName` 退回**別稱**不是全名，是刻意的 —— 她要的預設是「LINE 跟一般一樣」，
而一般那個寫法括號裡放的就是別稱。退回全名的話她什麼都沒設定時 LINE 會寫
「復能(超磁場)」，跟畫面上不一樣。

### 二、三種情境怎麼組

`domain/naming.js`（新，純函式）：

```js
export const NAME_CONTEXTS = ['short', 'full', 'line'];

/** 一筆主檔在某個情境要唸成什麼。 */
export function nameOf(record, context) { … }

/** 一段來訪要唸成什麼。**這一支是唯一的一份。** */
export function slotName(slot, { courses, equipment }, context) { … }
```

| 情境 | 課程那一半 | 器材那一半 | 例 |
|---|---|---|---|
| `short` 月檢視 | `shortName` | `shortName` —— **有器材就只印器材** | `SIS` |
| `full` 一般 | `name` | `shortName` | `復能(SIS)` |
| `line` LINE 草稿 | `lineName` | `lineName` | `復能(SIS)` |

三條共同的規則：

1. **沒有器材就只有課程那一半。** 健檢、二返、營養點滴一個字都不會變。
2. **器材那一半跟課程那一半一樣時不加括號。** ILIB 的課程與器材同名，
   所以是 `ILIB` 不是 `ILIB(ILIB)` —— 她指名這件事。
3. **課程先查主檔，查不到才退回 `slot.courseName` 快照。** 匯進來的舊來訪
   （ADR-0011）與被刪掉的課程都還印得出名字。

**器材的全名只出現在兩個地方**：設定的器材清單、壓表／來訪編輯器選器材那一排。
在時段的名字裡一律用別稱 —— 她要的就是 `復能(SIS)`。

### 三、`設定 → 名稱怎麼寫`

一頁，一列一筆，就地改**別稱**與 **LINE**，右邊即時畫出三種情境：

```
名稱怎麼寫

          別稱          LINE         月檢視   一般          LINE 草稿
復能      [復能    ]   [        ]    復能     復能          復能
  超磁場   [SIS     ]   [        ]    SIS      復能(SIS)     復能(SIS)
  INDIBA  [        ]   [        ]    INDIBA   復能(INDIBA)  復能(INDIBA)
  高能量雷射[       ]   [        ]    高能量雷射 復能(高能量雷射) …
ILIB      [        ]   [        ]    ILIB     ILIB          ILIB
健檢      [        ]   [        ]    健檢     健檢          健檢
```

- **全名不在這一頁改。** 改全名會動到主檔清單、方案範本、稽核紀錄，那是課程／器材
  自己那一頁的事。這一頁只管「同一個東西的另外兩種寫法」。
- 器材縮排掛在它的課程底下（`03` 之後每一台器材都知道自己屬於哪個課程），
  因為她要看的正是那兩個字組起來長什麼樣。
- **預覽是即時的**，打字不重畫（同 `buy.js` 那句「會變成『8萬健檢』」的作法）——
  重畫會洗掉游標與輸入法的組字狀態。

### 四、種子只預填一個別稱

`超磁場 → SIS`（她指名的）。其餘留空 —— 空的就是全名，行為跟今天一模一樣。
「高能量雷射」在月檢視上會有點長，但那是她自己填一次就好的事，
系統不要替她猜一個縮寫。

### 五、呼叫端

| 畫面 | 情境 | 檔案 |
|---|---|---|
| 日曆月檢視的小條 | `short` | `ui/views/calendar.js` |
| 日曆日／週檢視的列 | `full` | `ui/views/calendar.js` |
| 來訪讀取卡片的時段列 | `full` | `ui/views/calendar.js` 的 `visitReadHtml()` |
| 壓表的記錄面板 | `full` | `ui/views/schedule.js` |
| 來訪編輯器 | `full` | `ui/views/visitEditor.js` |
| LINE 草稿 | `line` | `domain/messages.js` |
| 試算表的器材註記 | `short` | `14` |

**`visitReadHtml()` 會跟著改，而它是四個畫面共用的**（ADR-0018、0056）——
這一次是刻意的：日曆、客戶詳情、待辦中心、進度追蹤四頁應該講同一句話。
CLAUDE.md 那一條擔心的是「只有一頁改到」，不是「四頁一起改」。

**稽核紀錄不變。** `visitCourseLabel()` 印的是課程名快照，
而稽核講的是「那一刻寫下去的是什麼」（`domain/audit.js`）。

## 不做的

- **不動 `slot.courseName` 這個快照欄位。** 它仍然是排班當下寫下去的字。
  名字是**畫出來的**不是存起來的 —— 她改一次別稱，全部畫面跟著改。
- **不讓她自己打組合的格式**（`{課程}({器材})`）。那是第二種模板語法，
  而這個專案已經有一種了（`domain/messageTemplates.js`），兩種她要記兩套。
- **不碰營養點滴的品項名。** 那一段的名字走 `itemisedLabel()`，是額度的名字
  不是時段的名字，兩條路不併。
