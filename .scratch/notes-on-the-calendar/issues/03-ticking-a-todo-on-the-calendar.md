# 在日曆上新增待辦、勾掉、改日期 —— 兩邊同一份資料

Status: done
來源：使用者，2026-08-23
動工前先讀：本資料夾的 `spec.md`、`issues/01`、`issues/02`、
`SPEC.md` 第 8.6 節「這一頁從頭到尾不換頁」、`docs/adr/0020`

## 原話

> 「todo 就是從隨手記那邊記過來的，或是我在這邊新增的，**也必須要同步到隨手記那邊**」
> 「完成後可以在日曆呈現他被杠掉了」

## 要做什麼

同步不用寫 —— 兩邊讀的是同一個 `notes` 集合（`spec.md`）。要寫的是日曆上的互動，
而且它必須守 ADR-0020：**這一頁從頭到尾不換頁。**

### 點一筆待辦 → 浮出讀取模式的卡片

跟來訪、行事備註一模一樣的動線（`openCard()`）：

```
記得幫王小明問週六有沒有位子
8/25（一）・王小明
                                  [ ✎ ]
[ ☐ 還沒做 ]  ← 點一下就勾掉
```

- 右上角鉛筆才進編輯。她點一筆的十次有九次只是要看那句話寫什麼。
- **勾掉那一顆在讀取卡片上就有** —— 這是待辦跟來訪不一樣的地方：
  勾掉不是「改資料」，是「這件事做完了」，那正是她點開它的原因。
  勾完卡片不關，`☐` 變 `☑` 並畫上刪除線，底下那一天的面板同步重畫那一列。

### 編輯

一張小表單，掛在同一張面板裡（不換頁、不開新畫面），用 `issues/01` 抽出來的
`ui/components/noteForm.js`：文字、日期、掛給誰、一顆勾。

底下多兩顆：

- **「從日曆拿掉」** —— 清掉 `date`，那一筆回到只有隨手記看得到。
  **不是刪除**，文案要講清楚（「這一筆會留在隨手記，只是不再出現在日曆上」）。
- **刪除** —— 走軟刪除，照 SPEC 第 6.5 節放在不容易誤按的位置。

### 新增

從泡泡的「新增待辦」或那一天面板裡的「＋」進來，同一張表單，
日期預設帶當下那一天。存完面板留在原地並重畫那一天。

## 一起要檢查的

- `views/calendar.js` 的 `openDetail()` 現在只認 `visit:` 與 `event:` 兩種前綴，
  要加 `note:`
- `openDay()` 那一天的面板要把待辦列進去
- 復原（`toast.withSaveState`）：勾掉、改日期、拿掉日期都是單一 commit，
  三個都要退得回去
- `tests/notes.test.js`

## 不做

- **不在日曆上做「掛在來訪底下」的待辦。** 隨手記可以掛客戶，不掛來訪 ——
  掛來訪的那種東西已經有名字了，叫任務。
- 不做拖拉改日期。ADR-0020 與 SPEC 第 8.0 節：手勢只能是快捷方式，
  而這件事沒有第二條路的話就是「不拖就做不到」。

## 驗證

- `npm test`
- 瀏覽器：日曆上勾掉一筆 → 回待辦首頁，那一筆也是勾掉的（不用重新整理，
  換頁本來就會重讀）
- 瀏覽器：待辦首頁勾掉一筆有日期的 → 日曆上那一條有刪除線
- 瀏覽器：「從日曆拿掉」→ 日曆上不見了、`#/todo/notes` 上還在
- 瀏覽器：面板開著時按上一頁 —— `openSheet()` 的 `hashchange` 會收掉它，
  確認沒有留下蓋在新畫面上的卡片

## Comments

**2026-08-23 —— done。** 兩件值得記著：

- **勾掉之後卡片不關，只把它自己重畫一次。** 她可能還想看那一天的其他東西。
  底下那一天的面板等關掉之後由 `render()` 一起更新 —— 兩邊同時重畫會讓
  卡片跳一下。
- **編輯器不改「掛給誰」。** 那是客戶詳情頁的事，而在日曆上她要改的是
  「哪一天」。多一個欄位會讓這張表看起來像另一種東西，而它就是隨手記本人。
