# 隨手記可以有日期，日曆上因此多一類「待辦」

Status: 全部 done（2026-08-23）
來源：使用者，2026-08-23（第二輪回饋的第三、四點）
動工前先讀：`SPEC.md` 第 8.1、8.6 節、`CONTEXT.md` 的「隨手記」「備註」
「個人行程」、`docs/adr/0015`、`0019`、`0020`、`0039`、`0040`

## 她說的（原話）

> **第三**：希望隨手記可以多一個日期（可以是今天或是跳出日曆讓我選日期）的選擇
> （不一定要選）但是可以選然後就會紀錄到日曆的 todo 類別，也會呈現在日曆上，
> 然後完成後可以在日曆呈現他被杠掉了。

> **第四**：不用個人行程，我覺得我需要的類別應該是
> 1. 客戶（來訪）2. todo 3. 休假 4. 備註。
> todo 就是從隨手記那邊記過來的，或是我在這邊新增的，也必須要同步到隨手記那邊。
> 備註其實就和之前的個人行程一樣，只是我想改名。
> 要記得也更新那個漂浮泡泡以及顏色配置，不能和客戶（來訪）的顏色重疊。

問過、定案的：

| 問題 | 答案 |
|---|---|
| 隨手記選了日期之後要不要也能選時間 | **只選日期**，整天，釘在那一天最上面 |
| 日曆那一類叫「備註」會跟詞彙表撞名 | 日曆那一類叫 **「行事備註」**，客戶身上的「備註」不動 |
| 日曆上 todo 那一類的顏色 | **不搶新色相，用記號**（方框勾勾＋勾掉畫刪除線） |

## 兩件事其實是同一件事

第三點與第四點講的是同一份資料的兩端：**日曆上的「待辦」就是有日期的隨手記。**
所以這一輪不新增集合、不在 `events` 底下開一個 `todo` 類別 —— 那會變成兩份資料
講同一件事，而她明確要求「也必須要同步到隨手記那邊」。同步最可靠的作法是
**根本沒有第二份**。

```
notes（隨手記）
├── date == null  → 只在待辦首頁與 #/todo/notes
└── date != null  → 上面兩個地方照樣有，而且出現在日曆那一天
```

在日曆上新增待辦 ＝ 建一筆 `date` 已經填好的隨手記。在日曆上勾掉 ＝
`notes.setDone()`，隨手記那邊當然也是勾掉的。

## 日曆上現在有四類

| 類 | 資料在哪 | 顏色 | 可以跨天 |
|---|---|---|---|
| **客戶來訪** | `visits` | 四個狀態色（琥珀／靛藍／墨綠／硃紅） | 不行 |
| **待辦** | `notes`（`date != null`） | **不搶色相**：墨色 ＋ `☐`／`☑`，勾掉畫刪除線 | 不行 |
| **休假** | `events`（`category: 'leave'`） | 灰青 ＋ 斜線紋 | 可以 |
| **行事備註** | `events`（`category: 'personal'`） | 紫（或她自己挑的六色之一） | 可以 |

**`events` 的 `category` id 一個都不改**（`personal` / `leave`），只改畫面上的 label。
Firestore 裡已經有的行程不必動，也不需要任何搬移。

## 為什麼待辦不給它一個顏色

ADR-0039 已經記著：色相輪上塞六個彼此分得開的顏色，最後兩個一定會擠在一起 ——
那是休假改走斜線紋的原因。現在要分辨的東西變成七種，色相只會更不夠。

而且待辦本來就不是「這裡有一件療程」。它跟休假是同一種東西：**用形狀講，
不要用顏色講**。方框勾勾（`☐` / `☑`）在 11px 的色條上仍然認得出來，
而且它自己就說明了「這是一件可以勾掉的事」——「勾掉了」也因此有畫法可用：
刪除線。

## 名字

- 日曆篩選丸上那四顆：**客戶來訪 · 待辦 · 休假 · 行事備註**
- `CONTEXT.md` 的「個人行程」那一條要改名成「行事備註」，
  但**它的 _Avoid_ 那句不能拿掉**：「不可以簡稱『行程』—— 那是『來訪』的禁用同義詞」。
  改名之後同一個坑還在，甚至更近了（「備註」現在是兩個詞的字首）。
- `CONTEXT.md` 的「隨手記」要補一句：**可以掛一個日期，掛了就上日曆**。
- **「待辦」這個詞現在有兩個意思**（待辦中心裡的每一列 vs 日曆上這一類），
  要在 `CONTEXT.md` 講清楚界線：日曆上那一類**只有**有日期的隨手記，
  任務（`tasks`）不上日曆 —— 任務跟著來訪走，來訪本身已經在日曆上了。

## 不做

- **任務（`tasks`）不上日曆。** 它們的死線是來訪日前一天，而那筆來訪就畫在那裡了 ——
  同一天畫兩條，一條寫客戶名一條寫「Examine」，那是同一件事佔兩格。
- **不做重複／週期性的待辦。** 隨手記是一次性的小事（`CONTEXT.md`），
  一加上重複就變成另一種東西了。
- **不讓待辦跨天。** 跨天的只有個人行程那一種（`CONTEXT.md` 寫死的），
  而一件「記得帶健保卡」沒有跨天的意思。
- **不做時間。** 她自己選的：只選日期。
- 不改客戶身上的「備註」（彩色小丸，ADR-0019）。
