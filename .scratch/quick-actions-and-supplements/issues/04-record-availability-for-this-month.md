# 「記一次」的新增那一排沒有這個月

Status: todo
來源：使用者，2026-09-01（需求 A.4）
動工前先讀：`public/js/ui/views/availability.js` 的 `openPicker()`、
ADR-0036、ADR-0053、`CONTEXT.md` 的「本輪可用性」

## 原話

> 在客戶詳情的「記一次（不可用時間）」中，假設現在是 9 月，
> 系統卻只允許新增或修改 10 月之後的時間。請修改邏輯，
> 讓「這個月」的不可用時間也能被記錄與修改。

## 根因

`openPicker()` 的迴圈從**下個月**起算：

```js
const AHEAD = 4;
for (let i = 1; i <= AHEAD; i += 1) {          // ← i 從 1
  const month = addMonths(today, i).slice(0, 7);
  if (!taken.has(month)) ahead.push(month);
}
```

那個 `1` 是從「她月底那一兩個禮拜問下個月」推出來的（ADR-0053 的節奏），
但那是**常態**不是**限制**：客人月中打來說「我這個月 20 號之後出國」，
她現在沒有地方記。

`defaultMonth(today) = addMonths(today, 1)` 也是同一個假設，
不過那只是新表單的預設值，她按哪一顆就開哪一個月，所以不必動它
（走「新增」那一排一定會帶 `picked`）。

`domain/availability.js` 那一側**沒有任何一條規則擋當月**：
`validateCollection()` 只檢查 `validFrom`／`validTo` 合不合法與先後，
`monthGrid()` 畫得出任何一個月。所以這是純粹的畫面限制。

## 要做什麼

`openPicker()` 一行：

```js
/**
 * 「新增」那一排給幾個月。**從這個月起算** —— 她的常態是月底問下個月
 * （ADR-0053），但客人月中打來說「我這個月 20 號之後出國」也要記得下來。
 * 已經有的月份不出現在這一排（動線本身保證同一個月不會有第二份）。
 */
const AHEAD = 4;
for (let i = 0; i <= AHEAD; i += 1) {
```

（`i = 0` 到 `4` 就是這個月加上往後四個月，共五顆。她本來看到四顆，
現在看到五顆，一排放得下。）

## 檢查過、不用改的三件事

1. **`collectionFor(month)`（ADR-0036）** 是照 `validFrom` 的月份挑的，
   所以九月那一份對壓九月的表天生就是對的。
2. **`currentCollection()`** 問的是「現在」，九月那一份在九月當然算數 ——
   而在這一支之前她**根本記不了**九月那一份，所以那一頁一直在說
   「還沒問 9 月的時間」。這一件會順便修好客戶詳情上那句話。
3. **`monthGrid(month, { today: null })`** 畫當月時會把已經過去的日子
   一起畫出來。**這是對的，不要擋** —— `notes.js` 的
   `validateNote()` 早就寫過同一條判斷：「不擋過去的日期，她會補記昨天那一件」。
   本輪可用性同理：她 9/20 才記「9/5 那天不行」是在補資料，不是在排班。

## 連動

- **資料健檢的 `duplicateAvailability`**（`domain/health.js`）列的是同一個月被記了
  兩份。這一支不會多製造重複：已經有的月份只出現在「改」那一排（`taken` 那個 Set）。
- `SPEC.md` 第 8.9 節與 ADR-0053 都寫著「一份就是一個月」，**這一支不推翻它**，
  所以**不用補 ADR** —— 改的只是「新增那一排從哪個月開始列」。

## 不做

- 不給「上個月」。過去的月份記了沒有人會讀（壓表只壓當月與之後），
  而多兩顆丸子就多兩次點錯。要補過去的資料走「改已經填過的」那一排。
- 不改 `defaultMonth()`。走「新增」那條路一律帶著她點的那一顆月份。

## 驗證

- 瀏覽器（今天是 2026-09-01）：客戶詳情 → 不能的時間 → 記一次 →
  「新增」那一排要有 **9 月、10 月、11 月、12 月、1 月**
- 瀏覽器：點 9 月 → 日曆畫的是 2026-09 的格子 → 點幾天 → 存起來 →
  客戶詳情那一塊抬頭寫「9月不能的時間」
- 瀏覽器：再按一次「記一次」→ 9 月**只出現在「改已經填過的」那一排**，
  新增那一排剩四顆
- 瀏覽器：壓九月的表時那一份要被 `collectionFor()` 挑中（卡片牆上寫的是 9 月那一份）
- `npm test` 全綠
