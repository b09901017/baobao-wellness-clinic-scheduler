# 「健檢不是我排的」：二返～十返不接健檢、不扣額度

2026-11-02 談定。主控 session 寫的；設計在對話裡一題一題跟她確認過。

## 現在為什麼做不到（主控 11/2 讀程式碼查過）

| 卡在哪 | 程式碼 |
|---|---|
| 「＋ n返」只在客戶有接得上的健檢時才畫，課程從那次健檢借 | `slotOptions.js:100-119`、`nthFollowup.js` 的 `courseIdForNth()` |
| n返 的課程算不出來 → `slotFromPicks()` 回「先選要做什麼」→ 拍 Abovee 那一列沒有醫師那一排 | `slotDraft.js:76-82、105` |
| 存檔：n返 沒接健檢是硬擋 | `visits.js:1870-1876` |
| 拍 Abovee 那一句「這位客戶還沒有排著或做完的健檢可以接 —— 選別的，或先去約健檢」 | `aboveeConfirm.js:588-590` |
| 二返沒有任何一筆二返額度 → 「要選一個額度」 | `visits.js:1739-1740` |

## 談定的設計

**一顆「健檢不是我排的」**，二返與三返～十返共用。按了之後選第幾返（二返～十返），**不扣任何額度、不接健檢**。

| | 一般（一個字都不改） | 按了「健檢不是我排的」 |
|---|---|---|
| 次數 | 二返扣二返額度；n返 本來就不扣 | 不扣 |
| 接健檢 | 二返沒接只提醒；n返 一定要接 | 不接 |
| 日曆、醫師、診間 | 照二返那門課 | 一樣 |
| 耀聖／Examine、寫紀錄的待辦 | 照課程長 | 一樣（照二返那門課） |
| 試算表 | 二返在額度那一列；三返在「三返（不算次數）」 | 二返在「二返（不算次數）」（排在三返那幾列旁邊）；三返進原本那一列 |
| 追蹤健檢報告、約二返那條鏈 | 照常 | 不碰（每一支都先問有沒有接健檢） |

### 資料的形狀（主控定的，理由寫進 ADR）

時段上多一格 **`examNotMine: true`**，其餘：

- `entitlementId: null`、`followupForVisitId: null`、`giftKind: null`
- `courseId`：二返那門課（某一門課的 `followupCourseId` 指著的那一門；`abovee.js:317` 已經這樣找）
- 二返：**`followupNth` 不寫（null）**；三返～十返：`followupNth` 3～10

二返**不**寫成 `followupNth: 2`：`nthOf()`／`isNthSlot()` 的約定是「二返也回 null —— 它走額度那條路」（`nthFollowup.js:84-99`），十幾支讀它；
寫成 2 就要改這個約定。標記另外一格，`nthOf()` 一個字都不動。

### 防一般的時候按錯（她：「多一點步驟，多一點提醒或是多一點確認」）

- 那一顆收在「做什麼」那一排最後的收合裡；收合那一顆的字改成「送的／體驗／其他…」
- 拍 Abovee **不替她按、不替她勾**：照片是二返／三返、而這位沒有接得上的健檢或沒有二返額度時，那一列講一句、指她去點開收合
- 第幾返：拍照照照片上的字；日曆、壓表**不預選**（她按一下）
- 沒按那一顆：照舊擋（n返 沒接健檢、二返沒有額度都照舊存不下去）
- **紅字**（不收進 `tip()`，進 `mustSee()`），存檔的確認框再講一次：
  - 這位客戶身上還有二返額度（還有剩）→ 二返按了「健檢不是我排的」時
  - 這位客戶有接得上的健檢 → 任何一段按了「健檢不是我排的」時
- 一般的規則都不改：`canBeGift()`、`MIN_NTH`、「二返走額度」、「n返 要接健檢」—— 只有帶著 `examNotMine` 的段放寬那兩道

### 她知道的代價

- 不在客戶詳情的額度卡上（它不是額度），來訪紀錄裡有
- 試算表那一列沒有應有／剩餘（一槓），只有做了幾次
- 第幾返要她自己選

### 被否決的兩條路（理由寫進 ADR）

1. **借「送的／體驗」**：名字會變成「三返(體驗)」「二返（體驗）」（她：「也不是送的就是它有的」）；要改 `canBeGift()`（16 個呼叫端），
   拍 Abovee 的「預約來源寫體驗」會把一般客戶的二返改成不扣（`aboveeImport.js` 的 `photoSaysTrial()`／`trialSay()`）
2. **補一筆二返額度再扣**：她否決（加購太繞）。另外兩個理由：「應有 1」是編出來的數字；同一位客人 app 裡也做過健檢時，
   扣錯那一筆（跟 app 裡健檢一起買的）會讓 `placeSeconds()`（`followups.js:1147`）把它算成那次健檢的二返做完了，那次的「約二返」被收掉
