# 讓畫面安靜下來（2026-09-10）

這一輪是她一次丟來的八條。表面上是八個 UI 抱怨，實際上收斂成**四件事**：

1. **版面上的小瑕疵** —— 切換器折行、兩顆箭頭、懸空的底條、拉滿整行的丸子
2. **畫面上講太多話** —— 一百五十段常駐說明，她說「一眼看下去非常雜亂，會視覺疲勞」
3. **講的話對不上做的事** —— 按鈕寫「取消一整天」、確認框寫「取消這一筆」
4. **名字印錯了那一種** —— 她自己看的地方印了要貼給客人的那一句

## 談定的策略（2026-09-10 對話）

| 她問的 | 談定的 |
|---|---|
| 第三條 (d) 三頁要不要單段化 | **每一段自己一列，點了才看細節。** 三頁先列「那一天有哪幾段」＋那一天的待辦，點某一段才浮出只有那一段的讀取卡片 —— 日曆已經是這個行為，四頁就一致了 |
| 第二條 tooltip 要做多大 | **先做元件 ＋ 最划算的那八處。** 其餘按畫面分批跟上 |
| 第七條 d 刪掉的第二條路 | **編輯狀態下多一顆低調的垃圾桶。** 長按鉛筆是快路，ADR-0060 不用動 |
| 怎麼分 PR | **五個 PR，小的先出**（實際切成六支，見下） |
| ADR-0085 的落差 | **改程式，真的拿掉那一塊。**「改整天的狀態」另外留一條點得到的路，舊 ADR 一個字不改 |
| 「這一天共用」 | **改成 tooltip，點了才講** |
