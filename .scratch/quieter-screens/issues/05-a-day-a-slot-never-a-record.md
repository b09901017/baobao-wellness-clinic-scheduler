# 05 三個詞、三個意思：這一段、這一天，而「筆」不上畫面

Status: todo
動工前先讀：`.scratch/quieter-screens/spec.md`、`docs/adr/0081`、`docs/adr/0083`、`docs/adr/0085`

## 她要的

> 我發現還是有很多地方寫這一天 ? 但是現在不都改成這一項了嗎?可以幫我整理所有這一項和這一天的相關內容嗎 ?  "這一天"有哪些是真的要綁在這一天的
>
> c 我長按然後選取消一整天（N段）出來的提示應該是取消...整天的來訪？ 而不是這一筆。一天一筆 所以取消整筆就是取消整天，寫"整筆"會讓使用者看不懂，改成寫整天，也全域檢查，有沒有地方也是寫"筆"的，確認到底是這一天，還是這一項，如果是這一天的意思，那就改這一天

## 為什麼會這樣

「筆」是**資料層的詞**。ADR-0083（一天一筆來訪）之後它在畫面上就沒有意義了 ——
使用者心裡的單位只有兩個：**那一天**，和**那一天裡的某一段**。但文案是一句一句長出來的，
沒有人回頭統一過，所以同一個動作會出現三種講法。

最明顯的一組（她指名的那個）：

| 在哪 | 字 |
|---|---|
| 長按選單的按鈕（`domain/visits.js:966`） | `取消一整天（3 段）` |
| 確認框標題（`ui/views/calendar.js:1077`） | `取消 王小明 這一筆來訪？` |
| 確認鈕（`ui/views/calendar.js:1084`） | `取消這筆來訪` |
| 內文（`domain/consequences.js:422` 起） | `3 個時段會退回去…`（**一次都沒提「這一天」**） |

## 規則

**寫進一支新 ADR。**

| 詞 | 指什麼 | 哪裡用 |
|---|---|---|
| **這一段** | 一個 slot | 只改那一段、只取消那一段、那一段的待辦 |
| **這一天** | 整筆 visit（一天就是一筆，ADR-0083） | 整筆的狀態、整筆取消、刪整份文件 |
| ~~這一筆／整筆~~ | 資料層 | **畫面上不出現**。唯一例外：資料健檢頁與稽核紀錄 —— 那兩處本來就是在講資料 |

### 一定要改（而且不只是文案）

| 檔案:行號 | 問題 |

| `domain/consequences.js:108` | `這一段先看一下`（`lines.length === 1` 時）—— **這裡的「這一段」不是時段**，是「這一件事」。在來訪表單的脈絡下 100% 會被讀成時段。改成 `這一件先看一下` |

### 刻意不改

- 資料健檢（`domain/health.js` 的 66/153/1252/1375、`ui/views/health.js` 的 235-236）——
  那一頁就是在講資料層，「整筆」在那裡是準確的
- 稽核紀錄（`data/health.js:181`）—— 同上
- 跟 visit/slot 無關的「整天／這一天」：all-day 行事備註、可用性的「整天不行」、
  稽核日的「這一天沒有留下任何紀錄」、隨手記、額度、匯入列。盤點時已逐條確認過

## 判準

- 全站 grep 使用者看得到的字串，`這一筆`／`整筆`／`一筆來訪`／`這筆` **只出現在**
  資料健檢與稽核紀錄兩處
- 「取消一整天」那條路：**按鈕、確認框標題、確認鈕、後果第一句四個地方都出現「這一天」**
- `domain/consequences.js:108` 的那一句在單段脈絡下讀起來不會被誤認成時段
- 每一句改完之後問一次：**這一行講的範圍，跟它按下去真的會動到的資料，是同一個嗎？**
- 補一支 ADR（下一個編號 0087），舊的 0081/0083/0085 一個字不改
- 測試：一支掃原始碼的測試，白名單以外的檔案出現「這一筆」「整筆」就紅
