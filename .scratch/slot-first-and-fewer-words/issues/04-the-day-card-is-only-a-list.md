# 04 一整天那一張只是目錄，不是詳情

Status: todo
Blocked by: 06

## 她要的

> 第一 : 不用再呈現"這一天的待辦"
> b 如果是一整天的詳情，那也請不要呈現"這一天的待辦"和SOP，直接呈現那幾個分段讓我點就好，點進去再呈現那項的詳情

## 為什麼會這樣

上一輪（`quieter-screens` 的 issue 10、2026-09-10）談定的是
「**先看到那一天有哪幾段 ＋ 那一天的待辦**，點某一段才看細節」——
那一層是她當時指名要留的。這一輪她把那一層也拿掉了：整天那一張**只是目錄**。

`ui/views/calendar.js` 的 `visitReadHtml()` 是**四個畫面共用**的（ADR-0018、0056），
裡面最後一塊是 `mirrorHtml()`（`ui/components/taskMirror.js`）。它現在兩種都畫：

```js
${focused ? '這一項的待辦' : '這一天的待辦'}
```

SOP 那一塊接在 `visitReadHtml()` **外面**，只有日曆有（ADR-0088）。

## 怎麼做

規則變成一句話：**沒指定哪一段的那一張，只畫那幾段。**

1. `mirrorHtml()` 在沒有 `focusSlot`（或那一段不存在）時**整塊不畫**
2. SOP 同理（03 之後它本來就吃 `focusSlot`，沒帶就不畫）
3. `taskMirror` 的抬頭從此只剩一種：**「這一項的待辦」**。
   那一支的檔頭有一整節在講「抬頭跟著範圍走、兩種都是真的」，要跟著改掉
4. 「記的話」那一列（`slotNoteOf()` 去重的那一塊）**留著** —— 那是她自己寫的字，
   不是說明；但目錄那一張上它應該長在**那一段自己那一列裡**，不是整張卡一行
   （否則兩段兩句話會分不出誰是誰）

**日曆一個 px 都不會變**：那一頁每一條路都帶著段（`visitRow()` 的 `data-open`
有第三格），所以目錄那一張在日曆上根本不會出現。

## 判準

- 一筆三段的來訪，從待辦中心點人名進去：看到的是**三列可以點的段**，
  沒有待辦、沒有 SOP
- 點其中一段 → 就地換成那一段的詳情（**不重開一張卡**，ADR-0073／0088），
  待辦與 SOP 這時候才出現，而且只有那一段的
- 日曆上點任何一列，畫面跟改之前一模一樣
- 那一塊仍然**只給看不給勾**（一個 `<input type="checkbox">` 都沒有）
- 「還沒讀到」與「真的一張都沒有」仍然是兩件事（`tasks` 是 `undefined` 時整塊不畫）
