# 07 「這一天」不再是可以動的東西

Status: done
動工前先讀：`.scratch/slot-first-and-fewer-words/spec.md`、`docs/adr/0088`、`docs/adr/0085`、`docs/adr/0060`、`docs/adr/0082`

## 她要的

> e 並且也不需要出現改這一整天的按鈕，如果要改我也會一項一項改

2026-09-12 追問「改整天的日期」與「刪除這一天」要不要留路，她的回答：

> 整個拿掉，兩件事都不要了，也不要取消一整天，畢竟如果我真的要取消一整天，我可以從壓表那邊刪

## 為什麼會這樣

那一顆是**兩天前才刻意加上去的**（ADR-0088，2026-09-10）。當時的推論是：
ADR-0085 說「帶了 slotIndex 就沒有整筆的狀態卡與危險區」，而 ADR-0060 說
「長按是捷徑不是唯一的路」—— 所以整天那幾顆從編輯器搬到讀取卡片底下那一顆
「改這一天」（`ui/views/calendar.js` 的 `openDetail()`，`data-edit-day`）。

**ADR-0060 的前提是「那件事還需要做得到」。** 她現在說那三件事她都不需要了，
所以那一顆不是搬家，是整條收掉。

清查過的入口（動工前再跑一次，不要照抄）：

| 那件事 | 現在的路 | 這一支之後 |
|---|---|---|
| 取消一整天 | 長按選單的「取消一整天（N 段）」／「取消這一天」、壓表的批次取消 | **只剩批次取消**（ADR-0082） |
| 改整天的日期 | 只有「改這一天」開的那一張 | **沒有路**（SPEC 第 7 節規則 10：改期＝取消後重排） |
| 刪除這一天 | 只有那一張的危險區 | **沒有路** |
| 整天改成已完成／未到 | 走簽療程單那條逐段的流程 | 不受影響 |
| 取消這一段 | 長按選單、來訪編輯器每一段右上角那顆 × | 不受影響 |

**一天只有一段的時候要小心**：`visitActions()` 現在的「取消這一天」
在那種情況下其實就是「取消這一段」（`canCancelOne` 要 `slots.length > 1`）。
整顆拿掉的話，單段那一天會**一顆取消都沒有** —— 所以要改成
**永遠只留一顆「取消這一段」**，收她長按的那一段。
`applyStatus(visit, 'cancelled', { slotIndex })` 走 `settle()`，
最後一段取消掉時整筆自己會變成 cancelled（`cancelledAt`、`released` 都設得對），
所以單段那一天的行為一個字都沒變。

## 怎麼做

1. `ui/views/calendar.js`：`editDay` 那一塊與 `[data-edit-day]` 的接線整個拿掉
2. `domain/visits.js` 的 `visitActions()`：`cancelled` 那一顆拿掉，
   `cancel-slot` 改成**不看 `slots.length`**（永遠有，只要那一段取消得掉）。
   `edit` 那一顆沒帶 `slotIndex` 時的「改這一天」也跟著拿掉
3. `ui/views/visitEditor.js`：`wholeVisit` 那條路上的 `statusCard()` 與 `dangerZone()`
   —— **網址那條路（`renderEdit()`）留著**，它沒有任何畫面上的連結（見 spec）
4. **文案**：`domain/consequences.js`、確認框、`docs/操作手冊.md`、`docs/常見問題.md`
   裡講「取消一整天」「刪除這一天」的那幾句。上一輪就因為文件叫她去點一個不在的
   按鈕修過一次（commit `7ffbff0`）
5. **補一支 ADR**（0089）：一天只是分組，動得了的只有一段。
   0087（單位只有兩個）與 0088（那一顆的位置）**一個字都不改**，在那兩支底下各留一行指路

## 判準

- 日曆點任何一段 → 讀取卡片上**沒有**「改這一天」
- 長按任何一列 → 選單裡**沒有**「取消一整天」，只有「取消這一段」
- 一天只有一段的時候，長按那一列**仍然取消得掉**（而且整筆跟著變 cancelled）
- 來訪編輯器（帶不帶 slotIndex）畫面上都找不到「刪除這一天」
- 全站搜不到 `data-edit-day`
- `tests/read-card-one-slot.test.js:179` 那一條（現在斷言那一顆要在）跟著改 ——
  **它釘的是 ADR-0088 的決定，不是 bug**
- 誤建的那一筆從此只能取消（暗掉但留在日曆上，ADR-0061）—— ADR 裡要寫明
