# 試算表報表和她原本那張對不起來：多了總表、少了備註與 TODO 區、勾的意思也不一樣

Status: open
回報者：使用者，2026-08-20
動工前先讀：`SPEC.md` 第 3 節（現行試算表結構）、第 4.8 節、
`docs/adr/0010-sheet-sync-is-an-export-not-a-service.md`、
`docs/adr/0013-sheet-sync-is-a-push-not-a-pull.md`、`docs/legacy/README.md`

## 症狀

她要的是「和我原本那個一樣」的試算表。現在 `domain/sheetReport.js` 與
`sheets/readonly-report.gs` 產出來的東西差在六個地方：

| # | 她要的 | 現在 |
|---|---|---|
| 1 | **不要多一個總表** | `overviewReport()` 與 `.gs` 的 `renderOverview()` 各做一張「總表」分頁 |
| 2 | 客戶名稱、購買名稱、療程內容、**應有次數、實際次數** | 四欄：應有／已完成／已排未上／剩餘 |
| 3 | 日期後面是**打勾的框框** | `✓` 字元（同一天用兩次是 `✓2`） |
| 4 | 要有**備註區**、**TODO / FINISHED 區** | `.gs` 的 `renderNotes()` 只有「這位客戶」與「來訪紀錄」兩塊，沒有 TODO / FINISHED |
| 5 | 有預約二返，要**備註在健檢那一欄最下面** | 沒有 |
| 6 | 只呈現他有買的課程 | ✅ 已經是這樣（只印還在的額度，0 的那幾列本來就不存在） |

還有一件她沒提、但一定會踩到的：

**第 3 項的「勾」現在什麼時候出現？** `mark()` 只要那一天有時段掛到這筆額度就打勾，
**不管來訪是待確認、已確認還是已完成**。但她描述的流程是第 5 步
（客人真的來了）才記進試算表。這兩件事對不起來，要先問她（見下）。

## 想要的樣子

### 一定要做的

- **拿掉總表**（或至少不推到她的試算表上）。`#/settings/report` 那個下拉裡的
  「總表」是手動貼用的，要不要留著問她。
- **備註區與 TODO / FINISHED 區**，全部唯讀。資料來源分別是：
  - 備註 → `customer.marks` / `customer.notes`（ADR-0019）與 `customer.flags`
  - TODO → `tasks` 裡 `done === false` 的
  - FINISHED → `tasks` 裡 `done === true` 的
  排版要照舊表的位置（`SPEC.md` 第 3 節：TODO 在下方、FINISH 在右方）。
  這一段的資料要從 `syncBundle()` 帶過去，`.gs` 一個判斷都不要自己做
  （ADR-0013：`.gs` 不重算任何東西）。
- **二返的備註**：健檢那一欄底下要有一句。格式**照她之前的寫法**，
  動工前跟她要 `.xlsx` 或一張截圖，不要自己編。
  資料現在拿得到 —— `domain/followups.js` 的 `describePair()` 已經算得出
  「健檢做完 N 次，二返還欠 M 次」，二返的來訪日期在 `visits` 上。

### 誤觸提醒已經有了，確認一下就好

`.gs` 的 `protectEverything()` 鎖住每一張分頁，`onEdit()` 把手改的值當場還原並
跳一句話。她說「不小心動到會有提醒」，這一段已經做到了。

## 三件要先問她的事（動工前）

1. **勾什麼時候出現？** 只有「已完成」才勾（照她講的流程），
   還是壓完表就勾（現在的行為）？
   建議：**同一格用不同符號分開** —— `✓` 已完成、`△` 已確認、`○` 待確認。
   這樣兩件事都看得到，而且和進度追蹤頁（`issues/07`）的三種狀態是同一組詞。
2. **次數退回兩欄，還是保留四欄？** `SPEC.md` 第 4.2 節當初改成四欄的理由，
   正是舊表兩欄講不出「已排未上」—— 而那是最容易掉東西的地方。
   要退回去的話，那一節要跟著改，並補一支 ADR。
3. **`✓` 還是真的核取方塊？** 真的核取方塊（`insertCheckboxes`）在被保護的分頁上
   點得下去但會被 `onEdit` 還原 —— 看起來像壞掉。傾向維持字元，但這是她的表，
   她要真框框就做真框框，只是要接受那個行為。

## ⚠️ 動工前一定要跟她講清楚的一件事

`sheets/readonly-report.gs` 的 `render()` 會呼叫 `removeStaleSheets()`，
**把不在這次推送裡的分頁刪掉**，而 `resetSheet()` 會把每一張清空重畫。

所以自動推送**只能指到一份全新的試算表**，不能直接指到她現在那份 ——
上面那些手寫的特殊狀況（`重大疾病治療中，食慾還可以` 那一類）會被清掉。
要嘛先把舊表另存一份備份，要嘛讓 `.gs` 只動它自己建的分頁。這件事現在沒有寫在
設定頁上，`#/settings/report` 應該講出來。
