# 小日曆上「他不行」的日子是米色的，看不出來

Status: done
回報者：使用者，2026-08-22

## 症狀

> 我希望挑日子那邊，如果不行的，能夠用紅色的去杠掉而不是米色，有點不明顯

## 根因

`.minical__cell--off` 一種樣子講三件事：他說不行、你自己休假、已經過去了。
三者都是 `--surface-2` 的米色加一條淡淡的刪除線，而她只會在
「為什麼這天不能點」上停下來。

## 做了什麼

三種原因三種樣子：

| 原因 | 樣子 |
|---|---|
| 他說不行 | `--overdue` 紅字、紅底、2px 紅色刪除線 |
| 你自己休假 | `--slate` 霧藍，跟日曆上的個人行程同一組顏色（ADR-0015） |
| 已經過去了 | 原本那個淡的樣子，不搶眼 |

**已經過去的優先於他說不行。** 月中打開時前面半個月本來就不能點，
那幾天再標紅，紅色就從「這天他不行」變成「這半頁都是紅的」——
紅要留給「本來排得進去、但他不行」的那幾天。

圖例跟著改成四個：可以排／已經記了／他不行／你休假。
