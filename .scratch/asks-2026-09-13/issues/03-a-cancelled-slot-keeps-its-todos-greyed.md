# 「這一項的待辦」：取消類只在它收的那一段，被取消的那一段原本的待辦灰掉

Status: todo
Blocked by: 02
來源：`../spec.md` 第二 b，她補的 a、b、c
動工前先讀：`domain/todoFlow.js` 的 `todosForVisit()`、`ownedKinds()`、`kindsOf()`；
`ui/components/taskMirror.js`；ADR-0080、ADR-0089；`tests/todo-flow.test.js` 的「只看她點的那一段」

## 她要的

> 這個待辦只應該出現在被取消的那邊吧

> a 有關被取消的那一段自己還列著「跟客人確認時間 ✓」和「簽療程單（這一段不用簽，但要結案）」，
> 可以留者但是就是灰掉就好

> c ……然後我會希望取消後，那一項的待辦可以不要只剩取消... 而是原本的那些一樣有然後灰掉然後多了取消...這樣

## 查到的（2026-09-13 實跑）

一天三段（復能、ILIB、EECP），取消第 1 段之後：

```
第 0 段 [ 跟客人確認時間✓, 簽療程單, 取消 Abovee ]              ← 不該有取消
第 1 段 [ 跟客人確認時間✓, 簽療程單（這一段不用簽，但要結案）, 取消 Abovee ]
第 2 段 [ 跟客人確認時間✓, 簽療程單, 取消 Abovee ]              ← 不該有取消
```

## 為什麼

任務身上沒有段落，`ownedKinds()` 只能推：「這一段自己長得出這一種嗎？」。取消類那一支
（`kindsOf()`）問的是「這一段是不是壓在 Abovee 上」，**沒問這一段有沒有被取消**。
`tests/todo-flow.test.js` 的「取消 X 那幾張跟著它要收的那個系統」兩段都活著卻斷言看得到取消任務 ——
那支測試把這個 bug 寫成了預期（跟 ADR-0087 那一次一樣的形狀），要改掉。

被取消的那一段：整天取消時 `todosForVisit()` 提早只回取消類（`visit.status === 'cancelled'`），
只取消一段時沒有這一條，於是照常列、也不灰。**她要的是兩種都照常列、灰掉，再加上取消類。**

## 她問的「推不出是哪一段」是什麼

有一種情況畫面真的不知道一張「取消 X」屬於哪一段：**那一天沒有任何一段被取消，卻有這一張**。
2026-09-12 之前「改整天的日期」「刪掉某一段」那兩條路會長出這種（ADR-0089 已經拿掉了），
新資料不會再有。issue 02 之後取消類自己帶 `slotIndexes`，連猜都不用猜。
沒帶的舊任務照舊每一段都列（她說舊資料不管，這條只是不讓它消失）。

## 做法

- 取消類：有 `slotIndexes` 就只掛在那幾段；沒有就退回「那一天被取消的、用得到那個系統的段」；
  那也沒有就每一段都列。
- **聚焦的那一段被取消了**（`slotStatus()` 是 `cancelled`，含整天取消）：
  - 照「它還活著的話」列出原本的那幾列（確認、簽療程單、掛號、寫紀錄；已經長出來的真任務帶著它的 ✓）
  - 每一列帶 `void: true`，畫面灰掉、不劃線（劃線是「做完了」，灰是「不會發生了」—— 兩件事）
  - 取消類照常（沒勾是 ○、勾了是 ✓），排在最後
- 「簽療程單（這一段不用簽，但要結案）」那句在被取消的那一段上不要算「不用簽」—— 照活著的時候算
- `taskMirror.js` 加一種灰掉的樣子（`.taskmirror__row.is-void`），`visually-hidden` 講「這一段取消了，不會做」
- 一個 `<input type="checkbox">` 都不可以有（ADR-0056 那條照舊）

## 判準

- 一天三段、取消第 1 段：第 0、2 段**看不到**「取消 Abovee」
- 第 1 段看得到：確認時間、簽療程單（灰）、「取消 Abovee」（不灰）
- 二返＋復能、只取消二返：二返那一段列著 Examine、耀聖、寫紀錄（灰）＋取消 Abovee、取消 Examine（不灰，如果 02 長了）；
  復能那一段只有它自己的
- 整天取消、點其中一段：原本的列灰掉＋取消類 —— 不再是「只剩取消」
- 沒有 `slotIndexes` 的舊「取消 Abovee」、那一天沒有任何一段取消：每一段都列（不靜默消失）
- 沒帶 `focusSlot` 時一張都不少（另外三頁一個字都不變）
- E2E：真的走一次取消，點另外兩段各一次
