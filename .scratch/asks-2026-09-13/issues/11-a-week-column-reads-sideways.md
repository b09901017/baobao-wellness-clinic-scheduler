# iPad 橫式週檢視：七欄裡的字不再一字一行

Status: done
來源：`../spec.md` 第三 c
動工前先讀：SPEC 第 8.6 節（週：iPad 橫式變七欄）、ADR-0020（左右滑換週）、
`app.css` 的 `.weekgrid`（≥900px）、`.timerow`、`.timerow__clock`、`ui/views/calendar.js` 的 `weekHtml()`、`agendaRow()`

## 她要的

> 在週顯示那邊，我發現一個就是如果是橫的顯示(ipad) 他會變成好擠，所有字都會變成直得顯示?
> 就會變超長一條 ? 看要變成可以橫的滑嗎還是你有其他想法?，交給你決定，你先了解我說的是什麼在幫我解決這個問題

## 重現（2026-09-13）

| 寬 | 一天一欄 | 名字那一格 |
|---|---|---|
| 1024 | 92px | **29px** |
| 1180 | 114px | 51px |
| 1366 | 134px | 71px |

一列是「左邊 42px 時間欄 ＋ 色棒 ＋ 內容」，那是給手機一整排寬度設計的；七欄時扣掉那 42px 與兩個間距，
名字只剩一兩個字寬，所以一字一行。

## 決定：保留七欄、不做橫向滑

- 週檢視本身**左右滑就是換一週**（`.swipe` 是 `overflow-x` 加 scroll-snap，ADR-0020）。
  裡面再放一層橫向捲動，兩個手勢會打架：她想看週五卻翻到下一週
- SPEC 第 8.6 節：一週是她真正在規劃的單位 —— 七天要一眼看得到

## 做法

七欄的時候（≥900px），`.weekgrid` 裡的一列改成直排：

```
09:00–10:00        ← 時間一行小字（原本左邊那一欄）
┃ 王小明           ← 色棒改成左邊框，名字一行，超過省略
┃ IN(60)・騰崴     ← 課程一行，超過省略
```

- 只改 `.weekgrid` 底下的 `.timerow`，日檢視與手機的週檢視一個像素都不動
- 狀態徽章（右邊那一顆）七欄時收掉，顏色已經在色棒上（圖例在上面）
- 「週一」那個字跟日期擠在同一行（`9/7 一`），不要換行

## 判準

- 1024 寬：名字那一格至少 70px，`王小明` 一行，`scrollHeight` 不因為字直排而變高
- 1180、1366 寬一樣
- 手機（414）週檢視的列跟改之前一模一樣（量 `.timerow__clock` 的寬度）
- 日檢視在 iPad 寬照舊是左邊時間欄
