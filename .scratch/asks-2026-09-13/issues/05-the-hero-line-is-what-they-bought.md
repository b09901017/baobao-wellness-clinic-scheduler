# 客戶清單與詳情的抬頭換成「買了什麼」

Status: done
Blocked by: 04
來源：`../spec.md` 第一 a，她補的 d
動工前先讀：`ui/views/customers.js` 的 `metaLine()`、`ui/views/customerDetail.js` 的 `contactLine()`、SPEC 第 8.5 節

## 她要的

> 有關hero__meta(就是姓名下面的那個小標題)，不論是點進去詳情還是在客戶那頁呈現的
> 我希望不用寫上次，下次麼時候來，不用寫line，電話(line和電話，我應該會寫在備註那哩，應該)

> d 卡片拿掉「上次／下次」只是不成現在詳情那邊而已，還是可以呈現在押表進去的客戶牆那邊?
> 就是原本有的還是要有，只是拿掉客戶這邊的就好

## 為什麼現在長這樣

SPEC 第 8.5 節（第 3 步開發時寫的）：總覽每列要「上次來訪／下次預約」，詳情要「聯絡方式」。
查過 ADR 與 commit 歷史，沒有另外的決策紀錄，所以這是改 SPEC 不是推翻 ADR。

## 做法

- 兩處都讀 `purchaseHeadline()`（issue 04），**同一支**。空字串就整行不畫
- 清單卡片那一行最多兩行（`-webkit-line-clamp: 2`），詳情不截
- **電話與 LINE 欄位留著**：搜尋框（「找人：姓名、電話、LINE、購買通路」）還靠它們，編輯表單也照舊
- `byCustomer()` 那一段（上次／下次）在清單頁只剩排序在用 —— 留著給「最近來過／最久沒來」排序
- 壓表客戶牆的「距上次 N 天」**不動**（那是 `schedule.js` 自己的，她的 d）
- 詳情頁 `paint()` 手上已經有這位客戶的額度與主檔；清單頁要多讀 `plans`（套數的退路要它）與 `courses`、`ivProducts`
- SPEC 第 8.5 節改兩句

## 判準

- 清單卡片與詳情抬頭都印 `0723 顧客會 新8萬方案x2+…`，一個「上次」「下次」「LINE」都沒有
- 什麼都沒買的客戶：沒有那一行（不是空的一行）
- 壓表客戶牆那一列照舊寫「距上次 N 天」
- 清單頁「最近來過／最久沒來」排序照舊
