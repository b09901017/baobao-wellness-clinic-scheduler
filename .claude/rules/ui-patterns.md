# 畫面的寫法：一層一層、換頁、說明、欄位、備忘錄

**每一節的標題是「改了這個」，底下每一條是「一定要一起檢查」的**（從根目錄 `CLAUDE.md`「容易漏掉的連動」那張表搬來，標題照舊）。
新長出來的連動補進對應的那一節（沒有就加一節）；不屬於這一份的補進別份或開新的一份，並加進根目錄 `CLAUDE.md` 的索引。

## 備忘錄編輯那張卡的版面

- 「掛課程」與「掛機構」收在**同一行**（`hangHtml()` 的分段切換，2026-09-08）—— 兩排各自一個標籤加一排丸子是四行，而那兩行正是把「存起來」擠出畫面的原因。
- 切換**只換 `hidden` 與 `aria-selected`**，兩個 hidden input 都留在 DOM 裡：拿掉節點的話她切一下就把掛好的課程清光了。
- 卡片裡**除了內文那一格，每一項都 `flex: none`**（`.pbcard--edit > *`），內文是唯一的 `flex: 1 1 0`。
- 少一條那一項就會被 flex 壓扁 —— `.emojirow` 被壓成 2px、textarea 被壓回 `min-height` 都發生過，而症狀是「東西在那裡但看不到也捲不到」。
- 高度由 `.pbdeck[data-editing]` 給死，**不要用 JS 撐 textarea 的高度**

## 畫面上一段常駐的說明

- **先想能不能收進 `ui/components/tip.js` 的 `tip()`**（點了才浮出來的小泡泡，ADR 見 issue 08）。
- 她 2026-09-10：「非常占版面，一眼看下去非常雜亂，會視覺疲勞」。
- **但會改變寫入結果的警告不可以收進去** —— 撞期、醫療禁忌、次數不夠那幾種她沒點開就等於沒看到，而她已經按下去了。
- 紅線寫在 `tests/tip-red-lines.test.js` 裡，掃原始碼盯著。
- 沒話講就一個像素都不佔（空字串回空字串）。
- **`components/form.js` 的 `hint` 參數已經畫成標籤旁邊那一顆 `?`** —— 不要再自己手寫 `field__hint`。
- 新增客戶那一頁的提醒（同名、沒電話也沒 LINE、幾套打 0）是**貼在那一格旁邊的 ⚠**（`tip(…, { kind: 'warn' })`），同名與沒聯絡方式存檔前 `confirmReview()` 再講一次（ADR-0102）—— 表單本體是 `ui/components/customerForm.js`，新增頁與拍訂購單那一層共用。
- 剩下幾段常駐說明寫在 `tests/fewer-words.test.js` 的 `KEEP` 裡而且**只准往下**，每一條都附理由；留著的只有三種：狀態（載入中）、空狀態、資料（她自己寫的字、筆數、到期日）。
- **拍 Abovee 收著的列上那一個紅字短標記也是紅線**（`abl-row__flag`、`rowTag()`，ADR-0170）：那是 `mustSee()` 的提醒，收著的列一定畫得出它、整句在「發現問題」那一頁（`abl-row__hint--warn`）與點開之後，兩樣都不收進 `tip()`

## 存起來的 `pushLayer()` handle

- **一律問 `.active`，不要問它是不是 null。** 換頁會把 `ui/nav.js` 的 stack 清光（那是對的：那幾筆紀錄現在在新頁面的下面），但畫面存著的那個變數不會跟著變 —— 於是 `if (!monthLayer)` 永遠不成立，再也不推新的一層，而**返回鍵會直接跳出整頁、一句錯誤訊息都沒有**。
- 七個畫面存著 handle（壓表的 `monthLayer` 與 `deckLayer`、本輪可用性的 `daySheetLayer`、備忘錄與長備註那一頁編輯中的 `editLayer`（按返回先問，2026-10-19）、長備註中間那張卡的 `layer`（`noteCard.js`）、待辦中心的 `drawerLayer` —— 「確認」「簽療程單」兩張自己畫的抽屜，2026-10-07），`tests/nav.test.js` 有一條原始碼掃描盯著（**它只認 `名字 = pushLayer(`，所以 handle 要存成變數，不要掛在物件屬性上**）。
- **自己畫、會跟著整頁重畫的抽屜**：那一層只在開的那一下推一次（`home.js` 的 `openDrawer()`），每一條把它關掉的路都走同一支（`closeDrawer()`）—— 每重畫一次推一層要按好幾次返回，漏還一條的話下一次返回被吃掉一次。
- **確認框接著收底下那一層**（「還有 N 位沒建立 → 離開」）會排兩趟 `history.go`，而瀏覽器兩趟都走完 —— 第一趟停在中途那一格不是「還差一格」，以前多退一次就退出 app 了；返回鍵那一圈也**只收按下去那一刻疊著的層**，在 `onPop` 裡問的那一道不可以被同一圈收掉（2026-09-17，兩條都有測試）。
- **換頁也會先來一下 popstate**：瀏覽器換 hash 時先發 popstate，`nav.js` 照返回鍵叫 `onPop`，接著的 hashchange 才收層 —— 所以 **`onPop` 裡會問一句的那一層，網址已經換了就不要問**（拍 Abovee 的「去日曆」，`aboveeConfirm.js` 的 `openedAt`），不然那一道確認框會留在下一頁上。
- `nav.js` 那一段不要為這個改：對話框等幾個元件換頁時靠它收掉

## 從一頁帶人到另一頁、而且要那一頁「進去就開某一張」

- 走 `ui/nav.js` 的 `leaveFor(key, value)`／`takeFor(key)`（2026-10-07）：留一句話、下一頁畫完拿走、**只活一次、不進網址**（那是看法不是位置，重新整理不該又彈一次）。
- 第一個用它的是日曆長按「客人來了，去簽療程單」→ 待辦那一頁直接開那一天的抽屜。
- **不要讓兩支畫面互相 import 來傳這件事**（待辦那一頁本來就 import 日曆）；壓表的 `pendingOpen` 與日曆的 `showDate()` 是同一種東西的舊寫法，單向的可以留著。
- **換頁前先 `await whenSettled()`**：長按選單／確認框收掉時排的那一趟 `history.go()` 晚到會把換頁退掉。
- E2E 等下一頁的抽屜時不要只等 `.drawer` —— 上一頁的面板也是 `.drawer`，換頁那一下它還在

## 日曆的標題、跳日期那一張

- 標題與面板翻頁那一格的字只寫在 `domain/calendar.js` 的 `titleOf()`（月 `9月`、週 `9月 W2`、日 `9/18(五)`，**不是今年才帶年份** —— 「今年」由呼叫端傳），第幾週只寫在同一支的 `weekOfMonth()`（**週四落在哪個月就算哪個月**，2026-09-13 她同意的）。
- 點標題那一張面板（`calendar.js` 的 `openDatePicker()`）的週列頭也讀它 —— 標題寫 W2、面板寫 W3 的話她不會知道哪個算數。
- iPad 橫式週檢視的一列是直排（`.weekgrid .timerow`），**不要改成橫向捲**：週檢視本身左右滑是換週（ADR-0020）

## 備忘錄的內容或它掛到哪些課程

- 規則只在 `domain/playbook.js`。
- 它只有**三個欄位**：標題、掛哪些課程、一大塊字（ADR-0069 把章節、分類、釘選、時機全部拿掉了）。
- 自己浮出來的那一小塊是**整份的前幾行**，**兩個入口共用 `ui/components/playbookHint.js`**（日曆的來訪讀取卡片、待辦的「跟客人確認時間」）。
- 它**綁課程不綁人、不上日曆、勾不掉**，也不產生任何任務（ADR-0067）。
- `visitReadHtml()` 一個字都不要改 —— 那一支是四個畫面共用的。
- **`playbooksFor()` 收 `focusSlot`**（2026-09-12）：帶了就只比那一段的課程，**而且掛合作機構的那幾份也不浮** —— 她點的是一段，那一家機構不屬於任何一段

## 任何一個 `type="number"` 或 `type="time"`

- **欄位的 `min` / `step` 要跟 domain 的驗證講同一句話。** HTML 的 `step` 從 `min` 起算，所以 `min="1" step="5"` 只收 1、6、11…… 30 存不下去，而**瀏覽器擋在 submit 之前，domain 的驗證跑都沒跑到**。
- 這個坑已經踩過三次（金額 `step="100"`、課程時長、方案項目時長）。
- 「通常是 N 的倍數」寫進 `hint` 不要寫進 `step`。
- `tests/number-fields.test.js` 掃原始碼、`tests-e2e/specs/17-settings-fields.spec.js` 掃瀏覽器真的看到的屬性

## 共用元件身上的屬性名字

- **`ui/components/` 底下產出的 HTML 不可以用頁面身上的名字**，例如裸的 `data-open`（頁面拿它當「這一列是誰」）。
- 記自己的狀態就用自己的前綴（`data-slotnote-open`）。
- 2026-09-12 的那個 bug 就是這個形狀：她點記一句的輸入框，跳出來的是「的 0 段」那張確認面板。
- `tests/slot-note.test.js` 掃 `components/` 底下每一支
