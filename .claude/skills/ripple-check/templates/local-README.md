# `.local`：這個專案的私人資料（目錄）

這份目錄**會進 graphify 的圖**，讓 AI 查圖時知道有哪些私人檔、什麼時候該打開。**這裡不寫任何真實值**（名字、金額、帳號）。

新增檔案時順手在下面補一行；`graphify --update` 之前跑 `node .claude/skills/ripple-check/scripts/private-index-check.mjs`，會列出還沒寫進來的檔。

## 進圖的（放在這些位置就自動進圖；`.graphifyignore` 要放回）

| 位置 | 是什麼 | 什麼時候讀 |
|---|---|---|
| `research/` | 設計參考（使用習慣、以前的做法、整理過的統計） | 設計相關功能之前 |
| `README.md` | 這份目錄 | — |

## 不進圖的（要用時直接打開那一份）

| 檔 | 是什麼 | 什麼時候讀 |
|---|---|---|
| `claude-memory/` | Claude 的記憶（每次對話本來就會載入） | 不用另外讀 |
| `claude-handoffs/` | 分段工作的交接開場 | 接手下一段的時候 |
| `.gitignore` | 這個私人 repo 自己的忽略規則 | — |

**預設不進圖**：放在 `research/` 以外的新檔都先不進圖；是設計參考就搬進 `research/`。有真實帳戶、金額、個資的檔只寫在這張表，讀過之後照專案的 lessons 比對，不把值抄進 repo。規矩是「不讀」的資料夾也寫一行，註明不讀。
