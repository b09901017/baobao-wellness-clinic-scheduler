# `.local`：這個專案的私人資料（目錄）

這份目錄**會進 graphify 的圖**，讓 AI 查圖時知道有哪些私人檔、什麼時候該打開。**這裡不寫任何真實值**（名字、金額、帳號）。

新增檔案時順手在下面補一行；`graphify --update` 之前跑 `node .claude/skills/ripple-check/scripts/private-index-check.mjs`（列出還沒寫進來的檔）
與 `private-graph-check.mjs`（進圖的那幾份有沒有名單上的字）。

## 進圖的（名單在 `.local/.graphifyignore`）

資料不進圖，「有什麼、什麼時候讀、決定了什麼」進圖。

| 位置 | 是什麼 | 什麼時候讀 |
|---|---|---|
| `README.md` | 這份目錄 | — |
| `research/` | 設計參考（使用習慣、以前的做法、整理過的統計） | 設計相關功能之前 |
| `知識庫/`（有的話） | 使用者現行的決定、跟她工作的方式、某件事之前要先知道的 | 動工之前 |
| 放真實資料的資料夾的 `README.md`（例：`references/README.md`） | 那個資料夾的目錄：一格一列「有什麼、什麼時候讀、誰在用」 | 要用真實資料參考的時候 |
| `claude-memory/` 挑過的幾份 | 跟大局有關、沒有名單上的字的記憶（一份一行列在 `.graphifyignore`） | 每次對話只載入記憶的索引；進圖才連得到 ADR 與程式碼 |

## 不進圖的（要用時直接打開那一份）

| 檔 | 是什麼 | 什麼時候讀 |
|---|---|---|
| `claude-memory/` 其餘的 | Claude 的記憶（有名字、帳號的不放進圖） | 索引每次對話本來就會載入 |
| `claude-handoffs/` | 分段工作的交接開場 | 接手下一段的時候 |
| 真實資料本身（截圖、匯出、名單、對帳結果） | 寫在它所在資料夾的 `README.md` | 那一列寫的時機 |
| `.gitignore` | 這個私人 repo 自己的忽略規則 | — |

**預設不進圖**：新檔先不進圖；是設計參考就搬進 `research/`，是真實資料就在它的資料夾目錄補一列。有真實帳戶、金額、個資的檔只寫在目錄裡，讀過之後照專案的 lessons 比對，不把值抄進 repo。規矩是「不讀」的資料夾也寫一行，註明不讀。
