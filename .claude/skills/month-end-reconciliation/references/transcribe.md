# 用看的抄 Abovee 截圖（給分頭抄的 subagent）

你拿到幾張 Abovee「預約清單」的截圖。把每一張的每一列抄成一個 TSV 檔。
**抄錯沒關係，之後每一格都會逐像素驗證**（抄的字重畫、跟截圖比，對不上會從候選字裡找出正確的那一個）。

看不清楚的格子：**照你覺得最像的完整的字抄，最後加 `??`**（例：`林小華??`＝我猜是林小華、沒把握）。
不要用 `?` 代替看不清楚的那一個字 —— `林?華` 永遠比對不到任何東西；猜一個完整的，錯了驗證那一步會換掉。

截圖裡有真實的客戶姓名。抄出來的檔只寫進交給你的那兩個資料夾（它們不進版控），**輔助的程式也不要寫到別的地方**
（共用的 scratchpad 會被別的 subagent 蓋掉，要的話檔名加上你負責的那幾張）。
回報**只講幾張、幾列、哪幾格打了 `??`**（用「第幾張第幾列哪一欄」講，不寫內容）。

## 一張圖怎麼看

1. 先用 Read 看整張，數有幾列資料（表頭不算；最上面或最下面被切掉一半、讀不全的那一列不抄，記在最後一行）。
2. 放大：`node <skill>/scripts/zoom.mjs <截圖> <放大資料夾> [倍數] [x 從-到]`
   - 不給後兩個：左右兩半、放大兩倍
   - 名字看不清楚：`… 4 240-340`＝只切那一欄（截圖上 x 240～340 像素）放大四倍。x 的位置看兩倍的那幾張估
3. 一列一列對著抄。**抄完再從放大的那幾塊逐列核一次**：日期、時段、病歷號、課程、服務資源。

## 欄位（固定 13 欄，用 Tab 分開，照這個順序）

| # | 欄名 | 抄什麼 | 注意 |
|---|---|---|---|
| 1 | 預約狀態 | 徽章上的字：`課程完成`、`已取消`、`確認前往`、`客戶失約`、`待確認`、`聯繫中` | 看顏色也看字 |
| 2 | 預約日期 | `2026-10-01`（照原樣，民國年也照原樣） | |
| 3 | 預約時段 | `09:30 - 09:45`（照原樣，含空白與破折號） | |
| 4 | 姓名 | 名字本身 | 名字前後的小圖示、按鈕不抄 |
| 5 | 病歷號 | `00006975`（前面的 0 要抄） | |
| 6 | 課程 | `ILIB 60`、`SIS 30`、`功醫門診`… | 空白照原樣（`ILIB 60` 不是 `ILIB60`；但 `EECP60` 原圖沒空白就不加） |
| 7 | 合併扣課 | 有字照抄，空的留空 | |
| 8 | 實際扣課病歷號 | 同上 | 有人用家人的額度，這一欄要抄 |
| 9 | 關係 | 同上 | |
| 10 | 預約來源 | `體驗`、`正式課`、`顧客會`… | |
| 11 | 診間 | `點滴室7`、`治療室2`… | |
| 12 | 服務資源 | 治療師名字、`ILIB6`、`I2治2`、`點滴6`… | 兩行的照順序接起來，中間一個空白 |
| 13 | 取消原因 | 有這一欄才抄 | |

- **這張截圖沒拍到某一欄** → 那一格寫 `-`（半形減號）。**拍到了但那一格是空的** → 留空。
  前者是「不知道」，後者是「Abovee 上就是空的」。
- 怎麼判斷拍到了沒（大部分截圖沒有表頭）：**欄位的順序是固定的**（狀態、日期、時段、姓名、病歷號、身份別、性別、電話、課程、
  合併扣課、實際扣課病歷號、關係、預約來源、診間、交通方式、車牌、東購紀錄、中心紀錄、服務資源、取消原因…）。
  兩邊的欄都拍到了，夾在中間的就一定拍到了 —— 課程與預約來源都看得到，合併扣課、實際扣課病歷號、關係那三欄空著就是空的（留空）。
  截圖右邊停在服務資源，取消原因就是沒拍到（`-`）。
- 電話、身份別、性別、交通方式、車牌、東購紀錄、中心紀錄 **不抄**（跟次數無關，少存一份個資）。
- 欄位的 x 位置每一張都不一樣（Abovee 照那一頁的內容調欄寬），所以沒有表頭時照「順序」對，不要照位置對。
- 有幾列特別高、看得到的欄卻只有一行字：多半是右邊沒拍到的那一欄（取消原因、中心紀錄）有兩三行。照常抄，不用管。

## 檔案格式

每張截圖一個檔：`<輸出資料夾>/<截圖檔名不含副檔名>.tsv`，UTF-8，欄位之間是真的 Tab。

```
# 截圖	01-05.png
# 起	2026-10-01
# 訖	2026-10-31
# 頁	第 1 頁 共 16 頁 共 151 筆
預約狀態	預約日期	預約時段	姓名	病歷號	課程	合併扣課	實際扣課病歷號	關係	預約來源	診間	服務資源	取消原因
課程完成	2026-10-01	09:30 - 09:45	王小明	00001234	功醫門診				體驗		某某	-
# 切掉	最下面一列只拍到上半，沒抄
```

- `# 起`／`# 訖`：畫面上方「預約日期(起)／(訖)」有拍到才寫；`# 頁`：分頁那一句（「共 N 筆」「第 1/16 頁」）有拍到才寫，照原字。沒拍到就整行不寫。
- 第一行一定是 `# 截圖`；表頭那一行一定要有（13 個欄名，照上面的順序）。**每一列都是 13 格**（12 個 Tab）——
  上面那一列：課程後面是三個空格（合併扣課、實際扣課病歷號、關係）才接預約來源；診間空的；最後的 `-` 是沒拍到的取消原因。
- 一列一行、照截圖上由上到下的順序。**不要排序、不要去重、不要合併** —— 兩張截圖重疊的那幾列兩張都照抄，之後的程式會對齊。
- 最後可以有幾行 `#` 開頭的備註（被切掉的列、看不清楚的格子在哪）。

## 回報

一張一行：`01-05.png：10 列，?? 2 格（第 3 列姓名、第 7 列服務資源）`。
最後一句講有沒有哪一張看起來跟別張不一樣（縮放大小、沒有表頭、有沒有拍到「共 N 筆」）。
