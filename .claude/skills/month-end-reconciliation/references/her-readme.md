# 月底對帳

每個月一次、多一層保障：以 **Abovee 截圖**為準，跟 **app、試算表、舊表（.xlsx）、TimeTree** 對一次，有額度的來訪次數有沒有對不上。
照理不會有問題；有的話這一頁會告訴妳是哪一天、哪一位。

## 怎麼用（三步）

1. **在 Abovee 截圖**：預約清單篩那一個月（預約日期 起～訖），瀏覽器縮放 100% 或 90% 都可以，從第一頁截到最後一頁（**每一頁截一張，換頁之後再截** —— 同一頁截兩次，下一頁就少了）。
   - 第一張盡量連上面的「預約日期(起)／(訖)」和表頭一起截；最後一張連「共 N 筆」那一行。沒截到也可以，跟我說截了哪幾天就好。
   - 右邊截到「服務資源」就夠了。電話、車牌那幾欄截到也沒關係，**不會被抄下來**。
2. **放進這裡**：`<月份>/截圖/`，例如 11 月就放 `2026-11/截圖/`。檔名照順序就好（`01.png`、`02.png`…，或像 10 月那樣用日期）。
3. **跟 Claude 說**「幫我對 11 月」。一兩分鐘之後打開 `2026-11/結果/對帳結果-2026-11.html`。

## 那一頁怎麼看

- **最上面一句**：綠色 ✓「全部對得上」，或紅色「有 N 件要看」
- **三個數字**：Abovee 課程完成 ＝ app 已完成 ＝ 試算表 ✓（只數有額度的課）
- **月曆**：紅色的那一天有事、虛線框的那一天可能少截了一頁，點它只看那一天
- 底下幾張小表，一列就是「哪一天、誰、Abovee 怎麼寫、app 怎麼寫」：
  可能少截 → Abovee 和 app 對不上 → 只有時間不一樣 → 舊表多勾／少勾 → Abovee 上有、app 裡沒有這個人 → 不影響次數，看看就好
- **每一位這個月做了幾次**：收起來了，點開才看

舊表與 TimeTree 讀的是 `references/xlsx/all_client.xlsx` 與 `references/ics/timetree.ics`，對帳之前換成最新的那一份就好。

## 其他資料夾

- `<月份>/過程/`：中間檔，不用打開
- `校正/`：讀截圖用的設定（縮放一樣就一直沿用）

這個資料夾有客戶姓名，不會進 GitHub；不要轉傳。
