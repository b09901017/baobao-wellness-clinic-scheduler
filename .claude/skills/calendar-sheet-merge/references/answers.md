## 2026-09-07（第三批檔案）

### 縮寫

| 她寫的 | 意思 | 出處 |
|---|---|---|
| `IN` | INDIBA | 行事曆與紙本療程單 |
| `IL` | ILIB | 行事曆。**她自己記的簡寫**，一般寫 `ILIB`、貼給客人寫 `靜脈雷射` |
| `營養針` | 營養點滴 | 舊表的療程列 |
| `營養素` | 營養品 | 舊表的療程列 |

`營養素` 那一條特別要小心：**營養品不排班**（ADR-0057），所以它進來之後
不可以流進任何「還要排幾次」。認成營養點滴的話那位客戶會多出一堆排不掉的次數。

### 日期欄底下那一格寫的品項

舊表有一列（她的表在第 14 列）在日期欄底下寫 `護肝`、`雪` 這種兩個字的簡寫。
**那是「這一天用了哪一款營養點滴」**，要進時段的品項（`ivProductName`），
不是備註。同一列也可能寫別的東西（例：`EECP體驗`），那一種還沒問。

### 客戶身上的標記

| 舊表上寫的 | 進哪裡 | 為什麼 |
|---|---|---|
| 合作機構名（例：某家美容機構） | **自動**變成 `partners` | ADR-0076。它不是限制，也不產生任何待辦 |
| 體內金屬類、血管難打類 | **自動**變成 `flags`（警示） | ADR-0074。它只提醒不擋，所以自動填的代價比漏掉小 |
| **否定句**（「夫妻無金屬」「沒有金屬」） | 只進備註，**一個 flag 都不可以長出來** | 這幾句話的意思跟前一列**相反** |
| 排班限制（「二四4：00」「五不行」「和妻同一天」） | 只進備註 | 本輪可用性由她自己在 app 裡填 |

否定句那一條是這一段唯一會造成實際傷害的：把「沒有金屬」讀成「有金屬」，
她在壓表卡片牆上會看到一顆假的警示丸子，而那顆丸子的存在本身就是資訊。
判準要看**否定詞**（無、沒有、皆無），不是只看有沒有「金屬」兩個字。

### 一張表兩個人

已知的第三種寫法：**日期欄底下寫家屬稱謂**（例：「姪女」），意思是
**那一天是家屬拿本人的次數去體驗**。所以那一段仍然扣本人的額度，
不是另外一位客戶。跟前兩種（A2 括號裡第二個名字、夫妻共用一張表）都不一樣。

### 整批對不上的名字

「行事曆上從頭到尾沒寫過這位」不一定是叫法不一樣 ——
**也可能是她還沒把那幾天記上行事曆**。⓪ 那一段的說明要把這一種講出來，
不要一律叫她去補別名。

### 還沒問到的（下一輪要問）

- 日期欄底下那一格寫的不是營養點滴品項時（例：`EECP體驗`）算什麼
- 行事曆上有時間有療程、但舊表沒有分頁的那 20 位（她要逐筆看）
- 三份資料對不起來時的順位（紙本 / 行事曆 / 舊表）
- 紙本療程單要不要進合併
- 舊表同一列被改寫成別的療程時怎麼認

## 2026-09-13（B2 購買名稱）

### B2 怎麼讀

她的原話：「我寫0617 顧客會-8+5 (其中0617代表6/17買的，8代表8萬方案(8+8代表8萬方案買了兩套)
5(0.75/12) 代表+5(0.75/12)萬健檢」。

| 問題 | 她的答案 |
|---|---|
| `新` 是什麼 | **新 8 萬方案**。`0820新 - 顧客會-only sis(60)x10` 那種沒買方案也寫了「新」的，應該是打錯 |
| `8` 以外的數字 | `5`、`12`、`0.75`、`3.6` **一律是健檢金額**。還沒有客戶買「5萬元氣馥活」方案 |
| 尾款 | 有「尾款」兩個字的備註**預設紅色** |
| 正式環境匯過了嗎 | **還沒有**，之後會全新重匯一次 |
| 驗證 | 「**所有的方案課程加購都可以再用各種課程的應有次數去驗證一次，然後合併的時候也可以再問我一次**」 |

所以報告的 ⓪c（購買名稱對不上的）**每一條都要問她**，不要替她決定哪一邊對。
匯進去的是 D 欄那一份（那是當初真的建進去的次數）。

### 客戶抬頭要的

「0723 顧客會 新8萬方案x2+12萬健檢+EECPx40+sis(60)x5+ILIB(60)x5」—— 由額度算出來（ADR-0090），
所以合併檔要帶得出購買日、方案名與套數（`baobao-merge/v2`）。營養品不進抬頭，但要進備註。

### 判斷

| 問題 | 她的答案 |
|---|---|
| 取消／預約／改／紀錄／約 的句子 | **一律不是來訪** |
| 沒有分頁的人在行事曆上的來訪 | 同事請假請她帶的，**當行事備註** |
| 行事曆有、舊表沒勾（沒有別的理由） | 「理論上我試算表上有勾的就是有」—— 沒勾的先當沒做，**但這一類她要逐筆保留再問** |
| 行事曆上的二返、舊表第 13 列也寫了同一天 | 補 |
| 同一位的二返在行事曆上出現兩天 | 舊表第 13 列寫的那一天才算，另一天是改期或取消 |
| 復健門診、心臟門診 D 欄空著卻勾了或標了「～」 | **送的**。照勾的次數加一筆額度，備註寫送的（買 EECP 前一定要先看心臟門診） |
| 家屬用本人的名額體驗（舊表第 13 列寫稱謂、第 14 列寫「EECP體驗」） | 扣本人，**各加一筆額度匯進去**（9/7 留下來的那一題） |
| 行事曆有 EECP、舊表沒勾、同一欄寫「療程單有簽」 | 那天沒做，**不補**；那一句進客戶備註提醒自己 |
| B2 買了方案但尾款沒繳、第 2–8 列是 0 | **方案先不算**，紅色備註寫「尾款沒繳，先不算」 |
| B2 沒提到的加購（EECP 40、營養點滴、健檢） | 這一批全部**跟 B2 同一天買的** |
| 超過 40 字的備註 | 照句號、驚嘆號、分號切成幾則 |
| 日期欄裡、沒有療程名稱那一列的字 | 逐則決定（刪、改寫進備註） |
| 待辦的字 | 回電、告知、給、退款、影本、更新、排、包、澆水 都當待辦 |
| 行事曆上的「休」（跨夜畫的） | 逐筆問實際日期；只休半天的**當行事備註**（app 的休假只能整天）；「去 Outlook 請假」「請生理假」是**待辦** |
