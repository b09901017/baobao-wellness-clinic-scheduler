# 讀客戶回覆的經驗（2026-11 那一批學到的）

客戶的回覆是 LINE 上隨手打的字，**同一句話可以有兩種完全相反的讀法**。這份是讀錯過、或差點讀錯的形狀，
跟她確認過的讀法。名字一律不寫在這裡（repo 是公開的）—— 某一位客戶自己的習慣記在 `.local/references/客戶時間/客戶記憶.json`。

## 先看「她問的是哪一種」

她通常問「**不方便**排的日期」，但**偶爾問「方便」排的日期**（2026-11 有一位）。問法不同，同樣一句「11/3（早上）」意思剛好相反。
- 截圖：讀客戶回覆**之前**先讀她自己那一則（「想請問您 11 月**不**方便排的日期～」還是「…方便排的日期～」），寫進讀法.json 的 `asked`。
- 文字檔：看不到她怎麼問。照回覆的語氣判斷（「都可以排」「選一天」是在講可以；「有事」「不行」「去旅遊」是在講不行），拿不準就問。
- 問「方便」的那幾位，頁面上放一行 `reminders` 提醒她。

## 她定過的讀法（2026-10-23）

| 客戶這樣寫 | 讀成 | 表上 |
|---|---|---|
| 只給了可以的日子（「11/5、6、7 都可以」「選一天」「星期五都可以」「排週二或週四」） | 給的那幾天優先；**其他天是「沒提到」，不是不行**。**這一條她定案了，不用再問**（2026-11 冷測試時又被問了一次） | 給的那幾天綠色，其他天 `rest: notMentioned`（灰色） |
| 「大約 11/10 號後都行」 | 之前是**不一定**，不是不行；之後優先 | 之前 `unsure`（淡黃「不一定」），之後綠色「優先」 |
| 「週二下午 3:30 以後來有空」（同一則還列了不行的日子） | 星期二要 3:30 以後，**其他平日照常可以** —— 不是「只有星期二」 | 星期二橘色 `partial`＋「3:30 後才行」，其他平日空白 |
| 「每週二五早上（整體課）」 | 那兩個早上**有別的課、不能來** —— 不是「整體課要排在那兩個早上」 | `am` 週二、週五 |
| 「11/4、17日前這些日子不行」 | 「日前」＝**目前**：11/4 與 11/17 兩天 —— 不是「17 號以前」 | 兩天紅色 |
| 兩個名字寫在同一則訊息（「A B」換行接時間） | 兩位**一起來**，照同一個時間排 | 拆成兩頁、內容一樣，`together` 寫「跟 X 一起來」 |
| 「○○姐妹」 | 兩位（姊妹），另一位問她是誰 | 拆成兩頁，`together` 寫「姊妹：X」 |
| 「眼前知」 | 目前知道的就這些，之後可能再加 | `reminders` 一行 |
| 「一樣～」 | 跟上個月一樣 —— 去 `客戶記憶.json` 看上個月那一句 | 照上個月，有出入就問 |

## 拿 app 的資料幫忙判斷

`history.mjs` 寫的 `客戶脈絡.json` 有她以前**實際來的**星期幾、上午／下午／晚上、最近 12 段。用法：
- **兩種讀法拿不準時當佐證**，例：「二五早上」那一句 —— 她以前一次都沒有在星期五來、多半是下午，支持「那兩個早上有課」。
- **對名字**：文字檔的字可能打錯（2026-11 有一位名字錯了一個同音字，app 上是另一個字）。名單上每一位都要對到剛好一位 app 客戶；
  對到 0 位或好幾位就問她，不要猜。
- 佐證**不能取代她說的話**：以前都是下午來，不代表這個月上午不行。只拿來挑兩種讀法裡哪一種，挑完照樣在頁面上照原文寫。
- `upcoming`（這個月已經排了的段）跟她這次說的不行撞到時，問她一句（可能是排好之後客人才說不行）。

## 頁面上寫什麼

- **「客戶交代（原文）」那一塊就是 `raw`，一字不改**（她 10/23：「直接呈現所有原文就好」）。不要挑句子、不要改寫、不要補括號 ——
  一挑就是你在替她決定哪句重要，而她要的是自己看原文。你的解讀與提醒放 `reminders`（字小一號，接在原文後面）。
- **交代的重點寫進那幾天的格子**（`dayWords`）：「2～5 點」「11 點後」「優先下午」「只有早上」「選一天」「早上可排復能」「3:30 後才行」。
  她要特殊需求「標得更明顯」—— 原文在上面一塊，格子裡讓她排到那一天時不用往上看。
- 一句話（`summary`）短：講這個月的大方向（「排星期三」「週末和紅色的日子不行」），細節交給原文與格子。
- **綠色還是橘色**，看那一天在她的話裡是「要排的日子」還是「照常的日子多一個限制」：
  - 要排的日子帶著時間（「星期五都可以，2～5 點」「排三四，11 點後」「11/3（早上）」）→ **綠色**＋格子寫時間。她就是要你排這幾天，時間是附帶的。
  - 其他日子照常、只有這一天有限制（「週二下午 3:30 以後來有空」而其他平日照常、「11/12 下午有別的課，早上可以」）→ **橘色**＋格子寫限制。
    這時候畫綠色會被看成「優先排這一天」，而她沒有這個意思。
- 沒有疑問的頁不放「還沒確定」那一行。
