# 客戶時間：每個月怎麼用

每個月在 LINE 問完客戶「下個月哪幾天不方便」之後：

1. 在這個資料夾裡開一個月份的資料夾，例如 `2026-12`（或直接跟 Claude 說「幫我開 12 月的資料夾」）。
2. **截圖**放進 `2026-12/截圖/`。檔名用客戶的名字最好（例：`王小明.jpg`），看不出名字的截圖 Claude 會問你。
3. **文字**貼進 `2026-12/文字.txt`。一位一段，名字寫在第一行，段跟段之間空一行。
4. 跟 Claude 說：「**12 月客戶的時間放好了，幫我整理成試算表**」。

Claude 會：

- 讀每一張截圖、每一段文字，**特別看你在截圖上問的是「方便」還是「不方便」**
- 對照 app 裡這一位以前都是星期幾、幾點來的、身上有沒有體內金屬，還有以前說過的時間
- 讀不準的地方**照人分開問你**（會寫名字）
- 你回答完，做出 `客戶時間-2026-12.xlsx`：一人一頁、一個月曆。客戶傳的原文整段放在名字底下那一塊藍色的；
  綠色是可以、優先排，灰色是沒提到；app 上有「體內金屬」的，名字旁邊一塊紅色
- 每一格都再對一次原文，對不上的會先修好才交給你

你回答過的事（例如「這兩位都是一起來」「她星期二早上有課」）會記在 `客戶記憶.json`，下個月就不用再問一次。

## 資料夾長這樣

```
客戶時間/
  README.md             就是這一份
  客戶記憶.json          每一位客戶，你回答過的事（Claude 自己維護）
  2026-11/
    截圖/                你放的截圖
    文字.txt             你貼的文字
    客戶時間-2026-11.xlsx ← 你看這一個
    過程/                Claude 的中間檔，你不用打開
```

這整個資料夾都在 `.local/` 底下，**不會進版控**（有真名）。
